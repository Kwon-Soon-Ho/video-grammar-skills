# 입력·근거 계약

원본 해시와 판본, 허용 구간, 추출 로그/프레임, 사용할 추출기와 한도를 입력으로 받는다. 과거 분석·사람 답변이 주어지면 그것은 관측 원본이 아니라 검수 이력이다. 독립 시험에서는 답안/기존 분석을 읽지 않는다.

## 시간

요청 시각과 실제 프레임 표시 시각을 분리한다. ordinal/FPS로 재생 시각을 대신 계산하지 않는다. PTS·time_base와 편집 목록/원점 매핑을 확인한 추출 로그를 사용한다. 미매핑이면 actual=null로 두고 시간 기반 결론을 보류한다. R4 구간은 시작 포함/끝 제외다. 끝 경계 프레임은 context_after로 표시한다. 분석 창의 끝에서 정착해 보여도 영상 전체 최종값으로 확장하지 않는다.

## 공간과 파생

원본 raster, resize/crop/padding/rotation 이력을 보존한다. 크롭 좌표를 전체 원본 좌표처럼 적지 않는다. SAR/회전/색 범위가 미상인 경우 해당 제한을 보존한다. 압축 영상의 픽셀색을 공식 CI색/AE 값으로 바꾸지 않는다. contact sheet는 탐색 자료이며 세부 주장은 원본 프레임 또는 검증된 크롭으로 대조한다.

## 문서·분류

원고가 없으면 영상 관측만 기록한다. 재구성 원고를 제작 전 의도의 증거로 쓰지 않는다. 문서 대응을 요청받으면 원문 버전·정확한 구절과 화면 문구/행위를 다대다로 연결하고 누락/추가/불명확을 보존한다. 오디오는 실제 접근/분석했을 때만 별도로 대응한다.

Phase 00의 영상 전체/설명 구간/화면 상태/동작을 구분한다. 프레임은 근거이고 화면 상태 자체가 아니다. 기존 용어사전에 대응하는 ID를 확인했을 때만 붙이고 미분류/복합을 허용한다. 시간 곡선 관련 ID는 CURVE-ACCEL, CURVE-DECEL, CURVE-INOUT이며 정의와 예외를 현재 정본에서 확인한다. AP-06/MP-02는 관찰 질문을 돕는 지식이지 렌더 증거가 아니다.

## 현재 도구 범위

evidence_catalog.py는 A2 호환 로그의 파일 해시, 실제 시각 순서, 입력 전후 해시 일관성과 기본 PTS 관계를 검사한다. 디코더/원본 내용/가속곡선/모든 컨테이너 편집 목록을 검증하는 도구는 아니다. 새 원본에는 사전 점검된 추출 어댑터가 필요하다. 실행 환경의 어댑터는 등록 원본·구간·읽기/출력 한도를 함께 제공해야 한다. A3의 inspect_more.py나 A4의 extract.py를 다른 영상에 적용할 때 기존 제한을 무단 우회하지 않고 새 원본에 대한 사전 점검과 시간 매핑 검증을 먼저 한다.

출력은 수집 초안이다. 기본 Markdown에도 위 근거 계약을 적용한다. JSON 기계 연계/회사 DB 등록이 필요하면 해당 시간·근거·좌표 계약에 변환하고 검사를 별도로 실행한다. 현재 JSON 형식 통과를 Markdown의 내용 검수나 R4 DB 검사와 혼동하지 않는다.
