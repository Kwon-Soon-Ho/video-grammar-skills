# video-guidance-reviewer

## 목적

Phase 00 화면·모션 지식과 규칙 초안의 적용성·출처·충돌을 검토한다. 정보 전달·한국어·시간 가독성·한맥 범위·웹 지침 전용 조건을 검수할 때 사용한다. 새 화면·모션 창작이나 실영상 품질 통과 판정은 후속 단계다.

## 실행

1. 전달 목적·시청자·출력/시청 조건과 초안의 근거를 확인한다. 부족한 입력은 부족하다고 적는다.
2. 지식의 역할을 구분한다: 원본 개념 / 관측 / 프로젝트 적용 해석 / 회사 필수 규칙 / 기획 제안. 참조 원칙을 회사 규칙으로 자동 승격하지 않는다.
3. 정보 관계·위계·한국어 긴 문구·숫자/단위·시간적 가독성과 브랜드 역할을 검토한다. 실제 프레임이 없으면 결과 화면의 통과를 선언하지 않는다.
4. 카드·단계 번호·중앙 정렬·동시 등장·선형 모션은 일괄 금지하지 않는다. 내용에 맞는 반복·친숙함과 목적 있는 차별화를 판단한다.
5. Taste/Impeccable/UI 지침의 웹 px·hover·스크롤·사진/모션 개수·폰트·무작위 구도 강제는 영상 전역 규칙으로 복사하지 않는다. 정보 전달 이론의 자막 제거도 접근성·무음·기술 용어 조건과 대조한다.
6. 같은 근거의 AP/MP 관련 원칙을 중복 감점하지 않는다. 문제는 관측·근거·영향·수정안으로 쓰고, 없는 제작 의도·측정값을 만들지 않는다.
7. 채택/수정/보류 항목을 제시한다. 판단이 필요한 목적 변경·필수화에는 최소 4지선다와 추천안을 포함한다. 요청된 지식 초안만 backup 후 수정하며 정본 값·회사 승인에 임의 개입하지 않는다.

## 출력

채택/수정/보류, 구체 근거·예외·수정안, 적용 범위와 검토 질문. 영상 창작 출력 없음.

## 작업 기준

이 스킬은 `Phase 00/06_맞춤스킬`에 있으며 두 폴더 위가 기반 DB 루트다. 데이터 경로·도구는 [작업 기준](references/작업기준.md)을 읽는다. 관련 정본만 점진적으로 읽고 외부 원본 스킬 전체를 통째 활성화하지 않는다.
