# video-knowledge-curator

## 목적

용어·원칙·레이아웃 지식을 출처·적용 조건과 함께 정리하는 Phase 00 스킬. 공통 사전·원칙 DB를 추가·정제·변경할 때 사용한다. 영상 프레임 분석이나 신규 화면 창작에는 사용하지 않는다.

## 실행

1. 요청한 지식 범위와 대상 정본을 확인한다. 기존 용어·출처·관련 항목을 먼저 조회한다.
2. 명칭·별칭·다른 의미를 구분한다. 목적/정보 관계/레이아웃/모션 기능/관측 속성/시간/매체를 섞지 않는다. 미분류·복합·신규 후보를 허용한다.
3. 출처에서 확인한 개념과 프로젝트의 적용 해석을 따로 적는다. 제목만 확인한 이론은 needs_primary_definition_review로 보류한다. 실제 사례가 없으면 case_refs를 비워 둔다.
4. 요청한 데이터 정리는 draft로 작성할 수 있다. 의미 병합·회사 필수화·승인·범위 확장은 후보와 이유를 제안하고 사용자 검토를 받는다. 검토 질문은 최소 4개 선택지와 추천안을 포함한다. 이미 승인된 동일 범위를 다시 묻지 않는다.
5. 변경 전 파일을 backup에 보존한다. ID·대체·버전·출처를 검사하고 읽기용 문서를 정본에서 갱신한다. 검사 실패를 통과처럼 보고하지 않는다.
6. 새 항목/변경/보류, 출처의 확인 범위, 적용·제외 조건, 남은 검토를 보고한다.

## 출력

신규/변경/보류 레코드, 출처와 자체 해석 구분, 변경 이유·검사 결과·사용자 검토 후보.

## 작업 기준

이 스킬은 `Phase 00/06_맞춤스킬`에 있으며 두 폴더 위가 기반 DB 루트다. 데이터 경로·도구는 [작업 기준](references/작업기준.md)을 읽는다. 관련 정본만 점진적으로 읽고 외부 원본 스킬 전체를 통째 활성화하지 않는다.
