# 기반 DB 작업 기준

스킬 경로에서 두 폴더 위를 Phase 00 루트로 찾는다. 작업 폴더를 찾지 못하면 경로를 확인하고 파일을 추측 생성하지 않는다.

- 01_공통용어/공통용어사전.json: 8축·ID·별칭·정의·대체 관계
- 02_원칙과레이아웃/: 원칙·화면·레이아웃 정본
- 03_한맥디자인/한맥디자인정본.json: profile_id=hanmac-video,version=0.1.0
- 04_기록규격/: 스키마와 synthetic_example 설명용 예
- 05_출처와검토/: 출처·버전·사용자결정·실제 검수 결정
- 07_실행도구/자료검증.py·지식조회.py: 자료 형식·연결 검사와 조회

프로젝트의 .환경/Scripts/python.exe로 자료검증.py를 실행한다. --record로 기록 파일, --output으로 Phase 00 안의 검사 결과를 지정한다. 도구가 없으면 먼저 확인하고 통과를 지어내지 않는다.

자동 스킬은 draft만 작성한다. 의미 병합·회사 필수화·승인은 검토 제안이다. 사람 결정은 실제 사용자 답변·검수 근거와 연결하고 승인 종류/대상/버전을 구분한다.

변경 전 해당 파일을 backup의 날짜/단계 폴더에 보존한다. 이전 정본·조사 원문은 최종 자료와 분리한다. 조사 스크립트·외부 다운로드·브라우저 실행은 별도 목적이 있을 때만 사용한다.

영상 프레임·PTS 획득·OCR·정밀 모션 추정·실영상 성능은 01-A, 실제 회사 문법 승인·사례는 01-B, 새 시나리오의 화면·모션 기획은 02다. 형식 검사는 영상 진실성·사람 신원·업무 효과를 증명하지 않는다.
