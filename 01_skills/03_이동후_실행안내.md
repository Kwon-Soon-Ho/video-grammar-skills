# 다른 경로에서 읽기와 한정 실행

세 ZIP을 같은 폴더 아래 푼다. Python3.10 이상 표준 라이브러리만으로 아래 도구를 실행할 수 있다. 과거 영상 도구에는 PyAV/NumPy/FFmpeg 등 별도 환경이 필요할 수 있으며 이 ZIP은 런타임 설치본을 포함하지 않는다.

```powershell
python -B -X utf8 C:/review/video/01_skills/portable_check.py --root C:/review/video --out C:/review/result01
```

`--out`은 아직 없는 별도 폴더여야 한다. 도구는 다음 한정 작업만 수행한다.

1. 추출 사본의 draft.13 `knowledge_links.py`로 00 기본 자료의 **새 카탈로그**를 만든다.
2. 최신 pilot 사본을 결과 폴더로 복사하고, 상대 경로가 아닌 기록 근거는 보존 바이트에 연결한다. 원본 pilot·기존 catalog/index는 바꾸지 않는다.
3. 두 정지 사례와 기존 모션 기록의 참조 검사를 실행하고 새 색인을 만든다.
4. 공통 표현·업무 묶음·건물/기단·원칙/모션 기능을 실제 조회해 JSON 결과와 실행 인수·종료코드를 남긴다.

이동 후 성공은 참조/해시/도구 실행 확인이다. 모든00 검사, 영상 의미/디자인 품질, 원칙 효과, R4통합v0.2 이관, 외부 원문 권리/회사 승인 검사가 아니다. 과거 절대경로 pin/영수증은 고치지 않는다. 원문에 연결되지 않은 항목은 한정 실행 성공만으로 해결됐다고 하지 않는다.

ZIP 자체 바이트는 `package-manifest.json`의 파일별 SHA-256과 검증 스크립트 `verify_package.py`로 대조할 수 있다.

```powershell
python -B -X utf8 C:/review/video/01_skills/verify_package.py C:/review/video/01_skills
```

각 ZIP 폴더에도 같은 스크립트가 있다. 새로 생성한 보고서 등 추가 파일은 포함 원본 검증 대상이 아니다. 원본 파일의 변경/누락은 실패로 보고한다.
