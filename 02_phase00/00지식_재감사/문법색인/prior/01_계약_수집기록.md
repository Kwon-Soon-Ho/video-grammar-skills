# VC-CASE-A - 계약 부문 수집 기록

상태: 원본 관측·기능 해석을 분리한 수집 초안. 제작 템플릿·회사 공통 규칙 승인 아님.

## 1. 이 사례를 찾을 때의 단서

- 내용: 계약으로 확보한 수주, 실제 매출, 투입비용을 구분해 설명.
- 정보 관계: 총량/일부 반영, 분야별 구성, 서로 다른 산정 역할의 지표.
- 시각 유형: 지표 비교 + 구성 도넛 + 정보 구역 누적 + 입체적 경제 도상.
- 검색어: 수주와 매출, 성과와 참고 지표, 도넛 두 개, 패널 추가, 큰 주황 금액, 동전과 상승 화살표.
- 원본 수치 예: 수주 17.5억원, 비용 8.7억원, 매출 12.9억원. 변경 시나리오의 17.6/8.4로 대체하지 않음.

## 2. 전체 디자인과 조합

### 공통 골격

왼쪽 위에는 녹색 육각 장 번호/TDC 배지와 짧은 장 제목 띠가 있다(VC-COMP-01). 밝은 민트·흰색 계열의 곡선 띠 바탕을 쓰고, 후반 구성 설명에서는 도시·지형·지도 핀/선과 건물 윤곽이 겹쳐진 배경으로 바뀐다. 배경이 실제 촬영물인지 CG인지, 각 선이 어떤 효과로 제작됐는지는 미확인이다.

장 번호는 유지되지만 본문 제목은 바뀐다. 84초의 ‘수주 확보·매출 실현’과 96초의 ‘기술개발센터의 성과’를 같은 고정 제목으로 기록하지 않는다.

### A-01: 수주·매출 개괄 - 78~84초 표본

| 층/부품 | 보이는 구성 | 역할 해석과 재사용 조건 |
|---|---|---|
| 왼쪽 넓은 정보판 | 둥근 흰 판, 녹색 경계와 그림자, 계약 아이콘/설명과 수주·매출 가로 막대를 세로 경계로 구분 | 계약이라는 맥락과 두 지표 비교를 한 묶음으로 읽게 함 |
| 막대·수치 | 수주 녹색, 매출 주황색. 라벨·끝값·밝은 트랙을 동반 | 동일 기준으로 길이를 비교하려면 분모/범위를 확인해야 함. 임의의 화면 길이를 데이터 비율로 확정하지 않음 |
| 가운데 도상 | 동전 기둥·곡선 상승 화살표·원형 받침. 위 설명 캡슐과 가는 연결선 | 수치 도표와 경제성과 이미지를 연결하는 보조 표현. 합산식이나 실제 추세 데이터로 해석하지 않음 |
| 오른쪽 세 줄 요약 | 직접 계약/총 수주/매출 반영의 원형 아이콘과 글. 매출은 주황 계열 | 같은 내용을 다른 밀도로 다시 설명. 왼쪽 막대의 복제 수치인지 별도 집계인지 구별 |

대략적인 면적 관계는 ‘왼쪽 넓은 정보판 / 가운데 도상 / 오른쪽 목록’이다. 모든 작은 간격을 좌표로 쓰는 대신 이 관계와 구성 부품을 남긴다. 정확한 화면비별 배치값은 아직 제작 명세로 확정하지 않았다.

### A-02: 수주 구성 → 비용 → 실제 매출 - 86~112초 표본

| 구역 | 내부 구조 | 시각 위계·묶음 |
|---|---|---|
| 수주 구성 | 민트 헤더 띠, 문서 아이콘과 제목, 우측 캡슐, 큰 총액. 하단 측량/R&D 도넛 2개, 중앙 구분선. 도넛 내부 금액과 옆 비율/인출선 | 구성 내역이 많은 넓은 구역. 도넛 둘을 독립 카드 2개로만 떼면 총수주의 하위 구성이라는 관계가 빠짐 |
| 투입비용 | 좁고 세로로 긴 밝은 판, 상단 제목, 큰 녹색 비용, ‘현재까지 투입’ 캡슐, 아래 동전·문서 도상 | 같은 스타일 계열의 별도 지표. 수주와 사이에 오른쪽을 향한 작은 꺾쇠가 보이지만 산식·인과 관계로 확정하지 않음 |
| 실제 매출 | 상대적으로 넓은 밝은 판, 따뜻한 경계, 상단 제목/중복 제외 설명, 큰 주황 금액과 짧은 밑 막대, 오른쪽 입체 막대·상승 화살표 | 원본에서도 색과 도상으로 매출을 강조. 세 구역을 ‘동급 3패널’로 단순화하지 않음 |

전경 정보판 뒤로 도시·건물·곡선 띠가 이어지고, 정보판 내부에는 흰 면·가는 이중처럼 보이는 경계·약한 명암이 결합돼 있다(VC-COMP-02). 폰트명·그림자 파라미터·실제 3D 여부는 확인하지 않았다.

## 3. 전체 모션 흐름

| 관측 표본 | 화면 상태/변화 | 다음 상태와의 관계 |
|---|---|---|
| 78→80→82→84초 | 수주가 먼저 정착하고 매출 막대·금액과 오른쪽 요약이 보강됨 | 이 구간은 기존 2초 표본. 상세 시작·겹침 미확정 |
| 84→86초 | 개괄 레이아웃에서 도시 배경의 수주 구성 화면으로 바뀜 | 정확한 전환 방식·경계 프레임 미확인 |
| 86→96초 | 측량 도넛 뒤 R&D 도넛이 보강되고 값/비율이 최종 상태로 이동 | 요소 순서의 개괄만 확인. 각 곡선·기간은 미확정 |
| 96→100초 보강 | 수주 구역이 왼쪽으로 재배치되는 과정과 비용 판의 등장, 동전·문서 도상, 설명 캡슐, 비용 숫자가 단계적으로 추가 | ‘판 등장’ 하나로 묶되 내부 순서와 기존 판 이동을 함께 기록(VC-MOTION-02의 원본 변형) |
| 103→106초 보강 | 기존 두 구역을 남긴 채 오른쪽 매출 판이 이동해 자리 잡고 제목·중복 제외 설명이 보강 | 첫 비용 추가와 같은 동작으로 단정하지 않음. 기존 판의 이동 여부가 다른 변형 |
| 108→112초 | 받침→막대 성장·매출 숫자/밑 막대→상승 화살표가 완성되는 흐름 | 수치가 정착해도 도상은 계속 완성됨. 관련 요소의 동시 완료를 규칙으로 만들지 않음 |
| 112→114→116초 | 계약 성과 화면에서 BIM 맥락으로 바뀜 | 114~116초는 다음 장면의 주변 맥락. 현재 계약 템플릿에 혼합하지 않음 |

## 4. 이번에 보강한 세부 동작

### A-M1 - 공간을 마련하며 정보판 추가

- 관측: 96·96.5초 수주 판 중심 상태 → 97초 비용 판/제목이 추가된 상태 → 97.5초 동전 일부 → 98초 문서 포함 도상 → 99초 ‘현재까지 투입’ 캡슐 → 100초 비용 숫자 표시.
- 연결 관계: 판의 외형, 제목, 도상, 설명, 숫자를 같은 시간에 한 번에 켜지 않는다. 기존 수주 구역의 재배치와 새 구역 추가를 함께 기록한다.
- 재사용 단위: **정보판 누적과 내부 조립 한 묶음**, 내부 단계는 하위 기록. 동전 하나·종이 한 장마다 새 패턴 번호를 만들지 않는다.
- 보강 상태: 0.5초 표본의 상태 순서. 첫 시작·정착 프레임과 속도 곡선은 미확인.

### A-M2 - 기존 비교 맥락 유지 + 매출 판 진입

- 관측: 103.5초까지 오른쪽 매출 판이 보이지 않다가 104초 판이 오른쪽에 보이고, 104.5초 더 안쪽 위치, 105초 제목, 106초 중복 제외 설명이 보인다.
- 시작 경계: 이 표본에서 외형의 첫 가시성은 **(103.5, 104]초** 안에 있다. 정밀 시작 프레임이라는 뜻은 아니다.
- 관계: 기존 수주·비용을 대체하지 않고 세 번째 설명 구역을 추가한다. 모든 카드 등장에 전체 재정렬을 강제하지 않는다.

### A-M3 - 숫자 정착과 입체 도상 완성의 시차

- 관측: 108초 받침, 109초 낮은 막대, 109.5초 매출 0.8억원, 110초 10.8억원, 110.5초 12.9억원. 111초까지의 표본과 112초 최종 상태 사이에는 상승 화살표 완성의 차이가 있다.
- 숫자 정착: 표본상 최종 금액에 도달한 경계는 **(110, 110.5]초**. 110.5·111·112초에서 같은 끝값이 보인다. 이후 전체 구간의 모든 프레임을 검사했다는 뜻은 아니다.
- 관계: 숫자 카운트와 도상 조립은 관련된 동작이지만 시작·완료가 동일하다고 저장하지 않는다.
- 재사용 조건: 확정 총액을 제시하는 성과 장면의 후보. 식별번호/날짜에는 숫자 카운트를 그대로 적용하지 않는다.

## 5. 재사용 시 보호·가변·미상

| 구분 | 기록 |
|---|---|
| 보호할 정보 관계 | 수주 구성의 상하위 관계, 수주/비용/실제 매출의 의미 차이, 기간·단위·중복 제외 설명 |
| 원본 스타일을 유지할 때의 묶음 | 녹색 장 표식·밝은 프레임·도시 배경층·입체적 도상·주황 매출 강조. 색 하나만으로 원본 언어 유지라고 판정하지 않음 |
| 바꿀 수 있는 것 | 문구·금액·구성 항목 수, 도상/배경의 내용, 화면비와 배치, 재질과 스타일. 정보 관계가 유지되는지 별도 확인 |
| 원제작 의도 | 화면 기능에 대한 위 해석은 AI 추론. 제작자에게 확인한 의도가 아님 |
| 미상 | 원본 폰트/토큰/효과/키프레임, 미보강 동작 경계·내부 변화, 음성과의 관계, 막대의 실제 분모/스케일 설정 |

이 기록은 원본에서 필요한 지식을 찾는 수집물이다. 새 화면 제작 여부나 스타일 선택으로 수집 완료를 판정하지 않는다.
