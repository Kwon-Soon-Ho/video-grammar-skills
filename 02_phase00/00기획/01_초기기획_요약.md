# 초기 기획안 요약과 최신 파이프라인 연결

2026-10-14 정리. 원본: [초기 기획 PDF](초기%20기획%20pdf/영상셀_성과물작업_방향성_재정립_아이디어_도출_v5.pdf). 10페이지의 텍스트를 확인했으며 원본을 수정하지 않았다. 파일명은 v5지만 본문 하단에는 v4가 표시되어 있으므로 실제 버전은 별도 확인이 필요하다.

## 원래 검증하려는 가치

자연어 시나리오를 영상 흐름·장면·화면·모션·제작·검수로 연결하는 전문 판단 스킬을 검증한다. 1차는 디자인팀의 제한된 실무에서 품질·독립 수행·반복 공수·다른 업무 전이를 확인하는 범위다. 비디자이너 활용과 전문가 고도화 협업은 효과 확인 후 검토한다.

원본의 출발 경험은 Astra+AE 실무에서 실행 가능성과 판단의 간극을 확인한 것이다. 최신 준비 파이프라인은 이 판단을 지원할 회사 지식과 사례의 입력 체계를 먼저 만든다. API·코드 기반 영상·편집 환경 확장이 초기 기반 작업의 목적을 대신하지 않는다.

## 판단 체계의 구성

1. 영상 기획 판단: 목적·대상·메시지·정보 구조·전개·장면.
2. 화면 판단: 위계·시선·타이포·여백·정렬·밀도.
3. 모션 판단: 등장·강조·속도·이징·전환·리듬과 이유.
4. 공통 제작 지시: 목적·요소 역할·시간·위치·수정·보호 기준.
5. 도구별 구현: 선택한 제작 환경의 실제 레이어·효과·시간 구조 구현.
6. 내용·시각 검수: 수치·명칭·누락·화면·모션·브랜드와 수정 결과.

회사 디자인 기준, 판단 사례, 정보 표현 방법, 재사용 모션 부품은 이 체계를 지원하는 자산이다. 판단과 도구 구현을 구분하며 사례는 강제 템플릿이 아니다.

## 최신 단계와의 관계

| 준비·개발 단계 | 초기 기획의 어떤 부분을 지원하는가? |
|---|---|
| 00 | 회사 디자인 자료·공통 용어·원칙·데이터·검수 기준 |
| 01-A | 실제 영상의 표현·정보 관계·시간을 근거로 기록하는 분석 기능 |
| 01-B | 회사 사례·반례에서 재사용 문법을 검수·승인 |
| 02 | 영상 기획·화면·모션 판단을 수행하는 스킬 |
| 후속 제작 검증 | 공통 지시→선택한 제작 도구→실제 결과·수정·효과 비교 |

초기 기획의 “1차 검증/2차 확장”과 개발의 “Phase 00/01-A/01-B/02”는 번호가 같은 체계가 아니다. 전자는 사업·사용자 확장의 순서, 후자는 스킬과 지식 기반의 개발 순서다.

## 유지할 평가 기준

품질·독립 수행을 우선하고 총 공수·전이·유지비를 기록한다. 절감 시간에서 유지·지원·추가 검수를 제외한 실제 여유를 확인한다. 일반 AI로 충분한 품질이 나오거나 유지비가 이익을 넘고 반복 수요·전이가 부족하면 범위를 줄이거나 방식을 재검토한다.

현재 실행 순서는 [최신 파이프라인](00_최종_파이프라인_계획.md)을 기준으로 한다. [Phase 00 현황](../Phase%2000/01_진행현황.md)에 기획·입력 기반의 완료와 운영 DB 잔여 작업을 구분했다.


2026-10-14 위치 갱신: 현재 Phase 00 자료는 [시작 안내](../Phase%2000/00_시작안내.md)와 [진행 현황](../Phase%2000/01_진행현황.md)을 기준으로 한다. 초기 설계·소스 검토 문서는 backup에 보존했다.
