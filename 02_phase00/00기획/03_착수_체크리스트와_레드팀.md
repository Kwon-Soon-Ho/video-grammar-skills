파일 이름을 모두 다시 바꾸지 않아도 된다. 원본 경로와 manifest ID로 연결한다. 계획상 최소 폴더 예시는 다음과 같다.

```text
input/PROJECT-A/
  final.mp4
  scenario-original.*
  context.md        # 목적·시청자·버전·승인·담당
  feedback.*       # 있으면
  source-project/  # 있으면, 영상과 같은 버전
```

이 폴더와 실제 파일은 이번 작업에서 생성하지 않았다. 최신 영상 전체 목록이 많으면 먼저 경로·날짜·유형·대표성만 표로 만들고, 분석 표본은 그다음 선정한다.

## 00의 종료 규칙

철저함은 모든 레이아웃과 모션을 미리 완결하는 것이 아니다. 아래 **작은 필수 계약**을 검토하면 00 v0.1을 닫고 01-A에 진입한다.

- [ ] 목적·정보 관계·레이아웃·모션 기능/구현·아트디렉션의 핵심 축을 구분한다.
- [ ] 용어 ID·동의어·정의·범위·미분류·버전/병합 방식이 있다.
- [ ] 12+10원칙에 출처, 짧은 정의, 적용/제외, 관찰/검수 질문이 있다. 회사 예시는 나중에 연결 가능하다.
- [ ] Taste·레이아웃·분석 스킬의 채택/제외·의존성·원본 조건을 구분한다.
- [ ] 시나리오→구간→상태/비트→근거/주장→패턴의 한 연결 예시를 검토한다.
- [ ] 관측/추론, 원본/재구성, 납품/분석/회사 문법 승인 상태가 독립적이다.
- [ ] 원본 PTS와 시간·공간 변환의 기록 규약, 재분석·승인 버전 연결이 정의된다.
- [ ] 01-A의 필수 출력·교정/실영상/홀드아웃 평가·치명 실패·누락/기권 기준을 정할 절차가 있다.

디자인 입력 기반은 `design-system/hanmac-video.json`과 파생 문서·CSS·대비표로 구현하고 정본 무결성을 검사했다. 브랜드/명암과 강조/중립의 출처 선택은 사용자 지시를 반영했다. 나머지 계약은 초안이며 전체 운영 파일·스키마·스킬 구현이나 팀의 영상 문법 검수가 끝났다는 뜻이 아니다.

새 용어, 더 많은 사례, 전체 외부 코드 동작 검증은 실제 파일럿에서 막히는 항목을 기준으로 추가한다. 원칙 예시를 모두 만들기, 외부 스킬 전부 설치하기, 모든 영상의 모든 요소 수치를 추적하기를 00의 종료 조건으로 만들지 않는다.

| 단계 | 반드시 확인 | 남아 있어도 다음 작업이 가능한 것 |
|---|---|---|
| 00 → 01-A | 위 작은 필수 계약과 개발·평가 명세 | 회사 예시 미확보, 상세 용어 부족. 명세 작업은 가능하나 실영상 평가 통과는 보류 |

| 01-B → 02 | 승인된 내부 패턴과 원본 증거 연결, 범위/변형/반례, 새 정보 관계 조회의 적합성 | 모든 영상 분류 미완료, 외부 사례 적음. 좁은 업무 범위에서 시작 |

평가 오류 0만으로 통과시키지 않는다. 필수 이벤트·주요 문구·시나리오 대응에서 결과를 얼마나 완성했는지 분모와 함께 보고한다. 어려운 항목을 전부 확인 불가로 넘기면 필수 분석 범위 미충족으로 처리한다.

정확도 목표, 누락 허용범위, 기권 범위는 교정·개발 파일럿 후 **홀드아웃을 보기 전에** 정한다. 정의가 모호한 이벤트는 사람의 허용 시간 범위로 평가한다. 알려진 단순 이벤트와 복잡한 불명확 이벤트를 같은 정확도 점수로 섞지 않는다.

## 실제 이익을 검증하는 비교 계획

01-A의 정확도 교정과 업무 효율 비교는 별개로 둔다. 같은 자료·필수 검수 수준에서 디자이너의 수동 분석, 기본 AI 분석, 커스텀 분석을 비교한다. 결과의 분량이 아니라 필수 정보·증거의 완성과 총 공수로 판정한다.

02에서는 기존 방식의 기획과 커스텀 기획을 비교한다. 내용·디자인 검수까지의 총 시간, 수정 횟수, 제작자가 다시 해석해야 하는 항목, 실제 제작 후 기획 재작업을 측정한다. 내부 문법만 적용한 안과 선별 Taste를 더한 안도 비교해 무엇이 효과를 냈는지 분리한다.

검수자의 방법명 가림이 가능한 범위에서는 결과를 익명으로 비교한다. 같은 프로젝트의 거의 같은 컷을 테스트·홀드아웃에 나눠 넣지 않고 프로젝트 단위로 분리한다. 설정 변경 후 평가 자료가 개발에 유입되면 새 홀드아웃을 확보한다. 아직 테스트하지 않았으므로 시간 절감률이나 합격률을 주장하지 않는다.
