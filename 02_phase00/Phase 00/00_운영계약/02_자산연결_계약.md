# 영상 자료와 회사 공용자산 연결 계약

사용자가 선택한 B안에 따라 영상·시나리오·분석 결과와 회사 공용 로고·폰트·이미지·도표를 같은 방식으로 등록한다. 8개 가족사의 CI는 회사ID로 구분한다. AE·3D·텍스처 프로젝트 전체 의존성 관리까지 확대하지 않는다.

## 자료 하나를 등록할 때

자산ID, 등록기록 버전, 현재/이전 상태, 소속회사, 자료종류, 원본/참고/파생 역할, 실제파일 경로와 SHA256, 원문출처, 관련자료, 생성방법, 사용범위, 미정사항을 적는다. `자산목록.json`이 등록기록 정본이며 파일의 실제바이트와 등록설명은 다르다.

같은자산ID·버전은하나의등록기록이다. 파일/설명/사용범위/출처가바뀌면새등록버전을만들고이전것을보존한다. 같은회사이름이나같은파일해시만으로서로다른등록을병합하지않는다. 관계는대상ID·등록버전·파일해시로고정한다.

| 자료 | 기록 방법 | 혼동하면 안 되는 것 |
|---|---|---|
| 최종 영상 | 원본등록, 제공경로·해시·해당버전 | 프로시/프레임을최종원본으로등록 |
| 시나리오 | 원문등록, scenario_for로영상참조 | 완성영상에맞춰원문덮어쓰기 |
| 프레임·프로시 | 파생등록, derived_from과생성방법 | 다른영상/다른버전의같은파일명연결 |
| 자동전사·OCR | 파생등록, 생성방법과원본참조 | 원래시나리오·제작의도확인으로승격 |
| CI·가이드 | 회사ID,공식/제공출처,언어/배경형은notes·variant_of | 흰색형/구형/웹축소이미지를유일한원본으로단정 |
| 폰트 | 파일이있으면등록,명칭/가이드만있으면reference_document | 이름만으로파일보유·영상사용범위확정 |
| 이미지·도표 | 원본/참고/파생구분,회사·프로젝트사용맥락 | 같은바이트를같은프로젝트승인이라고단정 |

실제파일이없으면awaiting_file이며path/sha256은null로둔다. 존재가확인된로컬파일만registered로등록한다. 설명용예의가상파일은실제자산목록에넣지않는다.

## 관계와 생성

derived_from은가공전입력,variant_of는언어·단색·배경형등변형,supersedes는같은대상의이전등록,scenario_for는대응영상이다. 현재목록안에현재/이전등록을함께보존할수있으며현재는자산당하나다. 등록된파생자료는실제입력파일의버전·해시와생성방법이필요하다. 서로를원본으로삼는순환관계는오류다.

재구성이미지는reconstructed_image로기록한다. 로고의PNG변환과색보정도파생자료이며원본CI를덮어쓰지않는다. 인쇄CMYK/별색자료의디지털변환은조건을남기고공식원색과별도로관리한다.

## 파일 보관

원본파일은10_공용자산/01_원본자료/회사명/에보관한다. 회사ID는회사목록정본을따른다. 보존원본은회사명폴더,공동AI는공통AI폴더에두고원본제공경로·원파일명을목록에서추적한다. CI원본·가이드·폰트·이미지·도표를종류별로나누고원래파일명을보존할수있다. 작업복사본은02_작업자료,변환·추출은03_파생자료에분리한다.

등록경로는Phase00기준상대경로다. 외부드라이브의제공파일은무단이동하지않고읽기참조를확인한뒤프로젝트에복사·해시확인한다. 경로정규화·루트밖쓰기차단·동일버전충돌·등록참조검사는R1전용도구가확인한다.

사용범위가모르면unknown이다. 가이드/실제지시가확인된맥락만permitted_for_context로기록한다. 회사자료라는이유로모든배포범위의승인을생성하지않는다. 이검사는사람신원·공식출처진위를인증하지않으며담당자확인이필요한경우를남긴다.

## R1과 다음 단계

R1은자료등록과회사별CI기록의기반이다. 분석에서영상유형/화면/모션을분류하는상세기록위치는R2·R4에서정한다. 현재분석스키마를이등록규격과동일한것으로자동바꾸지않는다. 페이지레이아웃·새팔레트·회사필수화는별도의설계/검토다.


## R1 최종 보완

등록규격0.2.0은 회사 수를 회사목록의 expected_company_count로 확인한다. 현재 사용자 확정값은8이다. 색ID는 회사ID+색ID+기록버전으로 구분한다. 현재 팔레트는 회사가 지정한 current CI 참조에 연결된 값만 조회하며 과거CI 기록은 보존하되 현재 팔레트에 섞지 않는다. 직접 palette 함수도 파일/참조/범위 검증을 수행한다.

collection_complete는 현재 원본 CI 지정+현재 CI의 공식/관측 화면색 조건이다. 응용색만 있거나 지정 원본CI가 없으면 완료가 아니다. official_values_complete는 별도 판정이며 현재 false다. 이 값은 회사의 최신CI 승인·배포 승인이 아니다.

래스터 색에는 샘플 영역·알파·배경·프로필 가정이 필요하다. 같은 sRGB 채널은 그대로 보존하며 원색 변경을 정규화로 처리하지 않는다. 조건을 기록한 합성전 반투명 샘플은 허용하지만 공식선언/불투명 identity와 구분한다.
