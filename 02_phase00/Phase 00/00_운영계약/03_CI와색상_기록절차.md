# 가족사 CI와 색 기록

8개 가족사 각각의 CI원본과색근거를독립적으로보존한다. 나중에페이지를설계할때회사ID로찾아공식지정값과추출/응용값을구분할수있게한다. 회사명단8개는사용자확인됐고제공CI와관측색을등록했다. 공식가이드·최신판은미확인이다.

## 자료를 받는 순서

1. 정확한회사명·공식사이트·명단근거를등록한다. 회사가소속됐다는확인과CI가최신이라는확인은별개다.
2. 제공된AI/SVG/EPS/PDF/PNG등로고와가이드를보존하고자산ID·버전·SHA256을기록한다. 원본표시와공식가이드의버전·언어·배경형을확인한다.
3. 가이드에색상값이있으면공식선언값을그대로옮기고페이지/절·CI자산·가이드자산의버전과해시를연결한다.
4. 벡터값이나래스터픽셀에서확인한색은관측/추출값으로남긴다. 샘플영역·배경/알파·색공간/프로필·방법을적고가이드값으로자동승격하지않는다.
5. 공식값과관측값이다르면둘다보존한다. 후보를검토하기전어느쪽이맞는지자동선택하지않는다.
6. 배경/강조/텍스트역할이나명암팔레트는ui_proposal로따로기록한다. CI원색을수정하거나회사승인을만들지않는다.

## 색 기록의 종류

| source_level | 뜻 | 후속페이지에서의처리 |
|---|---|---|
| official_declared | 공식가이드/공식선언에적힌값 | 원문확인·화면용값이있을때기본조회후보 |
| vector_literal | 로고벡터에들어있는관측값 | 가이드공식색과구분해서조회 |
| raster_sample | 이미지에서추출한관측값 | 추출방법·색공간·알파/배경조건과함께명시조회 |
| ui_proposal | 페이지에서쓸응용색·역할후보 | 새설계제안으로조회하며CI색을덮어쓰지않음 |

원문의HEX/RGB/CMYK/PANTONE표기를raw_value에보존한다. 화면용sRGB값은screen_value로분리하고변환방법과프로필을기록한다. CMYK/별색을출력조건없이HEX로자동환산하지않는다. HEX가공식적으로sRGB라고확인되지않았으면프로필미정과가정을기록한다.

CI색은회사ID·CI자산버전·색기록버전으로구분한다. 현재색기록의source_checked는원문대조기록이며회사필수화/디자인승인이아니다. 검사도구는출처자산연결과필드조건을확인하고원문내용의진위를증명하지않는다.

## 페이지에서 가져오기

기본조회는선택한회사에속한현재·원문확인된공식선언값중화면용sRGB가있는것만반환한다. 추출색·응용색은명시적으로포함해다른종류임을표시한다. 색이없으면없다고반환하고다른회사의색이나기존한맥팔레트를대입하지않는다.

공식로고색을본문텍스트/버튼에사용할때의가독성은페이지의실제조합에서별도로검토한다. 대비문제는원색변경으로자동해결하지않고텍스트색·배경판·역할/배치의대안을검토한다. 로고원본색과화면설계의사용역할을분리한다.

자료가모이면색상표와참조용토큰을정본에서생성할수있다. 현재규격은프로젝트자체형식이며DTCG/W3C규격준수로표기하지않는다. DTCG는색공간·값·역할분리의참고이며기존한맥프로필을전환하지않는다.


## R1 최종 보완

등록규격0.2.0은 회사 수를 회사목록의 expected_company_count로 확인한다. 현재 사용자 확정값은8이다. 색ID는 회사ID+색ID+기록버전으로 구분한다. 현재 팔레트는 회사가 지정한 current CI 참조에 연결된 값만 조회하며 과거CI 기록은 보존하되 현재 팔레트에 섞지 않는다. 직접 palette 함수도 파일/참조/범위 검증을 수행한다.

collection_complete는 현재 원본 CI 지정+현재 CI의 공식/관측 화면색 조건이다. 응용색만 있거나 지정 원본CI가 없으면 완료가 아니다. official_values_complete는 별도 판정이며 현재 false다. 이 값은 회사의 최신CI 승인·배포 승인이 아니다.

래스터 색에는 샘플 영역·알파·배경·프로필 가정이 필요하다. 같은 sRGB 채널은 그대로 보존하며 원색 변경을 정규화로 처리하지 않는다. 조건을 기록한 합성전 반투명 샘플은 허용하지만 공식선언/불투명 identity와 구분한다.
