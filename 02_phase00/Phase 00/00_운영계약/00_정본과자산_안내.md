# 정본과 자산 관리 — R1 완료

R1은 **어떤 파일을 원본으로 보존하고, 무엇을 현재 데이터로 쓰며, 복사·추출 자료가 어디에서 왔는지 연결하는 단계**다. 용어와 디자인 원칙을 새로 조사하는 작업은 R2·R3에서 이어간다.

사용자가 선택한 B안: 영상·시나리오·파생자료와 회사 공용 CI·폰트·이미지·도표 등록 구조. 회사 범위는 후속 D안으로 **8개 모두 별도 회사**로 확정했다. 7개라는 초기 가정은 현재 명단에 적용하지 않는다.

1. [보존과 버전 계약](01_보존과버전_계약.md): 원본·작업본·조회·backup, 버전 충돌과 복구.
2. [자산 연결 계약](02_자산연결_계약.md): 실제 파일과 회사·입력·파생 연결.
3. [CI색 기록 절차](03_CI와색상_기록절차.md): 공식값·벡터 원문·픽셀 관측·응용색 구분.
4. [회사별 CI 찾기](../10_공용자산/04_조회용자료/00_회사별자산목록.md): 보존원본68개, 편집용AI27개, SVG20개, PNG20개.
5. [R1 결과와 잔여 자료](../08_검증결과/R1_보완결과와레드팀.md).

[정본과 조회 연결목록](정본과표시_연결목록.json)은 실행경로와 정본 해시를 고정한다. R1 등록 규격은0.2.0이며, 기존04_기록규격의 영상 분석 스키마와 별개다. 자료 수집 완료 표시는 원본CI·관측색의 기록 조건 충족이며, 공식 최신CI/지정색 승인이나 전체Phase00 완료를 뜻하지 않는다.

[단계별 심화 보완 계획](../05_출처와검토/단계별_심화보완계획.md)에 따라 R2는 다음에 따로 진행한다. 스킬의 전체 심층검토·변형·Anthropic Skill Creator 평가는 R3/R8의 별도 작업이며 이번CI 자산 정리로 완료 처리하지 않는다.


[R1 종료 판정](../08_검증결과/R1_종료판정.md): 한맥 디자인 정본과 제공 CI의 관리 기반으로 R1을 완료했다. 추가 공용자산 수집과 공식 CI 확인은 후속 보충/개별 적용 조건이며 단계 종료를 막지 않는다.
