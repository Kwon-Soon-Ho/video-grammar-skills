# 필요할 때 보충할 공용자산

**R1 완료 후 보충 목록이다. 전체 자료 수집이 R1 종료나 R2 시작의 선행 조건은 아니다.**

R1은 관리구조·제공CI의 정리와 검증을 수행했다. 아래 실물/판정은 미확보다. 목록에 있다는 이유로 자산등록·사용승인을 생성하지 않는다.

| 준비할 것 | 왜 필요한가 | 받으면 기록할 내용 |
|---|---|---|
| 산하 CI AI/SVG/EPS·심볼 원본 | PNG 트레이싱으로 원래 벡터를 추정하지 않기 위해 | 제공경로·해시·버전·전체CI/심볼 역할, 기존PNG와대조 |
| 회사별 공식CI 가이드 또는 담당자 지정색/최신판 확인 | 추출색과 회사지정값을 구분하기 위해 | 페이지/절·개정일·RGB/CMYK/별색·프로필·현재CI연결 |
| 단색형·반전형·배경형과 보호공간/최소크기 | 화면 적용시 로고손상과잘못된변형 방지 | 각형태별원본·variant_of관계·가이드근거 |
| 회사 지정 폰트와 사용맥락 근거 | 웹폰트이름을 영상폰트보유로오인하지 않기 위해 | 파일/패밀리/스타일·버전·사내영상 등 적용범위 |
| 자주 쓰는 사진·아이콘·제품/현장 이미지 | 반복 사용 자산을 빠르게 찾기 위해 | 실제파일·출처·회사/프로젝트범위·파생관계 |
| 원본 도표·수치/단위의 출처 | 디자인 변경과 정보 변경을 구분하기 위해 | 원자료·버전·단위·원문위치·표현용파생 연결 |

원본 제공폴더는이동/삭제하지않는다. 새파일은01_원본자료에보존사본, 편집·변환은02/03에분리한다. 운영예와반례는 [R1 보고](../08_검증결과/R1_보완결과와레드팀.md) 참고.


## 추가 모음 반영

가로·세로형과 언어 변형이 포함된 7개 회사 모음을 확보했다. 삼안 색상 문구와 ㈜장헌 시그니처 설명은 검토 초안으로 기록했다. 이제 필요한 것은 “아무 자료도 없음”을 채우는 일이 아니라, 이 자료의 공식 최신판 여부와 남은 규정을 확인하는 일이다.

삼안 문서의 회색 HEX `#4D4D4D`, 주황 HEX `#F58220`, 두 별색명은 원문대로 보존했다. 색공간/출력 프로필과 회사 승인 없이 공식 화면 팔레트로 적용하지 않는다. 부분 인쇄채널은 원문 문구를 유지한다.

AI 내부에는 NanumSquareEB, NotoSansCJKkr, Pretendard 이름이 확인되지만, 이것은 문서에서 사용한 글꼴의 관측이다. 회사 지정 폰트·파일 보유·영상 사용범위의 증거로 삼지 않는다.
