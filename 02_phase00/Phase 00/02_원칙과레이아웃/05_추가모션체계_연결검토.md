# 추가 모션 체계와 기존 지식의 연결 후보

UX in Motion 12개는 저자의 UI 설계론이다. 아래 연결은 프로젝트의 제안이며 새 분류ID·회사 규칙으로 활성화한 상태가 아니다. 사례는 설명용이며 실제 회사 영상을 분석한 결과가 아니다.

| 외부 항목 | 기존 연결 후보 | 시간상 적용 예 | 반례 |
|---|---|---|---|
| Easing | AP-06, MP-02 | 설명 패널 정착 | 등속 실측 운동의 왜곡 |
| Offset & Delay | MR-04, AP-05 | 설명 대상과 라벨을 묶어 공개 | 지연을 실제 공정 순서로 단정 |
| Parenting | MR-07 | 부품과 주석이 함께 이동 | 공동 이동을 AE parent로 단정 |
| Transformation | MR-03 | 설명용 표식이 검토 중 원형 표시→확인 완료 체크로 같은 대상에서 형태·기능 상태가 바뀐다. 실제 제품 성능의 변화로 표시하지 않는다. | 동일 대상의 역할 변화가 없는 단순 전체→상세 확대를 Transformation의 대표 예로 사용한다. |
| Value Change | MR-08 | 실측 시계열과 연출 카운트를 구분 | 보간값을 실적 데이터로 저장 |
| Masking | MR-03 | 같은 도표의 가려진 부분을 시간에 따라 공개하고 경계·대상 위치를 이어서 식별하게 한다. | 이미 잘라 놓은 정지 이미지 하나만 보고 시간상 Masking 동작을 기록한다. |
| Overlay | MR-02 | 전경 설명판이 이동하여 뒤 도면을 드러냈다가 복귀하며 두 층의 위치 관계를 유지한다. | 고정 주석이 원도면 위에 있다는 사실만으로 시간상 Overlay 동작을 기록한다. |
| Cloning | MR-03, MR-07 | 원정보에서 파생 항목을 연결 | 서로 독립인 회사를 한 회사의 자회사처럼 복제 |
| Obscuration | AP-03, MR-02 | 전체 맥락이 보임→핵심 부품 강조에 맞춰 비주요 맥락의 가림·흐림이 변화→배경의 존재를 유지하며 복귀한다. | 정지 배경이 어둡다는 사실만으로 Obscuration 변화와 실제 주목 효과를 확정한다. |
| Parallax | MR-02 | 개념 장면의 층 관계를 제한적으로 제안 | 실제 도면의 깊이·거리로 단정 |
| Dimensionality | AP-11, MR-02 | 부품의 출발과 복귀 위치를 연결 | 도면에 없는 입체 관계 생성 |
| Dolly & Zoom | MR-03 | 전체도에서 동일 부위를 확대 | 영상만으로 실제 카메라 이동 확정 |
