# 실제 문구·화면비·가림을 넣어 보는 설명용 사례

아래12개는 가상 입력·조건을 이용한 설계 판단 사례다. 실제 시청자 검증·회사 영상 분석 결과가 아니다. 숫자는 예시이며 회사 기본값이나 실측 데이터로 쓰지 않는다.

## LS-01 · 긴 한글 기술명

입력: 지하구조물 침투수 저감 공법

- 검토 후보: LAYOUT-SINGLE-FOCUS, LAYOUT-SPLIT
- 판단: 글자 크기를 먼저 줄이지 않고 명칭 영역·의미 단위 줄바꿈·설명 구간을 조정한다.
- 반례: 지하구조물 침투수 저감 공법을 지하침투공법으로 허락 없이 축약하거나 2줄에 맞춰 자간을 극단적으로 압축한다.
- 기권: 화면비·출력 크기·실제 글꼴·필수 명칭 여부가 없으면 최종 가독성 통과를 보류한다.

## LS-02 · 숫자·단위·온도와 각도

입력: 설계 수압 120 kPa / 온도 30.2 °C / 방향 30°

- 검토 후보: LAYOUT-DATA-CHART, LAYOUT-SPACE-CALLOUT
- 판단: 값·단위의 의미 묶음을 유지하되 SI 공백·평면각 예외를 구분한다. 120 kPa를 같은 읽는 덩어리로 유지한다.
- 반례: 120과kPa를 다른 줄에 분리하거나30.2° C처럼 단위 기호를 쪼갠다.
- 기권: 의도한 단위·정밀도·서식의 출처가 불분명하면 데이터 담당 검토를 요청하고 값을 임의 변환하지 않는다.

## LS-03 · 표식·범례 과밀

입력: 동일 도면의 시설 8곳과 각각 긴 명칭

- 검토 후보: LAYOUT-SPACE-CALLOUT, LAYOUT-OVERVIEW-DETAIL
- 판단: 리더라인·번호+범례·상세 구간을 비교하며 실제 대상 위치를 보존한다.
- 반례: 보기 좋게 하려고 실제 시설 위치를 옮기거나 선이 다른 시설을 가리킨다.
- 기권: 원도면 버전·라벨 대응이 없으면 공간 정확성 보류.

## LS-04 · 같은 정보의 가로→세로→정사각

입력: 가상 공법 A:비용80/공기12, B:비용100/공기9. 단위·조건은 설명용.

- 검토 후보: LAYOUT-SPLIT-COMPARE
- 판단: 가로는좌우,세로는상하,정사각은공통항목축 중심 후보로 재배치한다. A/B의 항목·값·단위·순서는 보존하고 최종 비교 시점에는 양쪽이 함께 읽히게 한다.
- 반례: 센터 크롭으로B가 잘리거나 한쪽만 표시한 뒤 다른쪽을 보여주면서 직접 비교가 쉽다고 확정한다.
- 기권: 단위와 비교 조건의 실제 자료가 없으므로 가상 예의 우열을 실제 공법 주장으로 쓰지 않는다.

## LS-05 · 전후 상태의 조건 차이

입력: 같은 부위, 전은 정면·후는 사선 촬영

- 검토 후보: LAYOUT-BEFORE-AFTER
- 판단: 조건 차이를 밝히고 변화 확인의 한계를 기록한다. 대응은 후보로 검토하되 개선 효과·인과는 따로 보류한다.
- 반례: 배율·조명 차이를 실제 성능 개선으로 결론낸다.
- 기권: 동일 대상과 촬영 시점·조건이 확인되지 않으면 전후 관계도 보류.

## LS-06 · 막대와 추세선의 축

입력: 가상의 두 값98·100과 온도 추세98·99·100

- 검토 후보: LAYOUT-DATA-CHART
- 판단: 막대 길이의 비율 비교는 기준축을 확인하고, 추세선의98–100범위는 명시할 때 후보로 검토한다. 목적이 다른 두 그래프를 같은 축 규칙으로 처리하지 않는다.
- 반례: 모든 차트의0축을 강제하거나 막대의98시작을 숨겨 작은 차이를 과장한다.
- 기권: 실제 단위·목적·범위 설명이 없으면 축 적합성 보류.

## LS-07 · 결측과 압축 시간축

입력: 2020·2021·2025 자료,2022–2024결측

- 검토 후보: LAYOUT-TIMELINE, LAYOUT-DATA-CHART
- 판단: 연속시간척도와비례아님사건목록을구분한다. 결측을밝히고미제공값을실측으로연결하지않는다.
- 반례: 동일간격사건카드를기간비례축이라기록하거나결측값을0으로채운다.
- 기권: 실제 결측 사유와 추정 모델이 없으면 보간된 실측 주장을 보류한다.

## LS-08 · 가족사 병렬과 계층

입력: 사용자가 확인한8개 회사명만 제공, 지분·종속 자료 없음

- 검토 후보: LAYOUT-CARD-GROUP, LAYOUT-HIERARCHY
- 판단: 회사명은 병렬 항목으로 소개할 후보가 된다. 실제 조직·소유 위계 자료 없이는 계층 관계를 부여하지 않는다.
- 반례: 한맥기술을 맨위에 놓고 나머지를 자회사로 연결하거나 한 CI색을8개에 동일 강제한다.
- 기권: 법인 관계·공식 CI 적용조건은 별도 근거와R5검토 필요.

## LS-09 · PIP·자막·버튼 가림

입력: 제품시연+발표자삽입+하단자막, 배포UI미정

- 검토 후보: LAYOUT-PIP, LAYOUT-UI-ANNOTATION
- 판단: 핵심 조작·자막·삽입 영역을 구분하고 화면 상태별 가림을 확인한다. 배포 UI는 미정으로 남겨 납품 전 다시 검사한다.
- 반례: 하단19%를 모든서비스의영구안전영역으로승격하거나발표자창으로저장버튼을가린다.
- 기권: 실제 플레이어 UI가 없으면 플랫폼 안전영역 최종 통과는 보류.

## LS-10 · 실제UI 확대와 설명

입력: 확인된 제품 화면에서 대상버튼이 작은 조건

- 검토 후보: LAYOUT-UI-ANNOTATION, LAYOUT-OVERVIEW-DETAIL
- 판단: 실제 위치·기능을 유지한 확대와 외부 주석으로 설명한다. 작업에 필요한 주변 메뉴의 맥락도 남긴다.
- 반례: 화면을정리하려고버튼을옮기거나없는기능을추가한뒤실제제품이라고보인다.
- 기권: 실제 화면·기능·버전 근거가 없으면 실제UI 확정 금지.

## LS-11 · 정보 완성 상태와 등장 중 상태

입력: 제목→도표→단위 순차 공개, 완료 후 잠깐 유지

- 검토 후보: LAYOUT-DATA-CHART, LAYOUT-SPLIT
- 판단: 최종 정보가 모두 공개되고 가림·대비가 읽기 가능한 상태인 기간을 따로 기록한다.
- 반례: 정지 프레임 하나에서 문구가 보였으니 전체구간의읽기시간이충분하다고한다.
- 기권: 시간표본·완성시점·시청환경이없으면읽기충분성은보류.

## LS-12 · 글꼴 대체와 행 높이

입력: 확정 글꼴에 없는기호·영문모델명·m² 혼용

- 검토 후보: LAYOUT-SPACE-CALLOUT, LAYOUT-CARD-GROUP
- 판단: 실제 혼용 문자열과대체글꼴·기호·지수의표시를확인해라인박스·행간을검토한다.
- 반례: 행간160%를보편규칙으로강제하거나윗첨자를잘라단위의미를바꾼다.
- 기권: 실제출력글꼴·대체여부가없으면렌더가독성통과보류.
