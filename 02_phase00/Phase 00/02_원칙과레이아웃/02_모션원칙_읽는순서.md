# 모션 원칙을 읽고 적용하는 순서

1. 해당 구간이 설명할 정보와 시청 환경을 먼저 확인한다. 숫자·형상·시간이 실측인지 개념 표현인지 나눈다.
2. [심화카드](모션원칙_심화카드.json)와 [조회문서](03_모션원칙_적용예와반례.md)에서 해당 원칙의 예·반례·기권 조건을 확인한다.
3. 원문 설명과 우리 영상용 해석을 구분한다. 강의 제목만 읽은 MP 항목은 강사의 상세 정의를 검증했다고 말하지 않는다.
4. 사실·명칭·단위·가독성을 해치면 표현 효과를 조절한다. 음악·UI 템플릿의 시간 수치를 먼저 적용하지 않는다.
5. 같은 문제를 AP와 MP에서 반복 감점하지 않는다. 원칙을 쓰지 않았다는 이유로 실패를 주지 않는다.

**정지 상태도 선택지다.** 관계·배치를 읽어야 하는 구간에는 정지 그림이나 누적 요약을 고려하고, 이동·시간차 자체를 이해해야 하는 구간에는 동작 설명을 고려한다. 이는 연구에서 가져온 프로젝트 적용 가설이며 모든 영상의 이해도 향상을 보장하지 않는다.

IP-10은 2021 공식 Summary를 새로 확인했다. 사용자 A 선택으로 공식 Summary 수준의 조건부 참고를 기본 조회에 포함했다. 장 전체·진단도구·회사 영상 효과는 미검토다. 숙련도는 직급·부서명만으로 결정하지 않는다.

UX12는 [추가 연결 후보](추가모션체계_연결후보.json)다. 외부 체계의 항목명은 보존하고 기존 MR/AP/MP에 연결 후보로 둔다. 새 분류ID·회사 필수 규칙으로 자동 승격하지 않는다.

한맥·가족사 CI의 형태와 지정값은 원칙으로 덮어쓰지 않는다. 공식 보호 규정이 미확인일 때는 임의 변형을 기본값으로 정하지 않는다. 자산 위치·출처는 R1, 회사 디자인 적용 조건은 R5, 기록의 실제 필드는 R4를 따른다.
