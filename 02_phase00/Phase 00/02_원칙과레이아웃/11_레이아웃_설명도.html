각 그림은 구조와 오용을 설명하기 위한 간략도입니다. 실제 회사 영상·실측 자료·최종 템플릿이 아닙니다. 그림의 크기와 색은 회사 규칙으로 사용하지 않습니다.

읽는 순서: 정보 관계 확인 → 후보·대안 비교 → 문구·단위·가림 확인 → 실제 출력·유지 시간 검수.

단일 초점

핵심 메시지가 하나이며 나머지는 근거·맥락일 때

적용 침투수의 주요 경로를 하나의 단면도와 짧은 요점으로 설명한다.

반례 동등하게 비교해야 할 A/B 중 A만 거대하게 배치해 우열을 암시한다.

분할 비교

비교 대상과 공통 비교 항목·조건이 확인됐을 때

적용 가상의 두 공법에 비용·공기 같은 동일 항목을 같은 줄에 배치한다.

반례 A는 비용, B는 내구성만 보여 주고 종합 우열을 결론낸다.

전후 대응

동일 대상의 이전·이후 상태와 대응 조건이 확인됐을 때

적용 같은 부위의 처리 전후 상태를 명칭과 대응 표식으로 표시한다.

반례 서로 다른 현장 사진을 전후로 묶어 공법의 개선 효과라고 한다.

선형 프로세스

업무·공정 단계의 순서가 의미를 가지며 분기가 주요 내용이 아닐 때

적용 접수→검토→승인 흐름을 단계 이름·방향과 함께 표현한다.

반례 자료 공개 순서만 보고 실제 업무가 그 순서라고 연결하거나 분기·회귀를 숨긴다.

시간축

사건 날짜나 기간이 정보의 핵심일 때

적용 가상의 2020·2021·2025 사건을 날짜 표식으로 표시하고 비례축이면 간격 차이를 반영한다.

반례 2020→2021과2021→2025를 같은 폭으로 두고 기간 차이를 실측 축이라고 한다.

계층 구성

상하·종속·구성의 위계가 자료로 확인됐을 때

적용 문서에 확인된 부서와 팀의 상하 관계를 연결한다.

반례 8개 가족사를 이름 확인만으로 모회사·자회사 조직도에 배치한다.

연결 구성

여러 대상 사이의 관계·흐름·인과가 설명의 대상일 때

적용 시나리오가 설명하는 침투 경로와 압력 관계를 관계 라벨이 있는 연결도로 표현한다.

반례 관련 선 하나를 그렸다는 이유로 과학적 인과가 증명됐다고 기록한다.

전체와 상세

전체와 선택 부분의 대응을 유지하며 상세를 설명할 때

적용 교량 전체도에서 특정 접합부를 표시하고 같은 접합부 상세를 옆에 둔다.

반례 상세도와 다른 현장의 전체도를 가까이 두어 같은 부위처럼 보이게 한다.

공간과 설명 표식

위치·시설·부품과 명칭의 대응이 중요한 경우

적용 시설 도면의 대상에 번호와 명칭을 연결하고 중첩 라벨을 분산한다.

반례 보기 좋게 하려고 실제 위치를 옮기거나 연결선이 다른 시설을 가리킨다.

데이터 시각화

수치의 비교·변화·분포·부분전체를 읽어야 할 때

적용 가상의 공법 비용을 같은 단위·0 기준 막대로 비교하고 값과 조건을 표시한다.

반례 막대 길이의 비율 비교에서0기준을 잘라 작은 차이를 과장하거나, 다른 단위·기간을 같은 막대로 비교하거나, 자료 없는 중간값을 실측처럼 연결한다.

실제 UI와 설명

실제 제품 화면 출처가 확인되고 특정 조작·기능 설명이 필요할 때

적용 제공된 실제 프로그램 화면에서 저장 버튼과 결과 영역을 표식으로 설명한다.

반례 새로 그린 가상 버튼을 실제 제품 기능으로 보여 주거나 클릭 후 결과를 임의 합성한다.

카드 그룹

같은 역할의 독립 항목을 반복 구조로 묶으면 읽기에 도움이 될 때

적용 동등한 사업 분야를 명칭·대표 이미지·짧은 설명이 같은 순서인 카드로 정리한다.

반례 한 과정의 원인·결과를 독립 카드로 떼어 놓아 관계를 숨기거나 카드 자체를 항상 금지한다.

분할 구성

화면과 설명 등 서로 다른 역할을 나눠 동시에 참조할 필요가 있을 때

적용 공법 단면도 옆에 해당 부위의 설명을 두고 색·번호로 대응한다.

반례 왼쪽은 A 공법 사진, 오른쪽은 회사 소개문인데 비교 화면이라고 한다.

화면 속 화면

주 화면을 유지하며 보조 화면·발표자·다른 관점을 함께 보여 줄 때

적용 실제 제품 시연의 주화면 안에 작은 발표자 창을 삽입하고 중요한 버튼·자막이 없는 위치에 둔다.

반례 작은 발표자 창이 제품의 저장 버튼이나 핵심 수치를 가린다.

같은 정보의 화면비별 구조 후보

LS-04: A 비용80·공기12, B 비용100·공기9. 숫자는 가상 예이며 실제 단위·비교 조건 확인 전입니다. 재배치해도 대상·항목·값의 대응은 유지합니다.

이 그림만으로 작은 화면의 가독성·안전영역·노출 시간이 검증되지는 않습니다. 실제 문구·글꼴·배포 UI와 유지 구간으로 다시 확인합니다.
