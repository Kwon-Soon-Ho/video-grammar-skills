# R3에서 무엇을 조사하고 정리하는가

R2는 화면과 움직임에 붙일 이름을 정했다. R3는 그 이름을 **왜·언제·어떻게 참고할지** 정리한다. 원칙을 많이 쓰는 것이 목표가 아니라 정보에 맞는 선택과 기권을 할 수 있게 만드는 단계다.

| 순서 | 쉬운 설명 | 조사와 산출물 | 완료 판단 |
|---|---|---|---|
| R3-1 모션 원칙 | 무엇을 움직일지, 언제 멈출지 정하는 참고 지식 | 12/10원칙 대조, 정보 전달·관계·접근성, 추가 체계, 출처 깊이와 적용 예·반례 | 원문/자체해석 구분, 의미 왜곡·웹 지침 오용·기권 조건을 레드팀이 확인 |
| R3-2 레이아웃 지식 | 같은 정보를 어떤 화면 구조로 보여줄지 | R2의 14개 이름에 선택 조건·읽기 순서·한국어·정보량·비율 예와 반례 연결 | 단순 배치 예와 품질 판단 분리, 내용에 따른 대안 비교와 불확실성 검토 |
| R3-3 스킬 심층 검토 | 위 지식을 다룰 외부 스킬에서 필요한 기능을 골라내기 | Taste 외 후보, 고정 커밋 원본, SKILL·참조·스크립트·의존성·통신·쓰기·라이선스 추적 | 다운로드/내용 검토/기능 채택/실행 평가를 구분하고 기능별 채택·변형·제외·보류 결정 |

각 소단계에서 작성 → 레드팀 → 보완 → 결과 보고를 마친 다음 다음 소단계를 진행한다. 이번 묶음은 R3-1이다. R3-2·3을 함께 완료로 처리하지 않는다.

R3의 지침은 참고 지식과 초안이다. 회사 필수 규칙·의미 병합·새 체계 활성화가 필요하면 4지선다와 추천안으로 검토받는다. 외부 스킬을 그대로 실행하거나 일괄 활성화하지 않는다.

맞춤 스킬은 R3에서 검토한 기능을 바탕으로 R8에서 Anthropic Skill Creator를 이용해 재구성·평가한다. 기존 세 스킬의 소량 시범 사용 결정은 유지하며 성능 향상을 확인한 것으로 표시하지 않는다. 실제 영상 분석 스킬 구현은01-A다.


## 현재 결과

R3-1의 공개 범위 조사·설명용 적용 지식·레드팀 보완을 마쳤고 사용자 A의 조건부 참고 범위를 반영했다. [결과 보고](../08_검증결과/R3_01_보완결과와레드팀.md)를 따른다. R3-2 레이아웃과 R3-3 스킬 심층 검토는 이후 별도로 진행한다.


R3-2도선택지식·설명용예/반례·레드팀보완을마쳤다. [R3-2 보고](../08_검증결과/R3_02_보완결과와레드팀.md)를따른다. R3-3 스킬심층검토는남아있다.
