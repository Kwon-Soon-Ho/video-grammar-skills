# Visual Style Direction

Translate the user's brief and references into a coherent visual system. Read only the relevant sections of [visual-style-guide.md](references/visual-style-guide.md):

- Brief and reference interpretation: constraints, reference ledger, originality, direction thesis.
- Image construction: color, composition, texture, material, lighting, lens and camera language.
- Series: invariants and controlled variations, cross-shot continuity, review and repair.
- Brand systems or production handoffs: tokens, typography, accessibility, adaptation and deliverables.

For a single still, return the relevant direction and prompt rather than the full production handoff. Preserve the user's palette, lighting, framing and requested scope. Examples are optional guidance and do not impose a house palette or a dark cinematic look.

In this suite, use the host-native image tool or prompt-only output. API, external CLI and key setup are outside this local workflow. Treat provider-specific notes in source material as references, not tool contracts.

Use actual outputs for visual review. Plans, unsupported dimensions and missing references remain unverified. Keep source LICENSE and SOURCE.json with the skill.
