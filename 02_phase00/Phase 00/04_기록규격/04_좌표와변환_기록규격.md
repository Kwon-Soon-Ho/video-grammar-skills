# 좌표·변환 기록 규격 — R4-3

2026-10-15, 독립 초안 v0.1.0. 사용자 A: 좌측 위 **화면 경계**가(0,0),x는오른쪽/y는아래다. 기본단위는해당프레임의raster px. 실제영상/이미지를가공하거나영역을탐지하지않는다. R4-1시간·R4-2근거 계약을재사용하고기존DB통합은R4-4,실제추출/영상가공/자동측정은01-A다.

## 1. 어떤 화면의 좌표인가

spaces는ID/버전,frame자료ID/버전/hash,원본frame_ref,가로/세로해상도,원점/축/단위,SAR,표시회전메타/적용여부,한계를기록한다. 같은자료/frame에다른해상도인공간을중복등록하지않는다. 파생이미지는별도자료와공간이다. material/space의hash·version이맞아야하며실제파일hash·픽셀크기는여기서읽지않는다. width/height 미상은둘다null,0이나음수로채우지않는다.

1920×1080 화면의영역은[0,1920)×[0,1080)이다. 전체box는x=0,y=0,w=1920,h=1080. 마지막pixel중심은(1919.5,1079.5)이고(1920,1080)은그화면의관측point가아니다. 점과box를구분하고box는시작포함/끝제외의양수범위다. pixel_center는반정수grid에만쓰며대상의center/일반위치는geometric_point다. 텍스트baseline·특정도형anchor의내용적정확성은별도사람검수다.

geometries는space/버전,frame,해당이미지의frame근거/버전,대상/버전,point/box,anchor,role,단위,좌표,오차,한계를연결한다. frame을화면상태로바꾸거나R2에새분류축을추가하지않는다. roi는관측할수있는이미지내영역,model_position은입퇴장/가림등에서음수·화면밖위치를보존할수있는모델좌표다. 화면밖모델을오류라삭제하거나관측물체라고확정하지않는다.

normalized는해당space의x와폭을W로,y와높이를H로나눈0~1표현이며px와동일숫자로혼용하지않는다. 물체가밖에있으면model_position의비율도0~1밖일수있다. 소수는분자/분모정수로저장하여임의반올림/오차epsilon을도입하지않는다. 1D x속도/y속도와2D거리는다르다. 가로와세로normalized변위를그대로유클리드거리로합치거나서로다른해상도의px로비교하지않는다. 이계약은point/box의기하대응을검사하며scalar속도/폭등과측정식의필드연결은R4-4에서한다.

## 2. raw raster·표시 화면·픽셀 종횡비

W/H는저장된프레임raster의크기다. SAR는픽셀가로/세로비이며정방픽셀은1,모르면null이다. 표시비율DAR=(W/H)×SAR. 720×576/SAR16:15이면DAR4:3이다. 720/576만보고표시비율을판단하지않는다. CSS px,화면캡처의device px,AE comp 단위,코딩해상도/clean aperture는자동으로같다고보지않는다. viewer의영상영역·DPR·여백·크롭이확인되지않은스크린샷은unknown으로둔다.

rotation_metadata.clockwise_degrees는**우리규격에서정규화한시계방향보정각도**이고원본container의부호/태그를그대로가져오는값이아니다. 원본도구/정규화방법을note·근거에기록한다. applied가미상이면False/0으로채우지않는다. 표시보정목적의rotate는applied=True에다시적용할수없다. 수동연출회전과표시보정은reason으로구분한다. 실제decoder의auto-rotate여부/내보낸프레임크기는01-A의메타획득/검수대상이다.

## 3. 변환과 순서

각transform은from/to space와버전,kind,params,근거ID/버전,한계를갖는다. **한edge당한연산**이며각도착space에는원본경로하나만허용한다. 근거·원본/파생자료의직접parent pin·동일원본frame identity가맞아야한다. 경로는순서대로이어지고중복·순환·없는ref를거부한다. 여러연산을한개이름으로숨기지않는다.

| 연산 | 선언과 기하 |
|---|---|
| crop | 입력space의정수x/y/w/h,원본안에포함. (x′,y′)=(x−crop_x,y−crop_y) |
| rotate | raster 전체기준cw90/180/270. cw90은(x′,y′)=(H−y,x),출력W/H교환. 회전대상중심을임의로바꾸지않음 |
| resize | 실제출력W/H,가로/세로배율,비율정책,왜곡허용,리샘플링방법 |
| pad | 실제출력canvas와내용시작offset. 원본이canvas안에포함. letterbox는resize+pad로표현 |
| unknown | perspective/비선형/가변/미확인변환. 이유를보존하고좌표결과는미해결 |

crop→rotate와rotate→crop은다르다. 경로의from/to를바꿔같은결과라고주장할수없다. 임의matrix·특이행렬·음수scale를받지않고위core연산에서정확한affine식만만든다. arbitrary각도/원근/렌즈왜곡/3D/뒤집기는현재core밖이며unknown으로보존한다.

resize의preserve_sar는SAR유지,비율이변하면allow_distortion=True필수다. preserve_display_aspect는SAR′=SAR×W×H′/(H×W′)로DAR를보존한다. square_pixels는SAR′=1이며알려진원본DAR와다르면왜곡허용을명시한다. SAR미상은확정보정으로간주하지않는다. 90/270회전은픽셀축이바뀌므로SAR를역수로관리한다. 크롭·패딩의이core는SAR를유지한다. crop keep_aspect등다른동작은별도resize/SAR처리확인없이끼워넣지않는다.

params는**요청값이아닌실제로적용된effective값**이다. FFmpeg의chroma정렬/가분성옵션등으로crop/resize가반올림되면결과크기와원점을기록해야한다. 리샘플링은기하의scale와별개의픽셀보간이며화질·색·alpha·보간결과는검증하지않는다. 원본pixel중심이scale후0.25에오면그좌표를새이미지의pixel_center라부르지않는다.

## 4. 관측 영역과 역변환

mappings는source geometry→명시한경로→target space/result geometry를비교한다. forward는각edge정방향,reverse는명시된역순edge의역행렬을쓴다. 위치는이동성분을포함하고box의폭/높이는이동성분을더하지않는다. box는네모서리변환후범위를비교한다. 박스가부분적으로잘리면새관측부분과원래물체의범위를구분한다.

unclipped_geometry는모델기하전체,visible_fragment는관측가능부분이다. 시작화면과각연산후canvas를기준으로visible geometry를따로전파한다. 사라진부분은후속pad로되살리지않는다. visibility는visible/partial/outside/unknown이다. 밖의visible_fragment결과는null이며이미지안에임의ROI를만들지않는다. 역변환으로돌아가는것은기하좌표이며크롭/리샘플링으로사라진픽셀이아니다. inverse_restores_pixels는항상false다. visible_fragment의역좌표를원래물체전체box로승격하지않는다.

## 5. 오차·내용 검수·남은 연결

geometryuncertainty는좌표와같은단위의명시적absolute_bound 또는unknown이다. point는x/y,box는x/y/w/h의0이상오차를구분한다. 미상은null이고0으로채우지않는다. 현재검사기는선언된명목좌표의affine일치만검사한다. 비영오차의상관/전파·클리핑경계·보간/원본메타의실오차는**미해결·사람검수**로남기며결과오차를승인하지않는다. standard uncertainty나AI confidence를보장상한으로바꾸지않는다.

모든space의해상도/SAR/회전상태,모든geometry의대상/anchor/가림/오차를사용자또는지정담당자의내용검수대기에남긴다. 합성예시는specimen_only,실제초안은awaiting_human으로구분한다. 실제자료가없어이번에는사람의실영상내용검수를하지않았다. 구조오류는invalid,해상도/메타/미지원/오차의미확인은draft+unresolved다. valid와formula_checked는사실확인이아니다.

R4-2의coordinate_space_ref는현재string이고공간supported차단을유지한다. 새좌표기록이생겼다고기존주장을확인됨으로바꾸지않는다. 새공간/변환/geometry와측정표본·검수context의버전/hash연결은R4-4통합/이관때검수한다. R6/R7은실제권한과검수결정,01-A는메타획득·ROI탐지·실제픽셀가공·추적·정확성시험을담당한다. 기존3스킬/R2/R3/한맥정본은변경하지않는다.

### 레드팀 보완 규칙

SAR·회전 메타는 양쪽 값이 알려져 있을 때만 모순을 판정한다. 한쪽이 미상이면 invalid 대신 unresolved로 남기고 알려진 값을 지우거나 미상 값을 추정하지 않는다. 명목 기하를 계산할 수 있어도 이 관계의 실제 확인을 뜻하지 않는다.

모든 변환의 effective 원점·출력 크기·적용 순서·회전/SAR 정책·리샘플링·왜곡 허용 목적과 연결 근거의 내용을 별도로 사람 검수 대기에 둔다. 설명용 기록의 EX-DURATION은 참조 구조를 보여주기 위한 합성 근거이며, 크롭·리사이즈가 실제 적용됐다는 증명이 아니다. 실제 기록은 원본·도구 기록 또는 확인 가능한 작업 지시를 근거로 추가하고 담당자가 검수해야 한다. 검사기는 근거 내용의 충분성을 자동 판단하지 않는다.

오차가 미상 또는 0보다 크면 outside/null 결과도 경계 검수를 생략하지 않는다. mapping_results의 visibility_basis는 nominal_geometry_only, uncertainty_verified는 false다. unclipped_geometry에서 원본이 모델 위치이거나 관측 상태가 partial/outside이면 결과도 model_position이어야 한다. 패딩 후 좌표가 이미지 안에 들어와도 관측 ROI로 승격할 수 없다. 해상도 미상으로 normalized 계산을 못 하는 geometry도 개별 사람 검수 대기에 남긴다.
