# 근거·주장 적용 예와 반례

모두 구조 설명용 가상 사례다. 실영상의 사실이나 회사 승인 사례가 아니다.

| 사례 | 바른 기록/처리 | 반례와 보완 |
|---|---|---|
| 1초에 제목이 있다 | visual_presence/instant + 해당 원본frame. 내용 검수 대기 | ‘제목이 등장했다’로 확대하면 temporal_change 필요 |
| 화살표가 이동했다 | 같은 대상의 다른시각 2표본 + sampled | 같은 프레임 복사2장은 변화근거가 아님 |
| 화살표가 가속했다 | 측정량 average_acceleration·3시각·방법/단위·사람 확인 | 2표본의 위치차만으로 가속/순간 이징 확정 금지 |
| 전체 구간에 로고가 없다 | 범위 clip·가림/ROI·사람 내용 검수 | 한 시점에 안 보였다고 전체 부재로 주장 금지 |
| 화면이 큰 경우 crop표본 측정 | 원본frame/좌표변환 연결이 필요. R4-3 대기 | 리사이즈 후 px를 원본px처럼 비교 금지 |
| 대본에 ‘화살표 등장’이 있다 | scenario_content로 해당 인용위치 기록 | 렌더가 그대로 만들어졌다는 주장은 별도 영상근거 필요 |
| OCR이 ‘등장’을 읽었다 | OCR 파생/정확성 한계를 기록 | 원문 시나리오 또는 제작자 의도처럼 사용 금지 |
| 디자이너가 순서 강조 의도를 확인 | 확인자/구절/대상버전·범위 + 사람 검수 | 일반브랜드문서나 AI의 인상만으로 intent_confirmed 금지 |
| 두 자료가 충돌한다 | support/oppose 모두 보존하고 해결 또는 inconclusive | 좋은근거 하나로 반대자료/잘못된링크 삭제 금지 |
| 웹자료 내용이 바뀌었다 | 버전/hash/고정표현 위치로 확인 후 재검수 | 최신URL만 유지해 기존 검수 재사용 금지 |
| 검수 뒤 statement/대상/selector 바뀜 | context hash 불일치→stale→사람 재검수 | version이 그대로라고 기존 receipt 유지 금지 |
| unit=px/s, input=px | 구간평균과 실제추적 정확성을 따로 검토 | unit=kg 또는 input=s인 공간속도 거부 |
| standard uncertainty=2 | 표준편차 성격을 표시하고 내용 검수 | ±2가 확실한 최대오차라고 단정 금지 |
| emoji🙂를인용 | 고정plain-text에서Unicode code point 위치 | UTF16두단위를문자2개로세어인용불일치금지 |
| 단일장면에서회사의공통문법추정 | hypothesis/generalization + 한계·후속검수 | 이번단계에서company_rule 승인 금지 |
| 가짜hash·검수자이름이있다 | spec_test/선언검사. 사실·정체성 미검증 명시 | 구조통과를진짜파일/사람승인으로승격금지 |

## 사람 검수 인계 항목

원본/파생자료의 ID·버전·해시·위치 → 해당 프레임/구간/인용 → 대상·주장·범위 → 지지/반대/문맥근거 → 측정표/방법/가정/오차 → 미확인 이유 → 검수 담당자·의견·판정·재검수 조건을 전달한다. 자료가 없어 검수할 수 없으면 미해결로 둔다. 실제 파일 수집과 추출은01-A 준비/구현과 구분한다.
