# 좌표·변환 적용 예와 반례

실제미디어가아닌합성설명예다. 다음을기록하고독립반례와대조한다.

| 상황 | 적용 예 | 반례/대응 |
|---|---|---|
| 1920×1080→960×540 | (960,540)→(480,270) | 파생px480을원본480으로사용하지않음 |
| crop(100,50,800,600)→resize400×300 | 원본(300,250)→(100,100),역변환(100,100)→(300,250) | cropoffset누락시(150,125)로틀림 |
| cw90 | 1920×1080의(300,250)→1080×1920의(830,300) | W/H교환누락·반시계방향혼동·자동회전2회금지 |
| box | 전체1920×1080이crop후800×600,resize후400×300의보이는부분 | 원래물체전체box를복원했다고단정금지 |
| pixelcenter | 첫중심(0.5,0.5),마지막(1919.5,1079.5) | 경계(1920,1080)를픽셀표본으로사용금지 |
| normalized | (300/1920,250/1080)을동일space에서px로변환 | 300을normalized로쓰거나가로세로비율의metric혼용금지 |
| SAR | 720×576,SAR16:15는표시4:3 | SAR미상에1을자동대입금지 |
| letterbox | 균등resize후pad offset을명시 | 검은여백을영상자체좌표로혼동금지 |
| 화면밖입장 | model_position x=-10을보존 | ROI로관측확정하거나pad후물체가생겼다고보지않음 |
| partialcrop | 관측fragment는작은box로따로기록 | crop밖은‘없음’이아닌미관측 |
| unknown | 해상도/SAR/회전상태/원근/동적변환을미해결로보존 | 항등변환/0회전/정방픽셀로채우지않음 |
| 비율왜곡 | 배율x≠y이면왜곡허용·목적명시 | 편집화면fit을무조건원본동일비율로단정금지 |
| 원본별칭 | 같은원본frameidentity를확인해연결 | 다른시점이미지를같은frame명으로연결금지 |
| 오차 | 단위와unknown/absolutebound를구분. outside/null도 비영 오차면 경계 검수 | 원본오차가있는대상을변환후오차0으로확정금지 |
| 메타 미상 | 원본 SAR/회전이 null이고 출력값이 확인됐으면 관계만 unresolved | 알려진 값끼리 모순은 invalid. 미상을 1/0/false로 추정 금지 |
| 변환 근거 | 실제 적용 원점·출력 크기·순서를 도구 기록과 대조해 사람 검수 | 연결된 근거 ID의 존재만으로 내용까지 충분하다고 판정 금지 |
