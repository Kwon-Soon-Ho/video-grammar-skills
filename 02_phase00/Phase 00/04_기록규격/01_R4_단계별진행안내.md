# R4 단계별 진행 안내

2026-10-15. R4는 분석 결과의 **기록 형식과 검사 조건**을 설계한다. 영상 분석 스킬 개발·추출/OCR/자동 측정은 01-A다. 기존 최소기록 v0.1.0은 현재 호환용 초안이고 R4 보완을 반영한 최종 규격이 아니다.

| 단계 | 쉽게 설명하면 | 산출물과 종료 조건 |
|---|---|---|
| R4-0 착수 감사 | 기존 기록에서 무엇이 빠졌는가 | 누락 재현·작업 순서·독립 레드팀 |
| R4-1 시간·프레임 | 어느 순간/구간을 보고 말하는가 | 재생 0초 기준·원본 시간·프레임 경계·정상/오류 예 검사 |
| R4-2 근거·주장 | 그 판단을 무엇으로 확인하는가 | 관측/시나리오/추정 분리·근거 대상/버전/시점·측정 근거 계약 |
| R4-3 좌표·변환 | 어느 화면의 어느 부분인가 | 원본/회전/크롭/리사이즈 좌표·단위·변환 참조·범위 검사 |
| R4-4 통합 최소 규격 | 기록끼리 어떻게 연결하는가 | R2 영상→설명 구간→화면 상태→동작 필드, run/metadata, 기존 기록 이관, 참조·회귀·인계 |

단계마다 적용 예·반례 → 자체 검수 → 독립 레드팀 → 보완 → 결과 보고로 진행한다. 위쪽 단계의 검사가 통과해도 R4 전체·Phase 00 완료로 표시하지 않는다. 지침 충돌·필수 범위·승인 권한처럼 판단이 필요한 경우 최소 4지선다와 추천안을 제시한다.

사용자가 선택한 시간 기준은 A: **재생 시작을 0초로 통일하고 원본 타임스탬프와 변환 근거도 보존**한다. 4단위 의미는 이미 R2에서 승인했으며 다시 선택하지 않는다. 한맥 profile/taxonomy 버전 참조는 통합에서 유지하고 실제 디자인 적용 기준은 R5다.

## 2026-10-15 단계별 판정

R4-1 시간·프레임, R4-2 근거·주장, R4-3 좌표·변환의 독립 계약·합성 검수 범위를 완료했다. 실제 영상 내용·사람 검수·기존 DB 통합의 완료가 아니다. [R4-3 결과](../08_검증결과/R4_03_보완결과와레드팀.md)를 참고한다. 다음은 R4-4 통합·이관이다. 사용자 좌표 기준 A(좌측 위 화면 경계 원점·raster px·픽셀 중심 0.5)를 반영했고 공간 supported 보류를 유지한다.


## R4-4 완료 판정

시간·근거·좌표를 새 v0.2 최소 기록에 연결했고, 구형 미완 자료5개는 사용자A의 원문·누락 접수함에 보존했다. 기본 도구/호환의 합성·독립 검수를 마쳤다. [최종 보고](../08_검증결과/R4_04_보완결과와레드팀.md)를 우선한다. 실제 영상 분석·내용/권한/회사 승인·R8 스킬 재평가는 후속 범위다.
