# 원문 위치와 조사 깊이의 보완

기존 스킬 파일대장544행(고유 경로+hash533조합)의 존재/byte해시를 대조했다. 이는544개 본문을 새로 읽거나544개 스킬을 새로 검토한 성적이 아니다.

- 540행은 원래위치에서동일hash다.
- 발표스킬 호스트캐시26.1011.11113의4파일은 기존경로가없었다. 현재26.1013.11914의대응파일4개가 기존hash와모두동일함을확인했다.
- 같은byte만별도backup에보존하고 [복구연결](원문경로_복구연결.json)로옛경로와이어두었다. 기존R3대장과원래깊이는변경하지않았다.

원문에 접근할 수 있다는 사실과 본문/참조/실행의 확인 깊이는 별개다. 캐시 버전이 더 새롭다는 이유로 해시가 다른 파일을 옛 원문으로 대체하지 않는다. 기존4개와 동일hash인 경우에만 현재복구사본으로 읽을 수 있다. 새원문실행·프레젠테이션제작·스킬활성화·전역설정/AE/Computer Use연결 변경은 하지 않았다. 호스트참조원문의 재배포라이선스 미확인상태도 그대로다.
