# R4·R5와 사람 검수 연결 사용 안내

2026-10-15. **별도 R6 문맥으로 기존 출처·검수 선언·R4/R5 계약의 현재 연결을 확인한다.** 기존 R4/R5 정본·예시·검사기와 세 스킬은 변경하지 않는다. 영상 분석이나 새 화면 제작 기능은 없다.

## 한 번에 확인하는 것

1. 원기록·원문 파일이 고정한 판본/hash와 맞는가: R6-2 검사.
2. 질문·대상·근거·실제 회신 원문·부분 확인·정정/철회가 현재 문맥과 맞는가: R6-3 검사.
3. 이 두 결과를 지금의 R4/R5 계약·한맥 정본·회사/자산 목록과 함께 사용해도 판본이 어긋나지 않는가: 별도 R6-4 입력 고정.

현재 조회는 **R4/R5 계약의 참조 동일성만** 확인한다. 실제 분석/적용 기록을 입력받아 R4/R5의 내용까지 검사한 결과가 아니다. 그런 기록은 각 기존 검사기를 별도로 거쳐야 한다. R4의 과거 review context는 R6의 회신·권한 맥락을 포함하지 않으므로 새 R6 입력 고정을 대신할 수 없다.

## 현재 자료를 읽는 법

- 8회사 CI는 ‘제공 자료가 모두 최신’이라는 사용자 확인이 접수됐다. 산하 AI원본 부재도 원문에 보존했다. 이는 원래 자료에 없는 파일을 새로 만들라는 지시가 아니다.
- 한맥 웹 정제본은 기존 정본과 원작업 JSON의 hash가 동일하다. 브랜드·명암 Storybook/강조·중립 Vercel, 전역 컬러 라이브러리/UI선택참고는 계속 유지한다.
- CI 세부 사용 조건(보호공간·최소크기·허용형·프로필 등)이 자료에 없으면 미상으로 남긴다. 이 미상은 한맥 디자인 시스템이 없거나 기존 내부 참고/초안 작업을 전부 중단한다는 뜻이 아니다.
- 조회가 통과해도 R4 spatial supported 보류, 사람 신원/내용 진실성, 회사/외부사용권한 승인, 실제 납품 품질을 자동 해제·승격하지 않는다.

## 실행과 결과

`07_실행도구/R6_통합조회.py --base "Phase 00의 절대 경로"`를 프로젝트의 기존 Python 환경으로 실행한다. CLI/API는 읽기 전용이다. 네트워크·미디어 디코더·AE·Computer Use·외부 스킬은 실행하지 않는다. 성공은 exit0, 실패는 exit1이며 JSON 진단을 반환한다.

`valid=true`와 `r4_r5_contract_references_current=true`는 지정된 연결이 현재 입력과 맞는다는 뜻이다. `actual_r4_r5_records_validated=false`, `actual_video_analyzed=false`를 함께 표시한다. 사람 대기의 covered는 확인한 범위의 **선언 기록**이며 실제 사람 신원/사실/회사 승인 인증이 아니다. 철회는 현재 covered에서 제외된다.

저장된 조회 JSON은 **생성 시점의 결과 사본**이다. `current_context_sha256`는 그때 확인한 입력 고정의 hash이며 현재도 유효하다는 보증이 아니다. 파일을 열어 보는 것으로 현재 판정하지 않고 조회 도구를 다시 실행해야 한다. 저장본은 실제 근거/회신 변경 시 자동 갱신되는 live 파일이 아니다.

## 자료가 바뀔 때

통합조회는 입력 고정을 자동 갱신하지 않는다. 정본/근거·질문·회신/철회·규격/검사 코드가 바뀌면 오래된 문맥으로 조회하지 않고 실패한다. 원문과 옛 문맥/대장/입력을 backup에 남기고, 달라진 범위·기존 선언의 적용 가능성을 사람이 검토한 뒤 새 버전의 기록/입력 고정을 만든다. 모든 과거 답변을 현재 것으로 자동 이동하지 않는다.

현재 사람 대장은 한 문맥에 한정된 접수·정정/철회 이력이다. 다른 대상/근거 판본의 옛 대장은 별도 snapshot으로 조회한다. 서로 다른 문맥을 한 대장에 섞어 현재 검수처럼 해석하는 기능은 구현하지 않았다. 파일 hash와 조회 시작/끝 대조는 시험한 변경 시점을 탐지하며 원자 잠금·서명·악의적인 검사기 교체 방어를 보장하지 않는다.

입력 고정의 기본 구조와 고정 파일 hash를 **스키마 해석 전에** 확인한다. 변경된 스키마를 먼저 실행해 해석하지 않으며, 외부 스키마 참조를 자동 조회/다운로드하지 않는다. URI를 해석할 수 없으면 구조화된 오류로 반환한다.
