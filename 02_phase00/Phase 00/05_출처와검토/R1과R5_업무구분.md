# R1과 R5의 업무 구분

R1은 자료가 어디에 있고 어떤 원본에서 왔는지 관리한다. R5는 그 자료의 디자인 기준을 영상 분석·기획에서 어떻게 참조하고 적용할지 정한다. 같은 정본 파일을 두 단계에서 참조하며 중복 복사하지 않는다.

| 자료와 작업 | R1 자산 관리 | R5 디자인 연결 |
|---|---|---|
| 한맥 디자인 시스템 | 정본 경로·프로필 버전·출처·조회 문서·해시 연결 | 컬러·타이포그래피·간격·표면 기준 정제, 참고/권고/필수 범위 구분 |
| 회사 CI·심볼 | 제공 원본·작업 사본·파생본 보존, 회사ID·버전·해시·backup | 회사별 CI색·언어/가로세로 변형·사용 규정과 실제 화면 역할 연결 |
| 문서의 명시색·형태 설명 | 근거 자산·원문 위치·초안 상태 보존 | 출처 권위·적용 조건을 확인해 디자인 기준으로 채택할지 검토 |
| 미확보 자료 | 없다는 상태와 추가 등록 방법 기록 | 해당 자산을 적용할 때 필요한 확인 조건 결정 |

**R1은 완료다.** 8회사 자산 관리와 정본/조회/버전 연결을 검증했다. 한맥 디자인 기준 정제는 이미 진행된 **R5 선행 산출물**이다. R5 전체 종료는 아직 아니다.

R5에서는 기존 한맥 정본을 출발점으로 생성기 경로, 영상 전용 미정 항목의 기록·검수 계약, 회사 CI와 화면 역할의 연결을 보완한다. R2에서는 디자인 값을 바꾸지 않고 영상·화면·모션을 부르는 용어와 분류 단위를 정리한다.
