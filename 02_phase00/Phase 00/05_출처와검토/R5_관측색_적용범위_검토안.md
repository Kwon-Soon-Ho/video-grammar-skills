# R5 관측 CI색의 화면 역할 적용 범위 — 4안 비교

2026-10-15. **사용자 A 확정(2026-10-15).** 디자이너가 명시 선택한 프로젝트 초안에서만 관측색을 역할 후보로 연결하고 출처·가정·검수 상태를 기록한다. 아래 네 안은 결정 당시 비교 이력이다. 이미 허용된 R1 관측색의 명시 조회를 재승인받는 질문이 아니다. 이번 결정은 ‘확인된 관측색을 새 화면의 배경/글자/강조 역할 후보로 얼마나 적극적으로 연결할지’다.

8회사 모두 기본 조회 조건을 만족하는 공식 화면색은 현재 0개다. 기존 래스터 관측 화면색은 명시 조회 가능하며, 벡터 CMYK/별색은 프로필/변환 근거 없이 HEX로 바꾸지 않는다. 삼안 선언 후보 4개는 검토 전 draft로 유지한다.

| 안 | 화면 역할 처리 | 영향 |
|---|---|---|
| A (추천) | 회사별 관측색을 디자이너가 명시 선택한 프로젝트 초안에서만 역할 후보로 사용. 출처/가정/선택 이유와 사람 검수 상태 유지 | 공식 가이드 미확보 상태에서도 기획 비교 가능. 자동 기본/공식 지정색·회사 승격은 하지 않음 |
| B | 공식 가이드 확인 전 관측색은 자료 조회만 하고 새 역할 후보에 연결하지 않음 | 보수적이나 시안 탐색의 활용이 늦어짐 |
| C | 현재 관측 sRGB색을 해당 회사 프로젝트의 기본 역할 후보로 자동 제안 | 반복 선택은 줄지만 대표 픽셀과 브랜드 역할 혼동 위험. 제안임을 표시하고 검수 전 확정 금지 |
| D | 한맥 공통 30색을 기본 화면 후보로 쓰고 회사 구분은 로고 위주로 처리 | 공통 템플릿 탐색이 쉽지만 가족사 고유 톤과 어긋날 수 있음. 회사 CI색으로 부르지 않음 |

모든 안에서 회사별 원본은 그대로 보존한다. 가이드 출처·회사/자산 pin, 원색/응용색 분리, 공식 미확인 상태, 화면 품질 검수는 유지한다. 사용자 선택은 프로젝트의 적용 정책이며 회사 공식 CI/법적 배포 승인으로 해석하지 않는다. A가 선택되어도 사람이 원문 내용·최신성·적용 범위 판단이 필요한 부분은 건너뛰지 않는다.

R5-1 자료 감사·누락 정리는 선택과 무관하게 진행한다. R5-2 역할 후보 계약은 사용자 A 범위에서 작성한다. 이 결정이 개별 시안·색 조합의 디자이너 검수나 회사 승인을 대신하지 않는다.
