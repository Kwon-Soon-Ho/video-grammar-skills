# 새로 확인한 모션 지식의 사용 범위 검토

이번에 IP-10 숙련도 역전 원칙의 2021 공식 Summary를 확인했다. 장 전체와 진단도구는 미검토다. UX in Motion 12개 항목의 공개 저자 텍스트도 확인해 기존 원칙과의 연결 후보를 작성했다. 모든 항목을 새 분류체계로 등록한 상태는 아니다.

기존 사용자 결정인 ‘초안 작성·검증, 의미 병합·회사 필수화·승인은 제안’은 그대로 유지한다. 아래 검토는 새 공식 근거를 확인한 뒤 **기본 조회와 지식 확장의 폭**을 정하는 것이다. 회사 규칙 승인이나 외부 코드 실행 허용을 묻는 것이 아니다.

| 선택 | 변경할 내용 | 장점·부담 |
|---|---|---|
| A · 조건부 참고와 기존 연결 (추천) | IP-10을 공개 Summary에 근거한 참고 지식으로 기본 조회에 포함. 숙련도 입력이 없으면 기권. UX12는 원문 항목을 보존하되 기존 AP/MP/MR 연결 후보로 사용하고 새 분류ID는 만들지 않음 | 영상용 해석을 활용하면서 체계의 중복을 줄인다. 본문 전체·실제 효과 검증 미완 표시는 유지 |
| B · 독립 체계로 확장 | IP-10 조건부 참고를 포함하고 UX12를 별도 지식ID·스키마·조회·검수표로 구축. 기존 체계와의 중복·역방향 연결도 검토 | 외부 체계 검색에 유리하나 유지·검증 범위가 늘고 의미 연결 검토가 필요 |
| C · 현재 조회는 유지 | IP-10 기본 제외 유지. UX12는 조사·설명용 후보만 보존. 기존42개 참고 원칙의 심화카드만 실무 참고 | 현재 계약 변경 최소화. 새 지식을 추천에 쓰려면 다시 검토 필요 |
| D · 상세 원문 확보부터 | 기본 활성화를 보류하고 IP-10 장 전체·MP 유료 강의 등의 상세 원문 확보·읽기 범위를 우선 협의 | 더 깊은 이론 비교 가능. 접근 권한·자료 확보가 필요하며 확보 없이 읽었다고 하지 않음 |

추천은 A다. 정보 전달형 회사 영상의 초기 지식 DB에는 요약 수준의 조건부 참고도 쓸 수 있지만, 숙련도 진단·이해도 개선·회사 필수화를 증명하는 자료로 쓰지 않는다. 실제 효과는 후속 영상 자료로 평가한다.

선택 전에는 기존 모션 정본·IP-10 대기 상태·분류ID를 변경하지 않는다. 레이아웃과 스킬 심층 검토는 별도 소단계다.


## 사용자 결정 반영

사용자가 A를 선택했다. IP-10은 공식 Summary에 근거한 조건부 참고로 기본 조회에 포함했다. UX12는 연결 후보이며 새 분류ID는 없다. 위 ‘선택 전’ 문구는 검토안 작성 시점의 조치다. 회사 필수화·실제 효과 승인은 하지 않았다.
