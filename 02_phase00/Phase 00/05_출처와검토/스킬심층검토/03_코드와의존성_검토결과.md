# 코드와 의존성 — 정적 검토 결과
외부 원본은 실행·설치하지 않았다. 아래는 읽은 코드의 동작 경로와 잠재 오용이며 재현 성공/실패 점수가 아니다.

| 대상 | 확인한 실행 경로 | 도입 판단 |
|---|---|---|
| Taste | Node22+·Chromium계열; draw는 .taste-skill 방향 파일, assets는 외부 아카이브와 이미지/영상 다운로드·credits 쓰기, inspector는 로컬 서버·새 임시 프로필·스크린샷 삭제/저장. 기본 라이브러리/본문 linter는 웹 house rule | 지식만 선별. 별도 browser 자기 process 관리 코드는 확인했으나 실행 테스트 없음. CU/AE 연결을 건드리지 않음 |
| Impeccable | Node CLI와 shell 런처가 별도 네이티브 바이너리를 내려받거나 실행. Node>=22.18, build는 Bun·개발 SDK·5 optional platform packages. release/clean·hooks·config·live·generate·환경 지정과 캐시 가지 존재 | 선택 참조만. Rust387/Cargo16·바이너리·lock 전체 미검토. required 미확보14, tree에도 없는 직접 import3 분리. fetch-engine의 checksum조회실패 허용은 런처의 신규 다운로드와 불일치 |
| Skill Creator | 고정 커밋 runner는 Claude CLI·표준Python subprocess/pipe·.claude/commands 임시파일·환경 인증 상속. 개선도 CLI 호출. viewer 기본3117·lsof listener SIGTERM·feedback쓰기·CDN/폰트; static 경로도 파일쓰기/외부표시의존 남음 | R8에서 Codex용 평가 경로 별도 설계. CLI/인증/timeout/pipe 오류를 정상False로 묶지 않음. 원본 viewer와 전체폴더 packaging 보류 |
| data-cleaning | 선택 Python profile/reconcile와 테스트는 표준 라이브러리. 입력samefile 보호는 있지만 다른 기존 output은 덮어쓰기. header/빈키/허용delta gate·JSON schema연결 없음 | 원본 도구를 DB gate로 쓰지 않음. flat JSONL profile과 CSV/TSV reconcile 구분; nested값·absent/null·메모리/스냅샷 제한 기록 |
| 디자인 명명/작성/검수 | 선택 작성/검수 본문은 지침, design-system 선택test는 최소 frontmatter 검사. critique CLI는 타깃폴더 복사/병합. 문서 지침도 에이전트를 통해 실제 쓰기를 요구할 수 있음 | 본문을 읽었다고 readonly권한이 보장되지는 않음. 정본·승인은 제안, draft 범위만 후속 구현 |
| PPTX 원본 | pptxgenjs/markitdown/Pillow/defusedxml/lxml·LibreOffice/Poppler 외부 실행, 원본덮어쓰기/clean삭제. soffice AF_UNIX 실패 분기의 gcc .so/LD_PRELOAD·캐시; 14파일전문(SKILL/LICENSE2+Python12), Python2부분·빈init1목록/해시, XSD39는참조구조만 | proprietary 제한으로 직접/파생 재구성 제외. 형식통과는 실제 PowerPoint/내용/회사승인 증거 아님 |

Skill Creator의 같은 test를 반복해 best를 고르는 구조는 선택용 validation이다. 최종 독립 test는 선택 뒤 새로운 자료로 수행한다. infra_error·미측정값·char/token·실제 run수를 별도 기록한다. 포장 대상은 allowlist staging으로 제한하고 symlink·비밀·산출물 포함을 검사해야 한다.

Taste 저자 benchmark의 마지막 평균7.7과 baseline7.8, 같은3brief 재사용·모델juror·한정 표본을 확인했다. house-rule0FAIL은 효과 증명이 아니다. 발표 전치 예의 Q4 Revenue180→98, 모션 예의 VO/transition 불일치·빈문자0·소수반올림·값초과/결측fill은 이식에서 제외한다.
