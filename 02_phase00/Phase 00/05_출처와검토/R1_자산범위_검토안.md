# R1 자산 관리 범위 검토안

목적은 원본과 파생자료·근거·분석 기록을 같은ID·버전으로 연결하고, 원본을 덮어쓰거나 파생물을 원본처럼 기록하는 오류를 막는 것이다. 실제 영상 추출·제작 자동화는01-A 이후다.

| 선택 | 관리 범위 | 영향 |
|---|---|---|
| A 추천 | 영상·시나리오·파생자료·분석 산출물을 먼저 연결. 로고·폰트·회사공용자산은 필요한 참조만 등록 | 초기 분석 자료의 추적을 충분히 설계하면서 공용자산 라이브러리 구축을 별도로 유지 |
| B | A에 더해 로고·폰트·이미지·도표의 회사공용자산 표준을 함께 구축 | 자산별사용조건·버전·역할·중복까지 검토하는 작업이 추가 |
| C | 영상·공용자산과 AE/3D/텍스처 등 제작 프로젝트 전체를 관리 | 도구별 의존·연결·패키징까지 포함해 R1의 범위가 넓어짐 |
| D | 별도 자산 계약을 두지 않고 기존 최소 기록의 asset 영역 안에 자료 연결을 확장 | 단순한 묶음을 유지하지만 여러기록의 같은원본/파생물 중복 관리 조건을 더 정해야 함 |

A안의 초안에는 자산ID·버전·역할·자료종류·등록상태·경로/해시·원본/파생관계·원문출처·작성/확인정보를 포함한다. 물리 원본 내용과 설명 메타데이터를 구분하고, 변경 전backup과 실행로그를 연결한다. 실제 파일·시간을 받지 않은 예는 설명용으로 표시하며 값을 발명하지 않는다.

소량 DB 정리의draft 권한, 의미병합·회사필수화·승인 제안정책은 유지한다. 한맥컬러·ID·프로필과 기존기록의참조를 이번계약설계에서 임의변경하지 않는다.
