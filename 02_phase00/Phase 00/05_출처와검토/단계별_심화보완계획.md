# Phase 00 단계별 심화 보완

2026-10-14 사용자 지시: 01-A로 넘어가지 않고 R단계 하나씩 작성·심층 검토·보완·보고한다. 여러 단계의 산출물을 한 번에 완료로 처리하지 않는다. 필요한 판단은 최소4지선다와 추천안으로 검토한다.

|---|---|---|
| R1 | 정본·자산 연결·ID/버전·원본/파생·backup·경로 계약 | 원본 변경, 파생자료 오인, 버전/해시 모순, 처음 보는 사람의 동선 |

## 스킬 심층 검토를 별도 수행

다운로드·파일 해시 확인, 심층 검토, 우리 시스템 적용, 맞춤 스킬 평가를 별개의 상태로 기록한다. 기존 원본 스냅샷과 세 맞춤 스킬은 보존한다. 시범 허용 결정은 조사·검토·성능 완료의 증거가 아니다.

외부 스킬 하나를 검토할 때:

1. 고정 커밋의 SKILL.md와 실제로 호출하는 참조 파일을 읽고 지침을 목록화한다.
2. 실제 호출 코드·설치 명령·외부 통신·쓰기 경로·도구 의존성을 따라 확인한다. 실행할 필요가 없는 후보는 원문을 실행하지 않는다.
3. 원문에서 요구하는 규칙과 우리 단계의 목적을 대조한다. 채택·변형·제외·보류를 지식ID/근거 파일·절과 연결한다.
4. 정보 전달형 영상에 맞는 적용 예·오용 반례·기권 조건을 만든다. 원본 영문폰트/웹px/랜덤 구도/카드금지/상시움직임을 법칙처럼 복사하지 않는다.
5. 이용 조건과 불명확한 확보 범위를 기록한다. 원문 내용 검토와 실행 성능 시험을 혼동하지 않는다.
6. 레드팀이 과잉 지침·누락·권한·근거·출력 계약을 검토한다. 변경 목적이 필요한 경우4지선다+추천안으로 사용자에게 제안한다.
7. 선택한 기능만 자체 지침으로 재구성하고 Anthropic Skill Creator로 비교·쓰기/보호/기권 평가 후 채택 여부를 검토한다.

한 저장소의 파일 수를 심층 검토 범위로 간주하지 않는다. 스킬별 기록에는 읽은 파일, 추적한 호출, 미검토 파일, 채택 근거와 평가 범위를 남긴다. 외부 스킬 전체를 동시에 활성화하거나 검토 전 실행하지 않는다.

## 현재 작업

R1은 완료했다. R1의 수행 순서는 현황 확인 → 범위 검토 → 계약/설명 예 → 기계 검사 → 별도 레드팀 → 보완 → 결과 보고였다. R2~R8의 정본·스키마·스킬 기능은 이번 차례에 함께 변경하지 않는다.


R1 종료 범위는 [종료 판정](../08_검증결과/R1_종료판정.md)을 따른다. 추가 자산 실물 수집을 단계 종료에 요구하지 않는다. R2는 별도 차례에서 진행한다.
