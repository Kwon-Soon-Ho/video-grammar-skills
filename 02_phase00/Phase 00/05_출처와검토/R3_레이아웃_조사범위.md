R3-1에서 확인한 Cambridge 정보 관련성·일시 정보 Summary 두 개를 재사용했다. 이번에 학술 장 전체를 새로 읽은 것으로 계산하지 않는다.

W3C KLREQ는2026-03-21 Group Note Draft다. 영상 글자 수·행간·최소px 표준으로 표시하지 않는다. Adobe 안전영역은 편집 도구의 조정 가능한 가이드이며 각 변 여백·서비스 UI 크기를 추정하는 근거로 쓰지 않는다.

Impeccable의2개 참조와shot-composition의entrypoint는 텍스트 대조만 했다. 호출 참조·코드·의존성·라이선스·실행 성능은R3-3에서 별도 검토한다. detector·설치·외부 통신·Computer Use를 실행하지 않았다.
