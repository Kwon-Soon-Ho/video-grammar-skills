| 스킬 | 무엇을 넣는가 | 입력 → 출력 | 넣지 않는가 |
|---|---|---|---|

## 공통 운영안
명시적으로 요청한 정리는 draft 생성·수정으로 진행하고, 의미가 달라지는 병합·필수화·회사 승인은 검토 제안으로 남긴다. JSON 정본을 검증하고 변경 전 자료는 backup에 보존한다. 서로 다른 용도의 원본 스킬을 통째 로드하지 않고 선별 참조를 사용한다.

## 테스트 예정
큐레이터: 동의어/다의어·웹 규칙의 영상 과잉 적용·출처 부족 항목을 구분하는가.
기록 관리자: 잘못된 token/ID/시간/승인·근거 누락·synthetic 예의 회사승인을 차단하는가.
검토자: 번호·카드·동시 등장·선형 모션을 이유 없이 금지하지 않고, 한글/데이터/시청 조건의 구체 문제를 지적하는가.

Anthropic Skill Creator의 초안→기본 비교→검수→수정→결과 보기 절차로 확인한다. 형식 검사 통과와 실제 영상 성능은 다르다. 실제 영상 성능은 01-A 이후다.
