## 블로그에서 그대로 옮기지 않은 내용

10개 항목명의 대응과 한국어 설명은 참고한다. 무거우면 항상 더 빨리 멈춘다는 설명은 힘·환경 조건이 빠져 있어 질량 법칙으로 등록하지 않는다. 두 배속과 출력 프레임레이트는 별개이므로 ‘24fps가 12fps로 바뀐다’를 기록 규칙으로 쓰지 않는다. 영상 데이터에서 실제 fps·타임스탬프·재생속도는 따로 확인해야 한다. 이것은 블로그의 모든 내용을 검증한 판정은 아니다.

## 깊이에 따라 가능한 주장

- 공개 본문: 읽은 절의 개념 요약과 적용 검토 가능. 이미지·임베드의 실제 동작 검증과 구분.
- 공개 학술 요약: 원칙의 요약 수준 확인. 효과크기·모든 경계조건·회사 영상 성과 보장 불가.
- 공식 강의 목록: 항목명과 순서 확인. 강사의 상세 설명을 검토했다고 표시 불가.
- 검색 추출: 조사 후보만 유지. 직접 본문 확인 완료에 포함하지 않음.

조사기록 JSON이 읽은 범위의 정본이다. remote_content_sha256은 null이며 원격 웹 내용 전체를 고정 보존했다는 뜻이 아니다. 자체 요약·조회본·변경 전 프로젝트 파일은backup에 보존한다.
