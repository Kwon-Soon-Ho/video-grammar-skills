# 구형 기록 접수함

새 통합 기록은 v0.2다. 이 폴더는 정보가 부족한 구형 원문을 **그대로 보존하고 누락·검토할 항목을 찾는 곳**이다. 분석/회사 문법 검색에서 제외한다.

각 폴더의 원문.json은 사본이고 접수기록.json은 원문 JSON hash·출처·누락·처리 이력이다. 원문 JSON hash를 영상 hash로 쓰지 않는다. 원래 파일과 과거 스킬 평가 자료도 유지했다. 상태 legacy_requires_mapping은 새 통합 규격에 맞춘 분석 기록이 아니다.
