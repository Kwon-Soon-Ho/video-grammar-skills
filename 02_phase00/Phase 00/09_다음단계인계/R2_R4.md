# R2의 의미기준을 R4에 연결할 항목

R2는 용어를 어느 대상·범위에 붙일지 정했다. 실제 영상 DB의 필드와 시간 검증은 R4에서 다룬다. 현재 최소기록 스키마와 설명용 예시를 R2 때문에 바꾸지 않았다.

| R2 의미기준 | 현재 기록과의 차이 | R4에서 연결할 일 |
|---|---|---|
| 전체영상 유형과 구간 역할 구분 | 현재 classification은 segments에 있음 | 전체영상/구간의 분류 범위와 참조 위치 |
| 화면 상태는 프레임 표본과 다름 | 별도 state 필드 없음 | 상태/대상영역/근거프레임의 최소참조 |
| 동작은 유지·정지 시간사건도 포함 | beats 있음 | 대상/관측량/시간범위, 상태교차·중첩 연결 |
| 한축에서도 관측과 구현기권은 별도주장 | 동일축의단순태그배열로는구분불충분 | 대상범위·주장범위·근거·미확정한계 |
| classified/unknown/비적용/후보/미검토 | 현재 empty배열+unclassified_reason과다름 | 의미상태와실제필드매핑. 배열자리에null 강제안함 |
| 시간곡선은 방향과속도크기구분 | 기존수치추정계약 있음 | 관측량·단위·시간표본·부호/반전의한계 |
| 복합/상하위태그는자동중복집계하지않음 | 상세집계계약미정 | 동일범위의기하/역할/상하위중복을어떻게조회할지 |

[R2 운영규칙](../01_공통용어/분류운영규칙.json)과 [용어판정기준](../01_공통용어/용어판정기준.json)을 입력으로 삼는다. 설명용분류사례는R2전용연습형식이며R4실제영상기록으로그대로복사하지않는다. 실제동작추출/측정/분류구현은01-A다.
