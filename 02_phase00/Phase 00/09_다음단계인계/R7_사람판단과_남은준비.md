# 사람 판단과 남은 준비

2026-10-15 · 실제 검수 요청을 접수한 대장이 아니라 다음 작업용 준비 안내다. 현재 새 R7 내용 검수 대상/답변은 없으며, 기존 R6 CI 최신성 실제 회신1건과 구분한다.

## 이미 정해진 내용

- 항목별 판정·해당 목적의 준비 제안, 단일 품질 총점 없음.
- 예비 자료로 기준 보정 후 다른 원본 묶음의 잠금 자료 확인. 수치는 예비 후 검토.
- R7 별도 연결 목록·인계 문서와 읽기 전용 확인 도구. R4/R5/R6의 규격 유지.
- 기존 세 스킬 목적·draft 권한·소량 시범의 A 승인 유지. 같은 사항을 재승인받지 않는다.
- 제공CI 8회사 최신성·산하 Illustrator 원본 부재는 사용자 확인. 추가 가이드/색 프로필/개별 사용 조건·회사 승인은 확인 범위를 넘는다.

## 자료가 생기면 넘기지 않고 요청할 내용

| 계기 | 누구에게 무엇을 확인할까 | 확인 전 처리 |
|---|---|---|
| 기술 수치·문구·제작 의도가 충돌/근거 부족 | 실제 내용 담당자에게 대상·버전·원문/시각·쟁점을 제시 | 내용 판단보류. 화면에서 보이는 관측과 기술 사실을 분리 |
| 가독성·모션/정보 흐름에 실제 시청 판단 필요 | 디자인 담당/필요 시청자에게 출력 환경·질문·근거 제시 | 설계 제안만 기록. 사용자 확인을 받지 않고 시청 검수 통과로 만들지 않음 |
| CI 보호공간·사용형/프로필·자료 사용권한이 실제 사용에 필요 | 해당 가이드/권한 담당자에게 적용 범위 확인 | 미확인 항목을 분리. 안 쓰는 자산 때문에 전체 일괄 차단하지 않음 |
| 예비 후 표본·시행·오차·평가 수치 결정 | 근거·부담·대안 최소4개와 추천안으로 사용자 검토 | 수치는 미정 유지. 잠금 전에 결정·버전 고정 |
| R8에서 목적·권한·회사 필수화 변경 필요 | 구체 변경안 최소4개와 추천안을 사용자에게 제시 | 승인된 draft 범위만 수행. 승인/의미 병합은 제안으로 남김 |

답변은 확인한 대상·버전·판단 범위만 기록한다. 부분 확인/모름/기권·정정/철회도 보존한다. 내용에 대한 실제 답변은 자유 서술과 근거를 받아야 하며, 선택지를 근거 없는 승인 유도로 쓰지 않는다. 운영 방식의 판단에는 최소4지선다·추천안을 제공한다. 이 준비 안내를 작성했다는 사실만으로 R6 새 접수/회신이나 회사 승인이 생기지 않는다.

다음은 R8 스킬별 재구성·시험·레드팀과 Phase 00 전체 종료 검토다. 실제 자료가 없는 점은 향후 실평가 준비 과제로 남기며 R7의 기준/연결 설계 완료와 혼동하지 않는다. 01-A는 별도 지시 후 시작한다.
