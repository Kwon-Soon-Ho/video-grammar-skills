# Phase 01-A 영상·시나리오 자료 준비

지금은 Phase 00 종료 보완이 남았다. 자료 정리는 병행할 수 있다. 아래는 앞으로 쓸 구조 제안이며 실제 입력 영상이나 폴더를 받았다는 뜻이 아니다. 이 안내·양식은 Phase 00/09_다음단계인계에 있다.

## 먼저 준비할 최소 한 묶음

1. **최종 영상 1개:** 최초 분석용 대표작을 원래 파일 그대로. 메신저 재압축본·화면 녹화 대신 가능한 최종 납품/배포본 MP4 또는 MOV. 전체 영상을 유지하고 분석 관심 구간을 메모한다.
2. **해당 버전의 시나리오 또는 콘티:** 원본 DOCX/XLSX/PPTX/PDF/TXT 등 있는 형식 그대로. 여러 버전이면 최종 영상과 연결된 버전을 표시한다. 시나리오를 새로 완성 영상에 맞춰 고치지 않는다.
3. **짧은 자료 설명:** 프로젝트명, 제작일/버전(모르면 미정), 영상의 목적·대상·실제 배포/시청 환경, 최종본 여부, 시나리오 일치 여부, 확인 담당자, 특히 보고 싶은 구간과 이유.

이 세 가지가 최소다. 시간표·FPS·해상도·PTS·해시·OCR·장면별 캡처를 사용자가 수작업으로 만들 필요는 없다. 기술 정보 추출과 프레임 생성은01-A에서 내가 수행한다. 날짜·버전·수치·승인을 모르면 미정으로 남긴다.

시나리오가 없으면 없다고 표시해도 된다. 영상 관측·실제 발화/화면 문구를 대체 입력으로 분석할 수 있지만 원래 제작 의도를 확인한 것으로 기록하지 않는다. 시나리오와 영상이 다르면 그 차이가 분석 대상이다. 자동 전사·OCR을 원래 시나리오와 같은 파일로 덮어쓰지 않는다.

## 권장 표본 묶음

먼저 1편으로 입력·시간·보고서 경로를 교정한다. 이후 추가1~2편으로 다른 유형/정보 관계를 비교하고, 그중 일부는 개선에 쓰지 않은 검증용으로 남긴다. 이는 출발 제안이며 강제 개수나 모든 과거 영상의 수집 요구가 아니다.

- 첫 후보: 글자·도표·모션이 함께 있는 기술 설명/업무 안내 영상. 순차·비교·전체/상세 등 몇 가지 관계가 포함되면 좋다.
- 추가 후보: UI 시연·성과 보고·회사 소개 등 첫 영상과 정보 구조가 다른 작업.
- 검수자: 화면/모션을 볼 디자인 담당과 내용·기술 사실을 볼 담당을 표시한다. 한 사람이 겸할 수 있으나 판단 종류는 기록에서 구분한다.

## 있으면 도움이 되는 선택 자료

| 자료 | 용도 | 없을 때 |
|---|---|---|
| 실제 내레이션 대본·SRT/VTT | 영상과 원래 시나리오의 대응 확인 | 영상에서 전사 후보 생성 후 검수 |
| AE 프로젝트·원본 이미지/도표/3D·연결 자산 | 관측 수치·실제 제작 설정 대조 | MP4에서 보이는 변화만 분석. 원본 Scale/opacity/ease 수치 단정 금지 |
| 최종 피드백·버전별 수정 요약 | 선택의 이유·실패 조건 확인 | 실제 제작 의도는 미확정 |
| 로고 원본·폰트명·기존 자막/안전영역 가이드 | 알려진 회사 조건 연결 | 새 회사 규칙을 임의 생성하지 않음 |
| 좋았던/문제였던 구간3~5개 메모 | 01-A 정답 검수의 출발 | 상세 시간표는 분석 결과를 보며 함께 표시 |

프로젝트 원본은 선택사항이다. 원본을 넣는다면 상대 경로를 유지해 연결 자산이 깨지지 않게 보관한다. 폰트명·라이선스 파일은 보유한 것만 넣으며 새 폰트 설치를 준비 조건으로 삼지 않는다.

API 기반 처리에 필요한 입력 조건으로 자료별 외부 모델 업로드 가능/불가/확인필요를 자료설명에 표시한다. 확인되지 않은 제한 자료를 사용 가능으로 가정하지 않는다. 분석기는 이 입력 조건에 맞춰 사용할 경로를 결정한다.

## 프로젝트 루트 아래의 권장 폴더

```text
2026-10-02_AI 기반 영상 기획·제작 스킬 체계 개발 및 검증/
├─ 00기획/
├─ Phase 00/
└─ Phase 01-A/
   ├─ 00_진행안내/
   ├─ 01_입력자료/                    ← 사용자가 준비
   │  ├─ 영상001_프로젝트명/
   │  │  ├─ 00_자료설명.md
   │  │  ├─ 01_최종영상/
   │  │  │  └─ 영상001_최종_v01.mp4
   │  │  ├─ 02_시나리오/
   │  │  │  ├─ 원본_시나리오_v03.docx
   │  │  │  └─ 시나리오정리.csv        ← 선택
   │  │  ├─ 03_내레이션과자막/         ← 선택
   │  │  ├─ 04_프로젝트원본과자산/     ← 선택, AE 등 원래 연결 유지
   │  │  ├─ 05_검수메모/               ← 선택
   │  │  └─ 06_회사디자인참고/         ← 해당 프로젝트의 추가자료만
   │  └─ 영상002_프로젝트명/
   ├─ 02_분석작업/                    ← 내가 생성
   │  └─ 실행001_영상001/
   │     ├─ 01_입력목록과환경/
   │     ├─ 02_추출프레임/
   │     ├─ 03_전사와화면문구/
   │     ├─ 04_구간과시나리오대응/
   │     ├─ 05_관측기록/
   │     └─ 06_근거와실행로그/
   ├─ 03_분석스킬/
   ├─ 04_검증자료/
   │  ├─ 교정용_합성자료/             ← 내가 제작, 사내사례와 분리
   │  ├─ 사람검수_정답/
   │  └─ 추가검증_보류표본/
   ├─ 05_결과보고/
   └─ backup/
```

**사용자는01_입력자료의최종영상·시나리오·자료설명만먼저준비하면된다.** 선택 폴더는 자료가 있을 때 사용한다. 02_분석작업 이하를 수작업으로 채울 필요는 없다. Phase 00의 사전·한맥 정본은 이 폴더에 복사해 독립 수정하지 않고 ID와 버전으로 참조한다.

위 파일명은 권장 예시다. 원래 파일을 바꿔야 하는 의무는 없다. 원래 이름을 유지해도 자료설명에 최종본과 대응 버전을 분명히 적으면 된다. 수정본은 덮어쓰기보다 v02 등 새 버전으로 보존한다.

## 01-A 시작 순서

00의 시간·분류·검수 계약을 보완 → 입력 묶음 확인 → 도구/모델/API 경로 결정 → 분석 스킬 초안 → 대표1편과교정fixture로기본검증 → 추가표본/사람검수 → 분석정확도평가. 회사 문법의 승인·전역 디자인 수치 확정은01-B다.
