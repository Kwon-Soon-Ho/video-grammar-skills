# R7 이후 읽는 순서와 다음 작업

2026-10-15 · R7 연결·인계의 현행 사용 안내. 최종 완료 여부는 [진행 현황](../01_진행현황.md)을 확인한다. Phase 00 전체와 R8은 아직 완료되지 않았고 01-A도 시작하지 않았다.

## 처음 보는 사람의 읽는 순서

1. [Phase 00 진행 현황](../01_진행현황.md)에서 완료 범위·실제 자료 미확보를 확인한다.
2. [R7 판정 운영](../13_품질검수/03_판정운영기준.md) → [조건부 품질 항목](../13_품질검수/04_품질항목_읽는순서.md)을 읽는다. 26항목은 목적에 따라 적용하며 단일 품질 총점은 없다.
3. [평가 계획](../13_품질검수/06_평가계획_읽는순서.md)에서 정답·예비/잠금 표본·분모·보류·사람 의견 차이를 확인한다. 현재 실제 정답/시행/성적은 없다.
4. [기존 기록 연결 규칙](../13_품질검수/연결과인계/03_검수와보류_연결규칙.md) → [현재 연결 확인 사용법](../13_품질검수/연결과인계/04_연결확인_사용안내.md)을 읽는다. 저장된 검사 결과와 지금 실행한 결과를 구분한다.
5. 다음 작업에 따라 [R8 스킬 재구성 인계](R7_R8_스킬재구성_인계.md) 또는 [01-A 구현 전 인계](R7_01-A_구현전_인계.md)를 읽는다. 실제 자료·사람 판단은 [남은 준비](R7_사람판단과_남은준비.md)를 따른다.

## 자료의 기준 위치

| 자료 | 기준 파일 | 읽는 의미 |
|---|---|---|
| 품질 항목 | [품질항목 정본](../13_품질검수/품질항목_정본.json) | 조건·근거·예·반례·보류·사람 역할 |
| 평가 설계·지표 | [평가설계 정본](../13_품질검수/평가계획/평가설계_정본.json), [지표 정의](../13_품질검수/평가계획/지표정의_정본.json) | 실행 전 계획이며 자동 평가기가 아님 |
| 기존 기록 위치 | [연결표](../13_품질검수/연결과인계/기존기록_연결표.json) | 22필드 위치·26항목 연결 후보. 실제 근거 목록 아님 |
| 실제 검수 전 준비 | [빈 검수 양식](../13_품질검수/연결과인계/품질검수_작성양식.json) | 실제 대상 없이 승인/판정이 생기지 않는 템플릿 |
| 현재 파일 식별 | [정본 연결목록](../00_운영계약/정본과표시_연결목록.json), [버전목록](../05_출처와검토/버전목록.json) | ID·버전·경로·SHA. 등록이 회사 승인은 아님 |

현재 인계는 로컬 기존 규격·사용자 결정·R7 원문 근거를 연결한 결과다. 새 외부 이론을 조사했거나 모든 기존 파일의 의미를 다시 정독했다고 주장하지 않는다. 과거 단계 보고서는 그 시점의 이력으로 보존하고 현재 진행 판정은 시작 안내/진행 현황을 우선한다.
