# R4 통합 규격과 스킬 호환 인계

새 기본은 v0.2다. 4단위·5판정·시간·근거·좌표·run/metadata·한맥/분류 pin·통합 검수 context를 사용한다. 구형 정보 부족 자료는 11_기록접수함에 원문과 누락 목록으로 보존했다. 실제 회사 영상 기록은 아직 없다.

R8은 세 스킬의 역할/초안 권한을 유지한 채 새 기본 입출력 계약과 구형 기권을 반영해 Anthropic Skill Creator로 재구성·평가한다. 기록 관리자는 구형을 가짜 hash/시간/화면 상태로 채우지 않고 접수/준비 대기로 인계해야 한다. 두 검수 스킬도 관측·계획·추론과 내용 검수 대기를 구분한다. 기존 본문·참조·평가 원문을 덮어쓰거나 과거 평가 성적을 새 규격 성적으로 재사용하지 않는다.

이 변경은 승인된 시범 목적·권한을 다시 묻는 것이 아니다. 구형 기록을 쓰는 흐름은 새 규격과 호환 검수 전까지 접수/기권 경로를 사용한다. 신규 v0.2의 자동 쓰기 시범 검증은 R8 잔여다. 로그·원문/변경 전 backup·검증은 계속 필수다.

01-A는 실제 영상·시나리오를 입력받아 원본 메타/PTS·프레임·OCR/대상·좌표·모션을 추출/분석하고 사람 정답으로 정확성을 검증한다. 현재 제공한 통합 설명 예시는 합성 계약 설명이며 실제 추출 결과가 아니다. Phase 00의 R5~R8 잔여를 마치기 전 01-A로 넘어가지 않는다.
