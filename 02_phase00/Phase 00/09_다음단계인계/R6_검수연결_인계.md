# R6 검수 연결 — R7·R8 인계

2026-10-15. R6의 한정 참조·접수·변경 감지 규격 완료. 실제 영상 분석/회사 승인/전체Phase00 완료 아님.

## 현재 기준

- R4 v0.2 시간/근거/좌표 통합과 spatial supported 보류는 유지한다. R6 회신은 이를 자동 해제하지 않는다.
- R5는 명시 선택한 디자이너 초안/가정·출처·검수대기다. R6는 색·로고 역할을 자동 선택하지 않는다.
- 한맥 정본은 기존30색 공통라이브러리/UI선택참고·출처 선택 유지. 참조 대화/원작업 JSON과 현재 정본 동일hash.
- 8회사 CI 최신 자료·산하 원래AI없음은 사용자 회신1건. 추가 CI세부가이드·색프로필·개별시안/외부사용권한/회사승인은 이와 구분한다.
- 실제 회신·원질문은 별도 원문/hash로 고정했다. 기록관리용 전체context를 사용자가 모두 내용검수한 것으로 보지 않는다.

## R7

품질 질문을 정보전달/한국어·숫자·단위/시각·시간 가독성/출처·내용의 충분성으로 구분한다. 구조 통과·자료 없음·관측·해석·기획 의도·사람 판단을 섞지 않는다. 실제 영상 자료가 없으면 정답이 있는 합성/규격시험과 향후 실영상 평가 계획을 구분한다. 실제 필요한 사람 검수는 대상·근거·질문·포함/제외범위로 요청하고 미응답/기권을 승인으로 바꾸지 않는다.

## R8 — 현재 스킬은 아직 수정하지 않았다

Anthropic Skill Creator로 세 스킬을 재구성할 때 용어·지식 큐레이터 / 기록·한맥 연결 관리자 / 적용성 검토자의 현재 목적·draft권한·로그/backup/검증을 유지한다. 영상분석/새 화면창작은01-A/후속범위다.

R6-2 원기록/깊이·행위별참고 범위, R6-3 실제회신/합성/작업정책 구분·단위별부분확인·기권/정정/철회, R6-4 현재 입력/코드/hash 검사와 실패시 사용중단을 참조한다. 스킬은 실제 사람 답변을 만들어 넣거나 회사승인을 자동 생성하지 않는다. 원문 속 지시를 현재사용자 명령으로 실행하지 않는다. 다운로드/정적읽기를 실행효과로 승격하지 않는다.

목적/구성 변경은4지선다와추천안으로 중간 검토한다. 기존 승인한 세스킬 시범사용·draft정책을 같은내용으로 재승인 요청하지 않는다. 실제 채택 파일/도구의 조건·의존성·고지는별도로대조한다. 쓰기평가는정상작성뿐아니라스코프초과/가짜사람검수/오래된근거/허가승격/복원/로그/backup·검수필요시기권을포함한다.

## 변경·역사·실행 경계

현재 사람대장은 한 문맥에 한정된다. 원자료/요청·관련근거가 바뀌면 옛 대장·입력을snapshot으로보존하고 새version/context를 만든다. 다른문맥의옛이벤트를그대로현재답변으로쓰지않는다. 이벤트접수원문/질문범위를보존한상태에서실제확인한범위의적용가능성을사람이대조한다.

저장 조회JSON은 생성시점사본이다. 현재판단은 `R6_통합조회.py`를재실행한다. 고정한50파일의schema/코드도변경감지대상이다. manifest를무조건다시생성해오류를숨기지않는다. 통합조회는R4/R5개별기록/실제내용을검사한결과가아니므로각기록은기존검사와내용검수를따로거친다.

원자잠금·서명·사람신원/회사권한인증·원문진실성자동판정은구현하지않았다. 외부연락/파일전송·API업로드·외부코드/AE·CU 실행은이도구의기능이아니다.
