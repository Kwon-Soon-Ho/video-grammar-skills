# R7 품질 검수 기준과 평가 준비

2026-10-15. **R7-1~4 판정 운영·조건부 품질 지식·평가 계획·연결/인계와 독립 검토의 한정 범위 완료. 전체 Phase 00은 R8/최종 종료 검토가 남아 있으며 01-A는 미진행이다.**

R7은 결과를 무엇으로 검수할지 정하는 단계다. 정확한 기록과 좋은 영상은 서로 다른 질문이다. 잘못 만든 원본 영상을 정확히 분석한 기록은 분석 정확도에서 통과할 수 있고, 보기 좋은 영상을 근거 없이 분석한 기록은 분석 신뢰도에서 수정이 필요할 수 있다.

| 단계 | 쉽게 말하면 | 조사·정리 | 끝내기 전 확인 |
|---|---|---|---|
| R7-1 현황·판정 기준 | 무엇을 검수하고 어떤 상태로 기록할까 | 기존 R3~R6/옛시험과 미정 대조, 검사 대상/필수 근거·판정/심각도·사람역할 | 실제 근거 없이 통과/낙제·회사승인을 만들지 않는지 독립 레드팀 |
| R7-2 품질 항목·적용 예/반례 | 어떤 오류를 어떤 조건에서 볼까 | 정보/한국어·숫자단위/무음·자막/가독성/모션·시간/브랜드·출처 조건, 적용·제외·보류 예 | 원칙을 전부 의무화하거나 웹 px/자막초수/스코어를 회사값으로 만들지 않는지 레드팀 |
| R7-3 평가 계획 | 만든 기준과 향후 분석 스킬을 어떻게 시험할까 | 규격시험/사람판단/실영상 성능을 분리, 정답/불일치·개발/잠금표본·지표/분모·재시험 계획 | 합성시험을 실영상효과로 쓰지 않고 누락·기권·미상·유출을 구분하는지 레드팀 |
| R7-4 연결·인계 | R8과01-A가 그대로 쓸 수 있나 | 근거/버전·대기·수정/중복·현재/과거 연결, 읽는 순서/최종 보완보고 | R4/R5/R6/세스킬 불변·R8로 스킬 수정 인계·01-A 구현 제외 검토 |

한 단계 작성→레드팀→보완→재검토→보고 후 다음 단계로 간다. 영상 추출/OCR/모션분석/모델API/새화면 제작·렌더·스킬 재구성은 하지 않는다. 현재 실제 영상/시나리오는 없으므로 검수 기준/합성 설명/실평가 준비를 만든다. 실제 내용/시청품질 판단이 필요한 항목은 구체 자료/사람 질문으로 남긴다.

## 기존 기반을 이어 쓰기

- R3 원칙/레이아웃의 적용 조건·반례는 품질 질문의 근거다. 개수만큼 의무 검사하지 않는다.
- R4 시간/근거/좌표·통합기록과 R6 출처/사람회신은 기존 계약을 사용한다. 구조 통과를 내용 진실성으로 바꾸지 않는다.
- 한맥 공통 컬러/선택UI와 R5 초안 정책, 8회사 최신CI/산하AI원본부재 확인을 유지한다. 미정 자막/보호공간/영상글자 수치를 임의로 채우지 않는다.
- 과거보고의26+추가13 구조검사·스킬11/12동률·쓰기시범8조건은 당시 조건의 기록이다. 새 품질 기준/실영상 성능을 검증한 것으로 합산하지 않는다.
