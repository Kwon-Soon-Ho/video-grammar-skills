# 판단보류·비적용·미채점의 처리

2026-10-15 · 평가 계획. 항목별 통과/수정필요/보류/비적용은 R7-1을 유지하고 아래는 평가용 구분이다.

## 보류를 잘하는 능력과 답하는 능력은 함께 본다

| 상황 | 모델에 기대하는 행동 | 평가 |
|---|---|---|
| R_A: 충분한 허용 입력과 확정된 기준답안 | 필요한 내용을 근거와 함께 답함 | 명시 보류는 오답 단정과 구분하지만 정답 산출로 세지 않음. 커버리지·전체 발견율에 남김. |
| R_H: 원본만으로 제작 구현/의도를 알 수 없음, 또는 필요한 입력이 없음이 확인됨 | 확인 가능한 관측은 유지하고 단정할 수 없는 부분·이유·필요 사람/자료를 밝힘 | 적절한 보류인지 사람 루브릭으로 평가. ‘모름’ 한마디나 실행 실패를 성공 보류로 세지 않음. |
| R_U: 평가자도 아직 기준답안을 만들지 못했거나 의견 충돌 미해결 | 정오를 평가할 수 없음 | 확인된 별도 근거 없이 모델의 답/보류를 정답으로 확정하지 않음. 자료 품질/검수 대기 수를 공개. |
| R_N: 실제 해당 없음이 확인됨 | 이유와 적용 범위를 밝혀 비적용 | 미상·자료 없음과 구분. 적용 대상인데 비적용으로 숨기면 부당 제외로 기록. |
| 출력 누락·도구/파싱 실패 | 실제 상태와 실패 범위를 보고 | 명시적 판단보류의 성공으로 보지 않음. 누락/실패·재시도 기록을 보존. |

R_H에서는 판정 단위를 미리 고정하고 단위당0/1로 집계한다. 적절한 보류율=근거/범위/필요 확인을 충족하고 근거 없는 단정이 섞이지 않은 단위 수 / 검수된 R_H 단위 수. 근거 없는 단정률=정당화 못하는 확정 주장이 하나라도 있는 단위 수 / 같은 R_H 단위 수다. 같은 단위에 올바른 보류와 근거 없는 단정이 섞이면 적절 보류 성공은0이고 단정 위반은1이다. 실제 단정 개수/유형은 별도 건수로 남기며 비율 분자에 더하지 않는다. 단위당 여러 단정을 내도 위반률이100%를 넘지 않게 한다. 나머지 누락/실패·부분 적절·잘못된 비적용도 숨기지 않는다. R_H 자체의 이유·실제 판단 상태가 검수되지 않았다면 먼저 R_U다. R_U는 두 지표의 분모에 임의 포함하지 않는다.

정답이 확인된 R_A에서 많이 보류하는 문제와, 보류해야 할 R_H에서 아는 척하는 문제는 다른 실패다. 후자가0이라고 전부 보류하는 시스템을 유용하다고 판정하지 않는다. 반대로 커버리지가 높아도 근거 없는 단정이 있으면 해당 필수 기준의 보완이 필요하다. 우선순위/허용 부담 수치는 예비 후 사람이 검토하며 둘을 하나의 가중 점수로 상쇄하지 않는다.

## 보류 항목에 묶을 정보

대상ID/버전·과제/항목·확인된 부분과 보류 부분·근거/반대 근거·부족한 입력·판단 범위·사람 역할/질문·중요도·접수 상태·재검수 조건을 남긴다. 실제 대상 없이는 준비 템플릿이다. 답변이 오면 확인한 범위만 그 버전에 연결하고 회사 규칙/권한 승인으로 확대하지 않는다. 미응답/해석 불일치/오래된 근거를 자동 통과시키지 않는다.

사람 답변으로 내용이 확인돼도 구조/시간·좌표의 필수 누락을 우회할 수 없다. 반대로 비공간 문서 전사에 필요 없는 좌표를 만들지도 않는다. 필요한 근거의 종류·정밀도는 주장/검수 목적에 맞춘다.

## 가상 반례

- 같은 부품이 움직이는 두 표본만으로 AE parent라고 확정 → 의도/구현의 근거 없는 단정 후보. 실제 연동 관측은 별도 보존.
- 정답이 확인된 오류 항목 모두를 보류 → 잘못된 통과는 없더라도 정답 산출/오류 발견 성공은0, 커버리지0. 서비스 성능 합격이라고 하지 않음.
- 애매한 사람 정답5건을 평가에서 조용히 삭제 → R_U5건의 중요도·제외 사유·전체 분모·부분 판정 범위를 공개해야 함. 이5건을 맞혔다고 세지 않음.
- 시간 제한으로 출력이 안 나옴 → 실패/미완료. 적절한 내용 보류가 아님.
- 무음 여부를 확인하지 않고 자막을 비적용 처리 → 부당 제외 후보. 실제 입력/요구 확인이 필요하며 모르는 상태를 무음으로 고정하지 않음.

이 예들은 설계 설명이고 실제 모델 시행 결과가 아니다. 각 보류의 정당성은 실제 근거로 사람에게 맡긴다. [공통 운영](../03_판정운영기준.md) · [지표와 분모](03_지표와_분모.md).
