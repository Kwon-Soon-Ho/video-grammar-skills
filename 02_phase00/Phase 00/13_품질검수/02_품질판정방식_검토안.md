# R7 품질 판정 방식 — 4안 비교

2026-10-15. **사용자가 A를 선택했다.** 아래는 선택 당시4안 비교 이력이다. 기존 스킬 draft권한·R5 관측색·R6 대화접수 방식을 재승인받는 질문이 아니다. 새 품질 기준을 어떤 상태/종합 방식으로 운영할지 정한다.

| 안 | 방식 | 장점/부담 |
|---|---|---|
| A (추천) | 항목별 통과/수정필요/판단보류/비적용. 핵심 정보 오류·근거/사람검수 보류는 다른 장점으로 상쇄하지 않고, 적용 대상에 맞춘 준비상태를 제안. 단일 총점 없음 | 이유·근거·부분확인이 보이고 임의 점수보정이 적음. 실제 최종판단과 승인 주체는 별도 |
| B | 항목 판정과 핵심 조건은 유지하고 가독성/완성도 등의 점수 요약도 병행 | 비교표가 쉬우나 점수척도·가중치·검수자 보정을 추가로 정해야 함. 점수로 핵심 오류를 통과시키지 않음 |
| C | 항목별 결과만 제공하고 종합 준비상태는 항상 사람이 작성 | 자동 종합 판단을 최소화하지만 매번 종합 검토 담당자가 필요 |
| D | 한 영상유형/업무의 검수표를 먼저 고정하고 적용 검토 후 공통 규격 확장 | 초기 범위가 작지만 다른 영상유형으로 확장 전 추가 작업/검증 필요 |

모든 안에서 분석기록 정확도와 원본영상/기획물 품질을 구분한다. 합성예·관측자료·실제기획안·최종영상은 적용 항목과 필요한 근거가 다르다. 확인되지 않은 제작 의도/시청효과는 확인된 사실로 쓰지 않는다. 회사 규정의 공식화·실제 납품 합격점은 이번 선택 대상이 아니다.

A의 준비상태 제안도 자동 승인/회사 통과 판정이 아니다. 핵심 오류가 확인됐으면 수정 제안, 필요한 근거/사람 판단이 없으면 판단보류로 남긴다. 심각도는 미관 취향이 아니라 해당 목적에서 발생하는 정보 손실/오해의 영향으로 설명한다. 비적용에는 이유를 적고, 아직 모른다는 이유로 비적용을 선택하지 않는다. 중복 오류는 같은 원인/대상으로 연결하고 임의 감점 합산하지 않는다.


레드팀 보완: D는 대상/진행순서를 좁히는 안으로 A~C의 종합방식과 축이 달랐다. D가 선택됐다면 한 유형의 항목판정/종합판정 유보 등 운영방식을 추가로 정해야 했다. 실제로는 A가 선택됐으므로 이번 진행 범위/판정에는 영향이 없다. 원래 질문과 사용자 A답변은 변경하지 않는다. 핵심/사람보류의 반영은 현재 목적에 적용되는 필수항목에 한정한다.
