## Q-BRAND-01 · 회사·CI 원형·사용형

- **검수 질문:** 올바른 회사의 제공 자산/허용 사용형을 참조하며 원형·법인명을 보존하는가?
- **적용 조건:** 회사명/로고/심볼을 사용하는 화면.
- **필요 근거:** 회사ID·제공 자산/버전·사용형·최종 표시, 해당 보호공간/반전형 등의 근거.
- **검토 방법:** R6 현재 최신성 확인과 R5 세부 미정을 구분. ㈜장헌/장헌산업 병합 금지. 원형 변형·재생성 없이 자산 대조.
- **적용 예:** 8회사 자료를 별도 참조하고 산하는 제공된 원본 형식을 보존해 프로젝트 배치 검수한다.
- **오용·실패 반례:** 산하에 AI원본이 없으니 가짜 원본을 만들거나 로고를 흰색으로 바꿔 공식 반전형으로 등록한다.
- **허용 예외·비적용:** 로고 미사용이면 해당 적용 항목 비적용. 제공/허용된 변형형은 근거 연결 후 가능.
- **판단보류 조건:** 실제 적용 버전·사용형/보호공간·법인 대응이 없으면 해당 적용만 보류. 최신 자료인지 반복 질문하지 않음.
- **영향·우선순위:** 회사 혼동/원형 훼손 우선 수정. 최신성 확인은 배포·세부가이드 승인 아님.
- **사람 검수:** 디자인 검수자·해당 사용규칙 확인 담당자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** R4/R5/R6 또는 공통 운영 기준. 새 R3 분류를 만들지 않음.

## Q-BRAND-02 · 웹 참고·CI 관측색·역할

- **검수 질문:** 한맥 웹색·CI 관측색·화면 역할의 출처와 선택 조건을 구분했는가?
- **적용 조건:** 회사 디자인 참조/색을 새 화면에 적용하는 초안.
- **필요 근거:** R5 프로필·색 출처/가정·프로젝트 명시 선택·색관리/합성 조건·역할·실제 시안.
- **검토 방법:** 공통 웹 컬러/선택 UI·공식색·관측색을 구분. 관측색 역할 후보는 디자이너 명시 선택 초안 범위에서만 사용하고 대비/가독성 별도 검수.
- **적용 예:** 한맥 웹Green과 로고 관측색을 서로 다른 출처로 기록하고 선택한 초안의 강조색 후보로 검토한다.
- **오용·실패 반례:** 웹Green을8회사 공식CI색으로 복사하거나 CMYK를 단순 계산해 공식HEX로 확정한다.
- **허용 예외·비적용:** 웹 UI 참고를 사용하지 않는 구도도 가능. 공식 화면색/허용 조합은 실제 가이드 근거가 있을 때 추가 연결.
- **판단보류 조건:** 명시 선택·출처/프로필·역할 조건이 없으면 적용 적합성/공식성 판정 보류. 단순 관측 값 자체는 보존.
- **영향·우선순위:** 출처/권위 혼동을 방지. CI색 대비를 이유로 원본 자동 재색칠 금지.
- **사람 검수:** 프로젝트 디자이너·필요시 브랜드 규칙 담당자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** R4/R5/R6 또는 공통 운영 기준. 새 R3 분류를 만들지 않음.
