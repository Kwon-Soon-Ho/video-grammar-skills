# 자막·전달 경로 — 항목별 품질 기준

2026-10-15 · 품질항목 정본 v0.1.1에서 만든 읽기용 문서. 실제 검수 결과·회사 의무 규정이 아니다. 적용 예/반례는 모두 가상 설명이다. 각 항목은 적용 여부를 먼저 정하고 [공통 판정 운영](../03_판정운영기준.md)을 따른다. 원문 요약과 우리 프로젝트의 적용 해석을 구분한다.

## Q-CAP-01 · 음성·소리의 자막

- **검수 질문:** 이해에 필요한 발화·화자·비언어 소리가 자막에 정확히 전달되는가?
- **적용 조건:** 음성/의미 있는 소리가 있고 자막으로 그 정보를 전달해야 하는 영상.
- **필요 근거:** 실제 오디오·자막·화자/소리의 의미·목적·자막 요구.
- **검토 방법:** 전 구간의 필요한 음성/소리를 자막과 대조. 자동 생성 여부나 단어 개수만으로 승인하지 않음.
- **적용 예:** 공정 중 경보가 의미 있는 경우 경보의 발생과 해당 발화를 적절한 자막으로 전달한다.
- **오용·실패 반례:** 자동자막에 부정어가 빠졌거나 필요한 화자 전환/경보를 누락해도 생성 완료라며 통과한다.
- **허용 예외·비적용:** 소리가 오직 의미 없는 배경음악이거나 순수 무음이면 발화 자막 비적용 가능. 그 사실 확인 전에는 비적용 불가.
- **판단보류 조건:** 오디오/자막/청취 조건 또는 소리의 의미가 없으면 해당 정확성·누락 판정 보류. 자막 요구가 미확인이면 필요 여부를 확인하고, 자막이 없다는 이유만으로 비적용 처리하지 않음.
- **영향·우선순위:** 오해/청각·무음 조건 정보 손실. WEB-CAP을 한국어 속도 규격으로 전용하지 않음.
- **사람 검수:** 자막 검수자·소리 의미를 아는 내용 담당자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** IP-03, IP-08

**원문 근거와 가져오는 범위**

- [W3C WAI Captions/Subtitles](https://www.w3.org/WAI/media/av/captions/) · Introduction; Does My Media Need Captions?; Automatic Captions are Not Sufficient; Positioning and Styling Captions. 음성·의미 있는 소리의 자막과 자동자막의 오류 가능성을 설명한다. 음성 자동전사를 내용 승인으로 취급하지 않는다. 한국어 CPS·최대 줄 수를 정하지 않는다.
- [04_모션원칙_충돌과예외](../../02_원칙과레이아웃/04_모션원칙_충돌과예외.md) · MC-01~08 전체. 기존 프로젝트의 조건부 지식·기록·사용자 확인 범위 과거 단계의 후보/미확인 도입부는 작성 당시 이력. 현재 상태는 R6 확인 현황과 진행 현황을 함께 따른다. 구조/정적 검사를 내용/회사 승인으로 확대하지 않음.

원문의 개별 수치/사례를 회사 기준으로 자동 채택하지 않는다. 위 적용 예·검토 질문·보류 조건은 우리 프로젝트의 설계이며 원문이 이 가상 사례를 직접 검증했다는 뜻이 아니다.

## Q-CAP-02 · 자막 동기화·지속·가림

- **검수 질문:** 자막이 해당 발화·사건과 대응하고 실제 읽을 시간·공간이 확보되는가?
- **적용 조건:** 자막이 있는 렌더/영상. 시안은 배치/예정 타이밍만 검토.
- **필요 근거:** 실제 자막/오디오/영상의 공통 시간축, 발화 구간, 전환·가림·플레이어 UI, 시청 조건.
- **검토 방법:** R4 시간축으로 시작/종료 대응을 확인하고 완성된 문구의 읽는 구간·다른 핵심정보와의 가림을 전 구간 확인.
- **적용 예:** 화자 전환과 자막 대응을 유지하고 도면의 부품 번호를 가리지 않는 위치를 확인한다.
- **오용·실패 반례:** 자막이 다른 부품 설명까지 남거나 등장300ms를 긴 자막의 충분한 읽기시간으로 인정한다.
- **허용 예외·비적용:** 의미 보존을 검수한 분절/요약·위치 이동은 가능. 모든 서비스에 같은 하단 안전영역을 강제하지 않음.
- **판단보류 조건:** 해당 판정에 필요한 공통 시간축·대응 근거(원본 PTS/시각 변환은 확보 범위 기록)·실제 자막/발화·배포 UI가 없으면 그 정밀도/범위의 시간·가림 판정 보류. 제한 구간의 수작업 관측은 보존하되 스틸로 동기화 통과, 미상 시간의 임의 추정, R4 필수값/검사 우회는 금지.
- **영향·우선순위:** 잘못된 대상 대응·정보 손실. 시간 허용오차와 CPS는 사전 검토 전 null.
- **사람 검수:** 자막/디자인 검수자·필요시 실제 시청자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.

## Q-CAP-03 · 무음·시각 대체·감각 단서

- **검수 질문:** 사용 조건에서 필요한 정보를 소리·색·위치 한 가지에만 의존하지 않는가?
- **적용 조건:** 무음/청각·시각 접근 요구가 있는 제작물. 요구 범위가 불명확하면 먼저 확인.
- **필요 근거:** 사용 환경·접근 요구·필수 메시지, 시각/음성 정보 목록과 실제 대체 경로.
- **검토 방법:** 음성 정보의 자막과 시각 정보의 설명을 별도 확인. 자막이 있다는 이유로 시각 대체까지 해결됐다고 하지 않음.
- **적용 예:** ‘초록색 끝’에 명칭/형상 단서를 더하고, 무음용에는 필요한 발화를 텍스트로 전달한다.
- **오용·실패 반례:** 중복을 줄인다며 무음용 핵심 문구를 지우거나 색 변화만으로 합격/불합격을 구분한다.
- **허용 예외·비적용:** 별도 자막/설명 트랙 또는 본문에 통합된 설명도 요구와 플레이어 지원을 충족하면 가능.
- **판단보류 조건:** 배포 환경·요구·대체 자료 접근성이 미확인이면 해당 전달 보장만 보류. 전체 접근성 인증은 하지 않음.
- **영향·우선순위:** 특정 사용 조건에서 핵심 정보에 접근하지 못할 위험.
- **사람 검수:** 기획 책임자·디자인/접근성 검수자·필요시 대상 사용자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** IP-03, IP-08

## Q-CAP-04 · 발화 명료성·음악 경쟁

- **검수 질문:** 실제 청취 조건에서 기술명·수치·지시를 알아들을 수 있는가?
- **적용 조건:** 음성 설명이 의미 전달의 일부인 영상.
- **필요 근거:** 실제 오디오와 재생 조건, 대본·명칭 발음 근거, 배경음악/효과음, 청취 검수.
- **검토 방법:** 발음·속도·겹침·잘림·배경음 경쟁을 실제로 듣는다. 파형/전사만으로 청취 명료성을 통과시키지 않음.
- **적용 예:** 가상 공법명과 수치를 내용 담당자에게 확인하고 최종 음악과 섞인 상태에서 청취한다.
- **오용·실패 반례:** TTS 생성 완료만으로 고유명사 발음을 통과시키거나 자막이 맞으니 묻힌 음성을 무시한다.
- **허용 예외·비적용:** 확인된 무음 전용 출력은 발화 명료성 비적용. 대본/계획 검토로 렌더 오디오까지 통과하지 않음.
- **판단보류 조건:** 음성·장치/환경·발음 근거가 없으면 해당 청취/발음 판정 보류.
- **영향·우선순위:** 수치/지시 오인 위험. 회사 LUFS/dB 기준은 이번에 만들지 않음.
- **사람 검수:** 내용 담당자·오디오/영상 검수자·필요시 실제 시청자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** R4/R5/R6 또는 공통 운영 기준. 새 R3 분류를 만들지 않음.
