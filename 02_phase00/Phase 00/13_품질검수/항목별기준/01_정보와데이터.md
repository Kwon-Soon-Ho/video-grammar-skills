2026-10-15 · 품질항목 정본 v0.1.1에서 만든 읽기용 문서. 실제 검수 결과·회사 의무 규정이 아니다. 적용 예/반례는 모두 가상 설명이다. 각 항목은 적용 여부를 먼저 정하고 [공통 판정 운영](../03_판정운영기준.md)을 따른다. 원문 요약과 우리 프로젝트의 적용 해석을 구분한다.

## Q-INFO-01 · 목적·대상·전문용어

- **검수 질문:** 이 화면에서 누구에게 무엇을 이해시키려는지, 용어 설명 수준에 근거가 있는가?
- **적용 조건:** 기획/시안/실제영상의 전달 목적을 검수할 때. 분석은 목적이 제공됐을 때만 목적 적합성까지 판단.
- **필요 근거:** 버전이 정해진 브리프/시나리오, 필수 메시지, 해당 주제의 시청자 사전지식 근거, 시청 환경.
- **검토 방법:** 필수 메시지와 화면·발화의 대응을 확인하고, 모르는 전문용어가 설명 없이 전제되는지 본다. 직급으로 지식 수준을 추정하지 않는다.
- **적용 예:** 신입 교육이라는 확인된 목적에 따라 침투수 용어를 먼저 정의하고 공법을 소개한다.
- **오용·실패 반례:** 기획실이면 모두 비전문가라며 근거 없이 설명을 유아화하거나 전문어를 임의 삭제한다.
- **허용 예외·비적용:** 해당 기술을 아는 대상이라는 근거가 있으면 짧은 전문 용어 중심 요약도 가능.
- **판단보류 조건:** 목적/필수 메시지/사전지식이 없으면 성공·난이도 적합성만 보류. 보이는 정보 자체는 기록.
- **영향·우선순위:** 핵심 메시지 누락은 목적 수행에 영향. 설명 취향 차이는 별도.
- **사람 검수:** 기획 책임자·해당 주제 담당자; 필요시 실제 대상 시청자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** IP-01, IP-07, IP-10

**원문 근거와 가져오는 범위**

- [W3C WAI Audio Content and Video Content](https://www.w3.org/WAI/media/av/av-content/) · Audio: clear speech / processing time / clear language / sensory characteristics; Video: overlay text / description. 발화 명료성·처리 시간·용어 설명·감각 단서의 중복을 다룬다. 실제 청취를 대신하지 않으며 소리 크기·읽기 속도의 회사 수치는 채택하지 않는다.
- [모션원칙_심화카드](../../02_원칙과레이아웃/모션원칙_심화카드.json) · 선택 카드 AP-01/03/04/06/09/10; IP-01~10; MR-01~08; ACC-01~03의 기존 적용 조건 참고. 연결 ID는 각 항목의 knowledge_refs에서 특정. 기존 프로젝트의 조건부 지식·기록·사용자 확인 범위 과거 단계의 후보/미확인 도입부는 작성 당시 이력. 현재 상태는 R6 확인 현황과 진행 현황을 함께 따른다. 구조/정적 검사를 내용/회사 승인으로 확대하지 않음.

## Q-INFO-02 · 원문·부정어·수치 일치

- **검수 질문:** 표시문구·음성·시나리오의 부정어·소수점·이름·단위가 필요한 의미를 보존하는가?
- **적용 조건:** 수치·기술문구·고유명사·중요 지시가 있는 기록/기획/영상.
- **필요 근거:** 원문과 정정 이력, 실제 화면·청취 가능한 음성, 동기화된 시나리오, 값의 출처.
- **검토 방법:** 원문 전사와 제작용 수정 제안을 분리하고 차이 위치를 적는다. 원문끼리 다르면 권위 있는 버전을 내용 담당자에게 확인.
- **적용 예:** 가상 원문 0.25 m가 화면·음성에서 같은 의미로 유지됐는지 대조하고 수정 제안은 별도 표시한다.
- **오용·실패 반례:** 0.25를25로 옮기거나 ‘하지 않는다’의 부정을 삭제하고 글자가 예쁘다는 이유로 통과시킨다.
- **허용 예외·비적용:** 의미가 같은 요약/정정은 담당자 확인 근거와 버전을 남겼을 때 허용. 분석 원문을 몰래 고치지 않음.
- **판단보류 조건:** 음성만 없으면 음성 일치성만 보류. 시나리오와 원본 충돌/판독 불가이면 해당 내용 보류.
- **영향·우선순위:** 핵심 수치·부정 반전은 우선 수정/확인. 관측과 사실 정확도는 별도.
- **사람 검수:** 기술/업무 내용 담당자·자막 검수자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** R4/R5/R6 또는 공통 운영 기준. 새 R3 분류를 만들지 않음.

## Q-INFO-03 · 비교 조건·전후·인과

- **검수 질문:** 두 대상의 조건이 대응하며, 전후 차이를 입증되지 않은 개선·인과로 확대하지 않았는가?
- **적용 조건:** 공법/성과/비용/전후 사진·도표를 비교하거나 인과 화살표를 사용하는 경우.
- **필요 근거:** 비교 데이터·대상·기간·분모·단위·촬영조건, 관계의 출처, 원본 화면.
- **검토 방법:** 동일 항목 대응과 조건 차이 표기를 확인. 좌우 배치나 시간 순서만으로 실제 인과를 인정하지 않음.
- **적용 예:** 같은 부위 사진의 촬영각 차이를 밝히고 관측 가능한 외관 차이와 성능 주장을 분리한다.
- **오용·실패 반례:** 조명·배율이 다른 사진을 효과 입증으로 쓰거나 단위가 다른 값을 같은 크기의 성과로 비교한다.
- **허용 예외·비적용:** 조건이 다른 비교도 차이를 밝혀 설명용으로 쓸 수 있으나 동등성/인과를 주장하지 않음.
- **판단보류 조건:** 원자료·조건·관계 근거가 없으면 우열/개선/인과 판정 보류. 비교 배치 관측은 남김.
- **영향·우선순위:** 과장된 개선·잘못된 의사결정 위험. 외형 대칭 여부로 대체 불가.
- **사람 검수:** 기술/데이터 담당자·기획 책임자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.

## Q-INFO-04 · 결측·추정·카운트 값

- **검수 질문:** 실측·예측·결측·연출 중간값을 구분했는가?
- **적용 조건:** 시계열·수치 카운트·보간·효과 시뮬레이션이 있는 화면/분석.
- **필요 근거:** 데이터 버전·실측/추정 표기·결측 구간, 실제 재생과 최종값, 연출 목적.
- **검토 방법:** 값의 종류와 시간 대응을 확인. 화면 카운트 중간값을 실제 연도 값으로 저장하지 않음.
- **적용 예:** 가상 최종 실적100만 제공됐다면 등장 카운트의37은 연출값으로 구분하고 최종100과 단위를 확인한다.
- **오용·실패 반례:** 결측을0으로 채우거나 움직이는 숫자를 전부 실제 중간 실적으로 기록한다.
- **허용 예외·비적용:** 검토된 예측/보간 모델을 명시하고 실측과 시각적으로 구분하면 추정 표시 자체는 금지하지 않음.
- **판단보류 조건:** 종류/모델/최종값 출처가 없으면 실측 주장 보류. 보이는 숫자 관측은 유지.
- **영향·우선순위:** 허위 시계열·실적 과장 위험. 연출을 금지하는 항목은 아님.
