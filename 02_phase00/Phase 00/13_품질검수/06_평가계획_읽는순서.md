# R7-3 평가 계획 읽는 순서

2026-10-15 · **평가 계획과 독립 정적 검토 범위 완료.** 실제 자료 확보·사람 기준답안·수치 합의·잠금 통제·실행 성적은 아직 없다. R7은 기준·계획·연결/인계의 한정 범위 완료이며 전체 Phase 00은 R8/최종 종료 검토가 남아 있다. 01-A는 미진행이다.

사용자 선택 A: **예비 자료로 기준을 보정 → 다른 원본 묶음의 잠금 자료로 확인.** 표본 수·반복 수·허용오차·합격 수치는 예비 근거를 제시해 이후4지선다·추천안으로 검토받는다. 기존 단일 품질 총점 없음·핵심 오류/필요 사람 검수의 비상쇄 원칙은 유지한다.

평가 설계 데이터는 [평가설계 정본](평가계획/평가설계_정본.json), [지표 정의](평가계획/지표정의_정본.json), [26항목 평가 준비표](평가계획/항목별_평가준비표.json)다. 준비표26행은 실제26과제/정답이 아니며 실제 자료 연결은 비어 있다. R7-2의 조건부 항목 전체를 모든 영상에 일괄 의무화하지 않는다.

구조/기록 계약, 영상 분석 정확성, 지식 적용 검토, 실제 전달/업무 효과는 서로 다른 평가다. 현재 검토는 평가 계획의 정합성과 경계에 관한 것이다. 평가기·모델/API·영상/OCR·스킬 재구성은 실행하지 않았다. 실제 모델 성적·두 사람의 실제 합의/계수·시청/시간 개선을 만들어 기록하지 않는다.
