# 사람 검수 준비 목록

현재 실제 검수 대상·영상·시나리오가 없으므로 **실제 접수·사람 검수 0건**이다. 아래7개 묶음은 접수 준비 템플릿이다. 자료가 들어오면 적용되는 항목만 실제 대상 버전·위치·근거·판단 범위와 연결하고 사람에게 질문한다. 질문을 만들었다는 사실을 답변/승인으로 적지 않는다.

운영 선택이 필요하면 최소4지선다·추천안을 제시한다. 개별 내용 질문은 실제 근거와 함께 자유 답변/추가 자료도 받을 수 있게 한다. 미확인·반대 근거·기권을 기록하고 확인한 범위만 보존한다. 회사/사용 권한 승인은 내용 검수와 구분한다. 외부 담당자에게 메시지를 보내는 승인은 이 준비에 포함하지 않는다.

원본 자료가 없어도 기획 검토는 가능한 범위에서 진행한다. 반대로 시안만으로 실제 자막 동기화/청취/섬광 검사까지 통과시키지 않는다. 현재 단계는 구체 자료가 없는 판단을 넘겨 통과시키는 대신 **실제 검수 미실시·필요 입력**으로 남긴다.
