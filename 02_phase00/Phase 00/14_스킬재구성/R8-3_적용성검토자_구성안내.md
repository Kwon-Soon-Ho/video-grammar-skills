# R8-3 — 적용성 검토자

2026-10-15 · 기존 목적/draft 검토 권한을 유지하는 재구성 후보다. [R8-2 실제 회신](사람피드백/R8-2_기록관리자_검토답변.json)은 구성·분량 유지와 R8-3 진행만 확인한다.

쉽게 말해 이 상황에 어떤 기준이 필요하고 왜 맞거나 맞지 않는지 설명하는 검토 담당자다. 예쁘게 만드는 작업/영상을 읽어 측정하는 작업은 하지 않는다.

[후보 SKILL](../06_맞춤스킬/재구성후보/video-guidance-reviewer/SKILL.md)에 대상·근거·선정·조건·결과/사람 질문·쓰기 범위를 담고, 참조 두 개에 근거 찾기와 항목별 판정/사람 검수를 나눴다. R7 조건부26항목을 전부 의무화하지 않고 총점을 만들지 않는다. 확인 가능한 오류는 지적하고 근거 없는 판단만 보류한다.

1. 기존 지침·R3~R7·원문 확보/이식 범위를 대조하고 후보 정적 레드팀을 받는다.
2. 같은 요청/같은 분리 사본에서 새 후보와 기존 버전을 비교한다. 한국어/수치/무음·회사 CI 확인 범위·외부 지침/출처 충돌의 개발 사례를 사용한다.
3. 실제 출력·입력 보존·출처/판본·사람 질문과 보류 범위를 독립 검토하고 공식 정적 뷰어로 사람 피드백을 받는다.

합성 개발 검토이며 영상 분석/측정·실제 가독성·회사 승인·R8-4 새 미사용 사례와 통합/전환은 별도다. 원격 원문을 다시 열거나 외부 코드를 실행한 것으로 보고하지 않는다.
