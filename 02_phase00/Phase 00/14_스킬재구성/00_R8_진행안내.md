**한 스킬의 초안·시험·레드팀·보완 보고와 사람 피드백을 먼저 다룬 뒤 다음 스킬로 넘어간다.** 같은 목적/draft 권한/기존 소량 시범 A는 다시 승인받지 않는다. 새 목적·의미 병합·회사 필수화·운영 범위 판단에는 최소4지선다와 추천안을 제시한다.

## 파일 위치

기존 [세 스킬](../06_맞춤스킬/00_스킬안내.md)은 R7 고정 입력이므로 유지한다. 새 후보는 `06_맞춤스킬/재구성후보/<동일 스킬명>/`에서 작업한다. 새 버전 후보가 있다는 사실을 기본 전환·전역 설치·운영 승인으로 해석하지 않는다. R8 마지막에 실제 비교 결과/피드백을 바탕으로 색인·기본 사용 위치·새 조회 문맥을 검토한다. 기존 고정 목록을 자동 재생성해 어긋남을 숨기지 않는다.

시험은 각자 분리된 사본에서 동일 요청/동일 입력으로 수행한다. 편집기능 시험에는 읽기 전용 검토 외 실제 draft 파일 변경도 포함한다. 정본/원본/다른 파일의 무단 변경, version/hash/근거·로그/backup·실패와 복구를 확인한다. 개발용·도전/회귀 사례와 미사용 확인 자료를 구분하며 공개한 예를 잠금 자료라 부르지 않는다.

각 결과에는 초안/정적 검사/합성 행동 시험/사람 평가/실영상 효과의 구분과 미실시 범위를 표시한다. 성공한 시행만 남기거나 실험 점수를 회사 영상 품질 총점으로 합치지 않는다. 실행 token·시간이 실제로 제공되지 않으면 null/미수집으로 남긴다. Claude CLI 기반 자동 트리거 최적화는 실행하지 않으며, 단순 설명문 정적 대조를 실제 자동 호출률로 제시하지 않는다.

## 비교 조건과 측정 한계

old/new 실행 에이전트는 부모 대화 없이 같은 모델/설정·같은 요청/입력/도구·권한으로 시작한다. 상대 스킬·예상 답안/채점표·레드팀 결론은 열람하지 않는다. 기술적으로 파일 접근을 완전히 차단한 별도 계정은 아니므로 지시상 격리와 실제 파일/실행 로그 대조의 한계를 기록한다. 평가 사본에서 두 버전 모두 같은 상대 위치에 스킬을 두어 경로 이동 자체가 baseline 실패 원인이 되지 않게 한다. 후보/구버전 중 하나만 절대 경로로 읽고 전역/자동 발견 설정을 바꾸지 않는다.

동시 실행 슬롯 제한 때문에 사례별 old/new 쌍을 함께 실행한 뒤 다음 쌍을 실행할 수 있다. 각각 별도 입력 사본/출력 디렉터리를 사용한다. 이를 서로 독립인 새 에이전트 실행으로 기록하고 한 에이전트의 앞선 시행 대화가 다음 사례에 전달되지 않도록 한다.

설치본 aggregate_benchmark.py는 token 미수집 시 출력 문자 수를 대신 쓰고, 시행 수 기본값/구성 순서를 가정한다. 이 값을 실제 token/반복 수/새-구 개선량으로 사용하지 않는다. 공식 집계 형식은 호환 참고이며 프로젝트 결과 정본은 실제 관측수·미수집null·실패/보류·명시 비교 방향을 기록한다. 출력 검토는 공식 generate_review.py의 --static 경로를 사용하고 UTF-8 환경/원문 표시 대조를 수행한다. 시간/token이 없으면 뷰어에도 해당 통계를 넣지 않는다.


## 첫 출력 뷰어의 표시용 사본 검증

설치본 뷰어의 원래 template에는 외부 Google Fonts/SheetJS 참조가 있고, embedded JSON을 script에 직접 넣는다. 정적 생성만으로 완전 오프라인/문자열 안전 표시가 보장되지는 않는다. 이번 MD/JSON 시험은 공식 도구로 만든 원본을 backup에 보존한 뒤, 별도 표시용 HTML에서 불필요한 외부 font/script 참조를 제거하고 embedded JSON의 `<` 등 script 종료 경계 문자를 이스케이프한다. JSON을 해독한 원문 내용은 같아야 하며 실제 시험 출력은 수정하지 않는다. 표시 전 외부 요청 참조가 없고 한국어·소수/단위·script 종료 문구가 데이터로 유지되는지 대조한다. 미수집 통계 객체는 뷰어에 넣지 않는다.

이 제한된 표시 가공은 새 제품/대체 뷰어 개발이 아니라 기존 공식 정적 뷰어의 시험용 사본에 적용하는 호환 조치다. 원본/가공 사본·도구/LICENSE·차이와 검증을 보존한다. 사람의 실제 피드백은 뷰어 생성/AI 검사와 별도로 접수한다.
