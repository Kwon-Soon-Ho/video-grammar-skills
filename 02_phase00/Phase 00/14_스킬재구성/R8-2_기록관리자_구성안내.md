# R8-2 — 기록·한맥 연결 관리자

2026-10-15 · 기존 역할과 draft 수정 권한을 유지한 재구성 후보다. 큐레이터의 구성·분량 유지/R8-2 진행 회신은 [실제 답변](사람피드백/R8-1_큐레이터_검토답변.json)에 기록했다. 첫 스킬의 기본 전환이나 R8 전체 승인은 아니다.

쉽게 말해, 기록의 번호·버전·연결이 맞는지 확인하고 **요청한 부분만 고치면서 원본을 지키는 담당자**다. 시간·좌표 값을 새로 알아내거나 화면을 제작하지 않는다.

[후보 SKILL](../06_맞춤스킬/재구성후보/video-record-steward/SKILL.md)에 작업 루트·허용 변경·원본 값 보존·R4/R5/R6/R7 역할·실제 쓰기/실패·보고를 담았다. 세 참조는 기록 연결 기준, 수정/백업/복구, 결과 보고로 나눴다. 기존 스킬·정본·고정 목록은 유지한다.

진행은 현행 대조 → 후보 정적 레드팀 → 격리된 동일 자료의 구/신 실행 → 실제 파일·backup·diff·검사 결과 독립 채점 → 공식 결과 뷰어/레드팀 → 사람 출력 피드백 순서다. 정상 수정, backup 실패, 실패한 초안의 checkpoint 복구를 개발 과제로 다룬다. CI 최신 회신을 새 승인으로 쓰지 않는지도 확인한다.

수행 사본에서는 평가 설계·스킬 평가/이식 문서·다른 실행 결과를 분리하고 포함/제외 목록·원문 SHA를 보존한다. R4/R5 검사에 필요한 등록 자산·코드·규격은 포함한다. R6 full 원문 검사와 R7 전체 고정 문맥은 해당 수행 사본의 범위 밖이며 D 운영의 별도 정상 결과를 사본 통과로 전용하지 않는다. 이 역할별 개발 시험은 R8-4 미사용 사례 확인을 대신하지 않는다.

R8-3·R8-4/기본 전환·01-A 구현은 아직 시작하지 않는다.
