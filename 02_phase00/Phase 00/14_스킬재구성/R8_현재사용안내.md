# R8 현재 사용 안내

2026-10-15 · R8-1/2/3 출력 구성 유지 회신을 접수했고, R8-4와 전체 재검수/2차 보완의 한정 기술검수를 종료했다. [최종 결과](../08_검증결과/R8_04_통합검증/00_최종보고.md)를 확인한다. 후보 기본 전환·회사 승인·실영상 효과/포괄 Phase00 승인은 별도이며 01-A 구현은 시작하지 않았다.

먼저 [현재 진행 현황](../01_진행현황.md)을 읽는다. 과거 단계 보고는 그 당시의 상태다. 처음 결과보고를 봉인한 뒤 받은 회신은 [R8-1 현재안내](../08_검증결과/R8_01_큐레이터/01_회신이후_현재안내.md)·[R8-2 현재안내](../08_검증결과/R8_02_기록관리자/01_회신이후_현재안내.md)·[R8-3 현재안내](../08_검증결과/R8_03_적용성검토자/01_회신이후_현재안내.md)와 실제 회신 대장에 분리했다. 봉인보고·receipt·기존 출력/채점은 보존한다.

## 어떤 규격을 쓰는가

기본 기록은 R4 통합 v0.2다. [현재 상태 정정표](현재상태_정정표.json)는 고정 원문의 path/SHA·결정 근거를 함께 확인한 경우에만 적용한다. 옛 '후보/전환 후속'·'state 필드 없음'은 당시 상태 표시다. 정정표는 원문과 규격을 수정하거나 회사 규칙/권한을 만드는 문서가 아니다. 원문 또는 판단 근거 파일이 없거나 SHA가 다르면 해당 정정만 보류한다. 사본의 자료 부족을 다른 안전한 한정 작업의 전체 차단으로 확대하지 않는다.

의미 단위 네 개는 영상·설명 구간·화면 상태·짧은 동작이다. 이를 배타적인 4층 트리로 저장하지 않는다. 현재 예시는 `/spatial_contract/evidence_contract/targets`에 단위를 두고 `/units`의 `target_ref`와 `related_state_refs`로 연결한다. 화면 상태와 동작은 segment에 연결하며 동작은 여러 상태를 가로지를 수 있다. 프레임은 표본이다.

R7→R8 인계의 “아직 재평가하지 않음”도 그때의 상태다. 고정 문서를 단독으로 읽어 현재 단계 완료/미완료를 추정하지 않고 이 안내·진행 현황·정정표의 범위와 근거를 함께 확인한다.

## 스킬과 검사 범위

기존 기본 경로는 `06_맞춤스킬/<스킬명>`이다. 새 후보는 `06_맞춤스킬/재구성후보/<스킬명>`의 명시 경로로만 확인한다. 후보를 기본 경로에 덮거나 전역 설치하지 않는다. 큐레이터는 지식 초안, 기록 관리자는 기록/참조/복구, 검토자는 적용성·근거/예외/사람 질문을 맡는다. 수정/의미병합·공식화/승인은 별개다.

R6 현재 출처/회신 조회와 R7 고정 연결 조회는 기존 문맥을 읽는다. R7의 옛 스킬/평가계획 pin을 새 후보로 교체하지 않는다. 역할별 행동 시험은 평가 자료를 분리한 사본에서 하며 full 원문 고정조회 사본과 구분한다. full 구조조회 통과가 실제 영상·내용·후보 행동 통과를 뜻하지 않는다.

옛 `R3_스킬자료검사.py`는 설치본 presentations의 이전 절대경로를 직접 검사해 실패할 수 있다. 현재 복구별칭/원래 SHA의 출처 현재성은 `R6_출처사용검사.py`와 `R6_통합조회.py`로 확인하고, 옛 도구의 오류를 숨기거나 원문 목록을 재고정하지 않는다. R3의 자연어 지식/라이선스 의미까지 자동 재검수한 것은 아니다.

실행 전 도구의 실제 루트 결정과 출력 경계를 확인한다. 지정 Python은 `-B`/UTF-8로 실행하며 읽기 전용 사본에는 `__pycache__`나 기본 출력 파일을 만들지 않는다. `--base` 지원 여부는 도구마다 다르므로 확인 없이 공통 인수처럼 사용하지 않는다. 옛 시험 도구의 D 절대경로를 그대로 둔 채 격리 시험이라고 부르지 않는다. stdout/API 결과는 명시 결과 폴더에 저장하고 실행 인수·종료·미실시를 남긴다.

## 미정 자료와 다음 단계

[제한 소스의 보관·활용 미정](제한소스_보관과활용_미정.json)은 해당 pptx 소스만의 국소 상태다. 자료 확보·감사 목적이 보관/실행/이식 허락을 뜻하지 않는다. 추가 복제·실행·이식은 보류하고 기존사본은 임의 삭제/이동하지 않는다.

실제 영상·시나리오·정답·표본/수치계획은 [01-A 자료 준비](../09_다음단계인계/01-A_자료준비안내.md)에서 후속으로 준비한다. 사용자에게 PTS/OCR/좌표 수작업을 요구하지 않는다. 01-A 구현·API·영상 분석, 01-B 회사 문법 승인, 02 새 화면 창작은 아직 시작하지 않는다.

[별도 R8 문맥](현재후보_입력고정.json)과 `07_실행도구/R8_후보연결확인.py`는 후보11파일·현재 정정의 원문/근거·기존 구조조회 영수증을 읽기 전용으로 대조한다. 기존 R6/R7 pin을 바꾸지 않으며 live 재실행·내용/권리/영상/채택 승인 기능이 아니다. `python -B <도구> --base <Phase 00 루트>`로 실행하고 stdout을 결과 폴더에 보존한다.
