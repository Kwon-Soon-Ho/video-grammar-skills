# 용어별 적용 예와 반례

현재75개용어의프로젝트적용초안이다. 모든예는설명용상황이며실제영상사례가아니다. 기존사전ID/정의는유지한다. 구현만모를때에는충분한관측태그를지우지않고구현주장을별도로미확인으로남긴다.

## 영상 유형

| 용어 | 적용 예 | 반례 | 판단을 보류할 때 |
|---|---|---|---|
| 소프트웨어 소개 | 제품의 입력→결과 확인 흐름을 설명하는 전체영상. | 소프트웨어 화면이 한컷 나오는 회사소개 전체를 SW소개로 확정. | 전체내용/기획근거가 없고 UI이미지 한장뿐이면 유형 보류. |
| 기술 설명 | 침투수 발생과 배수공법 작동을 설명하는 영상. | 3D로 만든 축하영상이라는 이유로 기술설명으로 분류. | 공법/원리 설명인지 제품홍보인지 맥락 부족 시 복수후보. |
| 회사 소개 | 사업부·사업분야·보유역량을 소개하는 영상. | 회사 로고가 붙었다는 이유만으로 회사소개 판정. | 로고만 있거나 부분클립이면 전체유형 미확인. |
| 기업 브랜딩 | 가치와 태도를 문구·이미지로 표현하는 브랜드필름. | 정보량이 적다는 이유로 모두 브랜드필름 판정. | 분위기만으로 기획목적을 단정하지 않고 표현 후보로 남김. |
| 성과 보고 | 기간별 실적과 주요 성과를 설명하는 영상. | 장식 숫자카운터가 있다는 이유로 성과보고 분류. | 수치가 실적/제품사양/장식 중 무엇인지 불명확하면 보류. |
| 교육·안내 | 현장 작업자가 따라 할 절차와 주의사항을 설명. | 작동원리를 설명한다는 이유로 교육용/관객수준 확정. | 학습/업무안내 맥락과 대상이 없으면 기술설명 등 후보 유지. |
| 인터뷰 | 인물 발화를 중심으로 질문·답변이 이어지는 영상. | 인물 사진 한장과 인용문만으로 인터뷰 영상 확정. | 실제발화/전체구성을 확인할 범위가 없으면 후보. |

## 전달 목적

| 용어 | 적용 예 | 반례 | 판단을 보류할 때 |
|---|---|---|---|
| 단계 설명 | 화면에 준비→시공→검수의 실행순서가 명시됨. | 3개 사업 소개카드가 차례로 등장해서 단계설명 판정. | 순서가 업무단계인지 등장순서뿐인지 모르면 후보. |
| 비교 | 동일 조건의 공법A/B 성능을 같은 항목으로 설명. | 좌측 사진·우측 설명이라는 이유로 비교 판정. | 공통비교기준과 대상관계가 없으면 분할 배치만 기록. |
| 변화 설명 | 동일 시설의 보수전/후 상태와 달라진 점을 설명. | 100으로 숫자가 증가했다고 개선목적으로 확정. | 증가의 의미·동일대상의 전후 근거가 없으면 보류. |

| 구조 이해 | 구조물 전체와 부품 위치·역할을 함께 설명. | 입체 렌더가 있다는 이유로 구조이해 목적 확정. | 입체대상이 장식인지 구성설명인지 근거 부족 시 후보. |
| 공간 이해 | 지도에서 현장 위치와 접근경로를 설명. | 카메라가 움직이므로 공간이해 목적 확정. | 위치/방향/거리 정보가 전달되는지 확인 전 보류. |
| 핵심 강조 | 여러 항목 중 핵심수치를 별도로 표시하며 문구로 지목. | 화면에서 가장 밝은 색이므로 제작자의 핵심목적 확정. | 주목시킨 대상은 기록하되 의도와 효과는 후보. |
| 데이터 해석 | 수치의 기간·단위·차이를 차트와 문구로 설명. | 차트 아이콘이 있다는 이유로 데이터해석 분류. | 실제데이터인지 장식인지 원문/표현맥락 부족 시 보류. |
| 상태 안내 | 문구가 작업 진행중/검수 완료 상태를 알림. | 초록색 도형만 보고 완료 상태로 확정. | 상태명/범례가 없으면 색상 관측과 의미후보 분리. |

|---|---|---|---|
| 순차 관계 | 1단계 완료 뒤 2단계로 진행한다고 명시된 항목관계. | A/B/C가 늦게 나타났다는 이유로 정보도 순차관계 판정. | 화면번호가 업무순서/단순번호 중 무엇인지 보류. |
| 병렬 관계 | 독립 사업부 세개를 동등항목으로 제시. | 카드가 동시에 나타나서 병렬관계로 확정. | 동등관계인지 상하관계인지 표현근거 확인. |
| 계층 관계 | 본부 아래 두 부서가 종속되는 조직도를 표시. | 제목글자가 더 커서 계층관계로 확정. | 연결/종속의 명시근거가 없으면 시각위계만 설명. |
| 부분과 전체 | 시설전체와 그 시설을 구성하는 펌프/배관을 대응. | 한장의 사진을 크게 잘랐다고 부분전체 관계 확정. | 크롭 대상이 구성부분인지 상세확대인지 구분 불가 시 후보. |

| 공간 관계 | 시설지도에서 두건물의 위치와 연결통로를 표시. | 좌우 배치된 두카드가 실제공간관계라고 판단. | 도식배치/실제위치/정확한거리를 각각 구분. |
| 상관·관련 | 표현에 인과를 주장하지 않은 관련성/함께 변하는 지표. | 동시에 움직이는 아이콘의 정보가 상관관계라고 판정. | 자료가 관련성을 표현하는지와 통계상관검증을 분리. |

| 가시성 변화 | 문자가 서서히 보이거나 가려졌다가 드러남. | 흰배경과 섞여보이므로 Opacity0→100 확정. | 밝기/가림/합성/배경변화의 원인은 미확정. |
| 오퍼시티 변화 추정 | 원본 속성자료 또는 합성조건을 적은 추정으로 opacity변화를 제시. | 렌더에서흐려보인다는 이유로 opacity수치 확정. | 원본/배경색/합성조건이 없으면 가시성만 관측. |
| 마스크 공개 | 시간에따라 공간경계를 따라 문구가 드러나는 모습. | 경계공개를 보고 AE 마스크경로/트랙매트를 확정. | 관측범위는 경계공개. 구현마스크/크롭/가림원인은 미확인. |
| 경로 관련 변화 | 선공개인지 이동인지 세분불가하지만 경로관련 변화가 보임. | 모든단순이동에 경로구현을 단정. | 세부유형 불명확할때 상위후보+이유, 하위태그발명안함. |
| 카메라·전역 변화 | 명시한화면전역에분포한배경/대상에서일관된시점·배율·방향변화가보이고국소그룹변화와구분됨. | 우측아래아이콘3개만함께커지고중앙도표/배경이그대로인데전역변화로확정. | 전역범위의근거가없으면해당대상의크기/위치변화만기록. 전역관측이충분해도실제카메라/그룹transform원인은별도미확인. |
| 문자·값 변화 | 화면문자·수치의 표시내용이 구간동안 바뀜. | 0→100이 실제실적변화나 비율이라는 의미 확정. | 단위/값의뜻/실제시간 대응이 없으면 표시면변화만. |
| 대상 경로 이동 | 대상의 위치가 관측된 궤적을 따라 달라짐. | 선자체가길어지는 것을 대상경로이동으로 기록. | 대상추적과 궤적이 불명확하면 경로관련상위후보. |
| 선 공개 | 선의보이는 길이/구간이 시간에따라 늘거나 줄어듦. | 점이선위를이동하는것을 선공개로 기록. | Trim Paths/dashoffset/마스크 구현은 원본없으면 미확인. |

## 시간 곡선·사건 관계·유지

| 용어 | 적용 예 | 반례 | 판단을 보류할 때 |
|---|---|---|---|
| 등속 | 같은관측량을 같은시간간격으로 보았을때 변화량이 일정. | 같은속도로보인다는 인상만으로 정확한linear코드 확정. | 짧은표본/원근변화/추적오차면 곡선후보 또는 미분류. |
| 가속 | 동일대상·관측량에대해사건방향을고정했을때변화의빠르기/속도크기가커짐. 방향과증가/감소는별도로기록. | 도형이커져서 진행곡선도 가속이라 단정. | 관측량/시간표본/방향전환이불명확하면후보. 원근/추적오차를한계로남기고정확한원본베지어/키프레임은확정하지않음. |
| 감속 | 동일관측량의속도크기가작아짐. 예:위치10→6→4는반대방향이지만빠르기4→2로감속. | 오브젝트끝이멈췄다는 사실만으로 전체가 감속이라 확정. | 관측량/시간표본/방향전환이불명확하면후보. 원근/추적오차를한계로남기고정확한원본베지어/키프레임은확정하지않음. |
| 가속 후 감속 | 같은동작의속도크기가커졌다작아짐. 축소/페이드아웃의음수방향을가속/감속과혼동하지않음. | 여러대상이 차례로 등장하면 ease-in-out이라 분류. | 관측량/시간표본/방향전환이불명확하면후보. 원근/추적오차를한계로남기고정확한원본베지어/키프레임은확정하지않음. |
| 진동·정착 | 대상이 방향을 반복 바꾸며 진폭을 줄이고 정착. | 루프의주기움직임을 정착으로 분류. | 최종정착까지 관측못하면 진동후보, spring구현미확인. |
| 순차 발생 | 대상A 시작후 대상B가 시작하는 사건순서가 보임. | 순서등장을 보고 정보관계도 반드시순차라 판단. | 시작순서/완료순서 중 무엇인지 구분 못하면 보류. |
| 동시 발생 | 두대상의 시작이 같은관측시점에 나타남. | 동작범위가 일부겹친다는 이유로 같은시작시각 확정. | 시간해상도/시작또는완료의기준 없으면 후보. |
| 중첩 | A동작이끝나기전에 B동작이시작하여 범위가 겹침. | 완료된A가남아있다고 A동작이여전히겹친다고 판단. | 정보유지와 동작의진행범위를 구분. |
| 지연 | 명시한기준사건A와 B의 시작/완료 사이 시차가 보임. | B가늦게나와서 항상 부정적지연/응답지연 판정. | 기준사건/대응관계/관측시각이 없으면 시차후보. |
| 유지 | 설명이식별가능하게유지되는동안 배경은움직임. | 유지가있으면 화면모든것이 정지했다고 판단. | 대상/유지정보/범위가없으면 보류; 읽기충분성은R3/R7. |
| 정지 | 정한대상/범위에서시간동안 변화가 관측되지않음. | 정지화면 한장만으로 여러초 정지구간을 확정. | 관측시간범위/검출한계가없으면 정지판정 보류. |
| 반복 | 같은상태·동작패턴이 해당구간에 반복됨. | 한번의왕복운동을 무한루프/원본loopOut으로 확정. | 반복구간이 관측되지않으면 반복후보만. |
| 목표 초과 후 복귀 | 대상이최종위치/크기를지나친후 해당값으로 복귀. | 임의의급격한전환/방향변경을 overshoot라 기록. | 최종목표/동일대상/복귀가 없으면 목표초과 미확정. |
