# R2에서 조사하고 정리할 것

R2의 목적은 같은 영상·화면·동작을 사람들이 같은 기준으로 기록하도록 만드는 것이다. 이름을 많이 모으기보다 용어의 범위와 적용 예를 분명히 한다.

| 소단계 | 쉬운 설명 | 만들 결과 |
|---|---|---|
| R2-1 현황과 출처 | 기존76개 용어가 무엇을 뜻하고 어디에서 왔는지 확인 | 전수 점검·혼동 항목·추가 조사 범위 |
| R2-2 기록 단위 | 영상 전체, 설명 구간, 화면 상태, 짧은 동작을 어떻게 구분할지 검토 | 단위 정의·경계 예·기존 DB와 후속 연결 위치 |
| R2-3 용어 판정 | 목적/정보 관계/배치/모션 역할/보이는 변화 등을 구별 | 현재75개 용어의 판정 근거·적용 예·반례·판단 불가 조건 |
| R2-4 복합과 미분류 | 한 화면에 여러 구조가 있거나 근거가 부족할 때 처리 | 여러 태그의 범위·미분류 사유·별칭/폐기 처리 예 |
| R2-5 검수와 보완 | 잘못 분류하도록 공격해 보고 고치기 | 레드팀 발견·수정·정상/반례 검사·종료 판정 |

8개 축은 영상 유형, 전달 목적, 정보 관계, 화면 레이아웃, 모션 기능, 관측 속성, 시간 특성, 표현 속성이다. 예를 들어 두 카드가 차례로 나타나도 ‘순차 발생’이지 항상 ‘단계 설명’은 아니다. 좌우 분할도 항상 비교는 아니다.

외부 원문은 컷/숏·대상 범위·타이밍·합성 용어의 의미를 확인하는 데 사용한다. 우리4단위나영상유형분류가국제표준이라고표시하지않는다. 모든 용어는 현재 프로젝트 초안이며 실제 사내 사례 검증과 회사 규칙 승인은 후속 단계다.

단위/범위의 판단은4지선다와추천안으로검토한다. 새 의미를 병합하거나 회사 필수규칙으로 승격하지 않는다. 실제 영상 분석 스킬·화면 추출 구현은01-A, DB 필드/시간검증 개정은R4, 원칙/레이아웃의 품질 판단은R3에 둔다.


## 현재 판정

R2-1~5의의미기준·예/반례·설명용계약검수를완료했다. [단계별 결과](../08_검증결과/R2_보완결과와레드팀.md)를따른다. 실제영상분류성능과회사규칙승인은별도다.
