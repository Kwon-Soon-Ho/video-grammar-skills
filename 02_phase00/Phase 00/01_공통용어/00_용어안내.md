# 공통 용어와 분류를 사용하는 순서

R2의 의미·판정 기준 정리와 설명용 계약 검수는 완료했다. 실제 영상 분석과 회사 규칙 승인은 후속 단계다.

1. [기록 단위와 분류축](02_기록단위와분류축.md)에서 영상 전체·설명 구간·화면 상태·짧은 동작을 구분한다.
2. [용어별 적용 예와 반례](03_용어별적용예와반례.md)에서 현재75개 용어의 적용 조건을 찾는다.
3. [복합·미분류 처리](04_복합화면과미분류처리.md)로 여러 태그와 판단 불가 상태를 처리한다.
4. [범위별 설명용 사례](05_범위별분류사례.md)를 보며 대상·주장 범위를 나눠 기록한다.
5. [R2 결과와 레드팀 보고](../08_검증결과/R2_보완결과와레드팀.md)에서 조사 범위와 검증 한계를 확인한다.

기존 용어ID·정의의 정본은 [공통용어사전.json](공통용어사전.json) `company-video-taxonomy@0.1.1`이다. ID와 정의는 이번에 변경하지 않았다. 운영 기준은 [분류운영규칙](분류운영규칙.json), 개별 판정은 [용어판정기준](용어판정기준.json), 혼동쌍은 [혼동쌍사례](혼동쌍사례.json), 연습기록은 [설명용분류사례](설명용분류사례.json)에 따로 저장했다.

**보이는 사실과 구현·의도는 나눠 기록한다.** 대상이 확실히 커졌다면 크기 관측은 남기고, 원본 Scale이나 실제 카메라 원인은 미확인으로 둔다. 실제 촬영·실제 UI·opacity 값처럼 정의에 출처나 합성 조건이 필요한 용어는 해당 근거가 있어야 한다.

미분류의 의미 상태와 실제 DB 필드는 다르다. 기존 classification 배열 자리에 null을 넣거나 R2 연습기록을 실제영상기록으로 복사하지 않는다. [R4 인계](../09_다음단계인계/R2_R4.md)에 필드 연결할 항목을 정리했다.

스킬 조사·변형·영상 분석 구현은 수행하지 않았다. 새 의미 병합·회사 필수화·사람 승인을 만들지 않는다. 폰트·브랜드 토큰은 R5의 디자인 정본을 참조한다.
