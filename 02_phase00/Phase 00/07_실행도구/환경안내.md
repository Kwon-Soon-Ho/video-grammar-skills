# 기반 검증 환경

Phase 00/.환경의 Python 가상환경은 이 프로젝트의 스키마·반례·스킬 구조 검사 전용이다. 기존 AE·Computer Use 환경을 수정하지 않았다.

설치 패키지는 환경패키지.txt에 고정 버전으로 기록한다. jsonschema의 date-time 검증은 rfc3339-validator를 포함해야 한다. PyYAML은 Anthropic Skill Creator의 quick_validate.py 구조 검사용이다.

스킬 비교 평가는 한국어 3개 요청을 각각 스킬 사용/기본 실행으로 수행했다. 실행 환경 검사와 실제 영상 분석 정확도 검사는 별개다. Python 가상환경은 다른 경로로 복사만 해 재사용하지 말고 필요하면 해당 위치에 재구성한다.
