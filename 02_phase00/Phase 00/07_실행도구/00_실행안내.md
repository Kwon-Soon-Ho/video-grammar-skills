# 기반 데이터 실행 도구

프로젝트 전용 .환경/Scripts/python.exe를 사용한다. 설치한 검사 라이브러리는 jsonschema==4.25.1이다. 시스템 Python·AE 환경은 변경하지 않았다.

자료검증.py: 정본 스키마·출처·용어 축·한맥 참조와 최소 기록의 승인/근거/시간 계약을 검사한다. --record <기록경로>로 특정 기록을 검사한다. --output <Phase 00 안의 결과경로>로 결과를 저장한다.

지식조회.py: 검색어·--axis <분류축>으로 용어를 조회한다. --palette는 한맥 공통색만 반환한다. --include-optional로 선택 UI/표면을 추가한다. 미확인 IP-10은 기본 조회에서 제외하고 --include-pending으로만 본다.

이 도구는 영상 파일을 읽거나 프레임·OCR·곡선·회사 문법을 분석하지 않는다. 지식의 출처 내용과 적합성 자체가 참인지 증명하는 도구도 아니다. 형식·연결과 업무 경계 검사는 사람 검토와 함께 사용한다.
