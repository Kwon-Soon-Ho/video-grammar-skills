# R3 모션 지식 도구 사용

Phase 00 폴더에서 다음을 실행한다.

```powershell
& '.환경/Scripts/python.exe' '07_실행도구/R3_모션자료검사.py'
& '.환경/Scripts/python.exe' '07_실행도구/R3_모션조회문서생성.py'
```

첫 명령은 자료를 읽기 검사한다. 둘째 명령은 심화카드의 조회용 MD만 재생성하며 변경 전 조회본을backup에 보존한다. JSON 카드·원칙 정본·분류·승인·외부 스킬을 변경하지 않는다. 원격 사이트·편집 프로그램·Computer Use를 제어하지 않는다.

검사기는 43개 ID·출처 깊이·참조·초안 권한·IP-10 사용자 A의 조건부 참고 계약·원문/자체해석 구조·조회본 일치를 검사한다. 원문의 사실·자연어 의미 정답·실제 영상의 시선·가독성·학습 효과를 판정하는 도구는 아니다. 이 범위는 레드팀과 실제 자료 검증으로 보완한다.

심화카드에서 만든 조회본은 03_모션원칙_적용예와반례.md다. 조사범위·충돌사례·연결검토 MD는 수동 정리본이며 JSON 변경 시 함께 검토해야 한다. 이 세 조회본까지 자동 생성된 것처럼 표시하지 않는다.
