# 레이아웃 지식 검사와 조회문서 생성

Phase 00 폴더에서 실행한다.

```powershell
& '.환경/Scripts/python.exe' '07_실행도구/R3_레이아웃자료검사.py'
& '.환경/Scripts/python.exe' '07_실행도구/R3_레이아웃조회문서생성.py'
```

검사는 읽기만 수행한다. 생성기는 R3-2 JSON에서07/08/09/10 조회MD·11설명도HTML·조사범위MD만 재생성하고 변경 전 조회본을backup에 보존한다. 원칙정본·분류ID·회사승인·스킬·실제 영상기록은 변경하지 않는다. 외부API·Computer Use·AE를 제어하지 않는다.

출처 URL·확인 깊이·로컬 원문 해시·ID/이름·예/반례·기권·권한·정본 참조·A안 후보·조회 동기화를 검사한다. 자연어의 의미 정답·시선·실영상 가독성·연구 효과·라이선스는 판정하지 않는다. 외부 파일이 갱신되면 검증을 조용히 우회하지 않고 새 검토·버전 기록을 남긴다.

설명도 렌더 검사는 작업 중에만 격리한브라우저에서 수행했다. 외부스킬의detector나기존사용자브라우저를실행한것이아니다. 렌더검사.json은당시C워크스페이스의검수경로를기록한증거이며PNG사본은같은검증폴더에서볼수있다.
