# R5 자료 조회·적용 검사 사용 안내

이 도구는 Phase 00의 정본 참조·초안/검수대기 관리다. 영상 분석·새 화면/로고 제작·회사 승인 기능은 없다. 기존 스킬을 수정/재생성하지 않았다.

## 처음 보는 사람이 읽는 순서

1. [8회사 자료 현황](../03_한맥디자인/10_회사별_연결현황.md)에서 회사ID와 원문 자료를 확인한다.
2. [화면 역할 연결 규칙](../03_한맥디자인/07_회사CI와_화면역할_연결규칙.md)과 [영상 적용 예·반례](../03_한맥디자인/08_영상적용_예와반례.md)를 읽는다.
3. [설명용 예시](../03_한맥디자인/디자인적용_설명용예시.json)는 실제 인물/회사 영상 데이터가 아니다. 실제 초안은 별도 새 파일에 작성하고 원문/예시를 덮어쓰지 않는다.
4. 이 폴더의 R5_디자인적용검사.py에 초안 파일 경로를 전달한다. valid는 현재 구조/참조 검사이고 human_review_queue가 실제 적용/내용 검수 대기다. review/회사 승인 필드를 true로 바꾸지 않는다.

## 실행 예

Phase 00 폴더에서 `.환경/Scripts/python.exe -B`로 실행한다. 아래 경로는 Phase 00 기준이다.

```powershell
.환경/Scripts/python.exe -B 07_실행도구/R5_조회와표시.py
.환경/Scripts/python.exe -B 07_실행도구/R5_조회와표시.py --company saman
.환경/Scripts/python.exe -B 07_실행도구/R5_조회와표시.py --company saman --include-observed
.환경/Scripts/python.exe -B 07_실행도구/R5_조회와표시.py --company saman --include-hanmac --include-styles
.환경/Scripts/python.exe -B 07_실행도구/R5_디자인적용검사.py 03_한맥디자인/디자인적용_설명용예시.json
```

조회 기본은 공식 화면색뿐이며 현재 8회사 모두 해당 값이 없다. include-observed는 관측값만 추가하며 역할을 선택하지 않는다. 한맥 공통색과 참고 스타일도 각각 옵션을 켠 경우에만 반환한다. 없는 회사·검사실패 시 한맥색/타회사색으로 대체하지 않는다.

API 옵션은 boolean만 받는다. 문자열 false·숫자·목록·미상값을 명시 선택으로 해석하지 않는다. CLI의 옵션 조회는 회사ID를 함께 지정한다. 회사별 표의 이름에서 기존 CI·심볼 안내로 바로 이동할 수 있다.

## 표시 생성·기존 생성기

R5_조회와표시.py의 views(base)는 정본으로부터 8회사 현황·관측색 단색대비 표/JSON의 문자열을 반환하는 API다. 호출만으로 파일을 쓰지 않는다. 현재 출력은 [표시 입력목록](../03_한맥디자인/R5_표시_입력목록.json)의 hash와 기존 한맥 manifest를 확인한 뒤 생성했다. 정본/검사/생성입력이 바뀌면 생성/조회는 중단하고 재검토해야 한다. 입력목록만 자동 갱신하여 우회하지 않는다.

사례의 로컬 근거판본과 외부 조사기록의 hash/버전/깊이도 확인한다. 조회/표시 직전에 확인한 뒤 읽은 결과를 반환하기 전 다시 검사하여 단순한 확인-읽기 사이의 변경을 차단한다. 파일시스템 전체의 원자적 snapshot·잠금/동시성/보안 서명을 구현한 것은 아니다.

기존 03/문서생성.cjs는 초기 한맥 파생자료의 재현용이다. 일부 설명은 코드 상수여서 미래 정본 변경을 모두 반영한다고 보장할 수 없다. 현재 내용 재현을 C 사본에서 검수하고, R5에서는 검토한 hash가 달라지면 중단하는 입력 검사를 추가했다. D 원본 폴더에서 곧바로 재생성해 새 검토문서를 덮어쓰지 않는다. 새 정본/버전 도입은 과거 원문·manifest·pin·비교를 보존해 검토한다.

## R4와 스킬 인계

R4는 원본 관측/시간/근거/좌표, R5는 기획 선택 초안이다. linked_r4_record 검사는 로컬 파일·ID/버전/hash·실제/합성 범위 확인뿐이다. R4 전체 구조검사/관측 내용검수는 기존 R4 도구와 사람 검수에서 별도로 한다. 실제 자료가 없는 현재 연결 예시를 운영 원본으로 쓰지 않는다.

현재 검사는 현행 참조 기준이며 과거 초안을 새 정본으로 자동 소급 갱신하지 않는다. 과거 pin이 다르면 현재 검사 통과로 만들려고 값을 바꾸지 말고 해당 버전의 backup/이력과 당시 검토 범위로 읽는다. R6/R7에 내용/선택자/권한 검수를 연결하고 R8에서 Anthropic Skill Creator를 통한 3스킬 재구성·쓰기/기권/호환 평가에 반영한다.
