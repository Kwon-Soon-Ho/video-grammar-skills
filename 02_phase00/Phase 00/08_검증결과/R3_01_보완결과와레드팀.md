## 조사 깊이와 제한

Adobe의12원칙은 공개 텍스트 설명을 확인했다. Jorge의10원칙은 Learn Squared의 공식 강의 목록으로 항목과 순서를 확인했다. 유료 강의의 상세 설명은 미검토이므로 해당 카드의 원문 상세 요약은null이고 적용 해석을 별도로 적었다. 사용자 제공POLYUM의 항목명을 대조했고, 질량·정지와 재생속도·fps 설명을 조건 없는 DB 규칙으로 옮기지 않았다.

Mayer·Fiorella의 불필요 처리 감소5·필수 처리 관리3, 일시 정보·숙련도 역전은 Cambridge의 **공개 Summary**를 읽었다. 장 전체·실험별 경계조건·진단도구·회사 영상 효과를 검토한 상태는 아니다. 숙련도는 직급·부서명이 아니라 해당 주제의 입력 근거로 판단한다.

Carbon v10의 의미·공간·연속성·순차 구성과 productive/expressive, Fluent2의 네 모션 관점, UX in Motion 저자의12관점, W3C의 플래시·재생제어·상호작용 조건을 확인했다. 제품 UI의 경로 제한·ms·항상 이징을 회사 영상의 의무 규칙으로 가져오지 않는다.

추가로 교육용 애니메이션과 정지 그림의 선택 근거를 조사했다. APM5원칙은 공개 요약에서 존재만 확인했고 세부 목록을 만들어 등록하지 않았다. 2021 변화 학습 연구는 초록·선택 본문을 읽었으며 통계 전체를 독립 재분석하지 않았다. Material2는 검색 추출만 확보해 원문 확인 완료에서 제외했다.

[출처와 읽은 범위](../05_출처와검토/R3_모션_조사범위.md), [조사기록 JSON](../05_출처와검토/R3_모션_조사기록.json). 17개 중15개는 공식·저자·출판사·연구 본문의 관련 텍스트,1개는 사용자 제공2차 해설,1개는 검색 추출이다. 전수 조사나 모든 원문의 완독을 의미하지 않는다.

## 검사와 현재 판정

자체 계약 회귀28/28을 통과했다. 출처 깊이·회사 승인 위장·실영상 시험 위장·참조·정본 버전·예/반례·기권 누락·사용자 선택 근거 누락을 검사했다. 자연어 의미 정답이나 영상28개를 맞힌 결과가 아니다. 독립검사는 구조검사와 선택 반례를 재확인한 것이며28개와 별개 성능 점수로 합산하지 않는다.

IP-10의 사용자 A 선택은 참고 사용 범위다. 회사 필수 규칙·학습 효과 승인으로 기록하지 않았다. 기존43개 ID를 유지했고 IP-10만 조건부reference·새 Summary 출처·기권 조건으로 개정했다. 다른42개 원칙의 기존 정의·분류 사전·CI·한맥 디자인값·R4 실제 기록 스키마·세 맞춤 스킬은 변경하지 않았다. 변경 전 정본·중간 자료·레드팀 원본은backup에 보존했다.

남은 순서는 [R3 단계별 안내](../02_원칙과레이아웃/01_R3_단계별진행안내.md)를 따른다. **다음은 R3-2 레이아웃14개를 정보 관계·읽기 순서·한국어·정보량·화면비에 맞춰 보완하는 단계다.** 이어 R3-3에서 외부 스킬을 파일과 호출 코드까지 심층 검토한다. 스킬 재구성·Anthropic Skill Creator 평가·실제 영상 분석을 이번 결과에 포함하지 않는다.
