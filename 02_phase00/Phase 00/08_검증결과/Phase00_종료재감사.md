# Phase 00 종료 재감사

2026-10-14. 결론: **사용자가 정의한 Phase 00 전체는 아직 완료가 아니다.** 최소 기반 v0.1은 준비됐지만 자료의 조사 깊이·판정 계약·시간 검증·일부 스킬 쓰기 검증을 보완해야 한다. 이전의 “기반 구축 완료”는 이 구분이 충분하지 않았다.

별도 두 검토자가 데이터 계약과 지식/스킬 범위를 나눠 읽기 검토했다. 실제 정본·소스 스냅샷·검증 코드·평가 결과를 확인했고 시간 조건은 메모리 반례로 재현했다. 실영상·회사 승인·모든 원문 심층 독해를 수행했다고 주장하지 않는다.

## 이번에 확인한 실질 누락

원본 10초·구간 0~1초인 가상 구조에 프레임 100초를 넣거나, 구간 밖 프레임 2초를 넣어도 통과한다. 근거 자료 period의 9→1초 역전과 100초 종료도 통과한다. 실제 영상을 읽은 결과가 아니라, 구조 검증기가 막아야 할 조건을 메모리 fixture로 확인한 것이다. [재현 결과](Phase00_시간계약_누락반례.json)와 코드를 보존했다. 현재 검증기 자체는 이번 감사에서 수정하지 않았다.

기존39건 통과는 기존39조건의 결과다. 새 누락이 없다는 보증으로 쓰지 않는다. steward의 쓰기8/8은 기록 fixture 한 건을8조건으로 검사한 것이다. 비교3쌍의11/12동률은 스킬 효과 우월성 증명이 아니다.

## 이번 웹 재확인

[Jorge 공식 강의 목록](https://www.learnsquared.com/courses/motion-design)의10제목과 [Cambridge 불필요처리 공개요약](https://www.cambridge.org/core/books/abs/cambridge-handbook-of-multimedia-learning/principles-for-reducing-extraneous-processing-in-multimedia-learning/F29A19FCD34C542806F736E0661C05F5)을 확인했다. 공개요약은 관련성·표식·중복·공간/시간 근접을 설명하지만 학술본문 전체를 제공하지 않는다.

IP10은 이번 감사에서 [2021년 공식 장별 공개요약](https://www.cambridge.org/core/books/abs/cambridge-handbook-of-multimedia-learning/expertise-reversal-principle-in-multimedia-learning/F6793786D8F79519A22E967FC2563839)을 새로 찾았다. 초보에게 도움이 되는 설명이 숙련자에게는 불필요하거나 방해될 수 있어 숙련도에 맞춰야 한다는 개념을 확인할 수 있다. 이는 기존 조사가 이미 완료됐다는 근거가 아니다. 신규 확인 범위를 등록하고 DB 적용 해석을 재검토할 작업으로 남겼으며 자동으로 보류를 해제하지 않았다.

## 00 종료 전의 유한한 작업 순서

1. **R1·R2 계약 정리:** 자산 종류·명명·원본/파생 관계, 분류 기록단위와 미정 처리, 혼동쌍 설명 예. 초기 정보전달형 영상 범위를 명시한다.
2. **R3·R6 선별 지식 근거 보완:** 선택된43원칙·14레이아웃에 근거 수준/위치·프로젝트 해석·포함/제외 예 연결. MP/IP10을 재대조. 확보한379파일 전체 심층 독해나 새 저장소 무한 탐색을 종료 조건으로 두지 않는다.
3. **R4·R7 시간/기록 검증 보완:** 새4반례 차단, 정상대조 유지. 자산 video_type, metadata/run 최소필드와 시간/좌표변환 참조 계약을 확정한다. 실제값 획득 코드는01-A다.
4. **R5·R7 검수 판정표:** 각검수의입력·근거·통과/수정/보류·심각도·중복감점 규칙. 한국어·단위·무음자막·가독성·프레임경계 설명용 반례. 회사 폰트/안전영역/이징 숫자는 만들어내지 않는다.
5. **R8 스킬 시범 검증:** curator/reviewer의좁은변경·기권을복사본에서평가. 모든작업에원시로그·backup·diff·버전·검증·내부검토를남긴다. 사용자A의시범허용과스킬신뢰성검증을구분한다.
6. **종료 게이트:** 위산출물·검사·미정목록·01-A인계를다시확인하고그때00종료를판정한다. 의미 병합·회사필수화·목적변경이필요할때는사용자가요청한4지선다+추천안으로검토한다.

01-A 명세 준비와 자료 수집은 병행 가능하다. 다만 현재검증기를완성품처럼사용하거나01-A실출력계약이완료됐다고전제하지않는다. 실제사내문법·폰트/로고/자막/안전영역/이징수치의승인은01-B, 새화면기획품질은02로남긴다.

최종 문서 내부 재검토: 시간 반례 미수정 상태, 기존39시험의 한계, 00/01-A/01-B 경계, 사용자 최소자료와 기술작업 분리가 명확함을 별도 검토자가 확인했다. 자료설명은 아는 항목만 작성하도록 양식을 보완했다.
