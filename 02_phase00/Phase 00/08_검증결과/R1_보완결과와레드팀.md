## 추가 모음 검토 결과

AI7개/PNG41개를이름정리한원본사본으로추가했다. ZIP7개는해제파일과모든항목의SHA256이일치해backup에보존했다. 전체형태편집AI7개는아트보드/레이어이름만정리하고패스·문자/글꼴·위치·색의저장전후불변을검사했다.

17페이지중14페이지는MuPDF렌더바이트가같고, 3페이지는미세차이가있다(최대평균채널차이0.119/255). 3페이지는육안으로도원본과대조했다. 전체픽셀동일을주장하지않는다. [추가AI외형검사](R1_추가AI_외형검사.json)와 [추가보존기록](R1_추가모음_원본보존기록.json) 참고.

삼안의HEX/별색4값은draft로전사했다. Black70%와Magenta60%+Yellow100%는전체4채널이아니므로나머지를0으로발명하지않고원문문구만보존했다. ㈜장헌의형태/굵기/비례제한설명도 [문서명시검토목록](../10_공용자산/문서명시_검토목록.json)에draft로기록했다. 공식최신판/사내필수규칙채택은미확정.

삼안국문가로형과영문시그니처_kr파일은동일해시이지만두제공명을보존했다. 일부파일명2009/2016/2022와AI메타데이터2025등의연도차이는관측된문자열이며구형/최신판을자동판정하지않았다.

## 완료 판정과 남은 자료

collection_complete=True는8개회사에대한현재원본CI·조건기록된관측색등록이다. official_values_complete=False다. 폰트·이미지·도표실물도미확보다. 전체 공용자산 수집이나 공식 브랜드 확인까지 완료됐다는 뜻은 아니다. 이 항목들은 R1 종료 조건이 아니라 필요 시 보충할 자료와 개별 적용 조건이다.

산하벡터/별도심볼, 회사별가이드의공식권위·지정색/프로필·최신판·변형규정, 폰트/이미지/도표는 [준비목록](../10_공용자산/01_남은자산_준비목록.md)에따라추가한다. 현재조회자산은검토용으로사용할수있다.

R2는공통용어·분류단위·혼동쌍·적용예/반례를별도보완한다. R3는원칙·레이아웃과스킬별전체심층검토, R4는기록/시간계약, R5는한맥관련미정, R6/R7은출처/검수, R8은맞춤스킬쓰기평가다. 다음단계로자동진행하지않는다.

2. `추가모음`의 전체형태 편집용 AI에서 언어·가로/세로 구성을 확인한다. PNG는 제공 원본을 참고하고, 초기 분리 SVG/PNG는 별도 파생본으로 사용한다.
3. 색상을 고를 때는 관측색과 문서 명시 초안을 구분한다. 공식값 기본 조회는 현재 비어 있다.

검증 요약: 등록 계약 회귀29/29, 독립 회피반례7+5건의 기대값 검사와 정상 완료/변환/반투명 대조 통과. 제공 원본75개(압축7개 포함)의 바이트 보존, 관측좌표17건, SVG20개와 8회사별 조회도 통과했다. [최종 인계 검사](R1_최종인계검사.json)는 이 검사의 범위를 명시한다.

## 종료 범위 정정

한맥 디자인 시스템이 이미 정본·출처·역할·조회 구조로 연결되어 있으므로 R1은 완료한다. 모든 자산 수집을 R1 종료에 요구한 이전 설명을 정정했다. 현재 판정은 [R1 종료 판정](R1_종료판정.md)을 따른다.


## R1과 R5의 구분

[R1과 R5 업무 구분](../05_출처와검토/R1과R5_업무구분.md)을 따른다. 원본/사본·정본 경로·버전·해시 관리가 R1이고, 디자인 기준 정제와 영상 적용 연결은 R5다. 기존 한맥 디자인 정본은 R5 선행 산출물이며 R1에서는 관리 대상으로 연결했다. R1 완료와 R5 전체 완료를 혼동하지 않는다. R2의 심화 보완은 완료했고 R3는 대기 중이다.
