# R6-2 출처·사용 범위 연결 결과

2026-10-15. **출처·사용 범위의 비파괴 참조 규격과 읽기 전용 검사의 한정 범위를 완료했다.** R6 전체와 실제 사람 내용 검수·회사/사용권한 승인은 미완료다.

쉽게 말하면 ‘이 판단이 어느 자료의 어느 부분을 근거로 했는가’와 ‘어떤 용도로 참고한다고 기록돼 있는가’를 함께 찾도록 연결했다. 원래 자료·버전/hash·읽은 깊이·미검토 범위를 보존하고 실제 사용 허가로 확대하지 않는다.

## 결과

- 18개 입력 정본을 고정하고 byte 동일 사본을 보존했다. 초기20출처·9문서 맥락·출처66행·파일544행·스킬40후보·정책10개를689연결로 표시했다. 중복·재사용 포함이므로 서로 다른 자료689개나 신규 조사689건이라는 뜻이 아니다.
- 135자산의 기존 reference_only 사용 맥락과 파일을 대조했다. 이미 정한 R5 관측색 초안 정책은 유지하며, 외부 전송/배포·직접 코드 채택은 기존 기록만으로 허용하지 않는다. 도구는 행위를 수행하지 않는다.
- 자료별 조사 깊이 찾아보기를 추가했다. 제목/검색발췌/요약/부분 본문/정적 코드 검토·실행·효과를 한 ‘완료’ 상태로 합치지 않았다.

## 레드팀과 보완

독립 최종74/74·예외0, 자체41/41을 독립 담당자가 사본에서 재실행했다. 두 시험은 별도 범위이며 합산 점수나 실제 영상/사람 대상 효과로 해석하지 않는다. 추가 정적 대조14/14로 원기록·보존 사본·기존 R4/R5 핵심/스킬의 보존도 확인했다.

초기 독립59조건 중48통과/11불일치, 추가 형식5건의 실패를 보존하고 다음을 보완했다. 초기 시험 중 루트의 수정이 겹친 기록은 동결된 최종 성적과 구분했다.

1. 검증한 뒤 색인을 다시 읽으며 생기던 맥락 바꿔치기: 검증한 같은 사본에서 반환하고 현재 파일 hash를 재확인한다.
2. 확인과 반환 사이 입력 변경: 반환 직전 고정 입력을 재대조한다. 원자적 파일 잠금/모든 동시 변경 방어는 아니다.
3. 중복 JSON 키·비정상 문자·비유한수·과도한 중첩: 모호한 입력을 명시적 오류로 반환한다. 입력을 임의로 고치지 않는다.
4. 파일 검사 옵션의 truthiness·생략 표시: boolean만 허용하고 메타데이터 검사와 실제 파일 확인 여부를 구분한다.
5. JSON 최상위 구조/스키마 오류의 비정상 종료: 구조화된 오류로 반환한다. 명령행 검사 실패는 종료 코드1이다.

통과해도 content_verified / identity_authenticated / company_approved / permission_granted / operational_release는 false다. 실제 답변 발생·회사 최신판·담당 권한·법적 허가는 확인하지 않았다. 다음 R6-3에서 대상별 사람 질문·실제 답변·부분 확인·기권/자료 필요·정정/철회를 별도로 연결한다. 분산 R4 작업정책은 내용 승인으로 바꾸지 않는다.
