# R6 출처·사용 범위·사람 검수 연결 결과

2026-10-15. **R6-1~4의 자료 감사·참조 규격·사람 답변 접수·통합조회/인계 범위를 완료했다.** 전체 Phase00은 R7 품질 기준과 R8 맞춤스킬 재구성·평가가 남아 있다. 01-A와 실제 영상 분석은 시작하지 않았다.

## 쉽게 보는 결과

‘어떤 자료를 어느 깊이로 읽었는가’, ‘어떤 작업 맥락으로 참고하는가’, ‘사람이 어느 대상을 어디까지 확인했는가’를 따로 기록하고 버전/hash로 연결했다. 파일 보유·요약 읽기·구조검사·작업정책·내용 판단·회사 승인 사이를 자동 승격하지 않는다.

**한맥 디자인 시스템은 이미 있었다.** 웹을 보고 정제한 hanmac-video@0.1.0은 원작업 JSON과 Phase00 정본의 SHA256이 동일하다. 참조 대화 「한맥 디자인 시스템 정리」를 읽어 브랜드·명암 Storybook/강조·중립 Vercel, 전역 컬러 라이브러리/UI선택참고 결정을 별도 출처로 연결했다. 기존 정본을 다시 만들거나 영상 전체의 UI 의무로 바꾸지 않았다.

**이번 사용자 확인:** 8회사 제공 CI는 모두 최신 자료이며, 산하는 원래 Illustrator 파일이 없다. 실제 회신1건을 원질문 snapshot과 함께 접수했다. 추가 CI세부가이드·색 프로필·개별 시안/회사 사용권한까지 확인한 것으로 확대하지 않는다. 산하 AI원본 부재를 필수 누락으로 반복 요청하지 않는다.

## 조사한 자료와 깊이

기존 출처20개와 지정9조사문서의 출처 행/문서 맥락, 스킬40후보·544파일검토행(고유 경로/hash533), 자산135·분산 정책을 대조했다. 544개 본문을 새로 정독하거나 전체저장소·라이선스를 재검증한 결과는 아니다. 원래 제목/요약/선택본문/정적코드검토·미검토 범위를 그대로 남겼다.

W3C PROV-O의 자료·행위·책임 구분, DQV의 측정·평가 맥락, ODRL의 대상·행위·조건 구조는 관련절을 참고했다. 전체 표준/모델 구현·개별 권리의 법적 판정은 수행하지 않았다. 한맥 참조 대화는 과거 정제/출처 선택의 근거로 읽었고 이번에 현재 웹 전체를 재조사한 것은 아니다.

## 남은 실제 확인과 다음 단계

현재 자료에 없는 CI 보호공간/최소크기/허용형·색 프로필·삼안 선언후보의 공식 화면값은 적용할 때 구체 근거/담당자 확인을 받아야 한다. 이미 확보한 한맥 공통 컬러/선택UI와 기존 관측색 초안 정책을 미확보로 되돌리지 않는다. 외부 스킬 직접 복사/실행/배포는 실제 채택 파일과 행위가 정해질 때 조건을 확인한다. 실제 영상의 사실·의도·측정은 자료 접수 후 사람 검수한다. 이 대기를 생략하거나 승인으로 바꾸지 않는다.

R7은 품질 검수 기준·적용/반례·정답/보류 및 평가 계획, R8은 Anthropic Skill Creator로 기존3스킬을 새R4/R5/R6 계약에 맞춰 재구성·검증한다. 스킬 목적/구성의 중간 판단은4지선다·추천안을 유지한다. 기존 시범 사용 승인은 유지하며 새로운 내용/회사 승인은 만들지 않는다. 01-A 구현과 실영상 분석은 이후 단계다.
