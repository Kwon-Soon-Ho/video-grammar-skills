# R4·R5 레드팀 보완

발견한 우회: 중복 ID를 set으로 지워버림, 빈 분류, 재구성 이미지를 원본으로 표기, 수치 주장에 측정 없음, 가설을 회사 규칙으로 승인, 상위 구간 밖 모션.

보완: 원배열 ID 검사, 빈 분류 이유, 근거 대상/종류 연결, 주장·비트 모두 측정 계약, 승인 종류/별도 검수 결정, 시간 포함 관계. 기존 승인 구조와 회사 문법 승인을 분리한다.

검증기는 사람 신원·영상 내용 진실성을 증명하지 않는다. company_rule 승인은 이 사례 계약에서 수행하지 않는다. 실제 영상 내용·파일 해시·PTS·좌표 측정 확인은 01-A, 회사 문법은 01-B의 별도 패턴 검수다.

현재 버전 갱신 검사와 과거 버전 조회는 구분한다. 과거 기록은 backup의 version registry에 남기고 현재 버전 불일치를 발견해도 자동 덮어쓰거나 거짓 관측으로 바꾸지 않는다.
