# R8-2 수행 fixture 초기 지적

2026-10-15 · 실제 시행 전 정적 조사. 후보 정적 통과와 fixture 통과는 별도다.

초기 fixture의 `05_출처와검토/검수와사용범위/출처와사용범위_연결목록.json`에 R3/R8 평가 설계가 간접 복제돼 있었다. 평가/스킬 이식 원문 파일은 제외했지만 R6 연결목록의 `R6-LINK-0646`, `kind=skill_card`, `source_key=skill_cards`, `/cards/6`, `anthropic-creator`의 `original_record`가 해당 내용을 포함한다.

약12795~12826행에서 with-skill/baseline 비교, validation/holdout 분리, 개선 후 사용자 검토·기권/쓰기 반례, R8 정본 읽기/draft 쓰기/승인 보류 평가와 마지막 fixture 확인 등의 설계 문단을 확인했다. 구체 이번 과제 정답이 포함됐다는 판정은 아니지만 ‘스킬 이식/평가 설계 문단을 수행 입력에서 분리’한다는 정한 경계와 맞지 않는다.

main에 해당 파일 전체 제외 또는 CI 질문/답변의 필요 자료만 좁혀 포함하도록 요청했다. D 원문/pin은 바꾸지 않고 C 사본과 포함/제외 목록을 보완한다. 이미 full R6/R7 검증을 범위 밖으로 명시했으므로, 제거한 파일을 가짜 사본/새 manifest로 보완할 이유가 없다.

이후 초기 iteration은 main이 `시험준비이력/평가문단_간접포함_수정전`으로 보존했다. 수정 후 active 6run과 같은 입력·hash·실제 제외 상태를 다시 확인하기 전까지 fixture 판정은 보류다. 수행/채점기·기록 검사기는 실행하지 않았다.
