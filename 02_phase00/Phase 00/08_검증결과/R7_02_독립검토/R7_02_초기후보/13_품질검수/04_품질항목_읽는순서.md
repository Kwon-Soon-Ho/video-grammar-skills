# R7-2 품질 항목 읽는 순서

2026-10-15 · **초안 작성 후 독립 레드팀 대기.** 7묶음 26항목은 조건부 검수 지식이다. 26개를 모든 영상에 일괄 의무화하지 않는다. 실제 영상 검수나 자동 분석기를 구현한 단계가 아니다.

먼저 [공통 판정 운영](03_판정운영기준.md)을 읽고 대상이 분석 기록인지, 기획/시안인지, 실제 영상인지 정한다. 그런 다음 목적·매체·필수 메시지·사용 환경에 적용되는 항목을 고른다. 이유 없이 필수 항목을 빼거나 미확인을 비적용으로 바꾸지 않는다.

각 항목에는 원문 근거·적용 조건·필요 입력·검토 방법·적용 예·오용 반례·허용 예외·판단보류 조건·사람 역할이 있다. **분석 전사의 정확성과 원본 내용의 사실성**, **측정한 유지시간과 충분히 읽었다는 판단**, **정지 대비 계산과 실제 재생 가독성**을 나누어 읽는다.

웹 대비·UI 모션·한국어 조판은 해당 문맥을 가진 근거다. 회사 영상의 고정 글자 크기·CPS·줄 수·이징·안전영역·CI 보호공간 값을 만들지 않았다. 조판 문서는 초안, Carbon 자료는 v10 보존 지침, Cambridge는 공개 요약만 확인했다. 모든 논문·자막업체·플랫폼 납품 지침을 전수 조사한 것은 아니다.

자료가 없으면 필요한 항목의 판단보류/미검수 상태를 남긴다. [사람 검수 준비 목록](05_사람검수_준비목록.md)은 미래 입력 시 사용할 접수 설계이며 현재 누군가에게 발송하거나 실제 검수한 목록이 아니다. 이미 확인된 8회사 최신 자료·산하 AI원본 부재를 다시 요청하지 않는다.
