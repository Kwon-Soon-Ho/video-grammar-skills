# 한국어·단위 — 항목별 품질 기준

2026-10-15 · 품질항목 정본 v0.1.0에서 만든 읽기용 문서. 실제 검수 결과·회사 의무 규정이 아니다. 적용 예/반례는 모두 가상 설명이다. 각 항목은 적용 여부를 먼저 정하고 [공통 판정 운영](../03_판정운영기준.md)을 따른다. 원문 요약과 우리 프로젝트의 적용 해석을 구분한다.

## Q-TEXT-01 · 명칭·글리프·첨자

- **검수 질문:** 필수 기술명·한글/영문·기호·첨자가 실제 출력에서 의미를 보존하는가?
- **적용 조건:** 텍스트가 있는 시안/출력. 분석 전사와 제작 수정은 구분.
- **필요 근거:** 필수 명칭 원문, 실제 글꼴/대체글꼴과 출력 문자열, 최종 크기·해상도.
- **검토 방법:** 긴 명칭·부호·지수·대체 글리프의 잘림/오인을 실제 표시로 확인. 미관을 이유로 임의 축약하지 않음.
- **적용 예:** m²와 m³의 첨자, 긴 기술명을 실제 글꼴로 표시해 잘림과 의미를 확인한다.
- **오용·실패 반례:** ㎥/m³를m으로 바꾸거나 필수 기술명을 허락 없이 짧은 별칭으로 바꾼다.
- **허용 예외·비적용:** 검토된 짧은 표기와 원명 대응을 제공하면 요약 가능. 모든 기호를 같은 폭으로 맞출 필요는 없음.
- **판단보류 조건:** 글꼴·원문·실출력이 없으면 최종 표시 보류. 글꼴 이름만으로 설치/라이선스까지 통과시키지 않음.
- **영향·우선순위:** 단위 차원·회사명 변화는 내용 오류, 단순 조판 개선과 구분.
- **사람 검수:** 디자인 검수자·기술명 담당자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** SCREEN-TYPE-KO

## Q-TEXT-02 · SI 표기·값 보존

- **검수 질문:** 값·단위의 의미와 표기가 맞으며 원본을 임의 변환하지 않았는가?
- **적용 조건:** 측정값·SI 기호/접두어·온도·평면각을 포함하는 기술 화면.
- **필요 근거:** 원본 수치/정밀도/단위, 채택한 표기 지침, 문맥, 실제 표시.
- **검토 방법:** SI5.4.3–4를 참고해 값/단위 공백과 예외를 확인. 숫자 해석·단위 환산은 담당 검수 없이 수행하지 않음.
- **적용 예:** 120 kPa,30.2 °C,방향30°를 구분해 제안하고 실제 표시에서 값과 단위를 함께 읽게 한다.
- **오용·실패 반례:** 온도30.2° C처럼 단위를 쪼개거나 MPa/kPa를 바꾸면서 수치는 그대로 둔다.
- **허용 예외·비적용:** 표 머리글에 단위를 명확히 공통 표시할 수 있다. 재무·도면·인용 원문은 채택 문맥을 확인하고 SI식으로 자동 덮어쓰지 않음.
- **판단보류 조건:** 압력/힘 등 물리량·정밀도·소수 구분이 모호하거나 변환 근거가 없으면 해당 수정·사실 판정 보류.
- **영향·우선순위:** 값/차원 오류와 서식 차이를 별도 우선순위로 처리.
- **사람 검수:** 기술/데이터 담당자·디자인 검수자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** SCREEN-TYPE-KO, SCREEN-DATA

**원문 근거와 가져오는 범위**

- [BIPM SI Brochure 9th ed. v4.01 EN](https://www.bipm.org/documents/20126/41483022/SI-Brochure-9-EN.pdf/2d2b50bf-f2b4-9661-f402-5f9d66e4b507?version=7.0) · 5.4.3–5.4.4, printed pp.144–145 / PDF indices33–34. 값·단위의 공백, 평면각 예외, °C 표기, 소수점·숫자 서식을 다룬다. 원문/재무/도면의 기존 표기를 자동 변환하지 않는다. 값·정밀도·의미 변경은 별도 검수. 다른 장·전체 GUM 검토 아님.

## Q-TEXT-03 · 줄바꿈·문장 관계

- **검수 질문:** 줄바꿈이 문장·숫자·단위·첨자의 관계와 읽기를 해치지 않는가?
- **적용 조건:** 한국어/영문/숫자가 줄바꿈되는 화면·자막.
- **필요 근거:** 실제 문구·글꼴·줄폭·해상도, 중요 의미 묶음, 재생 시간.
- **검토 방법:** 행두/행말 부호·숫자열·첨자 분리를 확인하고 긴 기술명과 값/단위의 묶음을 프로젝트 문맥에서 검토.
- **적용 예:** 가상 ‘설계 수압 / 120 kPa’로 의미 묶음을 나누고 숫자열/단위는 읽기 덩어리로 유지한다.
- **오용·실패 반례:** 소수점 숫자를 두 줄로 쪼개거나 문장 끝 부정어만 잠깐 다음 화면에 보인다.
- **허용 예외·비적용:** KLREQ는 한글 글자/어절 줄바꿈 선택을 허용한다. 모든 어절 내 분리를 오탈자로 취급하지 않음.
- **판단보류 조건:** 실제 조판·시청 조건이 없으면 최종 줄바꿈 적합성/가독성 보류. 원문 전사 자체는 별도.
- **영향·우선순위:** 의미 반전/수열 분리는 우선 수정. 2줄/32자 일률 규정 없음.
- **사람 검수:** 디자인/자막 검수자·필요시 내용 담당자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** SCREEN-TYPE-KO
