## Q-MOTION-01 · 정보 완성과 읽기 유지

- **검수 질문:** 비교/설명에 필요한 정보가 완성된 뒤 읽고 연결할 시간이 있는가?
- **적용 조건:** 시간에 따라 정보가 나타나고 사라지는 영상/모션 기획.
- **필요 근거:** 대상별 등장·완성·유지·퇴장 시간과 발화, 필수 관계, 실제 시청 조건/필요시 시청자 확인.
- **검토 방법:** 전체 클립 길이 대신 실제 읽을 수 있는 구간을 확인. 비교할 값의 동시 유지·누적/요약과 과밀을 함께 검토.
- **적용 예:** A/B 수치·단위가 공개된 뒤 둘을 함께 읽을 상태를 유지하고 다음 설명으로 넘어간다.
- **오용·실패 반례:** 제목만5초 보였는데 뒤늦게 나온 단위까지 충분히 읽었다고 하거나 모든 이전 문구를 끝까지 쌓는다.
- **허용 예외·비적용:** 순차 공개·빠른 리듬도 목적·대상에 맞으면 가능. 정지/동시 공개 미사용 자체는 오류가 아님.
- **판단보류 조건:** 실제 시간·완성시점·시청 조건이 없으면 충분성 보류. 관측 유지시간은 근거가 있을 때 기록.
- **영향·우선순위:** 관계/수치 읽기 실패. 고정 초수는 아직 없음.
- **사람 검수:** 디자인/영상 검수자·필요시 실제 대상 시청자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** SCREEN-TIME-READ, AP-09, IP-09, MR-04

## Q-MOTION-02 · 동작 의미·대상 연속성

- **검수 질문:** 움직임·화살표·연동이 대상과 관계를 잘못 전달하지 않는가?
- **적용 조건:** 공정·구조·공동 이동·상태 전환을 표현하는 모션.
- **필요 근거:** 전후/중간 시계열·동일 대상 대응·기술 관계·실측/설명도 구분·실제 재생.
- **검토 방법:** 동일 대상 추적·라벨 연결·공간 관계·의미 일관성을 확인. 공동 이동을 실제 인과나 AE parent 증거로 만들지 않음.
- **적용 예:** 부품과 라벨이 함께 이동해도 해당 부품을 가리키며 시작/결과 상태의 관계를 유지한다.
- **오용·실패 반례:** 부품이 바뀌었는데 같은 라벨이 붙거나 흐름 화살표가 기술적으로 반대로 움직인다.
- **허용 예외·비적용:** 의도적 모션 차이로 서로 다른 의미를 표현할 수 있다. Carbon의 대각선 금지를 기술 이동 경로에 적용하지 않음.
- **판단보류 조건:** 중간 표본·동일성·실제 관계 자료가 없으면 해당 연속성/인과 보류. 보이는 연동 관측과 구현 추정은 분리.
- **영향·우선순위:** 동작/방향의 의미 왜곡. 미관 일관성으로 기술 오류 상쇄 불가.
- **사람 검수:** 기술 담당자·디자인/모션 검수자. 실제 내용·의도·시청 품질의 최종 판단은 해당 근거를 제시하고 맡긴다. 현재는 실제 대상 미접수이며 검수 완료가 아니다.
- **기존 지식 연결:** MR-01, MR-02, MR-03, MR-07

## Q-MOTION-03 · 이징·과장·장식의 역할

- **검수 질문:** 속도·변형·장식이 전달을 돕고 실측 의미·글자 형태를 훼손하지 않는가?
- **적용 조건:** 가감속·변형·과장·장식 모션이 있는 설명/브랜드 영상.
- **필요 근거:** 목적·시간 표본·실측/연출 구분·원형/문구·실제 재생.
- **검토 방법:** 장식과 측정 대상을 나누고 시간/경로·형상 보존 확인. 모든 동작에 이징/바운스·12원칙 사용을 강제하지 않음.

- **영향·우선순위:** 기술 의미 훼손과 선택적 미관 개선을 구분. UI 수치의 무조건 전용 금지.

## Q-MOTION-04 · 섬광·급격한 반복 변화

- **검수 질문:** 빠른 밝기·적색 변화 후보를 적절한 시간·면적·휘도 조건으로 검토했는가?
- **적용 조건:** 실제 영상의 시간적 접근성 검토. 컷 전환/플래시 후보를 확인하되 후보 목록만으로 전 구간 통과 불가.
- **필요 근거:** 최종 영상 전 구간의 연속 시간 정보·실제 재생 크기/밝기 조건·방법/검사 결과·후보 범위.
- **검토 방법:** 횟수만이 아니라 일반/적색 임계값·면적 등 출처의 조건을 확인한다. 전체 원본 확보 후 적절한 검사와 담당 검토 필요. 지금 도구 실행 없음.
- **적용 예:** 고대비 반복 구간을 위치·조건과 함께 검수 대기로 등록하고 확인 전 안전 통과라고 하지 않는다.
- **오용·실패 반례:** 몇 장의 프레임에 점멸이 없거나 정지 버튼이 있다는 이유로 영상 전체 섬광 검사를 통과시킨다.
- **허용 예외·비적용:** 급격한 컷 전환이 모두 기준상 섬광인 것은 아니다. 정지 기획물은 시간적 섬광 비적용이나 최종 렌더에 승계하지 않음.
- **판단보류 조건:** 연속 시간/휘도/면적·재생 조건·검사 근거가 없으면 안전 판정 보류. 후보 미검출을 비적용 이유로 쓰지 않음.
- **영향·우선순위:** 시간적 위험 후보의 우선 확인. 육안 노출 실험·의학적 안전 인증·WCAG 전체 인증 없음.
