# R6-4 통합 연결·조회 결과

2026-10-15. **현재 출처·회신과 R4/R5 계약 참조를 별도 R6 입력 고정으로 연결하는 한정 범위를 완료했다.** 실제 R4/R5 개별 기록·영상 내용 검수는 수행하지 않았다.

50개 입력의 hash와 출처·대상/근거·정책·회신/질문 snapshot을 대조한다. 최신 CI8회사 사용자 선언과 추가 CI가이드8회사 미확인을 구분하고 기존 한맥 source_selection/UI선택참고를 유지한다. 조회 실패 시 미검증 대기/회사 결과를 노출하지 않는다. R4 spatial supported 보류·회사/사용권한·사실 검증을 승격하지 않는다.

레드팀에서 스키마 해석이 hash검증보다 앞서 외부/미해결 참조의 예외가 빠져나오는 문제와 내부 결과의 CI필수행 누락 예외를 보완했다. 직접 기본구조 확인→모든 pin검사→읽은 스키마bytehash재확인→외부 참조 거절/비네트워크 registry→검수 연결→반환전 재대조 순서를 적용했다. 필수행·범위목록·답변 수의 내부계약도 확인한다.

자체26/26은 정상 조회와 함수 결함주입 범위이며, 독립 시험은 C사본의 실제byte변경/누락·변경 시점·스키마 URI/CLI 등을 따로 확인했다. 서로 다른 시험수를 합산하지 않는다. 초기 실패와 배포가 겹친 이력은 최종 동결 성적과 분리 보존했다.

50개 초기/보완 입력사본을 각각 보존했고 R4/R5/R6-2/3·기존 스킬·실제 회신의 원문은 유지했다. 저장된 조회JSON은 생성시점 사본이다. 현재 판단에는 도구 재실행이 필요하며 자동 갱신·원자 snapshot·암호학적 서명/신원/내용 인증을 구현한 것으로 해석하지 않는다.
