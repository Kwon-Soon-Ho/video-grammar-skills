# 평가 지표와 분모

2026-10-15 · 계획 초안. 아래 식/숫자는 설계 설명이며 실제 모델·영상 성적이 아니다. 지표는 과제별 진단에 사용하고 단일 영상 품질 총점으로 합치지 않는다.

## 먼저 기준답안의 상태를 나눈다

| 집합 | 의미 | 보고/사용 |
|---|---|---|
| R_A | 주어진 허용 입력만으로 답할 수 있고 사람 기준답안이 확인된 적용 대상 | 해당 과제의 정오/누락·오탐·커버리지 분모. |
| R_H | 입력 부족/원본 한계 때문에 이유를 밝힌 보류가 적절하다고 확인된 대상 | 적절한 보류·근거 없는 단정 지표를 별도로 봄. |
| R_U | 기준답안 자체가 미검수/충돌/미해결이라 아직 채점할 수 없는 대상 | 정오율에서 제외하되 개수·원인·중요도·담당·포함 전후 범위를 공개. 정답이 보류라고 임의 변환하지 않음. |
| R_N | 그 조건에서 비적용임을 확인한 대상 | 적용성 판정 평가에서 올바른 비적용/부당한 적용을 별도 확인. |

R_A/R_H는 원본 세상에 정답이 존재하는지뿐 아니라 **시험 때 모델에게 허용되는 입력으로 정당화할 수 있는지**를 본다. 평가자만 아는 제작 의도를 모델이 근거 없이 맞혔다고 정답 처리하지 않는다. 반대로 기준답안을 못 만들었다는 R_U를 ‘모델은 보류해야 한다’는 R_H로 바꾸지 않는다.

평가 예정 전체 수와 R_A/H/U/N, 필수항목의 미해결 수를 함께 표시한다. R_U를 빼서 높은 숫자만 보고하지 않는다. 미해결 필수 기준답안이 있으면 그 범위의 준비완료/성능 합격을 제안하지 않는다. 일부 확인 결과는 부분 결과로 보고할 수 있다.

## 오류 검출처럼 고정된 항목을 판단할 때

여기서 ‘양성’은 **오류 있음**, ‘음성’은 **오류 없음**이다. 품질이 좋다는 양성과 혼동하지 않는다. R_A의 항목마다 결과는 다음 중 하나로 상호 배타적으로 기록한다.

- D: 오류 있음/없음을 명시적으로 판정. TP(오류를 발견), FP(없는 오류를 지적), FN(오류인데 없다고 통과), TN(없음을 올바르게 판정).
- A: 이유를 갖춘 명시적 판단보류. 정답을 맞혔다고 세지 않는다.
- X: 적용 대상인데 근거 없이 비적용으로 제외. 보류와도 구분한다.
- M: 항목 출력 누락/미완료. 명시적 보류로 세지 않는다.
- F: 도구/실행/파싱 실패로 해당 항목을 평가하지 못함. 실패를 관측하지 않은 정상 판정으로 바꾸지 않는다.

`N_A = D + A + X + M + F`, `D = TP+FP+FN+TN`을 만족해야 한다. 전체 실행이 실패했다면 그 실행의 예정 항목은 F로 기록하고 같은 항목을 M에도 중복 계수하지 않는다. 재시도는 별도 시행이며 실패 이력을 지우지 않는다. 이 분류는 평가 집계용이며 R7-1 항목 판정을 대체하지 않는다.

| 지표 | 식·분모 | 해석 한계 |
|---|---|---|
| 지적 정밀도 | TP/(TP+FP) | 지적한 오류 중 맞은 비율. 아무것도 지적하지 않으면 분모0 → null. |
| 판정 커버리지 | D/N_A | 답할 수 있는 적용 대상에서 실제 결론을 낸 비율. 성공/정확성 아님. |
| 결론 낸 항목의 오류율 | (FP+FN)/D | 조건부 오류율. 보류/누락/실패를 숨긴 전체 정확도로 부르지 않음. |
| 전체 오류 발견율 | TP/P_A. P_A는 R_A에서 기준상 오류인 전체 항목 수 | 보류·부당 비적용·누락·실패에 있는 실제 오류도 분모에 유지. 소극적인 전부보류로 높일 수 없음. |
| 잘못된 통과율 | FN/P_A | 오류를 ‘없음/통과’로 처리한 비율. 보류는 잘못된 통과와 구분하나 발견 성공도 아님. |
| 전체 정답 산출률 | (TP+TN)/N_A | 이 고정 과제의 완수 진단. 전체 영상 품질 점수/배포 승인 아님. |
| 보류·부당 비적용·누락·실패율 | A/N_A, X/N_A, M/N_A, F/N_A 각각 | 네 원인을 나눠 보고. 보류 이유·필요 사람 판단·재시도 비용도 표시. |

모든 비율은 분자/분모/참조 버전과 함께 표시한다. 분모0은 null과 이유를 기록하고0/1·100%로 채우지 않는다. 양성이 없는 표본에서 오류 발견율을100%라 하지 않는다. 극소 분모의 비율 차이로 개선을 확정하지 않는다.

**가상 산술 예:** 답할 수 있는10항목 중 실제 오류4, 정상6이라고 가정한다. TP2/FN1/TN4/FP1, 보류2(오류1/정상1), X/M/F0이라면 판정 커버리지는8/10, 조건부 오류율2/8, 전체 오류 발견율2/4, 잘못된 통과율1/4다. 보류를 빼면 오류 발견이 더 좋아 보일 수 있으므로 전체 양성4를 유지한다. 이10항목을 실행·채점한 적은 없다. 전부 보류했다면 D=0이라 조건부 오류율은null이고 전체 정답 산출률은0이다.

## 태그·문구·사건을 추출할 때

고정 항목의 양성/음성 판정과 별도 과제다. 기준답안이 확인된 대상·범위에서 예상 항목 집합 G와 유효 예측 집합 P를 고정된 매칭 규칙으로1:1 대응한다. 종류·대상·의미·시간/좌표의 필요한 조건을 만족한 매칭 수가 TP, 대응 없는 예측이 FP, 빠진 기준 항목이 FN이다. 같은 정답을 중복 출력한 나머지는 TP를 늘리지 않으며 범위 내 중복 오탐으로 기록한다. 허용 대안의 동치군은 하나의 필요한 항목으로 취급하고 대안 전부를 동시에 내도록 요구하지 않는다.

추출 정밀도는 TP/(TP+FP), 추출 재현율은 TP/(TP+FN). 알려진 기준 항목은 보류·누락·실행 실패가 있어도 필요 항목 분모에서 없애지 않는다. 파싱 실패로 예측 항목 수를 알 수 없다면 유효 출력 조건부 정밀도와 실패 수/율을 명시하고 전체 정밀도가 확인됐다고 하지 않는다. 알려진 기준 항목은 해당 실행의 누락 수/재현율 진단에 반영한다. 항목 수 자체를 모르는 불완전 기준답안은 R_U로 남겨 범위 제한을 보고한다.

이 과제의 사건/문구 오탐 수와 고정 항목 판정의 FP는 단위가 다르므로 합산하지 않는다. 정확한 문자열/코드 매칭은 맞아도 원본 부분을 잘못 가리키면 근거 적합성 검수는 별도 실패/보류다. 도구가 형식에 맞는 ID를 반환했다는 사실은 의미를 확인한 것이 아니다.

## 시간·좌표·지식 적용·비용

- 시간/좌표 오차는 동일 대상·공간/시간축에 매칭된 항목에서만 비교한다. 경계별 절대 오차·분포와 단위/가정, 매칭 안 된 사건의 누락/오탐, 해당 결과의 커버리지를 같이 보고한다. 쉬운 매칭 항목만의 평균오차로 전체 추적 성능을 주장하지 않는다.
- 등장 시점·완성/유지 구간·대상 위치·bbox는 서로 다른 변수다. 허용오차/정규화/겹침 기준과 산출 방법은 예비 단계에서 정하고 잠금 전에 고정한다. VFR에 고정fps의 프레임차를 공통 시간오차로 쓰지 않는다.
- 지식 적용은 R7-2의 해당 항목마다 내용 보존·근거·유효 대안·과잉 강제·보류의 적절성을 검토한다. 사람 루브릭과 기계식 구조/참조 검사를 분리하고 미관 총점이나 원칙 사용 개수로 합치지 않는다.
- 비용/시간은 실제 로그가 있을 때만 모델/도구/재시도/대기·사람 검수/수정까지 구분해 기록한다. baseline과 과제·입력·환경·권한/도구가 다르면 차이를 설명하고 효과를 단정하지 않는다. 현재 측정값은 모두 null이다.

영상/원본 묶음·조건별 분자/분모를 먼저 보고한다. 프레임 단위 미시 평균과 영상별 평균은 의미가 다르므로 섞지 않는다. 실제 업무 표본과 도전 표본은 별도이며 모집 비중을 모르면 임의 가중 평균으로 업무 성공률을 만들지 않는다. 같은 영상의 많은 프레임이나 같은 과제의 반복 시행을 독립 영상 N으로 늘리지 않는다.

통계적 불확실성은 표본 설계에 맞는 방법을 선택해야 한다. [NIST의 이항 비율 구간 설명](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)을 독립 Bernoulli가 아닌 종속 프레임·군집 반복에 바로 적용하지 않는다. 작은 원본 묶음이면 근거 부족을 먼저 표시하고 신뢰구간/모집단 우월성을 억지로 만들지 않는다. 방법·신뢰수준·필요 표본 수는 예비 후 검토 항목이다. 오류0건도 모집단 오류0을 증명하지 않는다.
