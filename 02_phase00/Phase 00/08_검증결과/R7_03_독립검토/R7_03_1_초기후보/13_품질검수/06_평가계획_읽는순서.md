# R7-3 평가 계획 읽는 순서

2026-10-15 · **진행 중. 정답·표본 초안 작성, 운영 방식 검토 대기.** R7-3 전체와 Phase00은 미완료이며 01-A는 미진행이다.

이번에는 평가 계획을 만든다. 실제 영상·사람 기준답안·분할/잠금 자료·분석 실행은 아직 없다. 구조/기록 계약, 영상 분석 정확성, 지식 적용 검토, 실제 전달/업무 효과를 서로 다른 평가로 본다. 단일 품질 총점 없음은 기존 사용자 A를 유지한다.

1. [평가 운영 방식4안](평가계획/00_진행방식_검토안.md) — 추천 A는 예비 보정 후 다른 원본 묶음의 잠금 자료로 확인.
2. [정답과 판정 단위](평가계획/01_정답과_판정단위.md) — 복수 정답·관측/사실·허용오차·사람 근거.
3. [표본과 유출 방지](평가계획/02_표본과_유출방지.md) — 실제 업무/도전·예비/잠금의 역할과 독립 원본 묶음.

다음 소단계는 평가 지표·분모·판단보류의 처리, 그다음은 사람 의견 차이·중재·재시험이다. 소단계별로 레드팀 검토 후 보완한다. R7-4의 기존 규격 연결/인계·R8 스킬 재구성·01-A 구현을 대신하지 않는다.
