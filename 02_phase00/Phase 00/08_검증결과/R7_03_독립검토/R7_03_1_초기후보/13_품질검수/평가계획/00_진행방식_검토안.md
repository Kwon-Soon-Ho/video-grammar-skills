# 평가 운영 방식 — 검토할 네 가지 안

2026-10-15 · **검토 대기, A 추천.** R7-1의 항목별 판정/단일 총점 없음은 유지한다. 이번 선택은 미래 평가를 어떤 순서로 운영할지이며 01-A 실행 승인·회사 납품 기준·실영상 합격점 선택이 아니다. 실제 자료/합격 수치는 아직 없다.

| 안 | 평가 운영 순서 | 얻는 것 / 한계 |
|---|---|---|
| A 추천 | 예비 자료로 정답 기준·허용오차·합격 조건을 보정 → 다른 원본 묶음의 잠금 표본에서 확인 | 초기 근거 없는 수치를 피하고 최종 자료로 기준을 고치는 유출을 막음. 예비 후 표본 수·반복 수·허용오차·필수 조건의 수치 검토가 한 번 더 필요. |
| B | 예비 보정 없이 전문가가 합격 조건을 먼저 고정 → 잠금 표본으로 평가 | 이미 외부 요구·전문가 근거가 있을 때 적합. 지금 없는 수치를 AI가 채우지 않고 담당 근거를 받아야 함. |
| C | 예비·탐색 평가만 운영 → 공식 성능 판정은 이후 별도 결정 | 기준을 배우는 초기 단계에 가벼움. 결과로 독립 최종 성능이나 일반화 주장을 하지 않음. |
| D | 고정 공통 벤치마크 없이 건별 사람 검수 중심으로 운영 | 매 작업의 확인 범위를 보여줄 수 있으나 프로젝트 간 성능 추세·일반화 비교가 제한됨. |

모든 안에서 실제 업무 표본과 오류/희귀 조건을 집중한 도전 표본의 결과는 분리한다. 범위·입력·정답·실행·판정의 버전을 보존하고 핵심 오류나 필요한 사람 검수를 다른 장점으로 상쇄하지 않는다. 합격 수치/표본수/통계적 신뢰도를 지금 임의로 확정하지 않는다.

선택과 무관하게 정답 기록·지표의 분모·보류 처리·사람 의견 차이·재시험 원칙은 먼저 설계할 수 있다. 현재 A는 추천이며 사용자 선택이 접수되기 전 실제 결정으로 적지 않는다.
