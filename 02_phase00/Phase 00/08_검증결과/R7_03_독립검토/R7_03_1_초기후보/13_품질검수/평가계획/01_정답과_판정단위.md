# 정답과 판정 단위

2026-10-15 · R7-3의 평가 설계 초안. 실제 정답셋/실행 결과가 아니다.

## 평가 대상을 네 갈래로 구분

| 갈래 | 평가하는 것 | 근거/평가자 | 이 성적이 증명하지 않는 것 |
|---|---|---|---|
| 구조/기록 계약 | 버전·시간·좌표·참조/보류 기록의 일관성 | R4/R6 기존 규격과 범위가 고정된 반례 | 실제 화면 해석·가독성·회사 승인 |
| 영상 분석 정확성 | 보이는 내용·사건·시간/위치·주장 근거를 정확히 기록하는가 | 실제 입력에서 독립적으로 만든 사람 기준답안과 원본 | 원본 영상이 좋은 디자인/사실을 전달한다는 것 |
| 지식 적용/검토 | 목적에 맞는 후보·반례·보류·수정안을 제안하는가 | R7-2 항목별 근거/허용 대안과 전문가 판단 | 미래 렌더의 품질·실제 시청자의 이해 향상 |
| 실제 전달/업무 효과 | 필요한 내용을 읽고 이해하는가·수정/검수 포함 시간이 줄었는가 | 실제 출력/환경·대상 시청자·시간 실측 비교 | 구조 검사나 합성 예로 대체 불가. 후속 제작/실무 검증 영역 |

이번 단계는 네 갈래의 계획만 작성한다. R8 스킬 평가와 01-A 영상 분석 실행은 후속이며, 회사 문법의 승인/일반화는01-B다. 기존 세스킬의 옛3과제·11/12동률·쓰기시범8조건·R7-2 문서검토를 새 실영상 성적으로 합산하지 않는다.

## 작은 판정 단위와 정답 형태

영상 전체→설명 구간→화면 상태→동작의 R2 단위를 사용한다. 컷이나 추출 프레임 수를 독립 영상 수로 세지 않는다. 과제마다 평가 대상·시간 범위·필요 항목의 목록을 결과를 보기 전에 정한다.

| 정답의 형태 | 예 | 허용되는 것 / 보류 |
|---|---|---|
| 원문에 따른 값/전사 | 렌더의 문구·수치·단위 | 렌더에25라고 보이면 분석 전사는25. 기술 원문0.25와의 사실 충돌은 별도 검수. 원본을 몰래 정정하지 않음. |
| 집합/복수 태그 | 공존하는 레이아웃·표식·모션 | 허용된 여러 태그의 적용조건을 명시. 단어 하나가 다르다는 이유로 오류 처리하지 않음. |
| 사건/대상 매칭 | 표식 등장·같은 부품의 연속성 | 대상 동일성·종류·구간·시간 기준을 함께 만족해야 함. 중복 출력으로 한 정답을 여러 번 맞혔다고 세지 않음. |
| 수치/경계 | 등장 시점·읽기 유지구간·좌표 | R4의 축·단위·시각/공간 변환·불확실성과 정답의 허용구간을 기록. 임의1프레임/IoU0.5를 공통 정답으로 만들지 않음. |
| 근거를 가진 해석 | 비교형 선택·적절한 수정 후보 | 요구 메시지·유효 대안·금지된 확대 해석을 루브릭으로 명시. 하나의 스타일 문구만 정답으로 고정하지 않음. |
| 원본만으로 알 수 없음 | AE parent·제작 의도·정보 부족 | 충분한 원본이 있어도 의도/구현은 별도 근거 필요. 정답은 ‘단정 불가+이유/필요 확인’일 수 있음. |

정답의 epistemic 상태는 `확정 가능한 범위`, `복수 허용 답안`, `담당 판단 대기`, `근거 충돌`, `자료 부족`, `적용 안 됨`으로 이유와 함께 구분한다. 이것은 R7-1의 모델 결과 통과/수정필요/보류/비적용과 다른 축이다. 실제 사람 검수가 필요한 값을 AI가 확정 정답으로 승격하지 않는다.

## 기준답안 기록 항목

평가항목ID/버전, 대상·원본/파생ID·해시, 허용 입력, 관측 시간/좌표와 필요한 정밀도, 예상되는 항목/사건의 범위, 내용·근거·반대 근거, 정답 상태·허용 대안, 매칭/정규화 규칙, 허용오차와 이유, 중요도·적용/필수 이유, 독립 초기 판정과 검수자 역할, 불일치/중재 이력, 현재 답안 버전을 남긴다. 이 목록은 평가용 기록 설계이며 기존 R4/R6 DB 스키마를 바꾸지 않는다.

분석에 제공할 입력과 평가자만 보는 정답/근거를 분리한다. 실제 영상과 대본을 함께 입력할 과제인지 영상만 볼 과제인지 먼저 정하고, 영상에 없는 내용이 대본에 있는 조건도 포함한다. 정답을 모델 출력에 맞춰 사후 고치는 것은 금지한다. 정답 자체의 오류를 고칠 때는 양쪽 비교 대상 모두 같은 새 버전으로 다시 평가한다.

## 정규화와 허용오차

원문 문자열은 보존하고 비교용 정규화 규칙을 별도 고정한다. 띄어쓰기·NFC 등 허용 변경이 소수점/부정어/법인명/단위·첨자 의미를 지우지 않게 한다. 수치와 단위를 바꾸는 의미 정규화는 기술 담당자 근거 없이 하지 않는다. Unicode 문자 위치는 기존 R4 표현 계약을 따른다.

관측 불확실성과 평가 허용오차는 다른 값이다. 시간 경계는 원본 PTS/시각 대응·가변 프레임과 사건 정의를 보고 정하고, 좌표는 같은 공간/변환·경계 기준으로 비교한다. 사건 시작 정의(첫 식별 가능 상태 등)가 다르면 정의 불일치부터 해결한다. 중심 시점 하나가 맞아도 짧은 사건이 누락/합쳐졌는지 별도 확인한다. 합격 허용오차 수치는 보정/담당 검토 전에는 null이다.

사람 기준답안을 미리 만들 때 동일 원본을 독립 검수하고 초기 답을 잠근 뒤 비교한다. 지금은 실제 사람·영상·답안이 없어 정답셋 확보/사람 검수가 완료되지 않았다.
