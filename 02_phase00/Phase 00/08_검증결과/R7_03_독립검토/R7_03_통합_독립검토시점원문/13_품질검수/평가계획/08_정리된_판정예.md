# 평가 설계의 경계 사례

아래는 실제 시험을 하지 않은 설명용 예다. 이 표의 사례 수를 시험 통과 건수로 세지 않는다.

| 상황 | 계획상 처리 |
|---|---|
| 렌더25·기술 원문0.25, 모델은 렌더25를 정확히 전사 | 전사 정확성과 원본 정보 오류/원문 충돌 검수를 분리. 원본을 몰래 보정해 전사를 오답으로 만들지 않음. |
| 같은 장면의 세로본으로 개발 후 가로본을 잠금이라 이름 붙임 | 파생/핵심 내용 source_family 노출. 잠금 미노출 성적으로 쓰지 않음. |
| 잠금A에서 만든 오류A′만 도전 자료로 개발 | 역할이 도전이어도 노출. A그룹 미노출 성적 불가. |
| 검수자 정답이 미정인5항목을 조용히 삭제 | R_U5와 중요도·모집 전체·부분 결과 범위를 공개. 보류 정답R_H로 바꾸지 않음. |
| 전부 판단보류로 오답0이라고 주장 | R_A 커버리지0·정답 산출0·조건부 오류율null. 적절 보류R_H와 별도. |
| R_H 한 항목에 올바른 보류와 근거 없는3단정 | 그 단위의 적절 보류 성공0·단정 위반1, 단정3개는 별도 건수. 300%비율 금지. |
| 필요한 발생1개를 같은 대상/시점에서3회 추출 | 일대일 매칭TP1·중복FP2. 중복 제거로 정밀도 부풀리기 금지. |
| 같은 항목에 오류 없음/오류 있음을 둘 다 최종 결론으로 출력 | 유리한 답을 골라 정답 처리하지 않고 무효출력F1회·진단코드/원문 보존. |
| 두 사람이 토론한 뒤 초기 답을 고쳐 일치100% | 초기 독립 답 불일치를 보존. 중재 후 합의는 별도 이력. 같은 오답 합의도 가능. |
| 가장 잘된 재시도만 보고 | 최초/모든 시행·실패/재시도 조건·비용을 공개. 반복을 독립 영상 수로 세지 않음. |
| 정답/허용오차를 고쳐 새 모델만 다시 채점 | 비교 양측을 같은 버전으로 재채점. 새 정답 효과와 모델 변경 효과 분리. |
| CI 최신성 답변이 있으니 영상 시안/권한까지 승인 | 기존 회신의 범위만 유지. 실제 시안/사용권한 검수는 별도. |

검수 목적의 필수 오류가 실제로 확인됐으면 다른 지표 개선/미관 장점으로 상쇄하지 않는 R7-1 A 정책을 유지한다. 예비 후 정할 수치 조건도 이 원칙을 우회하는 허용선이 아니다. 합격 수치는 해당 과제·목적의 근거와 사용자 검토로 정하며 회사 납품 규정으로 자동 승격하지 않는다.
