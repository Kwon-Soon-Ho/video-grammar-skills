# R4-4 1단계 — 착수 감사·연결 설계 결과

2026-10-15. **착수 감사와 연결 설계 범위 완료.** 통합 코드·이관·전체 R4 완료는 이후 단계다.

기존 설명용/스킬 시험/과거 평가의 구형 독립 기록 5개를 찾았다. 모두 합성 예시이며, 원본 영상 버전/hash·실행/화면 상태가 부족하다. 영상 경로·원본 내용은 읽지 않았다. 기존 검사에서 원본 PTS와 재생 시각 모순, 구간 끝 프레임, 없는 변환/음수 해상도, 임의 run 객체가 통과하는 것도 메모리 복사로 재현했다. 기본 예시에서 layout이 구간에 붙는 문제는 R2 상태 단위와의 불일치로 확인했다.

독립 레드팀은 연결 설계를 지지하며, 구형 예시에 가짜 영상 hash/PTS/상태를 넣어 통합하는 것을 금지해야 한다고 지적했다. 원문 JSON hash와 영상 hash 구분, 과거 평가 입력 보존, 접수함의 별도 계약, geometry 성분/단위/오차 연결, 통합 context 확장과 버전별 검사 결과를 후속 필수 점검으로 반영했다.

사용자는 **A: 새 통합 규격 기본 + 부족한 기록은 원문·누락 목록과 접수함 보존**을 선택했다. 기존 3스킬 의미·권한과 R2/R4-1~3 결정은 유지한다.
