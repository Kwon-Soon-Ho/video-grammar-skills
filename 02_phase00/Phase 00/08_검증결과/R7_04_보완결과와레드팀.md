# R7-4 결과 — 연결·인계와 레드팀 보완

2026-10-15 · **기존 규격과 R7 품질 기준/평가 계획을 잇는 연결 설계·읽기 도구·등록/인계의 한정 범위로 완료했다.** 실제 영상·내용/시청 검수·정답·모델 시행/성적·사람/회사/사용권한 인증은 수행하지 않았다. 전체 Phase 00은 R8과 최종 종료 검토가 남아 있고 01-A는 미진행이다.

## 선택과 단계별 결과

사용자 A: 별도 R7 연결 목록·인계 문서 + 작은 읽기 전용 연결 확인 도구를 적용했다. [실제 선택 기록](../13_품질검수/연결과인계/연결방식_사용자결정.json)에 답변 원문·질문 식별자를 보존했다. R4/R5/R6 계약과 기존 세 스킬의 목적·권한·시범 승인은 유지했다.

| 소단계 | 정리한 내용 | 레드팀과 보완 |
|---|---|---|
| 1 현행 대조 | R2 네 단위·R4 시간/근거/좌표·R5 디자인 초안·R6 회신 문맥·R7 항목/평가 계획의 현재 참조 | 착수130입력/backup 대조, 과거 스냅샷과 현재 조회 구분, 실제 CI 최신성 답변과 새 내용 검수0 구분 |
| 2 검수/보류 연결 | 22필드 위치·26항목 연결 후보·빈 양식, 필수항목/근거·보류/수정·현재성, 읽기 도구 | 정책/필수키·필드 누락·자료범위·0과false 구분을 보강. 판정방법/담당역할 칸 추가. Windows 특수문자 경로 오류도 JSON 출력 |
| 3 사용 동선·인계 | R7 자료13종 ID/버전/SHA 등록, 현재 읽는 순서·R8/01-A·사람 판단 준비 분리 | 기존 등록 이력 유지, 안내와 자동생성 표시 구분, 문서/구조 검사와 실제 영상 평가의 경계 재검토 |

각 소단계 작성→독립 레드팀→보완/재검토 후 다음 단계로 넘겼다. [1단계 독립판정](R7_04_독립검토/R7_04_01_최종판정.md), [2단계 독립판정](R7_04_독립검토/R7_04_02_최종판정.md), [3단계 독립판정](R7_04_독립검토/R7_04_03_최종판정.md)에 원문 근거와 한계를 보존했다. 조건 수는 문서·구조·합성 결함 주입 검사이며 실영상/모델 성적과 합산하지 않는다. [1·2단계 상세 보고](R7_04_01_02_단계보고.md)도 함께 볼 수 있다.

## 적용 예와 반례

- 숫자/단위 오류는 해당 대상·버전과 원본/주장/반대 근거에 연결한다. 로고/관측색 검수는 R5의 회사 자산·명시 선택·출력 조건을 함께 본다. 모든 항목에 좌표를 강제하지 않는다.
- 같은 원인으로 자막·그래프가 틀리면 공통 원인으로 연결하되 각 영향은 남긴다. 고유 원인 묶음으로 R7-3의 사전 고정 평가 분모를 바꾸지 않는다.
- 기존 CI가 최신이라는 답변은 새 시안 가독성·기술 정확성/회사 승인 근거가 아니다. 새 사람 판단이 필요한 대상은 그 버전/질문으로 별도 접수하고 답변을 받을 때까지 해당 판단을 보류한다.
- 저장된 정상 결과·같은 파일명·등록 목록의 존재만으로 현재 참조/내용이 맞다고 하지 않는다. 해시 차이를 없애려고 입력 고정을 자동 재생성하지 않는다.

## 도구의 정확한 범위

[R7 연결 확인](../13_품질검수/연결과인계/04_연결확인_사용안내.md)은 지정 기반130파일·선택 참조·22필드/26항목·빈 양식의 구조를 읽는다. 현재 문맥 v0.1.3/양식 v0.1.1이다. R6 고정 파일의 바이트를 확인하지만 R6 조회를 실행하지 않으며 실제 R4/R5/R7 기록 검사와 내용/권한 검수도 대신하지 않는다. R6 현재 조회는 별도로 재실행했다. 저장 결과는 각 실행 시점의 사본이다.

초기 실제 파일 변경은 고정 해시로 차단됐다. 더 깊은 메모리 구조 단위검사에서 발견한 미검출과 추가 내용/콘솔 경계는 보완 후 재시험했다. 이 과정을 해시 우회·실제 자산 손상으로 과장하지 않는다. 도구는 파일을 쓰지 않고 영상/화면/네트워크에 접근하지 않는다. 동시 파일 묶음의 원자적 잠금·전자서명·악의적 동시교체/사람 신원 인증을 보장하지 않는다.

## 보존·현재성·남은 작업

착수130입력 원문은 모두 backup에서 원래 해시로 보존했다. 최종 등록/안내 정리에서 달라진 파일과 old/new 해시는 [마무리 확인](R7_04_마무리확인.json)에 별도로 기록했다. 과거 독립검토 after_hashes는 당시 스냅샷이며 현재 전체 폴더의 불변 목록이 아니다. 기존 R4/R5/R6 계약·한맥/CI 값·세 스킬은 바꾸지 않았다. 실패/보완·작성 도구·후보는 검증결과와 backup에 분리했다.

R7-4는 새로운 외부 지식 조사 단계가 아니라 기존 로컬 규격/결정·R7 원문 근거를 연결한 단계다. 앞서 조사한 원문과 읽기 깊이는 R7-2/3 조사 기록을 유지한다. 보존 파일 수를 신규 논문 조사량으로 세지 않는다.
