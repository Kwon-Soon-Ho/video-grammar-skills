# 최신 세 스킬 소량 사본 시범 결과

2026-10-16. **사본의 정상 지식 정리·연결·검토를 순서대로 완료했다. 다음 인계를 막는 미해결 결함은 없었다. 사람의 출력 피드백과 기본 전환은 별도다. 01-A는 시작하지 않았다.**

## 어떤 자료로 무엇을 했나

기존 Phase 00의 선형 프로세스·주목 이동·가시성 변화 3용어를 사용했다. 각 설명을 쉽게 쓰되 원뜻·적용 조건·반례·출처를 잃지 않는지 확인했다. 실제 사내 영상이나 새 화면 제작 자료는 사용하지 않았다.

최신 후보는 큐레이터 `0.2.0-draft.3`, 기록 관리자 `0.2.0-draft.5`, 적용성 검토자 `0.2.0-draft.4`다. 기존 기본 스킬이나 전역 설치는 변경하지 않았다. 원문 24파일과 후보 11파일의 해시를 확인한 사본에서 시작했다. 검수기준은 실행 전에 고정했다. 수행자는 역할별로 분리하고 이전 단계 실제 bytes를 전달했다. OS/모델의 완전 격리 시험을 뜻하지 않는다.

적용성 검토자가 사전 선정한 R7 품질항목에서는 `Q-INFO-01`의 **실제 독자 적합성이 판단보류**다. 나머지 선정 항목은 명시한 문서 대조 범위에서 통과했다. 시범 절차의 고정 조건 충족을 독자 적합성 통과나 전체 품질 합격으로 바꾸지 않는다.

## 레드팀과 보완 결과

착수 전에는 이 작업이 R4/R5 영상 기록이 아닌 **로컬 지식 인덱스**임을 확인했다. R4/R5 전용 도구로 억지 검사하지 않고 허용 필드·판본·해시·상류 연결을 좁게 확인하도록 범위를 명확히 했다.

1단계에서 연결목록이 옛 카드 판본을 가리키는 것은 수정 금지 범위를 지킨 정상 인계 상태다. 2단계에서 이 참조를 갱신했다. 3단계는 그 실제 결과를 검토했다. 원문과 승인 상태를 고쳐 문제를 숨기지 않았다.

2단계 최초 사전검사는 한맥 정본의 키를 `id`로 가정해 KeyError로 쓰기 전에 중단됐다. 실제 `profile_id`를 확인해 **이번 실행의 검사 코드만** 수정했다. 원문·스킬을 검사기에 맞춰 바꾸지 않았다. 실패 당시 코드와 stderr를 보존했고, 이후 inspect/update/verify는 각각 exit0으로 끝났다. 단순 첫 실행 성공으로 보고하지 않는다.

단계별 의미/범위 검토 후 인계를 막는 미해결 결함은 없었으며 스킬이나 원문 정의를 다시 수정할 사유는 발견하지 않았다. 판단 근거·실제 읽기 범위는 `독립검토/01_단계검토.md`부터 `03_단계검토.md`에 보존했다. 이상 없음은 모든 지식의 사실성·전체 도구·모든 실패 분기의 검증을 뜻하지 않는다.

PDF는 최초 검토 뒤 폴더 구조의 들여쓰기와 자료 준비/기본 전환의 순서 설명을 보완했다. 실제 시범 결과와 카드 발췌를 더해 최종 10쪽으로 정리했다. 최종 PDF 검토 기록은 별도다.

게시 전 독립 검토에서는 보고정리의 파일 생성 경쟁 가능성과 안내·접수 파일을 포함한 마지막 전체 해시 대조 누락을 지적했다. 새 파일을 배타 생성하고 모든 대상의 중복/기존 파일 검사를 첫 쓰기 전에 수행하며, 복사 원본·사본과 새 안내문 전체를 재대조한 뒤 완료기록을 남기도록 보완했다. 보완 전 코드도 보존했다.

## 사람이 남겨야 할 판단

이름과 정의를 다시 승인받는 것이 아니라 **이번 출력이 읽기 쉽고 실제 정리에 도움이 되는지** 확인할 차례다. 설명·예·조건의 이해, 보고서 분량, 검수 부담을 확인한다. 판단하기 어려운 특정 문장은 그 항목만 보류하고 나머지 근거 있는 정리는 유지한다.

기본 전환 선택지는 A. 후보를 명시한 소량 사본 사용을 유지하고 출력 피드백 받기 **(추천)** / B. 세 스킬 모두 기본 전환 검토 / C. 한 스킬씩 전환 검토 / D. 출력 보완 후 재시범이다. B/C는 다음 실행 범위에 대한 사람 답변을 받은 뒤 진행한다.
