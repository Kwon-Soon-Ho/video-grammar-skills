## 시간축 · LAYOUT-TIMELINE

- 다른 구조를 검토할 때: 직선 순서가 중심이면 프로세스, 실제 위치가 중심이면 공간 표식을 검토한다.

## 공간과 설명 표식 · LAYOUT-SPACE-CALLOUT

- 세로 화면: 같은 공간을 유지할지 상세 뷰로 분절할지 선택하고 실제 위치 이동은 피한다.
- 정사각 화면: 필수 내용·관계·비례를 잃는 중앙 크롭만으로 해결하지 않는다. 손실 없는 크롭·영역 재배치·구간 분절도 후보로 비교하고 실제 문구와 표시 조건을 확인한다.
- 시간·가림 조건: 정보가 완성된 상태와 유지 시간을 별도로 확인한다. 읽기 가능한 대비·가림·배치가 유지되는 구간인지 보고 모션 자체의 길이로 대체하지 않는다.
- 기권 조건: 위치·좌표·도면 버전·라벨 대응이 없으면 실측 공간 정확성을 주장하지 않는다.

## 데이터 시각화 · LAYOUT-DATA-CHART

데이터 관계를 차트로 구성 — 기존 프로젝트 정의.

관련 정보 관계 후보: REL-PARALLEL, REL-TIME, REL-PART, REL-CORRELATION · 모양만으로 자동 부여하지 않음.

- 선택 조건: 수치의 비교·변화·분포·부분전체를 읽어야 할 때
- 읽는 순서 후보: 질문·수량 의미→축·단위·범위→데이터→핵심 해석
- 구성할 때 판단: 질문에 맞는 차트 후보를 선택한다. 막대 비교의 기준축, 추세선의 범위, 결측·출처를 구분한다.
- 적용 예: 가상의 공법 비용을 같은 단위·0 기준 막대로 비교하고 값과 조건을 표시한다.
- 오용 반례: 막대 길이의 비율 비교에서0기준을 잘라 작은 차이를 과장하거나, 다른 단위·기간을 같은 막대로 비교하거나, 자료 없는 중간값을 실측처럼 연결한다.
- 허용되는 변형·복합: 추세선의 잘린 범위는 명시하고 검토할 수 있다. 모든 차트에 0 시작을 강제하지 않는다.
- 다른 구조를 검토할 때: 정확한 여러 값 조회는 표 후보, 하나의 값만 강조하면 단일 초점을 검토한다.
- 한국어·문구 조정: 수치·단위·축 라벨을 서로 대응하고 긴 범주명은 방향·차트 종류 변경을 고려한다.
- 가로 화면: 내용 역할을 나눈 영역의 폭을 조절한다. 화면 전체를 꽉 채울 의무는 없다. 핵심·단위·출처가 읽히는 완성 상태를 확인한다.
- 세로 화면: 범주/축을 재배치할 때 값·단위·범위·비율을 보존한다. 글자만 줄여 해결하지 않는다.
- 정사각 화면: 필수 내용·관계·비례를 잃는 중앙 크롭만으로 해결하지 않는다. 손실 없는 크롭·영역 재배치·구간 분절도 후보로 비교하고 실제 문구와 표시 조건을 확인한다.
- 시간·가림 조건: 정보가 완성된 상태와 유지 시간을 별도로 확인한다. 읽기 가능한 대비·가림·배치가 유지되는 구간인지 보고 모션 자체의 길이로 대체하지 않는다.
- 기권 조건: 데이터·단위·기간·척도·보간 구분이 없으면 차트의 사실성 통과를 보류한다.

## 카드 그룹 · LAYOUT-CARD-GROUP

독립 항목들을 카드 형상으로 묶음 — 기존 프로젝트 정의.

관련 정보 관계 후보: REL-PARALLEL, REL-ORDER · 모양만으로 자동 부여하지 않음.

- 선택 조건: 같은 역할의 독립 항목을 반복 구조로 묶으면 읽기에 도움이 될 때
- 읽는 순서 후보: 그룹 제목→항목 명칭→공통 역할 정보→차이
- 구성할 때 판단: 카드의 경계가 그룹을 돕는지 확인한다. 같은 역할은 같은 정보 순서, 서로 다른 관계는 연결·배치로 표현한다.
- 적용 예: 동등한 사업 분야를 명칭·대표 이미지·짧은 설명이 같은 순서인 카드로 정리한다.
- 오용 반례: 한 과정의 원인·결과를 독립 카드로 떼어 놓아 관계를 숨기거나 카드 자체를 항상 금지한다.
- 허용되는 변형·복합: 카드 안에 차트·단계·비교가 있을 수 있다. 카드라는 모양과 관계를 분리한다.
- 다른 구조를 검토할 때: 관계선이 핵심이면 연결 구성, 긴 정밀 비교는 표 후보, 핵심 하나면 단일 초점을 검토한다.
- 한국어·문구 조정: 긴 카드 제목은 영역·줄바꿈을 조절하고 한 카드만 작은 글자를 쓰지 않는다.
- 가로 화면: 내용 역할을 나눈 영역의 폭을 조절한다. 화면 전체를 꽉 채울 의무는 없다. 핵심·단위·출처가 읽히는 완성 상태를 확인한다.
- 세로 화면: 개수를 줄여 구간을 나눌 수 있으나 항목이 동등하다는 역할과 전체 개수를 잃지 않는다.
- 정사각 화면: 필수 내용·관계·비례를 잃는 중앙 크롭만으로 해결하지 않는다. 손실 없는 크롭·영역 재배치·구간 분절도 후보로 비교하고 실제 문구와 표시 조건을 확인한다.
- 시간·가림 조건: 정보가 완성된 상태와 유지 시간을 별도로 확인한다. 읽기 가능한 대비·가림·배치가 유지되는 구간인지 보고 모션 자체의 길이로 대체하지 않는다.
- 기권 조건: 독립·동등한 항목인지 불분명하면 반복 모양만 관측하고 정보 관계는 보류한다.

## 분할 구성 · LAYOUT-SPLIT

서로 다른 역할의 화면 영역을 나눈 구성 — 기존 프로젝트 정의.

관련 정보 관계 후보: 입력 관계에 따라 달라짐 · 모양만으로 자동 부여하지 않음.

- 선택 조건: 화면과 설명 등 서로 다른 역할을 나눠 동시에 참조할 필요가 있을 때
- 읽는 순서 후보: 주 대상→연결된 설명→필요한 추가 맥락
- 구성할 때 판단: 영역의 읽는 역할과 대응을 명확히 한다. 같은 폭·다른 폭을 역할에 따라 후보로 둔다.
- 적용 예: 공법 단면도 옆에 해당 부위의 설명을 두고 색·번호로 대응한다.
- 오용 반례: 왼쪽은 A 공법 사진, 오른쪽은 회사 소개문인데 비교 화면이라고 한다.
- 허용되는 변형·복합: 반반 배치 자체가 비교는 아니다. 동등 비교 항목이 확인되면 비교 태그를 추가한다.
- 다른 구조를 검토할 때: 전체/부분 동일성이 있으면 전체/상세, 작은 중첩이면 PIP를 검토한다.
- 한국어·문구 조정: 긴 본문은 요점·지원 정보를 나누되 사실과 필수 정보는 임의 삭제하지 않는다.
- 가로 화면: 내용 역할을 나눈 영역의 폭을 조절한다. 화면 전체를 꽉 채울 의무는 없다. 핵심·단위·출처가 읽히는 완성 상태를 확인한다.
- 세로 화면: 상하 재배열에서 그림과 설명의 대응을 유지하고 본문이 자막과 충돌하지 않게 둔다.
- 정사각 화면: 필수 내용·관계·비례를 잃는 중앙 크롭만으로 해결하지 않는다. 손실 없는 크롭·영역 재배치·구간 분절도 후보로 비교하고 실제 문구와 표시 조건을 확인한다.
- 시간·가림 조건: 정보가 완성된 상태와 유지 시간을 별도로 확인한다. 읽기 가능한 대비·가림·배치가 유지되는 구간인지 보고 모션 자체의 길이로 대체하지 않는다.
- 기권 조건: 영역 역할과 대응 대상이 없으면 적합한 읽는 순서를 확정하지 않는다.

## 화면 속 화면 · LAYOUT-PIP

주 화면 안에 별도 화면을 중첩 — 기존 프로젝트 정의.

관련 정보 관계 후보: 입력 관계에 따라 달라짐 · 모양만으로 자동 부여하지 않음.

- 선택 조건: 주 화면을 유지하며 보조 화면·발표자·다른 관점을 함께 보여 줄 때
- 읽는 순서 후보: 주 화면의 과제→보조 화면의 역할→둘의 대응
- 구성할 때 판단: 삽입 위치·크기가 주 화면의 필수 정보·자막·조작을 가리지 않게 하고 보조 화면을 읽어야 하는지 확인한다.
- 적용 예: 실제 제품 시연의 주화면 안에 작은 발표자 창을 삽입하고 중요한 버튼·자막이 없는 위치에 둔다.
- 오용 반례: 작은 발표자 창이 제품의 저장 버튼이나 핵심 수치를 가린다.
- 허용되는 변형·복합: 작게 중첩했다고 보조 역할인 것은 아니다. 어느 정보가 핵심인지 입력으로 확인한다.
- 다른 구조를 검토할 때: 두 화면을 모두 상세하게 읽어야 하면 일반 분할이나 구간 분절을 고려한다.
- 한국어·문구 조정: 삽입 화면 속 긴 텍스트는 확대·별도 장면 후보로 검토하고 무조건 작게 유지하지 않는다.
- 가로 화면: 내용 역할을 나눈 영역의 폭을 조절한다. 화면 전체를 꽉 채울 의무는 없다. 핵심·단위·출처가 읽히는 완성 상태를 확인한다.
- 세로 화면: 주/보조 역할을 유지하되 삽입 위치를 옮기거나 별도 장면으로 전환해 가림을 피한다.
- 정사각 화면: 필수 내용·관계·비례를 잃는 중앙 크롭만으로 해결하지 않는다. 손실 없는 크롭·영역 재배치·구간 분절도 후보로 비교하고 실제 문구와 표시 조건을 확인한다.
- 시간·가림 조건: 정보가 완성된 상태와 유지 시간을 별도로 확인한다. 읽기 가능한 대비·가림·배치가 유지되는 구간인지 보고 모션 자체의 길이로 대체하지 않는다.
- 기권 조건: 자막·플레이어 UI·중요 버튼의 위치를 모르면 최종 가림 검수를 보류한다.
