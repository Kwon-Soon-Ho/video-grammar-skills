# R4-3 좌표·변환 보완 결과와 레드팀

2026-10-15. **좌표·변환의 독립 기록 규격과 합성 검수 범위를 완료했다.** 기존 최소 DB에 통합하거나 실제 영상을 분석한 단계는 아니다. R4 전체와 Phase 00은 미완료이며 01-A는 시작하지 않았다.

## 쉽게 보는 결과

‘어느 영상의 어느 순간에 있는, 어떤 이미지의 어느 부분인가’를 기록하는 규칙이다. 원본 화면에서 (300,250)에 있는 점을 (100,50)부터 크롭하고 절반으로 줄이면 새 화면에서는 (100,100)이다. 원본 위치와 파생 위치를 혼동하지 않도록 화면 ID·버전·크기·변환 순서를 함께 보존한다.

사용자 A를 반영했다. 좌측 위 **화면 경계**를 (0,0)으로 삼고, 픽셀 중심은 (0.5,0.5)부터다. 비율 좌표는 해당 화면 크기를 사용해 명시적으로 변환한다. 회사 색·레이아웃·용어를 새로 정하는 작업은 이번 범위에 포함하지 않았다.

| 나눠서 보완한 것 | 적용 예 | 막는 반례 |
|---|---|---|
| 원점·단위·해상도 | 전체 1920×1080 영역과 마지막 픽셀 중심 구분 | 화면 경계를 픽셀 번호/중심으로 혼용 |
| 원본·표시 화면 | 해상도, 픽셀 종횡비(SAR), 표시 회전 적용 여부 기록 | SAR 미상을 1로 채움; 자동 회전한 화면에 또 회전 |
| 변환과 순서 | 크롭 → 회전 → 리사이즈를 별도 연산으로 연결 | 크롭 원점 누락, 순서 뒤집기, 다른 원본 프레임 연결 |
| 크롭·패딩·역변환 | 보이는 부분과 모델 전체 위치 구분 | 화면 밖 위치가 패딩 후 관측 ROI로 승격; 사라진 픽셀 복원 주장 |
| 근거·오차·사람 검수 | 이미지·대상·프레임·버전과 적용값 근거 연결 | 계산 통과를 실제 관측·작업 적용·오차 0으로 확정 |

## 조사와 검토 순서

1. **착수 감사:** 기존 자유 형식 metadata와 변환 참조에서 잘못된 해상도·회전 값/없는 변환 ID가 통과하는 것을 합성 기록으로 재현했다. 기존 파일을 고치지 않고 독립 계약으로 보완했다.
2. **원점·단위:** W3C Media Fragments의 공간 구간, SVG의 좌표계/viewport 관련 본문과 기존 시간·근거 계약을 대조했다. 우리 DB의 raster px와 웹 표시 좌표를 자동으로 동일시하지 않는다.
3. **변환:** FFmpeg crop/transpose/scale 관련 옵션 본문을 확인하고, 요청값과 실제 적용값·SAR·출력 크기·회전/뒤집기·리샘플링을 구분했다. 실제 FFmpeg 명령/미디어 가공은 실행하지 않았다.
4. **예·반례와 자체 검사:** 정상 순서·역변환·정규화·픽셀 중심·비정방 SAR를 보존하면서 잘못된 참조·경계·단위·불명확한 변환을 검사했다.
5. **독립 레드팀 → 수정 → 재검토:** 초기 독립 30건 중 5건이 실패했다. 초기 실패 입력·결과·원문도 백업에 보존했다. 추가 변환 내용 검수 제안까지 반영하고 현재 후보를 다시 검사했다.

## 레드팀 발견과 보완

| 발견 | 수정 |
|---|---|
| 밖의 모델 위치가 패딩 후 관측 영역으로 승격 | unclipped 모델/비관측 결과를 model_position으로 보존하고 ROI 승격 거부 |
| 결과가 null이면 비영 오차의 경계 검수 누락 | outside/null도 미상·비영 오차를 미해결과 사람 검수 대기로 남김 |
| 해상도 미상 normalized 기록의 개별 검수 누락 | 계산 가능 여부와 무관하게 해당 geometry 검수 항목 생성 |
| 원본 SAR 미상을 확인된 파생 SAR와 모순으로 판단 | 양쪽 확인값의 모순만 오류. 한쪽 미상은 관계 미확인으로 보존 |
| 원본 회전 미상을 확인된 파생 회전과 모순으로 판단 | SAR와 같은 규칙. 알려진 값을 지우거나 미상을 추정하지 않음 |
| 변환 적용값·근거의 내용 검수 항목 부족 | 변환별 실제 원점·출력 크기·순서·회전/SAR·리샘플링·왜곡 목적·근거 대조를 사람에게 인계 |

최종 내장 합성 검사 **53/53**, 독립 검사 **31/31**, 실행 예외 **0**. 독립 검토 중 원문 hash와 입력은 변하지 않았고 저장된 시험 결과와 재실행 결과가 일치했다. 발견한 차단 결함은 이 최종 후보에서 보완 확인했다. 이 검사 집합의 결과이며 모든 입력·실제 영상의 좌표 정확성을 증명하지 않는다.

## 사람이 확인할 것과 남은 단계

실제 자료가 없어 이번에 실제 영상 내용 검수를 수행하지 않았다. 공간의 원본/해상도/SAR/회전 상태, 변환의 실제 적용값·근거, 대상·앵커·가림·관측/모델 구분·오차는 사용자 또는 지정 담당자의 확인 대상이다. [사람 검수 대기 예시](R4_03_사람검수대기_설명용.json)를 별도로 저장했다. 합성 기록은 specimen_only, 실제 초안은 awaiting_human으로 남긴다. 검수 결과 전에는 확인된 사실로 승격하지 않는다. 검수 목록을 만들었다는 것이 외부 메시지 전송이나 실제 검수 수행을 뜻하지 않는다.

formula_checked는 명목 기하 계산의 일치다. visibility_basis=nominal_geometry_only, uncertainty_verified=false이며 fact_verified/company_approved/operational_release도 false다. 비영 오차의 전파·픽셀 내용·스크린샷 DPR/영상 표시 영역·3D/원근/비선형/시간 가변 변환은 이번 종료 범위 밖이다.

**R4-4:** 시간·근거·좌표의 독립 계약을 R2의 4단위·run/metadata·한맥 profile/taxonomy 참조와 최소 DB로 연결하고 기존 예시·검사기를 이관한다. 현재 기존 최소 DB의 시간 누락 4건·근거 누락 7유형·자유 좌표 metadata는 아직 통합 수정되지 않았다. R4-2의 공간 supported 보류도 R4-4까지 유지한다.

**01-A:** 실제 메타데이터 획득·프레임 추출·픽셀 가공·OCR/탐지/추적·실측 정확성 시험이다. 기존 세 스킬·R2/R3·한맥 디자인 정본은 변경하지 않았다.
