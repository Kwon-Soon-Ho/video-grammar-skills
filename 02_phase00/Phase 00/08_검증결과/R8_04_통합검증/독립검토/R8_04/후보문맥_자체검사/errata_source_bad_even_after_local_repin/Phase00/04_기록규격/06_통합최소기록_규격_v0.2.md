## 세 규격 재사용과 통합 프로필

시간·근거 정본과 검사기는 변경하지 않는다. 공간 정본도 변경하지 않는다. 통합 스키마는 세 규격을 로컬 본문으로 포함하고 원문 hash를 고정한다. 현재 원문에 원격 $ref가 없어 네트워크 조회가 필요하지 않다. 동일 본문을 여기저기 독립 수정하지 않도록 통합 스키마의 원문 pin을 검사한다.

유일한 공간 구조의 확장은 **좌표를 아직 기록하지 않은 경우 spaces=[]를 허용**하는 통합 프로필이다. 공간이 없으면 변환/기하/매핑은 참조 검사상 담을 수 없다. 시간·근거가 식별된 새 기록에 허위 프레임이나 공간을 만들 필요가 없다. 원본 identity 자체가 없는 구형 자료는 이 예외로 수용하지 않고 접수함에 보존한다.

## 좌표 표본 연결과 한계

R4-2의 공간 표본 px와 R4-3의 raster_px는 해당 raster 성분에 한해 같은 단위로 대응한다. normalized는 그대로 구분한다. geometry의 표본 근거·대상·원본 프레임, x/y/width/height 성분, 단위, 실제 공간 ID/버전을 대조한다. mapping을 쓸 때는 source geometry와 결과 geometry까지 따라간다. R4-3 mapping 자체에는 version이 없어 참조 version은 소유한 공간 계약 버전에 고정한다. 통합 context는 실제 mapping 내용도 hash에 포함한다.

표본 숫자는 geometry의 유리수 성분과 정확히 대조한다. 소수로 표현할 때는 exact_decimal 또는 자리수 0~12를 명시한 rounded_decimal(half-even)을 쓴다. 이것은 저장 표현의 반올림이며 측정 불확실성/허용 오차가 아니다. px 변환·단위 변환을 임의로 추정하지 않는다.

시간에 따른 스칼라 표본은 같은 축을 사용하고, 프레임별 명시 공간 기준/변환 계열이 다르면 비교 미해결로 남긴다. 동일 크기 화면이라고 카메라/대상 추적이 검증됐다는 뜻은 아니다. 모델 위치·잘린 결과·미상/비영 오차는 관측 사실로 확정하지 않는다. single_sample_component의 단일 성분 결과/표본/단위 일치만 자동 검사한다. 다른 계산법·속도/가속도·오차 전파·추적은 내용 검수 대기다. 새로운 자동 영상 분석/수치 추출은 01-A에서 한다.

**R4-2의 공간 supported 보류는 유지한다.** R4-4에서 표본 연결을 실제 검사하지만, 연결 검사를 사람의 측정 내용·권한·승인 대신 사용하지 않는다. 공간 연결 상태 linked도 사실/오차 검증을 뜻하지 않는다. 사람 내용 검수·검수자/행위·권한과 운영 승인은 R6/R7 및 실제 자료 확보 후 인계한다.

## 검수 문맥과 도구 결과

review_contexts는 시간·근거·좌표·분류·한맥 참조·실행 선언·통합 스키마/하위 검사기 hash 전체를 고정한다. 기존 review_ref/context만 복사하면 통합 검사에서 빠짐 또는 stale로 남긴다. context 계산의 직렬화는 제공한 Python 함수의 sort_keys/UTF8/유한수 방식이며 다른 정규화 표준과 같다고 주장하지 않는다. R4-2 receipt의 기존 context 검사는 별도로 유지한다.

valid(구조), unresolved(연결/내용 미확인), 사람 검수 대기, 사실 확인·회사 승인·운영 반영은 별개다. fact_verified/human_identity_verified/company_approved/operational_release는 이 검사기에서 false다. spec_test는 실제 DB·회사 문법 검색에서 제외한다.
