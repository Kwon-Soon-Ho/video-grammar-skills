# 무엇에 이름을 붙이는지 구분하기

사용자가 선택한 A안에 따라 영상 전체·설명 구간·화면 상태·짧은 동작을 구분한다. 컷 전환은 보조 정보다. 아래 단위는 모션그래픽을 기록하기 위한 프로젝트 기준이다.

| 단위 | 쉬운 예 | 나누는 기준 |
|---|---|---|
| 영상 전체 | 한 편의 기술 설명 영상 | 제공 파일과 버전 |
| 설명 구간 | 침투수의 원인을 설명하는 부분 | 설명하는 주제·질문이 바뀌는지 |
| 화면 상태 | 제목만 보임 → 제목과 도표가 함께 보임 | 정보 역할·배치·주석 대상이 달라지는지 |
| 짧은 동작 | 도표 공개·강조 이동·숫자 변화·정보 유지 | 어느 대상이 어느 시간에 변하거나 유지되는지 |

화면 상태는 완전히 멈춘 화면이 아니다. 제목을 읽는 동안 배경 입자가 움직여도 같은 정보 구성이 유지될 수 있다. 짧은 동작에는 움직임뿐 아니라 특정 대상의 유지·정지 같은 시간 사건도 포함한다. 이름이 고정된 최대 길이를 뜻하지는 않는다.

동작은 화면 상태 사이를 가로지를 수 있고 여러 동작이 겹쳐 발생할 수 있다. 그래서 모든 동작을 한 상태의 배타적인 자식으로 묶지 않는다. 레이아웃이 변하는 중에는 이전·이후 상태와 전환 동작을 구분하며, 중간 화면을 완성된 새 레이아웃으로 단정하지 않는다.

컷이 바뀌어도 같은 설명을 이어갈 수 있고, 컷 없이 설명 주제가 바뀔 수 있다. 경계가 불분명하면 후보와 이유를 남긴다. 프레임 간격이나 컷 검출만으로 설명 구간을 확정하지 않는다.

| 분류축 | 기록하는 단위 |
|---|---|
| 영상 유형 | 영상 전체·설명 구간 |
| 전달 목적 | 설명 구간·화면 상태·짧은 동작 |
| 정보 관계 | 설명 구간·화면 상태 |
| 화면 레이아웃 | 화면 상태 |
| 모션 기능·관측 속성·시간 특성 | 짧은 동작 |
| 표현 속성 | 화면 상태·설명 구간 |

화면 일부에 붙인 태그를 영상 전체에 자동 상속하지 않는다. 관측이 충분하면 태그를 유지하고, 구현만 불명확한 경우 구현 주장을 별도로 남긴다. 예를 들어 확실한 크기 변화는 기록하면서 카메라/Scale 원인은 미확인으로 둘 수 있다.

**프레임은 표본이며 화면 상태와 다르다.** 현재 DB에는 asset/segments/frames/beats가 있고 별도 state 필드는 없다. [분류 운영규칙](분류운영규칙.json)은 의미 기준이다. 실제 저장 필드·상태와 동작의 참조·시간 경계 검사는 [R4](../09_다음단계인계/R2_R4.md), 구현은01-A에서 연결한다.
