원문 읽기 → 후보 생성 및 좁은 구조/diff 확인 → CLI backup → 백업 바이트 대조 → CLI write → 실제 저장 바이트 대조 → CLI validate 실패 → 실패 파일 보존 → 현재 SHA로 CLI restore → 실제 복구 바이트 대조 → CLI read → CLI validate 성공 → 최종 원문 보존 및 결과 기록.
