# 실제 작업 transcript

작업 순서: 지정 자료/스킬 읽기 → 원문 bytes/SHA/ID/판본 보존 → 후보와 허용필드 diff → 작업 전/후보 검사 → R4 백업 → R5 백업 → 두 파일 원문 SHA 재확인 → R4 저장 → 저장 bytes 및 환경/구조 확인 → R5 저장 실패 → 부분 파일 보존 및 환경/구조 확인 → 서비스 소유 SHA 대조 → R5 복구 → R4 복구 → 정확 복원 대조 → 최종 환경/구조/바이트 차이 확인.

초기 candidate/자료 경로 읽기는 파일 없음으로 실패한 뒤 task 지정 DB 루트의 자료 폴더를 읽었습니다. 초기 읽기 원문은 초기읽기원문로그.json에 보존했습니다.

Python 호출은 지정 Python -B -X utf8이며, 작업수행.py의 subprocess도 같은 Python과 UTF8 및 PYTHONDONTWRITEBYTECODE=1을 사용했습니다. 환경/DB mutation은 시험IO.py만 사용했습니다.
