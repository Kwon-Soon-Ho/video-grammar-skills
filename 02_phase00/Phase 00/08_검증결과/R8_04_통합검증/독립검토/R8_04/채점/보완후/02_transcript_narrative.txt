# 실제 작업 기록

모든 DB backup/write/restore/저장 후 환경 검사는 지정 시험IO.py CLI를 사용했다. Python은 지정 실행파일의 -B -X utf8로 실행했다. 요청·후보·로그·증거 사본·보고서만 outputs에 일반 쓰기로 작성했다.

## 사전 확인

task.txt, 자료/IO사용안내.md, 자료/작업범위.json, 지정 curator SKILL.md와 references/작업기준.md·출력지침.md, 대상 원문, 00_운영계약/01_보존과버전_계약.md·정본과표시_연결목록.json, 14_스킬재구성/R8_현재사용안내.md를 읽었다. 원칙 정본 두 파일은 관련 항목/해시를 관련근거.json에 남겼다. 현재 안내의 다른 run·평가·과거보고 링크는 따라가지 않았다. 정정표는 이번 draft 내용에 적용하지 않았다.

PowerShell 도구가 사전 읽기부터 InitializeDefaultDrives/FileSystem 경고를 표시했다. 지정 Python CLI들의 stderr는 개별 원시 파일에 보존했으며 CLI exit와 외부 PowerShell 도구 exit를 구분했다. 환경검사.py의 외부 도구 exit는 1로 보고됐지만 내부 실제 CLI exit는 2다.
