# 결과를 남기는 방식

요청 형식을 우선한다. 지식 카드에는 기존 개념/후보 식별, 정리 상태와 이유, 출처·확인 절/깊이, 원문 개념/자체 적용 해석, 적용 조건·설명 예/반례·예외, 미확정/필요 사람 질문을 구분한다. 원문에 없는 실제 사례·시간/좌표·기본값은 비워 두거나 확인 불가로 표시한다.

출처 참조는 원본의 ID/버전 규칙과 연결하고, 읽은 로컬 근거는 경로·버전·SHA/관련 항목을 남긴다. 이 값은 파일 식별이며 저작권/내용 진실성 인증이 아니다. 상충·정의 미확인은 원문과 차이/추가 확인 범위로 기록한다. 의미 병합·정식 분류·회사 필수화가 필요한 경우 후보와 이유·대안 최소4개/추천안을 제시한다.

실제 draft 수정이면 작업 로그·변경 전 사본/해시 대조·변경 diff·수정 후 파일/버전/해시와 검사 결과를 함께 남긴다. 수정 안 한 부분과 보류한 부분을 구분한다. 개별 결과의 통과를 영상 전체 품질 총점으로 집계하지 않는다. 근거가 충분한 좁은 정리는 실제 수행하며 모든 일을 보류로 끝내지 않는다.
