# 현행 세 스킬과 새 기반의 차이

기존 세 스킬 v0.1.0의 목적·이름과 draft/시범 A를 유지한다. 기존 11/12 동률·한 쓰기 시범8조건을 이번 새 규격 호환·업무 효과 성적으로 재사용하지 않는다.

| 현황 | 보완 | 검증할 행동 |
|---|---|---|
| 공통 참조가 두 폴더 위를 DB로 고정 | 작업에서 명시한 DB 루트를 우선하고 실제 규격/색인 확인 | 후보/시험 사본에서 운영 DB를 잘못 수정하지 않는가 |
| 예전 자료검증.py 안내 중심 | 역할별로 R4 현재 규격·R5·R6·R7 확인의 범위를 구분 | 한 도구 정상으로 내용/회사 승인까지 통과시키지 않는가 |
| 세 본문에 R6/R7의 새 연결이 없음 | 출처/질문·실제 회신 문맥·26항목 조건·평가 보류를 필요한 역할에 연결 | CI 최신성 회신을 다른 주장에 이식하거나 가짜 검수하지 않는가 |
| draft 작성/backup은 있으나 좁은 시험뿐 | 요청별 허용 변경·입력 핀·backup/diff/log·실패와 재검토를 행동 시험 | 문서만 잘 쓰고 실제 수정·검증은 생략하지 않는가 |
| 외부 미적 지침을 잘못 일반화할 여지 | R3 조건부 지식·허용 예/반례와 회사 필수/취향 분리 | 정지/등속/반복·텍스트 단독·대칭·한국어/SI·CI를 일괄 금지하지 않는가 |

R8-1은 용어/지식 정리와 작은 draft 수정부터 시험한다. R4 통합 기록의 실제 작성·변환, 좌표 획득·영상 의미/모션 추정은 그 시험의 통과 범위가 아니다. R8-2 기록관리 시험과01-A 후속 구현을 대신하지 않는다. 필요 없는 기술 수치/좌표를 모든 지식 항목에 채우지 않는다.

R3가 제시한 표본 범위(정지·등속·동등비교·반복·주제명·텍스트·한국어/단위/결측·8회사CI)는 세 스킬 전체의 누락 점검표로 사용한다. 각 스킬에 전부 같은 과제를 강제로 넣지 않고 담당 역할/적용 이유와 미검증 범위를 연결한다. 소량 초기 비교만으로 모든 조건을 검증했다고 하지 않는다.
