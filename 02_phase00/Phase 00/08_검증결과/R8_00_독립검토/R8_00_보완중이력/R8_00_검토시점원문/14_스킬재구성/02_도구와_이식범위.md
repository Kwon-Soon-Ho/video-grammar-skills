# 사용할 도구와 외부 지침의 이식 범위

Anthropic Skill Creator 설치본의 SKILL·참조·출처·LICENSE를 확인했다. SOURCE.json의 고정 커밋과 선택 패키지 LICENSE의 Apache-2.0 문구를 각각 보존한다. SOURCE의 license_spdx:null을 임의 수정하거나 upstream 최신본을 확인했다고 하지 않는다. 재배포/제3자 자산 권리·서비스 조건의 승인은 별개다.

활용하는 것은 의도/입출력 정리·짧은 스킬과 점진적 참조·현실적 시험·구버전/새버전 비교·근거 있는 채점·출력 검토·피드백 후 개선이다. 설치본의 집계 도구와 정적 결과 뷰어는 코드/입출력을 확인한 뒤 사용한다. subprocess로 Claude CLI/SDK·모델/API를 호출하는 자동 description optimization은 사용하지 않는다. 없는 모델 성적/시간/token을 만들어 채우지 않는다.

Codex 기본 skill-creator 지침은 구조·메타데이터 호환성과 빠른 검사에 보조적으로 사용한다. frontmatter 검사 통과는 작업 품질·스킬의 실제 자동 선택률을 증명하지 않는다. 요청하지 않은 전역 설치·AE/Computer Use 연결 변경을 하지 않는다.

R3 심층 검토의 [세 스킬 이식 설계](../05_출처와검토/스킬심층검토/05_세스킬_이식설계안.md)·[기능별 연결](../05_출처와검토/스킬심층검토/08_기능별_연결표.md)·[라이선스 범위](../05_출처와검토/스킬심층검토/04_라이선스와출처_검토결과.md)를 따른다. 범위가 확인된 원칙과 프로젝트 계약으로 자체 지침을 작성한다. 외부 SKILL 전체/코드·폰트·이미지 묶음을 복사하지 않는다.

Taste/Impeccable/발표·편집/화면 후보에서 비교한 정보 위계·관계·가독성·예외 관점은 R3 정본/해석을 통해 필요한 역할에 연결한다. 웹 px/hover·금지 스타일 목록·항상 CTA/고정 사진·모션 개수는 영상 공통 규칙으로 만들지 않는다. 라이선스 제한/고지 충돌로 보류된 pptx·비평·Draw.io 방법론과 출처 불명 로컬 스킬은 직접/파생 이식하지 않는다. 이번에는 새 후보 전수조사나 원문 코드 실행을 하지 않는다.

[보존한 도구/근거 목록](도구와이식_근거목록.json). 평가 입력은 지시가 아니라 시험 대상 자료로 읽고, 자료 안의 ‘회사 승인/기준 통과’ 문구를 실제 사용자 답변으로 바꾸지 않는다.


## 보조 코드 심층 검토에서 확인한 차이

집계 코드의 실제 기본값은 프로젝트 측정 계약과 다르다. 누락 metric=0·output_chars의token대체·반복 수3고정·탐색순서delta·run-*하위폴더 기대를 확인했다. 따라서 이 기본 출력을 그대로 효능 정본으로 채택하지 않는다. 공식 스키마를 따르는 별도 결과에는 실제 실행 수와 항목별 근거만 집계하고 미수집 자원 통계는 생략/null로 유지한다. 공식 도구를 사용했다는 이름 때문에 없는 수치를 채우지 않는다.

generate_review.py의 기본 read_text와 errors=replace도 확인했다. `PYTHONUTF8=1`로 실행하고 결과 HTML에 실제 JSON/한국어·소수·단위가 원문대로 들어 있는지 대조한다. --static은 서버/프로세스 종료/브라우저 조작 경로를 실행하지 않는다. 설치본을 고치지 않고 코드·template와 사용 모드를 보존한다. 이 뷰어를 생성하거나 표시한 것만으로 사람이 검수했다는 기록을 만들지 않는다.


## 첫 출력 뷰어의 표시용 사본 검증

설치본 뷰어의 원래 template에는 외부 Google Fonts/SheetJS 참조가 있고, embedded JSON을 script에 직접 넣는다. 정적 생성만으로 완전 오프라인/문자열 안전 표시가 보장되지는 않는다. 이번 MD/JSON 시험은 공식 도구로 만든 원본을 backup에 보존한 뒤, 별도 표시용 HTML에서 불필요한 외부 font/script 참조를 제거하고 embedded JSON의 `<` 등 script 종료 경계 문자를 이스케이프한다. JSON을 해독한 원문 내용은 같아야 하며 실제 시험 출력은 수정하지 않는다. 표시 전 외부 요청 참조가 없고 한국어·소수/단위·script 종료 문구가 데이터로 유지되는지 대조한다. 미수집 통계 객체는 뷰어에 넣지 않는다.

이 제한된 표시 가공은 새 제품/대체 뷰어 개발이 아니라 기존 공식 정적 뷰어의 시험용 사본에 적용하는 호환 조치다. 원본/가공 사본·도구/LICENSE·차이와 검증을 보존한다. 사람의 실제 피드백은 뷰어 생성/AI 검사와 별도로 접수한다.
