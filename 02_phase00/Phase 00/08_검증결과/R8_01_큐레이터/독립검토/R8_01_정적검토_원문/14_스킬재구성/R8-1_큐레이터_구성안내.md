# R8-1 용어·지식 큐레이터 구성안

기존 역할/이름을 유지한 후보 v0.2.0-draft.1이다. [후보 SKILL](../06_맞춤스킬/재구성후보/video-knowledge-curator/SKILL.md)에는 루트 확인·관련 지식만 조회·출처 깊이/관측·적용 조건/예·반례·draft 수정·backup/diff/검사·보류/사람 질문을 담았다. 세부 경로/도구 범위와 결과 지침은 참조 파일로 분리했다.

이번 시험은 ①회의 메모의 조건부 지식 정리, ②작은 지식 초안의 실제 수정과 보존, ③같은 버전/이름의 원문 충돌에서 잘못 반영하지 않는지를 본다. 구버전과 후보에 동일 자료/요청·도구/권한을 주고 별도 사본에서 실행한다. 실제 영상·회사 문법·전체 기록 이관/스키마 쓰기는 시험하지 않는다. 표본이 작아 포괄적 성능 우위를 주장하지 않는다.

시험 출력은 Anthropic Skill Creator의 정적 뷰어와 한국어 비교 보고로 제시한다. 사람의 실제 내용 피드백을 받기 전 후보를 최종 채택하거나 다음 스킬까지 완료했다고 기록하지 않는다. 필요 검토는 구체 결과를 바탕으로4지선다와 추천안을 제공한다.
