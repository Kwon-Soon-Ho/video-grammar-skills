# 초안 문구 수정 결과

지정 초안의 KNOW-LAYOUT-SINGLE-FOCUS limits를 “단일 초점이 반드시 중앙 배치를 뜻하는 것은 아님”으로 실제 저장했습니다. 파일과 해당 항목 버전은 0.1.1 → 0.1.2로 구분했으며 다른 13개 항목·상태·출처·ID는 유지했습니다.

backup 바이트 일치, JSON 파싱·중복 키/ID, 기존 지식 목록 검사(후보를 메모리로 대입), 레이아웃 스키마, 허용 diff, 저장 후 재검사를 실행했습니다. 기존 검사 오류는 0개이고 보호한 17개 파일의 전후 SHA가 같습니다. 자세한 값은 실제결과.json, 변경 내용은 변경.diff에 있습니다.

이 초안은 운영 연결목록 미등록 상태이며 정본/기본 전환은 하지 않았습니다. R3 전체 외부 원문, R4 영상 기록, R6 전체 원문·자산, R7 및 사람 검수·회사 승인은 수행하지 않았습니다. 외부 원문을 새로 읽거나 실제 영상 효과를 검증했다는 뜻이 아닙니다.
