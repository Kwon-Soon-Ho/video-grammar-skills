# 회의 메모 공통 지식 초안

`knowledge_draft.json`에 5건을 정리했습니다. 운영 정본과 정식 분류 ID는 변경하지 않았습니다.

- 단계 번호는 순서·현재 위치를 돕는 기능을 먼저 봅니다. AI처럼 보인다는 인상만으로 번호와 카드를 일괄 금지하지 않습니다.
- 표·순환·조건 분기는 기존 지원 지식 후보로 참고합니다. 기존 14분류 유지 결정에 따라 새 정식 ID를 만들지 않았습니다. 맞지 않는 부분은 `other_candidate`로 남길 수 있습니다.
- 기획실이라는 부서명으로 초보자를 단정할 수 없습니다. 해당 주제의 사전 지식이 확인될 때 핵심 개념 소개와 요약의 깊이를 조절합니다.
- 등속 운동을 설명한다면 선형 변화가 적합할 수 있습니다. 설명 대상의 시간·경로를 보존하고 장식 패널의 이징은 따로 검토합니다.
- 제공 CI가 최신이라는 선언은 확인했지만 모든 본문색의 공식 지정은 아닙니다. 관측색은 명시 선택한 프로젝트 역할 후보이며 최종 배경·글자·움직임에서 검수가 필요합니다.

각 항목에는 적용 조건, 반례, 확인이 필요한 주장, 자료 참조와 기록용 질문을 넣었습니다. 질문은 각 4개 선택지와 추천안을 가지며 사용자 질문 도구로 보내지 않았습니다. 예시는 모두 합성 설명용이며 실제 회사 영상 사례 참조는 비워 두었습니다.

이번에는 로컬 지식·조사기록·결정 및 CI 답변 전사를 확인했습니다. 출판사 Summary·공개 글 일부·강의 목차 등은 **기존 조사기록에 적힌 깊이**이며 이번에 원문을 재확인한 것이 아닙니다. MP-02 강의 상세 정의는 `needs_primary_definition_review`로 보류했습니다. 회사 자산 바이너리·외부 스킬 원문·영상 효과는 확인하지 않았습니다.

기존 모션 지식 검사와 신규 초안의 한정 구조·참조 검사를 실제 실행했습니다. `validation.json`은 오류 0건과 입력 파일 267개의 실행 전후 바이트 불변을 기록합니다. 이 결과는 자연어 판단·학습 효과·사람 신원·회사 승인 또는 R6 전체 자산 검사 통과를 뜻하지 않습니다. 정본 변경이 없어 변경 전 백업은 비적용입니다.
