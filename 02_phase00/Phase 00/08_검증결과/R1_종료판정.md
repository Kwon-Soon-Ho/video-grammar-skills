# R1 종료 판정

2026-10-14. **R1 완료: 한맥 디자인 정본과 회사별 CI 자산을 보존·조회·연결할 관리 기반이 갖춰졌다.**

이전 보고에서 모든 공용자산 수집과 공식 CI 확인을 R1 종료 조건처럼 설명한 부분을 정정한다. R1의 목적은 정본·자산 연결·ID/버전·원본/파생·backup·경로 계약이다. 필요한 자료를 모두 모으거나 영상 전용 디자인 규칙을 승인하는 단계가 아니다.

## 후속 항목 — R1 종료를 막지 않음

- 산하 벡터·별도 심볼, 추가 폰트·사진·도표: 해당 자산이 실제 작업에 필요할 때 같은 등록 구조에 추가한다. 자료가 없다는 사실을 계속 표시한다.
- 회사 CI의 최신판·색공간·사용 규정: 해당 로고·색을 실제로 적용할 때 확인한다. 미확인 상태를 공식 승인으로 바꾸지 않는다.
- 한맥 영상 전용 글자 크기·자막·세이프존·모션 수치: R5에서 미정 항목의 기록·검수 계약을 보완하고, 실제 적용값은 영상 사례와 후속 단계에서 검토한다. 웹 수치를 영상 규칙으로 자동 적용하지 않는다.
- 추가 자산과 승인 확인은 필요한 기능의 적용 조건이다. 전체 사내 자산 수집이 끝날 때까지 R2를 기다리게 하는 조건으로 사용하지 않는다.

**R1 완료와 전체 Phase 00 완료는 별개다.** R2~R8의 용어·지식·기록·검수·스킬 심층 검토는 남아 있다. 이번 작업은 R1 종료 범위와 안내만 정정했으며 R2나01-A는 진행하지 않았다.

`collection_complete`는 회사별 CI 원본·관측색 등록 조건, `official_values_complete`는 회사별 CI 지정색의 별도 확인 조건이다. 이 값은 한맥 디자인 시스템의 준비 여부나 R1 전체 종료 판정을 대체하지 않는다. 현재 CI 공식값 확인은 false로 유지한다.


## R1과 R5의 구분

[R1과 R5 업무 구분](../05_출처와검토/R1과R5_업무구분.md)을 따른다. 원본/사본·정본 경로·버전·해시 관리가 R1이고, 디자인 기준 정제와 영상 적용 연결은 R5다. 기존 한맥 디자인 정본은 R5 선행 산출물이며 R1에서는 관리 대상으로 연결했다. R1 완료와 R5 전체 완료를 혼동하지 않는다. R2의 심화 보완은 완료했고 R3는 대기 중이다.
