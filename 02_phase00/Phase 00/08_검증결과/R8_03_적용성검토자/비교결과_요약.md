# 적용성 검토자 개발 비교

후보 v0.2.0-draft.2와 기존 스킬의 동일 요청/자료 비교다. 실제 영상이나 사람 검수 결과가 아니다.

| 과제 | 후보 | 기존 |
|---|---|---|
| 한국어_수치_무음과_부분판정 | 7/7조건 | 7/7조건 |
| 회사CI_회신범위와_사용조건 | 7/7조건 | 7/7조건 |
| 외부지침_과잉일반화와_출처충돌 | 7/7조건 | 7/7조건 |

기대항목21개를 첫 모델 실행 전에 고정했다. 실제 시행은 구/신3쌍=6회이고, 실패를 삭제하거나 준비 폴더를 시행으로 세지 않았다.

합성 개발 지침 검토이며 실제 영상/측정·실제 가독성·회사 승인·미사용 잠금 확인이 아니다.
같은 풍부한 공통 DB와 구체 요청을 사용해 스킬 독자효과·일반 우위·효율을 분리 입증하지 않는다.
평가표/기대항목/다른 스킬은 수행 사본 밖에 두었다. 일반적인 단계명/오류 집계 지식 문장은 남아 있으며 모든 평가 관련 문자열 제거를 주장하지 않는다.
실제 R6 회신은 원래 질문 범위로만 포함. full R6/R7 현재 문맥과 자산 실물/검사도구는 시험 범위 밖.
지식 draft 실제 수정/실패복구·스킬 간 전달·새 미사용 사례·기본 전환은 R8-4 잔여.
정적/해시 대조는 실행 중 모든 이벤트·사람 신원·내용 진실성을 인증하지 않는다.
각 과제/구성1회이고 시간/token은 미수집이다. 단일 품질 총점/통계 우위를 만들지 않는다.
