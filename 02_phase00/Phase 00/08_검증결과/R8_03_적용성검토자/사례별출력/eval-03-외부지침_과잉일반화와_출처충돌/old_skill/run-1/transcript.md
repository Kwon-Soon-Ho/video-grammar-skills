## 실패·한계·미실시

- 모든 PowerShell 호출에 FileSystem provider의 InitializeDefaultDrives 경고가 출력되었다. 요청된 파일 읽기·해시·쓰기·파싱은 정상 출력과 종료 코드 0을 반환했다. 해당 경고를 입력 파일 읽기 실패나 형식 검사 통과의 근거로 쓰지 않았다.
- 한 번의 긴 묶음 출력이 잘렸다. 핵심 레코드·필요 문서는 범위를 좁혀 재조회했다. 생략된 내용을 추정하지 않았다.
- 제공 사본의 07_실행도구/자료검증.py와 전체 검사기·스키마는 파일 목록에 없었다. 다른 DB에서 가져오거나 추정 생성하지 않았고 Python도 실행하지 않았다. 공식 구조/참조 검사·full R6/R7 통과 미실시다.
- 외부 원격 원문·임베드 움직임·예제 코드·효과·최신성 재확인 미실시. 이 결과의 출처 확인은 제공 로컬 레코드·발췌 범위다.
- 실제 영상·프레임·오디오·자산 실물이 없어 실제 가독성·시계열·측정값·모션 곡선·섬광·시청효과·성능·브랜드 사용형을 검수하지 않았다. 미관 총점과 전체 영상 통과는 기록하지 않았다.
- 실제 사람 질문·답변·회사 승인 없음. 기존 사용자결정 레코드는 원래 확인 범위의 근거로만 사용했다. R6 원문·다른 평가·다른 run·다른 DB·부모 대화를 열지 않았다.
- 새 화면 기획·제작, AE 실행, 도구 설치·다운로드·네트워크, API, Claude CLI, 추가 에이전트 사용 없음.
