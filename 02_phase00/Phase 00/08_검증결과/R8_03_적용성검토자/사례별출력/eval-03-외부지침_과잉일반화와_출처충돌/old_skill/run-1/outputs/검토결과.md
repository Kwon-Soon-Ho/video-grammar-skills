# 모션·화면 기준안 REV-C v0.1.0 검토결과

검토일: 2026-10-15 · 상태: 회의용 draft · 대상: `검토자료/기준안.md` C1~C6 · 범위: 제공된 합성 문서의 출처·적용성·충돌 검토

**현재 문구 그대로 Phase 00 기준으로 사용하기에는 수정이 필요하다.** C1~C6에는 조건부 참고의 전역 규칙화, 미확인 효과·시청자 특성의 단정, 새 ID·회사 필수화, 출처 해시 불일치, 미관 총점에 의한 전체 통과가 포함된다. 아래 대체 문구를 검토용 제안으로 사용하고 회사 규칙 승인은 별도로 남긴다. 기준안과 정본을 수정하지 않았다.

실제 프레임·영상·오디오·출력 조건은 제공되지 않았다. 등속 화살표·정지 정의·동일 구성 비교는 검토요청에 적힌 합성 사례이며 관측 결과가 아니다. 실제 가독성·운동 정확성·시청효과·전체 영상 품질은 미검수다.

## 유지할 부분

- **균일 유동 가정을 설명하는 등속 화살표:** 가정의 시간 의미를 보존하는 후보로 유지한다. 관측된 실측 운동이라고 바꾸어 기록하지 않는다. AP-06과 MC-01은 등속 전달의 선형 사용을 허용하며, 같은 원인을 AP-06/MP-02 두 건으로 감점하지 않는다.
- **정지 정의 문구:** 정의와 관계를 읽을 안정 상태가 필요한 경우 유지한다. 움직임 개수 부족을 오류로 삼지 않는다. 실제 문구·표시 크기·완성 후 유지시간을 확보한 뒤 가독성을 검수한다.
- **두 공법의 동일 구성·대칭 비교:** 대응 항목을 찾기 쉬운 반복으로 유지할 수 있다. 공통 라벨·단위·척도·비교 조건을 확인하고 비교 시점에는 양쪽 정보가 함께 읽히게 한다. 동일 구성을 바꾸는 일 자체를 개선으로 취급하지 않는다.

근거: `02_원칙과레이아웃/모션원칙_심화카드.json` AP-06의 project_interpretation·counterexample·duplicate_failure_policy, `04_모션원칙_충돌과예외.md` MC-01·02·06, `05_출처와검토/스킬심층검토/02_원문과참조_검토결과.md` Impeccable·LottieFiles 절. 이 근거는 프로젝트 조건부 해석·설명용 사례이며 이 합성 장면의 효과를 실증한 자료가 아니다.

## 출처 충돌을 처리한 방식

1. **원본 개념과 적용 해석:** Adobe의 공개 설명·명칭, Jorge의 공식 강의 제목 확인은 범용 참고다. 실제 등속 설명을 허용하는 조건·예·반례는 프로젝트 해석으로 기록한다. 유료 강의 본문을 읽었다고 하지 않는다.
2. **IP-10의 읽기 깊이:** 과거 목차 명칭만 확인한 SRC-CAM-EXPERTISE와 후속 공식 Summary의 정의를 확인한 SRC-R3-EXPERTISE-SUMMARY는 서로 다른 확인 범위다. 현재 IP-10 v0.1.2가 후자를 직접 참조하므로 “정의도 전혀 확인되지 않았다”는 결론도 부정확하다. 다만 장 전체·실험·회사 영상 효과는 여전히 미검토다.
3. **UX 자료의 범위 차이:** 출처목록은 12제목을 locator/content_scope로 적고, 연결검토 문서와 후보 JSON은 저자 글의 절별 설명 검토를 기록한다. 제공 기록의 상세도 차이는 보존한다. 원문을 이번에 재열람한 것처럼 합치거나 임베드 움직임·사용성 효과의 독립 시험으로 승격하지 않는다. 어떤 기록도 새 ID·회사 필수화를 지지하지 않는다.
4. **외부 웹 취향과 영상 기준:** 선별 가능한 것은 실제 입력 확인·내용 관계·구체 근거·자체 검토 절차다. 웹 px·UI ms·hover·스크롤·개수·글꼴 수 등의 조건을 고정 영상 전역 규칙으로 옮기지 않는다. 자막 중복 감소도 무음·접근성·기술 용어·단위 필요를 확인한 뒤 조건부 검토한다.

이 회차의 출처 근거는 제공된 로컬 레코드와 발췌다. 외부 원격 원문·코드·최신 버전을 확인하지 않았다.

## 회의에서 필요한 질문과 결정 제안

아래는 **미발송 제안**이며 답변·승인·담당자 접수는 생성하지 않았다.

**Q1 · REV-C v0.1.0의 운영 범위** — 프로젝트 책임자·분류 체계 담당자·회사 규칙 권한자에게 요청할 운영 선택이다.

- A. 위 수정안을 조건부 참고 초안으로 검토하고 기존 ID를 유지한다. **추천:** 제공 근거와 기존 사용자 선택 범위에 맞는다.
- B. 기존 ID를 유지한 채 특정 시청 목적·출력 조건을 정하여 후속 시안 검증용 후보로 한정한다. 실제 검증 계획은 후속 단계에서 작성한다.
- C. 전체 채택을 보류하고 대상 지식·시청 조건·필요 출처를 보완한 뒤 다시 검토한다.
- D. 신규 ID·회사 의무 규칙 변경안을 별도로 제출하고 권한·대상·버전·예외·검증 근거를 갖춰 별도 심의를 받는다. 이 선택 자체는 등록·승인·효과 검증이 아니다.

Q1의 제안은 기존 기록을 덮어쓰지 않는다. 이미 확인된 DECISION-R3-MOTION-SCOPE-A의 조건부 참고·새 ID 없음은 실제 재선택 답변이 오기 전까지 보존한다.

**Q2 · 시청자·전달 목적 확인** — 기획/내용 담당자에게 자유 답변과 근거를 요청한다. “기획실”이라는 소속 외에 이 주제의 실제 사전 지식 자료가 있는가? 정의·기술적 사실 중 생략할 수 없는 내용은 무엇인가? 근거가 오기 전 숙련도 unknown·설명 수준 조정 보류다.

**Q3 · 실제 화면 검수 조건** — 제작/디자인 검수자에게 화면비·출력 해상도·표시 크기/시청 거리·무음/음성·자막 필요·실제 문구·단위·완성 후 유지시간·재생 환경을 요청한다. 제공된 등속 화살표는 설명 가정인가, 실측 자료와 대응하는가? 후자라면 시간·경로 자료와 버전도 요청한다. 답변과 실제 재생 근거 전에는 가독성·운동 정확성을 통과시키지 않는다.

**Q4 · 참조 해시 정정** — 기준안 작성/자료 관리 담당자에게 REV-C의 AP-06 참조 대상이 이 제공 사본인지, 별도 버전을 의도했는지와 근거를 요청한다. 현재 확인된 파일 버전·레코드 버전·로컬 해시를 회의 기록에 사용하도록 제안한다. 별도 원본을 추정 생성하지 않는다.

**재검토 조건:** C1~C6 수정 문구의 새 버전·변경 이력, Q1의 실제 결정 범위, Q2~Q4의 필요한 자료를 대상별로 연결한다. 이후 실제 화면·시간 검수는 해당 산출물이 제공된 범위에서 따로 수행한다. 실제 영상·회사 문법 승인·후속 화면 제작·full R6/R7 구조 통과는 이번 결과에 포함하지 않는다.
