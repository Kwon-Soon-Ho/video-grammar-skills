# 모션·화면 기준안 검토결과

대상: **REV-C v0.1.0**, `검토자료/기준안.md` C1~C6. 지식·규칙 초안의 문서 적용성 검토다. 제공 사례는 균일 유동 가정의 등속 화살표, 정지 정의 문구, 동일 구성의 두 공법 나란히 비교다. 실제 프레임·영상·오디오는 없다. 대상 해시는 검토기록.json에 실제 계산값을 남겼다.

**현재 판본을 Phase 00 공통 기준으로 채택하는 것은 수정필요다.** C1~C6의 단정은 제공 정본의 조건·반례·조사 범위와 충돌한다. 등속·정지 정의·동등 비교는 목적에 맞는 후보로 유지한다. 시청자 사전지식, 실제 가독성·읽기 유지·이징 수치·시청효과는 판단보류다. 미관 총점이나 자료 경로 확인으로 이 보류와 오류를 상쇄할 수 없다.

## 유지할 범위와 출처 권위

제공 사례의 등속 화살표, 정지 정의 문구, 동일 구성 비교는 조건부 유지 제안이다. 그 화면을 실제로 관측하거나 학습 효과를 입증한 것은 아니다. 정지 정보의 위치 읽기와 시간 관계의 동작 선택은 MC-06처럼 목적을 나눠 판단한다. 필요한 경우 장식 패널의 이징, 근거가 확인된 입문 설명, 내용에 맞는 비대칭도 선택할 수 있다. 어느 한 형식을 새 절대 규칙으로 뒤집지 않는다.

이번 실행은 외부 URL을 열지 않았다. Adobe ‘6. Ease In, Ease Out’은 DB에 기록된 공개 기사 절 검토, Jorge ‘Lesson 2 / Eases’는 공개 강의 개요만 확인한 상태다. MP-02 상세 적용은 프로젝트 해석이며 유료 강의 본문 주장으로 인용하면 안 된다. IP-10의 오래된 SRC-CAM-EXPERTISE는 목차 명칭만 확인한 이력이고, 현재 IP-10 연결은 2021 공식 Summary인 SRC-R3-EXPERTISE-SUMMARY다. 어느 쪽도 학술 장 전체 검토가 아니다.

UX12는 저자 글의 12개 설명 검토 기록이며 임베드 움직임·사용성 효과 독립 시험은 없다. R3 이식 검토는 제공된 다섯 분야 발췌만 읽었다. Taste 원문/코드·라이선스 전수·원격 최신성을 확인한 결과가 아니다. R7 조사기록 v0.1.1 WEB-MOTION은 Carbon **v10 보존 UI 문서** 지정 절, WEB-KO는 **2026-03-21 Group Note Draft** 지정 절이다. UI px/ms·hover/scroll·이징·웹 줄 수를 고정 영상/한국어 공통 규칙으로 변환하지 않는다. 특정 외부 지침이나 최신 CI 사실을 회사 의무·새 시안 승인으로 승격하지 않는다.

## 회의에서 필요한 질문 — 제안만, 실제 질문/회신 없음

1. **사실 확인 / 내용 담당자·기획 책임자 / REV-C v0.1.0 C2**: 해당 주제의 실제 시청자는 누구이며 사전지식을 확인할 수 있는 입력·인터뷰·기존 교육/검토 자료와 필수 전달 내용은 무엇인가? 현재 확인한 것은 IP-10의 조건부 범위뿐이다. 자유 답변과 근거를 받아 해당 부분만 재검토한다. 부서명으로 답을 유도하지 않는다.
2. **사실 확인 / 기획·기술 담당자 / 검토요청의 제공 사례 및 C1·C4**: 균일 유동 화살표가 가정 설명인지 실측 표현인지, 정의 원문·비교 대상/공통 항목·유지해야 할 관계의 근거는 무엇인가? 실제 적용을 검토할 때 매체·화면비·무음/음성·표시/시청 조건도 제시해 달라. 현재 사례 설명은 유지하되 기술 사실·읽기시간으로 확정하지 않는다.
3. **운영 선택 / 품질 운영 책임자·회사 규칙 권한 담당 / C3·C6의 새 회사 필수화 추진을 계속하려는 경우만**: 현 기준안은 채택하지 말고 어떤 후속 경로를 택할지 검토한다. A. 기존 결정대로 연결 후보와 항목별 조건부 검토를 유지(추천: 현재 근거 범위에 맞고 새 규칙을 만들지 않음). B. 특정 목적/대상/매체를 정한 소규모 시범 후 항목별 재검토. C. 필요한 원문·표본·실제 시청 검토를 추가 확보한 뒤 회사 규칙 도입을 별도 제안. D. 회사 공통화 추진을 중단하고 프로젝트별 제안만 보존. 이 선택은 향후 운영 제안이며 답변을 생성하거나 기존 draft 권한·참고 범위를 반복 승인 요청하지 않았다.

원문 전문을 읽었다는 별도 근거가 제시되면 출처 담당자가 정확한 판본·절·원문 위치와 효과 주장의 범위를 제공해야 한다. 그 전에는 전문 검토/효과 검증 문구를 삭제하는 최소 수정으로 충분하다. 실제 회신은 이번 결과에 없으며 내용 검수는 대기다.

## 재검토 및 미실시

최소 수정 문구를 반영한 새 기준안과 실제 인용 범위를 다시 대조하고, 실제 적용을 추진할 때만 필요한 시청 조건·내용 근거·시안/재생 자료와 담당 판단을 연결한다. 필수 오류·보류 해소 전 전체 준비 완료로 제안하지 않는다. 실제 회사 문법 승인은 01-B, 새 화면 제작은 02의 별도 범위다.

입력·기준안·정본·검수 대장·pin은 수정하지 않았다. 실제 화면/시나리오/모션 제작, 네트워크·원격 최신 확인, CU·AE·API·Claude CLI, 추가 에이전트, 실제 사람 질문, OCR/PTS/좌표·이징 측정, R4/R5 검사기 및 full R6/R7 통합 검사는 미실시다. 관련없는 CI 미정을 이 검토의 차단 사유로 삼지 않았다.
