# 삼안 프로젝트 메모 REV-B 검토결과

검토 대상: `검토자료/프로젝트메모.md`, REV-B v0.1.0. 합성 프로젝트 초안의 문서 적용성 검토이며 실제 시안·회사 승인·납품 검수가 아니다. 대상은 삼안 단독이고 산하 로고·가이드는 사용하지 않는다.

**결론: 문서의 승인·색 자격·전체 사용 가능 주장은 수정필요다. 삼안 관측색과 한맥 공통 라이브러리를 조건부 후보로 검토하는 일은 계속할 수 있다. 정확한 역할 선택과 최종 적용 적합성은 판단보류다.** 자료 최신성을 다시 질문하거나 산하 Illustrator 부재로 전체 검토를 멈출 필요는 없다.

## 이번에 확인한 범위

- 2026-10-15 실제 회신 R6-REPLY-CI-20261015-001@0.1.0은 “8개 회사 모두 내가 준 ci 자료가 최신화 된 자료야. 산하는 원래 일러스트레이터 파일 없어.”라고 답했다. 접수 대장@0.1.1의 HUMAN-R6-CI-20261015-001은 최신성 8개 단위만 partial/limited_statement로 연결하고 사용 가이드 8개 단위는 unresolved로 남긴다.
- 신원 인증, 회사 승인, 외부 업로드·재배포 권한은 회신으로 생성되지 않았다. 회신 후 보완한 구조화 범위와 한맥 대화·스키마 전체를 사용자가 검수했다는 뜻도 아니다.
- R5 정책 DECISION-R5-OBSERVED-COLOR(선택 A, 2026-10-15)는 이미 선택된 운영 정책이다. 관측색을 디자이너 명시 선택·출처·가정·선택 이유·검수 상태를 갖춘 프로젝트 초안의 역할 후보로 쓸 수 있다. 개별 시안 검수나 공식색 승격은 아니다. 기존 정책을 재승인받을 필요는 없다.
- 한맥 웹 정제 라이브러리 hanmac-video@0.1.0은 이미 존재한다. 공통 컬러는 명시 선택해 참조 가능하고 UI·표면은 선택 참고다. 정확한 회색 토큰은 메모에 지정되지 않았으므로 임의로 골라 실제 선택을 채우지 않는다.

기존 회사·자산·색 대장의 “최신판 미확인” 문구와 현황 목록의 unresolved는 작성 당시 상태를 포함한다. 최신성의 현재 해석은 후속 실제 회신·확인현황을 함께 따른다. 그렇다고 사용 가이드·색관리·역할·승인까지 해결된 것은 아니다. 입력의 과거 문구나 상태값은 이번에 고치지 않았다.

| 항목 | 판정·영향 | 근거 | 최소 수정 제안 |
|---|---|---|---|
| B1 최신 자료이므로 이번 시안 회사 승인 완료, 검수 대기 삭제 | 수정필요. 자료 확인을 시안·권한 승인으로 확대한다. | R6 원문 not_confirmed 및 company_approved=false; 접수 대장 events[0] | “제공 CI 자료의 최신성은 확인됐다. 본 초안의 역할·조합·사용형·가독성 검수와 필요한 사용 권한 확인은 별도다.” |
| B2 한맥 웹 회색을 삼안 공식 CI색으로 등록 | 수정필요. 서로 다른 회사/공통 참고 출처와 공식성을 혼동한다. | R5 연결 규칙 4~5; Q-BRAND-02 | “한맥 공통 라이브러리의 명시 선택한 토큰을 삼안 프로젝트의 글자색 후보로 참조한다. company_id=null인 공통 자격과 출처·프로필 버전을 유지하고 삼안 CI색으로 등록하지 않는다.” 정확한 토큰·역할 선언은 아직 필요하다. |
| B3 낮을 수 있는 대비 때문에 CI 원색 자동 암화·새 기본형 지정 | 수정필요. 실제 대비 저하도 아직 확인되지 않았고 원형·기록을 훼손할 수 있다. | CI 기록절차 ‘페이지에서 가져오기’; R5 연결 규칙; Q-BRAND-01/02 | “CI 원색을 보존한다. 최종 배경에서 대비·가독성을 확인하고 배경판, 글자색, 역할·배치 조정 또는 근거 있는 허용형을 검토한다.” 새 응용색이 꼭 필요하면 별도 project_literal/ui_proposal 후보와 이유·검수 상태로 남기며 공식형/기본형으로 만들지 않는다. |
| B4 미관 총점 94로 전체 사용 가능 | 수정필요. 총점의 근거·측정이 없으며 미관이 필수 오류·미검수·보류를 상쇄하지 못한다. | R7 판정운영 ‘준비상태는 목적과 범위를 붙인 제안’ | “항목별 수정필요·판단보류·미검수를 표시한다. 현 단계에서 전체 사용 가능/준비 완료를 선언하지 않는다.” 94를 새 측정값이나 실제 평가 결과로 재사용하지 않는다. |
| B5 산하 Illustrator 부재로 삼안 전체 중단 / 8회사 최신성 재질문 | 두 제안 모두 수정필요. 이번 비사용 자료를 차단 조건으로 삼거나 이미 확인된 범위를 반복 요청한다. | 메모 대상 범위; R6 확인현황; R7 운영 4 | “산하 관련 사용형·원본 형식 검수는 이번 삼안 단독 범위에 비적용이다. 8회사 최신성 기존 회신을 인용하고 삼안에 필요한 남은 조건만 확인한다.” 산하 AI 원본을 요청·추정 생성하지 않는다. |

B1과 B4는 서로 연결된 승인·준비상태 확대 오류다. 같은 원인에 대해 중복 감점하지 않는다. 실제 화면의 대비가 낮다는 판정이나 실제 로고 원형 훼손 관측을 한 것은 아니다.

## 삼안 색 후보의 자격

회사목록·CI색상목록은 기록버전 0.3.1, 회사별 연결 현황은 0.1.0을 조회했다. 아래는 기존 기록의 조회 결과이며 이번에 원본 픽셀·Illustrator 문서를 다시 검사한 결과가 아니다.

| 참조 (회사ID=saman, 색 기록버전=0.1.0) | 기록 자격 | 이번 적용 |
|---|---|---|
| ci.observed.raster.1 / .2 / .3 | current, raster_sample, source_checked, sRGB 화면값 #F5821F / #F9A159 / #FCC28F. CI-SOURCE-009@0.1.0 PNG에서 관측; ICC 없음·채널 보존·sRGB 표시 가정 | 명시 선택 조건을 갖춘 초안 역할 후보로 검토 가능. 공식 디지털 지정색·자동 기본색 아님 |
| ci.observed.vector.1 / .2 | CMYK [0,0,0,72] / [0,60,100,0], source_checked지만 screen_value=null | 화면색으로 자동 연결·프로필 없는 sRGB 환산 보류 |
| ci.declared.draft.gray.hex / orange.hex | 원문 #4D4D4D / #F58220, source_level=official_declared이나 verification=draft, screen_value=null | 명칭만으로 공식 화면색 확정 불가. 선언후보4개 확인 항목과 연결해 자격·조건 보류 |
| ci.declared.draft.gray.pantone / orange.pantone | 원문 Pantone Cool Gray 10C / Pantone 165C, draft, screen_value=null | 별색을 임의 HEX로 바꾸지 않음 |

선언후보의 근거는 CI-COLLECTION-030@0.1.0 PDF호환 page1 우측중단 메인컬러 두 패널이라는 대장 위치다. 실물은 제공되지 않아 재열람하지 않았다. #F5821F 관측값과 #F58220 선언후보는 서로 다른 출처·자격을 보존하며 자동 병합하지 않는다. 부분 인쇄채널 Black70%, Magenta60%+Yellow100%를 전체 CMYK로 추정 보충하지 않는다.

## 근거와 미실시

주요 근거는 제공 사본 안의 R5 적용정책, CI·화면역할 연결규칙, CI색상목록의 saman 레코드, hanmac-video 정본, R6 회신 원문·접수 대장·확인현황, R7 판정운영기준 및 Q-BRAND-01/02다. 파일·위치는 검토기록.json에 연결했다.

자료검증.py가 제공 사본에 없음을 확인했다. R4/R5 검사기·자산 실물·전체 R6/R7 입력도 미제공이므로 정본 구조검사/full R6·R7 통과를 보고하지 않는다. 네트워크 원문 최신 확인, CU·AE·API·Claude CLI·사람 질문·추가 에이전트, 새 로고/화면/색 생성은 실시하지 않았다. 입력 대장·회신·회사색·프로젝트 메모는 변경하지 않았다.
