# 삼안 프로젝트 메모 REV-B v0.1.0 검토결과

검토일: 2026-10-15 · 합성 개발시험 · 문서 적용성 검토

B1~B5는 수정 제안이 필요하다. 기존 회신으로 삼안을 포함한 8회사 제공 CI 자료의 최신성과 산하 Illustrator 원본 부재는 확인할 수 있다. 이를 이번 시안 승인·공식 sRGB 자격·세부 사용 가이드·배포 권한으로 확대할 수는 없다. 원색과 로고 원형을 보존한 채 프로젝트 후보 검토는 계속할 수 있으나, 명시 선택·최종 조합·실제 시청 검수가 없어 전체 사용 가능 또는 준비 완료로 제안하지 않는다.

## 1. 대상과 선정 범위

- 대상: `검토자료/프로젝트메모.md`, “삼안 검토용 메모 REV-B v0.1.0”. 별도 대상 ID 미제공으로 제목을 식별자로 사용한다. 계산 SHA256: `9d298e42eb1d9d7dae22fbe406e7aabd0191a4b580919497f0c059d168728b2e`.
- 대상 종류: 합성 프로젝트 초안의 색 적용·검수 방식 메모. 실제 화면·영상·사람 선택·승인 결과가 아니다.
- 목적: 삼안 CI색의 배경/강조 역할 후보와 한맥 웹 라이브러리 회색 글자 후보의 적용 조건 검토. 삼안 단독이며 산하 자산은 미사용이다.
- 회의용 보고서 외 실제 전달 매체·무음 여부·화면비·출력/표시 환경·시청자 사전지식 근거는 미제공이다. 직급이나 부서로 추정하지 않았다.
- 판정 전 선정: Q-BRAND-02는 출처·명시 선택·역할, Q-BRAND-01은 B3의 CI 원형 변경 제안, Q-TRUST-02는 B1·B4·B5의 승인/일반화 범위, Q-SCREEN-03은 회색 글자 대비 검토에 필수다. 기준은 `r7-quality-criteria@0.1.1`의 해당 카드이며 이 메모 목적에서의 필수이지 회사 의무 규정이 아니다. 중간 선정 변경 없음.
- 자막·음량·모션·좌표·크롭·도표 전 항목은 이번 문서 적용성 판정 대상으로 선정하지 않았다. 실제 렌더 품질은 미검수이며 자료 부재를 통과나 비적용으로 처리하지 않았다.

### 삼안 색을 읽는 방법

`CI색상목록.json`의 saman:`ci.observed.raster.1@0.1.0`은 #F5821F를 screen_value에 보유한 source_checked 관측값이다. ICC 없음·sRGB 표시 가정·공식 디지털 색 인증 아님을 함께 보존한다. 관측값은 이미 선택된 정책 A에 따라 디자이너가 명시 선택한 프로젝트 초안의 배경/강조 후보로 검토 가능하지만 현재 메모는 그 선택을 완료한 기록이 아니다. raster.2 #F9A159, raster.3 #FCC28F도 같은 관측 범주다. vector.1/2는 CMYK 원문이며 screen_value=null이므로 프로필 없이 화면 HEX로 환산하지 않는다.

`/colors/91~94`의 `ci.declared.draft.gray.hex` #4D4D4D, `orange.hex` #F58220, `gray.pantone` Pantone Cool Gray 10C, `orange.pantone` Pantone 165C는 모두 verification.state=draft, screen_value=null이다. source_level=official_declared 필드만으로 공식 화면값을 확정할 수 없다. R6-REQ-SAMAN-VALUES@0.1.0도 needs_material이다. #F5821F 관측과 #F58220 선언은 다른 기록으로 유지하고 차이를 오탈자나 동일값으로 자동 교정하지 않는다. 본문에 나열한 값은 제공 JSON의 전사이며 원본 실물을 새로 측정한 값이 아니다.

한맥 정본에는 30개의 global_color_library와 별도의 optional_color_utility가 구분된다. “회색”이라는 말만으로 특정 토큰·합성 회색을 확정하지 않는다. 선택 시 실제 토큰ID·프로필 판본과 값/알파를 명시하고 삼안 공식 CI와 분리한다.

## 4. 운영 선택 제안

기존 정책 A와 내부 초안 작업 권한을 다시 승인받는 질문은 하지 않는다. 아래는 누락 조건을 채우는 작업 순서에 관한 회의용 선택안이며 실제 사용자 선택으로 기록하지 않았다.

| 선택지 | 진행 범위·장단점 |
|---|---|
| A · 삼안 관측색 후보를 유지하며 선택/조합 조건부터 정리 (추천) | 기존 정책을 활용해 검토를 계속할 수 있다. 명시 선택·출처/가정·역할·대기를 기록하고 최종 검수는 남긴다 |
| B · 공식 선언색 자격 확인을 먼저 진행 | 선언후보4개의 화면 표시 자격을 좁게 확인할 수 있으나 관련 자료를 기다리는 동안 그 선언값의 역할 확정은 보류 |
| C · CI색은 원형 참조로 두고 글자/배경의 분리 대안부터 문서 비교 | 공식색 변경 없이 가독성 대안을 검토할 수 있다. 프로젝트 색 역할·시청 조건은 여전히 필요 |
| D · 특정 색 역할 선택을 잠시 보류하고 기존 문서의 출처/회신 범위만 수정 | 새 조합을 정하지 않아도 B1~B5 문구 개선 가능. 실제 색 적용 적합성 판단은 뒤로 남음 |

추천은 A다. 현재 가능한 검토를 이어가면서 공식성·렌더 검수를 과장하지 않는다. 새 화면 제작은 어느 선택에서도 이번 작업에 포함하지 않는다.

## 6. 해결 조건과 미실시

B1~B5를 위 범위로 수정하는 것은 제안만 남겼다. 실제 선택·적용을 판정하려면 대상 판본의 색 역할 선언, 삼안의 필요한 사용 조건, 최종 조합/시청 자료를 연결하고 해당 필수 보류를 재검토해야 한다. 오류·사람 대기·미검수가 남아 있어 전체 사용 준비 완료를 제안하지 않는다. 현재 가능한 문서 검토와 후보 정리는 계속 가능하다.

입력 메모·정본·자산/색 목록·회신·대장·pin은 모두 보존했다. 새 로고/화면/시나리오 제작, 영상/프레임·오디오·PTS/OCR/좌표·실제 대비 계산·모션/이징 검사, 원격 원문 재열람·최신 웹 조사, 회사 승인·실제 사람 답변, 전체 R4/R5/R6/R7 검사기 실행은 하지 않았다. 일부 제공 문서의 hash 일치는 로컬 파일 확인이며 내용·권한·현재 통합 문맥 검증의 대체가 아니다.
