# REV-A 검토결과 — 공법 비교 설명 영상 준비 회의

**REV-A v0.1.0은 그대로 채택하기 어렵습니다.** 대본과 다른 부정어·소수점을 먼저 바로잡고, 180 ms 일괄 노출·무음 자막 전부 삭제·부서로 숙련도 단정·중앙 크롭만으로 검토 완료·장식 수량 강제·미관 총점 상쇄 규칙을 수정해야 합니다. A/B 동등 비교와 정지 정의 장면은 유지할 수 있습니다.

확인된 **수정필요**와 자료 부족에 따른 **판단보류·실영상 미검수**가 함께 남습니다. 준비 완료·회사 납품/배포 승인으로 제안하지 않습니다. 이 보고는 입력 수정이나 새 화면 제작을 수행하지 않은 지침 검토 제안입니다.

## 대상과 판정 범위

- 대상: `검토자료/검토초안.md`의 REV-A v0.1.0, 01–07. 대조 원문: `검토자료/대본원문.md` SCRIPT-A v0.1.0, S1–S3. 대상 해시 미제공·미계산.
- 목적: 공법 비교 설명 영상 준비 회의. 기획실·현장 직원 혼합이며 해당 공법 사전지식은 **unknown**입니다. 부서·직급으로 추정하지 않습니다.
- 시청 조건: 16:9·9:16, 휴대전화 무음 포함. 영상·캡처·오디오·재생 검수 자료 미제공.
- 기준: `13_품질검수/품질항목_정본.json` v0.1.1 및 `03_판정운영기준.md` R7-1. 회사 의무 규정이 아닌 조건부 지식입니다.
- 수행 스킬: 제공된 video-guidance-reviewer v0.2.0-draft.2. 경로는 모두 지정 DB 루트 아래 상대 경로입니다. 문서의 절/항목을 근거 위치로 쓰며 PTS·좌표·실측 시간을 만들지 않았습니다.

한국어는 실제 글꼴·줄폭·해상도에서 부정어, 소수 수열, 값과 단위를 함께 읽을 수 있는지 확인해야 합니다. SI 공백을 유지한 **0.35 mm**, **0.80 L/s**, **0.65 L/s**를 보존하고, 숫자/단위의 의미 묶음을 확인합니다. 모든 한글 어절 분리를 오류로 보거나 2줄·32자·고정 px를 강제하지 않습니다.

현 초안에 시계열/카운트·비례 그래프·실제 UI/도면 변환·회사명/CI 적용 주장은 없어 해당 기준을 의무화하지 않았습니다. 음질·연속 동작·섬광은 이번 문서 규칙 검토에서 선정하지 않았고 실제 영상에서는 **미검수**입니다. 자료 부재를 영상 안전 통과나 비적용으로 바꾸지 않습니다. 독립 영상 분석 기록도 없어 Q-TRUST-01·02의 분석 품질 판정은 하지 않았습니다. 제작/사용 범위가 바뀌면 재선정합니다.
