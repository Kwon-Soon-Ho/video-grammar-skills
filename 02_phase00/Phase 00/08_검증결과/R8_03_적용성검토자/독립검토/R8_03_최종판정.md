## 발견·보완 이력

1. 후보 draft.1의 ‘이 대화 회신’ 오독과 저장 실패 후 실제 상태를 구분하는 문구를 권고했다. draft.2에서 기존 유효 R6 회신 재사용과 내 쓰기 일치대상만 복구·외부변경 보호를 확인했다. 실제 스킬 쓰기 실패 분기의 동작을 시험한 것은 아니다.
2. 게시 스크립트의 완료상태 선행 저장, 복사 source 긴경로 미적용, 새 복사 전후 바이트 대조 부족을 권고했다. 후속 코드와 C격리시험 자료에서 보완을 확인했다. 이 부가 도구시험은 모델6run·스킬쓰기·영상성능 시험에 더하지 않는다.
3. 최종 감사에서 첫 공식 뷰어6과제가 모두 `(No prompt found)`인 표시 결함을 발견했다. 원본 case metadata가 공식도구 탐색위치보다 한 단계 더 위에 있었기 때문이다. 첫 생성본·중간 표시본/metadata·검사와 코드를 보존하고 모든 수행/채점 완료 후 run루트에 표시용6metadata를 만들었다. 최종 사본은 eval_id/eval_name/prompt만 포함한다. 기대항목은 넣지 않았으며 이를 시행 당시 제공물로 소급하지 않는다.

과제 표시 결함은 보완 후0건이다. 최종6prompt를 원래 case.prompt와 대조했고, 첫뷰어 원본SHA `1021a5a149519fa1c95b22730ad58b5ef9e26a2173a9361829770b4e5e7a61ee`의 보존 및 첫/최종 뷰어12출력·6grading·benchmark payload 불변을 확인했다. 수행입력·task/transcript/출력·고정 기준도 불변이다. 상세 발견은 `07_뷰어과제_보완필요.md`, 보완 결과는 `07_집계와뷰어_독립대조.json`에 있다.

## 결과가 증명하지 않는 범위

- 풍부한 동일DB와 비교적 명시적인 오류를 사용한 각1회 개발 비교다. 이21/21 동률로 개정효과를 변별하지 못했다. 일반 동등성·독자효과·효율·통계 우위·실영상 품질을 주장하지 않는다. 시간/token은 실제 미제공으로 null이다.
- transcript는 수행자 요약이다. 전후hash 일치는 중간 임시변경 후 원복·모든 읽기/금지도구 부재·선정 시점의 독립 raw호출 인증을 대신하지 않는다. 완료알림 접수는 main 관측기록과 파일을 대조했으며 신원 인증이 아니다.
- R3 제공물은 기존 이식검토 기록5절 발췌다. 원격 원문 최신성·학술 장 전문·실제 외부코드/라이선스의 새 전수검증을 하지 않았다. R7 WEB자료는 등록 locator/요약·이식 한계이며 원문전문/원격hash가 없다.
- 수행사본에는 자산실물·전체 R6선언/원문·R7고정문맥/검사기가 없다. 제공 회신 내용 검토와 D 기반 pin바이트 대조를 full R6/R7 사본검사나 내용 승인으로 옮기지 않는다. 감사자는 D검사기를 실행하지 않았다.
- 정적 뷰어의 데이터/소스 검사를 수행했으며 브라우저 렌더·클릭·시각가독성 검수는 하지 않았다. 실제 분량·읽기편의의 적합성은 사람 출력 피드백 대상이다. R8-1/2의 기존 뷰어 과제 표시도 R8-4 통합 검토에 남긴다.
- 실제 지식 draft 수정·설계된 저장 실패/복구·새 미사용 확인·스킬 간 전달·기본 전환은 미검증/미실시다. 회사 문법 승인·실영상/시청효과·01-A 분석 구현은 수행하지 않았다.

현재 출력은 사람 검토에 제시할 수 있다. 다음 스킬/전체 전환의 완료로 확대하지 않으며, 실제 R8-3 피드백과 R8-4 잔여는 별도로 다룬다.

## 지문 고정

`R8_03_최종판정.json`의 D_source_hashes는 D Phase00 상대경로, C_result_hashes는 C작업폴더 상대경로다. 현재 자료·코드의 SHA256을 게시 전 고정한다. JSON 자신은 순환 참조를 피하려고 자기 map에서 제외하며 이 Markdown은 포함한다. 게시 후 의도된5개 안내/상태 변경과 별도 영수증을 구분하고, 검토된 입력이 달라지면 새 검토 없이 지문을 자동 갱신하지 않는다.
