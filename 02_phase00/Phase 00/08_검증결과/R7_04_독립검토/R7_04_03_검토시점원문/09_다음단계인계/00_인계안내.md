# Phase 01-A로 넘길 계약

Phase 00은 용어·참고 지식·브랜드 연결·최소 기록·검증 도구·관리 스킬의 기반이다. 실제 영상 정확도나 회사 문법 DB 완성은 이 단계의 완료 기준이 아니다.

## 이미 준비된 입력 계약

- 사전 company-video-taxonomy@0.1.1: 8축, 신규 기록용 75개 용어, 폐기 ID 1개와 대체 관계.
- 모션·정보 전달 43개(42개 참고, 1개 정의 검토 대기), 화면 원칙 8개, 레이아웃 14개.
- 한맥 hanmac-video@0.1.0: 기존 전역 컬러 30개. 선택 알파·UI 표면은 선택 참고이며 회사 화면 규칙이 아니다.
- 최소 기록 JSON Schema: 자산·시나리오·구간·추출 프레임·근거·모션 사건·주장·디자인 연결·검수 상태.
- 자료검증.py와 지식조회.py: 형식·참조·시간·근거 수준의 검사와 조회. 실제 파일 내용·사람 신원을 증명하지 않는다.

## 01-A 착수 후 실행 순서

1. 실제 사내 영상 1건과 해당 시나리오, 배포 목적·시청자·출력 조건을 묶는다. 원본 경로·해시와 승인된 처리 범위를 기록한다.
2. 영상 분석 스킬 후보를 별도 검토하고 Anthropic Skill Creator로 01-A 전용 초안을 만든다. Phase 00의 세 관리 스킬에 영상 추출·OCR·창작을 덧붙이지 않는다.
3. 환경을 별도로 확인한다. ffprobe/FFmpeg·원본 PTS·프레임 추출·OCR·시나리오 매칭의 사용 방식은 01-A에서 구현·검증한다. Phase 00 환경에는 이 도구들이 준비됐다고 가정하지 않는다.
4. 대표 장면의 분류·화면 구조·모션 사건을 기록한다. 원본 키프레임은 화면 추적 결과와 구분한다. opacity·Scale·이징 수치를 단정하지 않고 추정 방법·오차·합성 조건을 남긴다.
5. 사람이 확인한 소량의 정답과 비교해 경계·누락·오탐·시간 대응을 평가한다. 실제 프레임과 근거 연결을 점검하고 분석 스킬을 수정한다.
6. 01-B에서 여러 사내 사례의 공통 문법을 추출·검수한다. 사례 분석 통과와 회사 필수 규칙 승인은 별개 기록이다.

## 현재 남은 자료·판단

실제 영상·시나리오 폴더, 결과 프레임, 사람 검수 정답은 아직 받지 않았다. 기록 예시는 synthetic_example이며 실영상 관측이 아니다. IP-10의 1차 정의 확인, 지식별 실제 좋은 예·반례, 01-A 측정 정확도 기준은 후속 작업이다.

이전 사전은 backup와 버전목록으로 보존했다. 현재 검증기는 현재 정본을 기준으로 검사한다. 과거 기록의 자동 변환·과거 버전 검증 엔진은 구현하지 않았으며 변경 제안을 사람이 검토한다.

## 착수 전 체크

스킬 비교 평가와 사용 범위를 사용자에게 확인한다. 목적·범위·회사 필수화가 바뀌는 검토는 최소 4지선다와 추천안을 포함한다. 이미 승인된 요청 범위의 초안 정리·검증은 다시 승인받지 않는다.

## 종료 재감사 이후의 인계 조건

Phase 00 전체 종료는 아직 미완료다. [종료 재감사](../08_검증결과/Phase00_종료재감사.md)의 시간·자산 분류·지식/검수·스킬 보완을 먼저 마친다. [자료 준비 안내](01-A_자료준비안내.md)에 따라 실제 자료 준비는 병행할 수 있다. 소량 시범 사용은 사용자A로 확정됐으므로 같은 목적·권한을 다시 묻지 않는다.
