# R4-4 2단계 — 통합 계약 검수 결과

2026-10-15. **v0.2 통합 기록 규격·적용 예/반례·합성 검수 범위 완료.** 기본 검사 도구 전환과 구형 접수/이관은 다음 단계다.

4단위 대상은 근거 계약 targets에 한 번만 저장하고, 시간과 근거는 공간 계약 안에서 공유한다. units는 대상 ID/버전을 참조하고 R2의 5판정·허용축·관측/계획/추론 출처를 연결한다. 좌표 표본은 실제 geometry·성분·단위·값·변환 경로를 따라간다. 시간·근거·좌표/분류·한맥/실행 정보가 바뀌면 통합 검수 context가 stale로 남는다.

독립 초기 42건 중 6건 실패·예외1에서 아래 5유형을 보완했다.

| 레드팀 발견 | 수정과 양성 유지 |
|---|---|
| RFC3339 소문자 t/z 날짜의 실행 예외 | 표기 정규화/안전 파싱. 유효한 날짜 표기는 계속 허용 |
| 컷 순간과 주장 시점이 달라도 통과 | 동일 시간축·순간 포함 검사. 범위를 덮는 clip은 허용 |
| 정지 외관을 컷의 시간 변화로 사용 | 관측 컷은 시간 변화 주장 필요. 계획은 별도 유지 |
| 순간이 낀 상태/동작 시간 교차 누락 | instant/range 모든 조합과 시작 포함/끝 제외 검사 |
| 원본 오차가 있는데 파생 표본은 linked | 원본 오차·모델 위치·경로 메타 미상을 표본 연결에도 unresolved로 전달 |

최종 내장 **61/61**, 독립 **42/42**, 실행 예외 **0**. 입력과 검토 원문 hash가 불변이고 내장 재실행/저장 결과가 일치했다. 초기 실패 코드·입력·결과도 별도 백업했다. 이 시험 집합의 결과이며 모든 영상/입력의 정확성 증명이 아니다.

시간·근거·공간 정본과 검사기는 변경하지 않았다. 통합 공간 프로필은 좌표가 없는 기록에 spaces=[]를 허용하는 확장만 명시했다. 원본 identity 미상까지 허용하거나 가짜 프레임을 만드는 확장이 아니다. 공간 supported 보류, 실제 사람 내용·권한 검수, 사실/회사/운영 false flag는 유지한다.
