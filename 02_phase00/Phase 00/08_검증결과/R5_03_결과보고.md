# R5-3 영상 적용 지식과 미정 항목 결과

2026-10-15. **조건별 설명용 지식·사람 검수 인계 범위 완료. 실제 시안/영상 검수와 회사 규정 승인은 아님.**

24개 적용 예/반례는 한맥 웹색과 CI, 로고 비례/여백/최소크기/배경형·언어·공동회사, 한국어/글자 단위/자막/정보밀도·화면비/레이아웃·도표·모션/알파, R4 관측/기획 분리를 다룬다. 9개 영상 전용 미정 항목은 null을 유지했다. 실제로 사용하는 조건만 담당자 검수가 필요하고 미사용은 후속 검수기록에서 비적용·이유로 구분한다.

레드팀 지적3종을 보완했다: 근거 경로만 있던 사례에 로컬판본/해시·외부 조사기록판본/해시/깊이를 고정했고, 항목별 보류/비적용 범위를 명확히 했으며, Markdown에 적용조건 열을 추가했다. 조사기록 재실행 시 출처ID가 중복되지 않게 보완했다. 상세 판정의 대조 범위와 보존 증거를 따른다. 정적 사례 대조를 실제 디자인 효과 시험으로 집계하지 않는다.

기존 R3 지식을 재사용했다. 외부 기준은 관련 본문/선택절 참고이며 전체 표준 준수/회사 의무화가 아니다. design-tokens의 웹 수치·자동 명암색 생성은 채택하지 않았고 px/pt 혼용을 공식문서 기준으로 구분했다. 필요한 실제 폰트·배포/권한 검수는 미확인이다.
