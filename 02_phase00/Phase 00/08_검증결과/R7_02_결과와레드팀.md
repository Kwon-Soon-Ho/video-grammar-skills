# R7-2 결과 — 항목별 품질 기준·예·반례

2026-10-15. **R7-2는 조건부 검수 지식 정리와 독립 정적 검토 범위로 완료했다.** 실제 영상의 통과 판정·사람 내용검수·분석 성능/시청효과 검증은 수행하지 않았다. R7-3/4와 R8이 남아 있으며 Phase 00 전체는 미완료다. 01-A는 시작하지 않았다.

26항목마다 **검수 질문·적용 조건·필요 근거·검토 방법·적용 예·오용 반례·허용 예외·판단보류 조건·사람 역할·영향·원문/기존 지식 연결**을 붙였다. 적용 예와 반례는 직접 작성한 가정이며 실제 회사 영상 사례가 아니다. 26개 영상 시험이나 자동 판단기의 성적이 아니다.

예를 들어 원본 그래프의 오류를 정확히 전사한 기록은 분석 정확성과 원본 정보의 정확성을 따로 본다. 30.2 °C와 방향30°의 표기 문맥을 구분하고 단위 환산·원문 정정은 별도 검수한다. 정보가 한 프레임에서 보인 사실과 읽을 시간이 충분했다는 판단도 분리했다. 카드형 화면·대칭 구도·선형 모션·정지 상태는 사용 자체를 오류로 만들지 않았다.

## 조사한 원문과 깊이

외부 제작자/저자/출판사의 **15개 공개 문서에서 지정 절**을 대조했고, 기존 프로젝트 자료9개를 연결했다. 이는15개 실험이나 신규 독립 연구의 개수가 아니다.

- W3C WAI의 자막·영상/음성 제작·시각 설명: 발화와 의미 있는 소리, 자동자막의 한계, 무음/시각 정보 대체, 명료성과 실제 표시 조건.
- W3C 대비·색·비텍스트 그래픽·섬광 해설: 적용 대상과 예외, 실제 배경/재생 조건. 웹 수치를 회사 영상의 고정 px·초수로 옮기지 않음.
- 한국어 조판 요구사항: 2026-03-21 Group Note Draft의 줄바꿈·첨자 관련 부분. 권고안/완결 표준이라고 부르지 않음.
- BIPM SI Brochure 9판 v4.01: 값/단위와 표 머리글 관련 부분,5.4.3–4의 공백·평면각·°C·소수 서식. 다른 장·전체 GUM 검토는 아님.
- NN/G 저자 해설, IBM Carbon v10 보존 문서, GOV.UK 표 지침: 위계·그룹·축/결측·모션 의미/연속성·행/열 대응. 웹UI 제한이나 구현 숫자를 영상 의무로 삼지 않음.
- Cambridge의 일시 정보 원칙: 출판사 공개 요약만 확인. 장 전문·인용 원실험의 전수 검토 또는 회사 영상 효과 입증은 아님.

각 문서의 URL·판본/절·열람 깊이·전이 한계는 [조사 기록](../05_출처와검토/R7_02_품질항목_조사기록.json)에 있다. 열람 실패한 현재 Carbon 주소와 과거 BBC 주소는 확인한 대체/보존 자료와 구분해 기록했다. 전체 WCAG 적합성·모든 플랫폼/방송 납품규격·법적 의무 검토·전수 문헌조사는 범위 밖이다.

## 사람이 맡아야 할 판단

업무 사실·원문 충돌·기술 수치/관계는 내용 담당자, CI 사용형/실제 시안은 디자이너 및 필요한 브랜드 담당자, 실제 읽기·청취·시청 조건은 검수자와 필요한 대상 시청자에게 맡긴다. 현재 실제 대상/영상/시나리오 미접수이므로 **이번 R7-2의 실제 사람 내용검수0건**이다. 기존 R6의 CI 최신성 회신을 새 검수 답변으로 재계산하지 않는다.

[사람 검수 준비 목록](../13_품질검수/05_사람검수_준비목록.md)은7묶음 템플릿이며 실제 접수/발송/사람 답변 목록이 아니다. 자료를 받으면 적용 항목을 대상 ID/버전·근거·위치·충돌·질문과 묶어 접수한다. 확인 범위만 보존하고 검수 필요 항목을 자동 통과시키지 않는다. 이미 답변받은8회사 자료 최신성·산하 AI원본 부재는 재질문하지 않는다.

기존 A안·R3~R6의 범위 안에서 기준을 보완했으므로 새 운영 선택이나 임의 회사 수치를 확정하지 않았다. 현재 추가 선택 질문은 없다. 앞으로 운영 판단이 필요해지면 구체 비교안에4지선다·추천안을 붙인다.
