2026-10-15. **자료 감사 → 회사별 초안 연결 → 영상 적용 예·반례 → 조회·표시·인계의 설계/정본·합성 검수 범위를 완료했다.** 실제 CI 최신성/공식성·회사 영상/개별 시안 검수·회사/운영 승인은 미확인이다. 전체 Phase 00은 R6~R8이 남아 있으며 01-A는 시작하지 않았다.

## 쉽게 보는 결과

‘이 회사의 CI는 어디에 있고 어떤 색을 어떤 근거로 참고할 수 있는가’를 먼저 찾고, 디자이너가 고른 배경·글자·강조 역할을 별도 프로젝트 초안으로 기록하도록 연결했다. 웹 한맥색·가족사 CI관측색·새 프로젝트 응용색을 구분한다. 로고/색/스타일은 자동 선택하지 않고 사람 검수가 필요한 내용을 남긴다.

사용자 A는 **명시 선택한 프로젝트 초안의 관측색 역할 후보 사용**이다. 회사 공식색/최신CI·실제 선택자 인증/디자인 승인을 대신하지 않는다. 한맥 정본과 8회사 자산·색 원문/ID·버전/hash, 기존 R4 계약과 3스킬 원문은 보존했다. R5는 별도 참조/적용 계약이며 기존 관측을 보정하지 않는다.

## 무엇을 조사했고 어디까지 확인했는가

기존 한맥 웹 정제 정본·회사/자산/CI색·문서명시 기록·R3 레이아웃/모션 지식·R4 연결을 대조했다. W3C 글자 대비/색 이외 정보 구분/비텍스트 대비의 관련 본문, DTCG 형식/색 모듈의 선택절을 참고했다. design-tokens SKILL.md는 정적으로 검토해 역할/값 구분만 선별했고 큰 글자 px/pt 오류는 공식 설명으로 바로잡았다. 자동 명암팔레트·웹 타입/간격·다크모드·hover를 영상 규격으로 채택하지 않았다.

한맥 라이브2페이지는 현재 웹 읽기에 실패해 10/14 전사 정본을 재사용했다. 최신 웹/모든 CI가이드·스킬·표준 전수 조사, 라이선스/폰트/배포 권한 승인, 실제 영상 검수는 하지 않았다. 자세한 깊이는 [조사기록](../05_출처와검토/R5_조사기록.json)을 따른다.

## 미정·후속 경계

로고 보호공간/최소크기·허용형, 영상 글자/자막/세이프존·모션 수치·차트 팔레트·실제 폰트 사용조건은 자료/프로젝트 확인 전 null로 유지한다. 값이 없는 항목을 자동으로 회사 규칙에 채우지 않는다. 해당 조건을 적용하는 프로젝트에서 담당자 검수가 필요하면 대기 상태로 인계한다.

R4 링크는 identity/hash·합성/실제 범위 확인이며 R4 전체 구조/관측 사실검사를 대체하지 않는다. 현재 R5 기록은 합성 설명용1개이며 실제 영상/실제 디자이너 검수 기록은0개다. 현재 규격은 회사/운영 승인false와 검수pending만 지원한다.

R6는 출처/권한·내용/선택자/검수 결정을, R7은 실제 품질 기준과 평가 계획을, R8은 Anthropic Skill Creator를 통한 기존3스킬 재구성·새R4/R5 호환·쓰기/기권 평가를 맡는다. [후속 인계](../09_다음단계인계/R5_디자인연결_인계.md)를 따른다. Computer Use·AE·전역 스킬 설정은 변경하지 않았다.
