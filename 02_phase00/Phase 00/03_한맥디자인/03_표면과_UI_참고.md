## 형태·깊이

Vercel 반경 단계는 none 0, xs 2, sm 4, md 6, lg 8, xl 12, 2xl 16, full 9999px다. Storybook의 control/button/input/select/container는 역할별 4px다. 같은 역할의 차이는 출처별로 유지한다. full=9999px는 캡슐/원형 의도를 구현하는 CSS 값이며 영상 도형의 실제 반경으로 복사하지 않는다.

| 그림자 | Vercel CSS |
| --- | --- |
| z0 | none |
| z1 | 0 1px 2px #0000001C |
| z2 | 0 2px 4px #0000001C |
| z3 | 0 3px 6px #0000001C |
| z4 | 0 4px 8px #0000001C |

그림자·그라데이션은 의미 구분과 분리가 필요할 때 선택한다. 매 장면의 입체감·금속 보더·그라데이션을 강제하지 않는다. UI hover나 z단계가 영상 속도·3D 깊이·카메라 위치를 뜻하지 않는다.

## 컴포넌트의 활용과 제외

| 항목 | 필요할 때 참고 | 영상 공통에서 제외 |
| --- | --- | --- |
| 버튼·탭 | 실제 SW 조작 데모, 클릭 대상·선택 상태 설명 | 화면당 1~2개 CTA, 31/34px 높이, hover/active 색과 120ms 전환의 강제 |
| 입력·체크박스·라디오·검색 | 제품 입력·선택·오류 상태를 설명하는 장면 | 44px 높이, focus border, 150ms 전환을 영상 등장 규칙으로 사용 |
| 카드 | 독립된 병렬 항목을 묶는 후보 | 모든 설명을 카드로 구성, 12px radius/24px padding 의무 |
| 테이블 | 동일 기준의 행·열 비교가 필요할 때 재구성 | 13px 본문/11px 헤더, dense row·hover·uppercase 규칙의 강제 |
| 웹 내비게이션·오버레이 | 해당 제품 화면이 실제 주제일 때 원본 확인 | GNB/LNB·모달·메뉴 구조를 설명 영상에 자동 삽입 |
| CENTER 제목 | 사업명·노선구분·사업노선 4종 조합의 정보 위계 | 7680×2160, 범위 한정 palette, TBD를 회사 전체 표준으로 승격 |
| 조직도·시설·공간 그래픽 | 주제와 관계가 맞을 때 해당 Story/원본을 추가 확인 | 부서색·시설별 색·좌표를 브랜드 글로벌 토큰으로 자동 편입 |

UI 페이지 설명과 CSS가 다를 수 있다. 예를 들어 카드 설명의 흰 배경·Brown hover와 CSS alpha white·accent Orange가 다르다. 실제 제품 재현은 캡처/현재 구현을 먼저 확인한다. 이 카탈로그는 제품 화면의 정확한 최신 재현을 보증하지 않는다.

Storybook의 전체 컴포넌트 변형은 전수 조사하지 않았다. Foundation 3페이지, Title 예시, 조직도 전용 페이지의 존재·범위를 확인했으며, Vercel의 표시 메뉴는 모두 읽고 분류했다. 조직도·시설·공간의 세부 팔레트는 이번 글로벌 컬러 정본에서 제외했다.
