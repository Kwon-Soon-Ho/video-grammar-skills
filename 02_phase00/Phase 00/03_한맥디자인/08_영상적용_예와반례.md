## 확정하지 않은 수치

[영상전용 미정 항목](영상전용_미정항목.json)의 값은 null이다. 공식 자료나 실제 프로젝트 조건이 없는데 스킬의 웹 타입/간격/hover 값을 대입하지 않는다. 기획 시안에서는 임시 수치 후보를 목적·조건과 함께 제시할 수 있지만 회사 공통규격으로 부르지 않는다. 필요한 사람 검수/자료 확보는 대기 목록으로 남긴다.

각 사례의 사람 검수는 적용 조건에 해당할 때 필요하다. 쓰지 않는 로고·자막·모션까지 프로젝트 전체를 자동 차단하지 않는다. 미사용은 후속 검수기록에서 비적용과 이유를 명시하고, 미상·미검토·통과와 구분한다.

## 외부 기준을 가져오는 범위

불투명 sRGB 단색 대비는 보조 계산이다. [W3C 대비 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)의 글자 크기 단위·최종 표시 조건을 확인하고, 영상 픽셀을 웹 CSS px/pt와 같다고 보지 않는다. 로고 예외는 본문 글자·UI·차트 전체의 면제가 아니다. 정보 구분에는 [색 이외 단서](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)를 함께 검토한다. [비텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)는 필요한 형태/배경 경계의 참고이며 영상 전체 접근성 인증이 아니다.

[정본 JSON](영상적용_예와반례.json)에 근거 경로와 사례 상태를 보존했다. 이 문서에서 ‘예’는 내용 설명용 사례이고 실제 산출물이 아님을 유지한다.
