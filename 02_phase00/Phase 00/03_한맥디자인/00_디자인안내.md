# 한맥 영상 시스템용 디자인 기반 v0.1

기준일: 2026-10-14. Phase 00의 회사 디자인 자료 정제 결과다. 기본 컬러를 바로 조회할 수 있는 JSON과 카테고리별 문서를 만들었다. 실제 영상 분석·회사 영상 문법 승인·전체 운영 DB 구축은 후속 범위다.

## 이번에 정한 기준

**브랜드 기본색과 명암 스케일은 Storybook, 강조색과 중립색은 Vercel 자료를 사용한다.** 사용자 지시로 출처 우선순위를 확정했다. UI 시스템은 선택 참고다. UI를 쓰지 않았다는 이유로 영상의 기획이나 검수를 실패 처리하지 않는다.

전역 컬러는 공통 라이브러리로 사용할 수 있다는 뜻이다. 모든 영상에 세 가지 브랜드색을 동시에 넣거나, 모든 화면을 Green/Brown 배경으로 만들라는 뜻은 아니다. 사진·3D 모델·고객 로고·실제 제품 캡처의 색을 브랜드색으로 자동 변경하지 않는다.

| 분류 | 영상 시스템에서의 처리 | 상태 |
|---|---|---|
| 브랜드 3색·명암 스케일 24색 | 전역 컬러 라이브러리에 등록. Storybook 값 사용 | 출처 선택 확인 |
| 강조 2색·중립 4색 | 전역 컬러 라이브러리에 등록. Vercel 값 사용 | 출처 선택 확인 |
| 흑백 알파 16개 | 합성·배경판 등이 필요할 때 선택 로딩 | Vercel 관측 참고 |
| 타이포그래피·간격 | 서체·위계·간격의 참고. 영상 크기·행간은 별도 설계 | 참고 |
| 그림자·반경·그라데이션 | 선택한 장면의 표면 표현 후보 | 참고 |

| CENTER 타이틀·조직도 등 | 범위 한정 정보 구성 사례. 전역 팔레트·규격으로 편입하지 않음 | 참고 |
| 로고 사용 규격·영상 자막·세이프존·이징·시간 수치 | 이번 자료에서 영상 공통값 미확인 | 미정 |

## 바로 쓰는 컬러 역할

| 역할 | 값 | 사용 방식 |
|---|---|---|
| HM Green 기본 | `#123328` | 브랜드 Green의 기준값 |
| HM Brown 기본 | `#3E3523` | 브랜드 Brown의 기준값 |
| HM Orange 기본 | `#CC5200` | 브랜드 Orange의 기준값 |
| 강조 액션 Orange | `#FF5C00` | 기본 Orange와 역할을 구분해 사용 |
| Green 배경 강조 Yellow | `#FFC600` | Green 배경의 강조 후보 |
| Green 테마 주 / 보조 텍스트 | `#F0F7F5` / `#B6D0C9` | 해당 어두운 배경과 함께 검토 |
| Brown 테마 주 / 보조 텍스트 | `#F6F4F2` / `#D4CBBD` | 해당 어두운 배경과 함께 검토 |

Green·Brown 기본 배경과 대응 중립 텍스트의 단색 대비는 충분히 높다. 다만 밝은 중립 텍스트 `#F6F4F2`를 강조 Orange `#FF5C00` 위에 놓으면 약 2.82:1이다. 컬러가 브랜드에 속한다는 이유만으로 글씨 대비까지 확보되는 것은 아니다. 최종 프레임에서는 배경·텍스트 조합을 따로 확인한다. 계산표와 전제는 컬러 문서에 있다.

원문에 있는 TOP/BOTTOM Zone, Neutral 경유, 금속 그라데이션, UI hover는 각각 맥락을 가진 표현이다. 이를 영상 상하 분할·모든 컷 사이 중립색 삽입·금속 표면 의무·영상 등장 시간으로 일반화하지 않는다.

## DB에 넣을 때 지킬 구조

[한맥디자인정본.json](한맥디자인정본.json)이 정본이다. 색상은 안정적인 token ID와 출처별 관측값을 저장하며, 장면은 `hanmac-video@0.1.0`과 token ID를 참조한다. 원래 영상에서 보인 픽셀값은 관측 기록에 그대로 남긴다. 공식 색과 다르다는 이유로 과거 분석값을 수정하지 않는다.

필수는 출처 선택·범위 구분 같은 운영 정책이다. 컬러는 `available`, 권고는 `recommended`, UI·표면은 `reference_only`로 나눈다. 회사 필수 규칙을 조회할 때 참고 항목을 의무로 반환하지 않는다. 실제 회사 문법의 승인 기록과 이번 자료의 출처 선택 기록을 구분한다.

Markdown·CSS·대비표는 [문서생성.cjs](문서생성.cjs)로 JSON에서 생성한다. 정확한 값을 바꿀 때는 정본을 수정하고 재생성한다. [공통컬러.css](공통컬러.css)는 30색과 기본색 별칭만 담아 UI 레이아웃·크기를 전역으로 주입하지 않는다. CSS는 웹 기반 제작 도구용 어댑터이며 AE·기타 도구는 같은 token ID와 값을 각 도구에 맞춰 변환한다.

## 확인한 범위와 다음 연결

Vercel의 표시 메뉴 전체, Storybook Foundation의 Color·Typography·Layout, CENTER Title의 범위와 조직도 전용 사례의 존재를 확인했다. Storybook 전체 컴포넌트 변형·시설·공간 팔레트를 전수 수집한 결과는 아니다. 사용자 목적에 필요한 공통 컬러와 디자인 참고를 먼저 정제했다.

정본 검증에서 토큰 ID·출처·선택값·역할 연결·UI 필수 제외를 확인했고, 단색 조합 대비도 계산했다. 실제 영상 렌더·사례 적합성은 아직 확인하지 않았다. 로고·영상 글자 크기·자막·세이프존·모션 수치는 자료와 실영상에서 확보할 때 추가한다. 이 미정 항목은 컬러 라이브러리 사용을 막지 않는다.

Phase 00에는 이 정제 자료를 디자인 지식 입력으로 연결한다. 01-A는 원본 화면을 관측하고 토큰 대응 여부를 별도 기록한다. 01-B는 실제 반복 사례·반례를 근거로 영상 전용 규칙을 검토한다. 02는 내용·정보 관계에 맞춰 컬러 역할과 선택 참고를 사용한다.

자료: [한맥 Storybook](https://design.hmac.kr/?path=/story/foundation-color--all), [한맥 디자인 정리 앱](https://hanmac-designsystem.vercel.app/claude_app/index.html). 라이브 자료의 조회일은 2026-10-14이며 원본 전체 배포 스냅샷은 확보하지 않았다.
