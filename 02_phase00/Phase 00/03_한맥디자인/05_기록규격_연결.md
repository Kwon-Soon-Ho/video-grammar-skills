# 한맥 프로필과 최소 기록 연결

기록의 design.profile_ref는 hanmac-video@0.1.0, palette_role_bindings는 기존 token ID다. 한맥정본의 available 30색·optional 16알파·reference_only UI/표면을 구분한다. 기본 조회는 30색만 반환하며 UI·표면은 명시 조회한다.

최소 기록의 unknown·관측·추론을 브랜드 값으로 덮어쓰지 않는다. 프로필에 대응하지 않는 실제 픽셀값은 관측 필드에 남긴다. source_selection_confirmed는 회사 문법 approved가 아니다.

자료검증.py는 ID·참조·프로필 버전·공통색 역할의 형식과 연결을 검사한다. 실제 프레임 대비·브랜드 적합성은 별도 검토다. 기존 컬러 30색의 값·ID는 이번 단계에서 변경하지 않았다.
