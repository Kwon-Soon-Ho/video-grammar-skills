# R5 — 회사 디자인 연결 단계 안내

2026-10-15. **R5-1 자료 감사·보충 안내 범위 완료. R5-2~4와 R5 전체는 미완료다.** R1은 원본·사본·출처·버전을 관리했고 R5는 ‘선택한 회사의 자료를 화면의 어디에 어떤 자격으로 쓸지’를 정한다. 새 영상 제작·영상 자동 분석은 수행하지 않는다.

## 쉽게 보는 연결

작업 목적/대상 회사 선택 → 회사ID로 CI 원본·변형·색 근거 조회 → 한맥 공통 참고 라이브러리의 사용 여부 명시 → 로고와 배경/글자/강조 역할 각각 선택 → 출력 화면/언어/배경 조건 검토 → 검수 대기 또는 프로젝트 초안.

한맥 웹의 Green/Brown/Orange와 한맥기술 CI의 관측 빨강/파랑은 서로 다른 자료다. 명칭이 같아도 같은 공식 팔레트로 합치지 않는다. 사진·3D·실제 UI 캡처·고객 로고를 브랜드색으로 자동 변경하지 않는다.

| 단계 | 조사·정리할 것 | 산출물과 검토 경계 |
|---|---|---|
| R5-1 자료·출처·기존 연결 감사 | 8회사/자산/색, 관측과 선언, 정본/파생 해시, 생성기, R4 연결 | 현황표·결함/누락·레드팀 보고. 공식성/최신성 승인 아님 |
| R5-2 회사별 적용 연결 | 회사/CI/변형/색 버전 참조, 화면 역할 후보, 공통 라이브러리 선택, 혼합회사·예외 처리 | 별도 적용 계약 초안·회사별 연결표. 관측색 역할 사용은 사용자 선택 후 반영 |
| R5-3 영상 적용 조건·예/반례 | 로고 원형/여백/최소크기/밝고 어두운 배경/자막/한국어/화면비/그라데이션/모션 | 정해진 것·미정·프로젝트 결정 항목 분리, 적용 예·반례·사람 검수 인계. 웹 숫자를 영상 표준으로 전환하지 않음 |
| R5-4 검사·조회·인계 | 계약 반례, 조회 조건, 재생성/변경 시험, R4/스킬 연결 경계 | 읽기 전용 검사·조회/안내, 단계별 원문·backup, R6~R8 인계. 실영상 효과/회사 필수화/운영 승인은 별도 |

각 단계는 먼저 작성 → 독립 레드팀 → 수정 → 재검토 → 결과 보고 순서다. 이전 단계를 건너뛰어 일괄 완료하지 않는다. 사용자가 결정해야 할 선택은 4지선다와 추천안으로 확인한다. 원본·R1 자산/색 정본·기존 스킬·R4 규격을 임의로 변경하지 않는다. 문서를 보완하면 변경 전 파일을 backup에 남긴다.

## 현재 이미 준비된 것

- 한맥 공통색 30개, 선택 알파 16개, 표면 참고 18개, 기타 참고 10개, 규칙 12개. 출처 선택은 기존 사용자 결정 유지.
- 8회사 자산 135개·색 기록 95개. 공유 AI 파일 때문에 회사별 자산 개수의 합은 전체 파일 수와 다르다.
- 관측색은 17개 래스터 + 74개 벡터 원문. 삼안 문서의 선언 후보 4개는 draft이며 화면용 sRGB도 미정이다.
- 기존 R4 v0.2는 한맥 프로필 pin·토큰 존재/범위를 검사한다. 회사 CI 선택·영상 적용 품질까지 보장하지 않는다.
