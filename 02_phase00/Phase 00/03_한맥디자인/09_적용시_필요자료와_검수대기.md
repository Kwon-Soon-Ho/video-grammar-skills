# R5 적용 때 필요한 확인 자료

자료가 없어도 출처별 지식/참조 계약을 정리할 수 있다. 다만 해당 프로젝트에서 미확인 내용을 공식/검수완료로 표시하지 않는다.

1. **회사별 CI 최신판과 사용 가이드**: 담당자가 확인한 원본/버전, 공식 지정색의 색공간/프로필, 국영문·단색/반전·가로세로형, 보호공간·최소크기·배포 맥락. 현재 제공 원본과 같은 자료인지도 확인.
2. **프로젝트 출력 조건**: 목적·대상 회사/공동주체, 영상/웹/발표매체, 해상도·화면비·최종 표시/시청 환경·자막/내레이션·언어. 모르는 값은 미정.
3. **실제 시안 검수 자료**: 긴 기술명·한글/영문·숫자/단위·차트/로고를 포함한 시안과 움직임, 배경이 변할 때 읽힘, 해당 프로젝트에서 사용한 폰트와 사용 범위.

공식 CI가이드 전체 수집·새 회사 모션 표준 확정은 현재 확보 자료로 대체할 수 없다. 값이 없는 항목은 [미정목록](영상전용_미정항목.json)에 남겼다. R6는 출처·권한·검수 결정을, R7은 실제 품질 판정/평가 계획을, 01-B는 반복 사내 영상의 문법 검증을 맡는다. 01-A의 영상 분석 구현은 시작하지 않는다.
