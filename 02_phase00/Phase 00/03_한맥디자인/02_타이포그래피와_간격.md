# 한맥 영상용 타이포그래피·간격 참고

JSON 정본에서 생성. 이 문서의 디지털 제품 수치를 영상 필수 규격으로 사용하지 않는다.

## 서체와 위계

양쪽에서 Noto Sans KR을 확인했다. 기본 후보로 참고하고, Storybook fallback인 맑은 고딕·시스템 sans-serif를 기록한다. 영상 폰트 설치·라이선스·제작 도구 지원은 이번 정리에 포함되지 않았다. 대체 폰트 사용 시 한글·숫자·단위·긴 기술명의 폭과 줄바꿈을 확인한다.

Vercel의 타입 역할:

| 역할 | 웹 크기 px | 굵기 | 행간 배수 |
| --- | --- | --- | --- |
| display | 42 | 700 | 1.15 |
| heading_1 | 30 | 700 | 1.25 |
| heading_2 | 24 | 600 | 1.3 |
| heading_3 | 20 | 600 | 1.35 |
| body_large | 18 | 400 | 1.6 |
| body | 16 | 400 | 1.6 |
| caption | 14 | 400 | 1.5 |
| button | 16 | 600 | 1 |
| label | 14 | 600 | 1.4 |

Storybook은 위와 같은 새 공통 타입 체계를 확정하지 않고 현재 컴포넌트 구현을 제시한다:

| 컴포넌트 | px 크기 | px 행높이 | 굵기 |
| --- | --- | --- | --- |
| page_header | 28 | 36 | 700 |
| card_title | 20 | 28 | 600 |
| description | 14 | 20 | 400 |
| label | 14 | 20 | 500 |
| input_sm | 12 | 18 | 400 |
| input_md | 14 | 20 | 400 |
| input_lg | 16 | 24 | 400 |
| button_sm | 12 | 18 | 500 |
| button_md | 13 | 20 | 500 |
| button_lg | 15 | 22 | 500 |

페이지 설명 400은 현재 계산된 굵기이며 컴포넌트 자체가 별도 weight를 지정했다는 뜻이 아니다. 역할 이름이 비슷해도 Vercel heading 30px와 Storybook page header 28px를 하나의 정답으로 합치지 않는다.

## 간격·레이아웃

Vercel 단계:

| 이름 | 웹 px |
| --- | --- |
| xxs | 4 |
| xs | 8 |
| sm | 12 |
| md | 16 |
| lg | 24 |
| xl | 32 |
| xxl | 48 |
| xxxl | 64 |
| xxxxl | 80 |

Storybook은 전역 spacing scale/grid가 정의되어 있지 않다고 표시한다. Dashboard 외곽 34px/모바일 20px, 섹션 간 24px, 카드 내부 24px, Page Header 아래 20px, GNB 연결 12px, LNB 연결 18px는 개별 구현 참고다. 같은 수치를 공통 토큰 하나로 합치지 않는다.

Desktop ≥1024px / Mobile ≤1023px는 웹 탐색 구조 경계다. 1280×900·390×844는 QA viewport이며 영상 해상도·세이프존이 아니다.

## 영상에서 결정할 것

1. 핵심 제목·주 설명·보조 주석을 정보 역할로 나눈다.
2. 화면 비율·최종 표시 크기·요소 수·문구 길이에 맞춰 글자 크기와 여백을 설계한다.
3. 긴 한국어 사업명, 괄호, 숫자와 단위가 잘리거나 의미가 갈라지지 않는지 본다.
4. 정보가 완성된 후 읽을 시간을 확보하고 내레이션·이동·줌과 겹쳐 읽기 어려운 구간을 확인한다.
5. 영상 크기·행간·자막 규격·세이프존·타이밍은 현재 미정으로 둔다. 웹 px를 임의 배율로 확대해 회사 표준으로 등록하지 않는다.
