# R5 현재 자료를 읽는 보충 안내

2026-10-15. 기존 정본 값·프로필 ID/버전과 R4 기록 pin은 보존했다. 아래는 기존 자료의 오해를 막는 보충 안내이며 CI/디자인의 신규 회사 승인이나 원문 수정이 아니다.

| 기존 위치/표현 | 현재 해석 | 후속 보완 |
|---|---|---|
| 한맥디자인정본.json → db_contract.authority의 build_views.cjs | D 현재 재생성기는 같은 폴더의 문서생성.cjs다. 옛 작업명으로 실행하지 않음 | 기존 프로필 해시를 유지하며 본 보충 안내를 현재 실행 안내로 사용. 다음 규격 갱신 때 이력과 함께 정정 |
| 같은 정본 db_contract.scene_contract | 초기 설명용 예시이며 R4 v0.2 입력 JSON이 아님 | 새 기록은 04_기록규격/06_통합최소기록_규격_v0.2.md와 해당 설명용 JSON을 따른다 |
| 한맥디자인정본.not_defined.logo_asset=null | 초기 웹 정제에서 로고를 내장하지 않았다는 뜻. 회사 CI가 전혀 없다는 뜻 아님 | 실제 CI는 10_공용자산 정본에서 회사ID·자산ID/버전/hash로 참조. 같은 로고 파일을 다시 복제하지 않음 |
| 모든 자료를 JSON에서 생성 | 현행 정본의 현재 내용 재현은 확인했지만 일부 설명은 생성기 안에 상수로 존재 | 미래 값 변경까지 모든 설명이 동기화됨을 뜻하지 않음. R5-4 변경 시험/검사로 보완 |
| 전역 한맥 컬러 라이브러리 | 선택 가능 공통 참고색. 모든 가족사 CI색이나 모든 화면의 기본색이 아님 | 대상 회사의 CI·관측색·화면 역할을 별도 기록 |
| R1 collection_complete=true | 제공 원본+현재 관측 화면색의 수집 계약 충족 | 공식 최신 CI·지정색·배포/디자인 승인 완료와 다름. official_values_complete=false 유지 |

웹의 서체 위계·간격·버튼 hover·그라데이션·UI 조합은 참고다. 영상 글자 크기/자막/세이프존/이징·읽기 시간을 웹 숫자로 채우지 않는다. CI의 여백·최소 크기·단색/반전형이 미확인이라면 null/검수 대기로 두며 임의 변형을 공식형으로 등록하지 않는다.
