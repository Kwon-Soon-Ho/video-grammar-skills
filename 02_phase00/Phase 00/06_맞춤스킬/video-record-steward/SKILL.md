# video-record-steward

## 목적

Phase 00 정본과 최소 기록의 스키마·ID·근거·시간·한맥 연결을 검사하고 요청한 초안 수정을 관리한다. 데이터 기록·참조 오류·버전·검수 상태를 정리할 때 사용한다. 영상 추출·OCR·모션 측정·회사 문법 승인은 수행하지 않는다.

## 실행

1. 대상 정본/기록과 버전을 읽는다. 현재 검사와 과거 버전 조회를 구분한다. 버전 불일치를 발견해도 원본을 자동 덮어쓰지 않는다.
2. JSON Schema 검사와 의미 검사를 함께 실행한다. 원배열 중복 ID, 출처/분류축/근거 연결, 숫자·단위·시간 포함 관계, unknown 상태를 확인한다.
3. 한맥 profile_ref/token ID를 연결한다. available/reference_only와 required를 구분한다. 과거 픽셀 관측을 브랜드 값으로 바꾸지 않는다.
4. rendered_observation은 원본 추출 프레임/클립의 대상 연결이 필요하다. reconstruction은 원본 증거가 아니다. numerical_estimate는 방법·단위·불확실성·추출 프레임·한계를 요구한다. 근거가 없으면 가설·확인 불가로 제안한다.
5. synthetic_example는 실제 사례·회사 승인으로 승격하지 않는다. 회사 규칙 승인은 01-B의 별도 패턴 검수다. reviewer 문자열이나 검사 통과가 사람의 승인·영상 진실성을 증명하지 않는다.
6. 요청한 형식·참조 정리는 변경 전 backup 후 draft로 수정할 수 있다. 의미·승인·필수화 변화는 최소 4지선다와 추천안을 포함한 검토 제안으로 남긴다.
7. 검사 오류·수정 내용·남은 미정·한맥 참조와 검수 범위를 보고한다.

## 출력

검사 결과, 안전한 수정 초안, 변경 이력, 근거·시간·프로필 연결, 남은 검수. 회사 승인은 생성하지 않음.

## 작업 기준

이 스킬은 `Phase 00/06_맞춤스킬`에 있으며 두 폴더 위가 기반 DB 루트다. 데이터 경로·도구는 [작업 기준](references/작업기준.md)을 읽는다. 관련 정본만 점진적으로 읽고 외부 원본 스킬 전체를 통째 활성화하지 않는다.
