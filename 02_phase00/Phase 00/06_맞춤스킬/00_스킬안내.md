## R4-4 이후 스킬 호환

세 스킬의 목적·초안 권한과 본문/참조/평가 원문은 유지한다. 기본 검사 규격이 v0.2로 바뀌었으므로 구형 기록 쓰기는 접수/기권 경로를 따른다. 새 규격의 자동 쓰기·기권 재평가는 R8 잔여이며 과거 점수를 새 호환 성적으로 쓰지 않는다. [호환 인계](../09_다음단계인계/R4_통합규격_스킬호환_인계.md)를 먼저 읽는다.

# Phase 00 맞춤 스킬

사용자가 선택한 A안 목적 분리와 draft 작성 정책을 반영했다. 세 스킬은 v0.1.0 초안이며 구조 검사·비교 평가를 마쳤다. 사용자가 A안을 선택해 세 스킬의 소량 DB 정리 시범 사용을 확정했다. 로그·변경 전 backup·검증은 필수다.

| 스킬 | 들어가는 내용 |
|---|---|
| [video-knowledge-curator](video-knowledge-curator/SKILL.md) | 용어·별칭·의미 경계, 원칙·레이아웃·출처와 적용 조건, 보류·정본/조회 문서 갱신 |
| [video-record-steward](video-record-steward/SKILL.md) | 스키마·ID·시간·근거·측정 조건·한맥 token/버전, 요청한 draft 수정·backup·검수 연결 |
| [video-guidance-reviewer](video-guidance-reviewer/SKILL.md) | 정보 전달·한국어·시간 가독성·정보 관계·UI 지침 전용 조건·예외·채택/수정/보류 |

요청한 정리는 draft로 작성·검증한다. 의미 병합·회사 필수화·승인은 최소 4지선다와 추천안을 포함한 검토 제안으로 남긴다. 영상 추출·분석·새 화면 창작은 이 스킬의 범위가 아니다.

[평가 결과](../08_검증결과/스킬평가/00_평가안내.md)를 먼저 확인한다. 비교 3쌍은 양쪽 11/12 동률이며 업무 효과 증명은 아니다. 기록 초안 쓰기 시범의 독립 검사 8개는 통과했다.

생성 위치는 프로젝트 폴더이며 전역 스킬·기존 AE 스킬을 덮어쓰지 않았다. 사용 요청에서 해당 SKILL.md 절대 경로를 명시해 읽도록 한다. 코드·환경이 다른 프로젝트로 복사되면 대상 DB 루트를 확인한다. 테스트 복사본 평가 입력의 원래 경로는 실행 당시의 provenance로 보존했다.

[시범 사용 절차](01_시범사용안내.md)에 따라 로그·백업·검증을 남긴다.
