## 무엇을 만들고 있었나

사내 영상에서 **레이아웃·편집 디자인·화면 구성·그래픽 표현 언어·부품 조합·모션**을 수집해, 이후 검색하고 새로운 내용에 적용할 수 있는 근거 연결 DB와 스킬 체계를 만드는 중이다. 전체 사례를 보존하면서 독립 조회 가치가 있는 배치·전체 흐름·세부 동작·부품 묶음을 번호/판본으로 연결한다.

기록의 첫 열람은 **사례 요약 → 전체 상세 → 근거**다. 정보 관계, 전체 구도, 디자인 언어, 핵심 미상을 먼저 보여준다. 좌표나 픽셀만 나열하거나 전체 디자인을 잘게 나눈 부품 목록만으로 대체하면 목적을 놓친다. 반대로 요약 때문에 상세·중간 상태·작은 동작을 지워서도 안 된다.

첫 관측은 충분히 분석하고, 반복 사용은 기존 정의의 번호·현재 근거·차이·조건으로 연결한다. 독립 재사용 가치가 없는 미세 변화마다 번호를 만들지 않는다. 업무 이미지 묶음과 건물/기단은 독립 조회하고 내부 소품은 하위로 연결하며, 지원 명찰은 별도로 연결한다.

모션은 전체 전달 흐름과 독립 세부 동작을 구분한다. 표본으로 확인한 순서·중첩·동반·정착 이후 변화를 기록하고 실제 관측하지 않은 가감속 곡선이나 AE 설정을 확정하지 않는다. 관측·계산·추론, 원본·수정 시나리오·새 제안을 구별한다. DB 수집 완료에 새 화면 재구축이나 영상 제작을 요구하지 않는다.

## 무엇이 들어 있고 빠졌나

이는 검수용 선별 사본이며 전체 프로젝트 복구 백업은 아니다. 각 ZIP의 `package-manifest.json`에 포함 파일별 원본 위치·SHA-256·크기를, `excluded-files.json`에 해당 단계에서 제외한 파일을 남겼다. 과거 원문을 편집하지 않고 원래 바이트를 압축했다. 새 안내/도구는 generated로 구별한다.

대용량 원본 MP4, 과거 분석의 개별 고해상도 프레임 전량, 관측 배열·런타임·중복 백업 트리는 생략했다. 주요 사례의 화면 근거·최신 평가 입력·연속 표본·시나리오 PDF는 포함했다. 따라서 제공 표본의 검수는 가능하지만 임의 시각 재추출·전편 모션 재검수는 원본 영상을 별도로 연결해야 한다. 원본 영상 이름/경로/메타데이터는 기록에 남아 있다.

외부 소스는 00의 검토 파일 대장과 최초 전문가 판단/REA 조사에서 실제 기록한 파일을 선별했다. 전체 저장소를 모두 읽었다는 뜻이 아니다. 기존에 추가 복제 보류로 기록된 `anthropic-pptx` 원문은 제외하고 조사 대장·판단 근거를 남겼다. 다른 외부 원문은 해당 LICENSE/NOTICE와 함께 조사 자료로 보관했다.

## 경로와 실행

원본 안의 C:/D: 절대경로와 과거 SHA pin은 이력으로 유지했다. 압축을 풀었다고 모든 과거 검사/HTML 링크가 자동으로 새 경로를 쓰지는 않는다. 원문 pin을 고치거나 검사를 우회해 통과시키지 않는다.

`03_이동후_실행안내.md`와 `portable_check.py`는 **새 작업 폴더에** draft.13 카탈로그/색인을 재생성해 제공 사례를 조회하는 한정 도구다. 프로젝트 원문은 바꾸지 않는다. 이 통과는 ZIP 이동 후 참조 연결 확인이며 영상 해석 정확성·디자인 품질·R4 적합성·회사 승인 검증이 아니다.
