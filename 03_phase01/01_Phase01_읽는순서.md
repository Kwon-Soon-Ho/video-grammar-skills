# 01단계 — 실제 수집·분석기 개발·시험을 읽는 순서

현재 진행 범위는 Phase01-A다. 01-B 회사 문법 승인이나 02 제작 완료로 확대하지 않는다. `Phase 01-A/00_먼저읽기.md`는 초창기 준비 이력이다. 최신 상태는 공통 안내와 아래 draft.13 보고에서 읽는다.

## 먼저 구현과 입력을 보고, 나중에 기존 결과를 본다

1. 스킬 ZIP에서 실제 사용판 draft.10과 최신 후보 draft.13을 구분한다. 단계 내부 `03_분석스킬`에도 코드·계약·평가 JSON을 원래 폴더 구조로 담았다. 반복되는 스킬 evals 바이너리 입력은 01 스킬 ZIP의 해당 판본에서 읽는다. 보고 안 candidate/backup에 반복된 입력도 같은 방식으로 생략했다.
2. 독립 행동 시험은 `10_독립검수입력/00_입력안내.md` → 정지 표본/기존 시간 표본 → 별도 출력 고정 순서다. `evals`·기존 사례·benchmark·grading·review는 시험 후 대조한다.
3. 최신 결과는 `Phase 01-A/05_결과보고/2026-10-19_draft13_00지식연결`이다. `00_현재결과와_읽는순서.md` → pilot 사례 요약→상세→근거 → 실제 실행 출력/코드 → 정정/평가 한계를 본다.
4. 00 연결 검토는 00 ZIP의 `00지식_재감사`와 위 보고의 `02_00지식_반영범위.md`를 대조한다. 기존 00에서 만든 개념과 현재의 정의/사용처/근거/검토 판단을 연결했는지 확인한다.

## 보존/제외 경계

각종 원본 기록·실패·정정·평가 출력은 포함했고 과거 고해상도 개별 프레임/배열 전량은 생략했다. 최신 보고와 주요 입력의 화면 근거는 포함했다. 모든 원문 링크의 도착 파일이 들어 있다고 가정하지 말고 manifest/제외 목록을 확인한다. 대용량 원본 MP4는 없으므로 전편 재분석은 별도 원본 연결이 필요하다. 원래 경로를 변경해 과거 receipt/pin 검사를 성공시켰다고 보고하지 않는다.
