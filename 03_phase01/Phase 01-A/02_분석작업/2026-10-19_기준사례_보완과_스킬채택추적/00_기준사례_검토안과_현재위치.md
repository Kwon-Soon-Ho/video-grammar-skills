# 두 기준 사례의 검토안과 현재 위치

사용자 선택 ①에 따라 기존 두 장면의 미해결과 전후 문맥을 보완했다. 현재 스킬은 여전히 draft.8 개발 작업본이다. 이번 묶음은 실제 사례·패턴 정의·조사 반영 추적을 추가했으며 스킬 전체 생성 완료가 아니다.

## 관측 범위

- 노듈러: 166~181초, 15초. 앞뒤 문맥 164/165초와181초 이후는 별도 근거 역할로 구분한다.
- PG: 40~53초, 13초. 38/39초·53초 이후와79~82초는 문맥 표본이며 중간 전체를 분석한 것이 아니다.
- 두 원본 전체 약630.272초 중 상세 기록 창 합계28초. 기록 창 밖602.272초. 두 창도 전수 native 프레임 검수·독립 정답·회사 승인 완료는 아님.

## 기존 미해결 5개

- N-background / addressed_with_limits: 세 배경 ROI의 위치 유사·밝아짐 이후 유지 확인. 모든 픽셀/원본 레이어 독립성 판정 아님.
- N-arcs-and-sway / partial: 한 차례 화살표 강조와 구조물의 왕복 기울임을 분리. 화면 투영 경사 가감속은 확인했지만 화살표 정확 강도 곡선·원본 동기화 설정은 남음.
- N-label-completion / addressed_with_limits: 완성 문구와 외곽 폭 정착의 시각 차이를 확인. 원본 폰트명·실제 마스크 설정은 미확정.
- P-connector / addressed_with_limits: 생성 중 유색 영역의 위쪽 성장, 정착 뒤 무늬 유지, 이후 묶음 이동을 구분. 최종 퇴장은 관측 창 밖.
- P-row-emphasis / addressed_with_limits: 기존 노란 행과 새 분홍 행의 한 차례 강조를 대조. 반복 주기/동기화 전제를 채택하지 않음.

## 이번에 바로잡은 기록

- 노듈러 완성 설명의 영상 표기는 “켄틸레버 바닥판 시공시 동바리 역할 수행”. 하단 자막은 “켄틸레버 바닥판 시공 시 동바리 역할도 수행하는 다목적 부재입니다.”로 구분한다. 통상 용어로 자동 교정하지 않는다.
- 왼쪽 설명은174초 문구 전체가 읽히지만 외곽선 간격은174.8초 무렵까지 정착 중이다.
- 화살표의 등장·유지·소실, 구조물의 왕복 기울임, 176초 이후 외곽 강조, 마감 판의 가림을 별도 사건으로 남겼다.
- PG 생성 중의 선 노출 경계 성장과 정착 뒤 무늬의 위치, 후속 기관 묶음 이동을 나눴다. 기존 노란 행을 새 분홍 행의 반복 점멸과 묶지 않는다.

## 번호 연결

기존6개 정의를 보존하고 새12개를 초안으로 등록했다. 총18개 중 이번 새 정의는 다음과 같다. 새 문구·화면비 재제작 성공을 확인한 라이브러리는 아니다.

- PAT-LAYOUT-0002: 두 도해의 비교 배치
- PAT-FLOW-0002: 조립·기울임 설명과 후반 마감
- PAT-LAYOUT-0003: 지도 위 기관·정책 소속 배치
- PAT-FLOW-0003: 기관 추가·행별 강조·묶음 재배치
- PAT-TEXT-0002: 중앙 세로선 분리와 문구 리빌
- PAT-DETAIL-0002: 구조물의 화면 투영 기울기 왕복
- PAT-DETAIL-0003: 주변 화살표의 한 차례 강조와 서로 다른 유지
- PAT-DETAIL-0004: 구조 형상에 밀착한 외곽·면 강조
- PAT-CARD-0003: 로고 선등장과 뒤따르는 밝은 카드 면
- PAT-TEXT-0003: 정책 띠 전개·문구·한 차례 강조
- PAT-DETAIL-0005: 기관 카드에서 접점까지 세로 무늬 채움
- PAT-DETAIL-0006: 연결된 기관 묶음의 수평 재배치

- 노듈러 왼쪽/오른쪽 설명은 같은 PAT-TEXT-0002를 인용하되 오른쪽의 가감속을 왼쪽 측정에서 복사하지 않았다.
- PG 두 정책 행은 같은 PAT-TEXT-0003에 서로 다른 등장·강조 시각을 연결했다.
- 전체 배치/전체 흐름/독립 세부를 조합한 사례 연결14개 모두 candidate다. 승인·재사용 성공·검증된 정답으로 승격하지 않았다.

## 외부 스킬 조사와 실제 반영

기존41개 조사 포인트를 draft.8 파일 지문과 연결해 갱신했다. 원본 정적 검토 범위는 full17/selected24 항목이며 전체 저장소 감사·원본 테스트 실행이 아니다. 현재 지침·형식10/코드 일부21/미구현4/직접 이식 제외·평가 참고6이며 서로 다른 크기의 항목을 합친 완료율이 아니다. 전문가 대안/비평·상충 판정 관리·편집 가능한 재제작/렌더 비교가 남는다.
