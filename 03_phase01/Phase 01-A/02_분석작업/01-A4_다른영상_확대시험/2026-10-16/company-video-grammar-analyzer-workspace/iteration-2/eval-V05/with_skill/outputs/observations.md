# V05 관측 초안 — 0~10.9666666667초

야간 작업실의 두 모니터를 배경으로 **인터페이스 → 메뉴 단순화 → 듀얼모니터 작업공간**을 순차 설명한다. 문서 없음, 오디오 미검수. 29개 기본 표본과 독립 보강 30개를 시간순·역순 확인하고 native ROI로 작은 요소를 대조했다. 모든 프레임의 연속 재생 검사는 아니다.

| 구간 | 관측한 동작과 근거 |
|---|---|
| 0~1.2초 | 배경이 밝고 선명해지고 조금 축소되어 정착한다. 떨어진 한글 획/글자 요소가 가운데로 모이며 밝아져 ‘인터페이스’가 완성된다. 0.2/0.6/1.0/1.2초. 개별 획의 회전·이징은 미확정. |
| 1.4~2.2초 | 작은 녹색 면과 흰 점선 사각형이 우하단으로 넓어져 큰 ‘Interface’를 드러낸다. 프레임의 확장 정착은 감속 성격이다. 텍스트 자체 확대와 구별했다. 적색·녹색 십자가 프레임 우하단으로 이동한다. |
| 2.6~3.3초 | 사각형의 좌변은 오른쪽, 윗변은 아래로 움직여 우하단으로 수축한다. 2.8/2.9/3.0/3.1초 좌변 이동량이 커지는 가속 성격. 3.1초 작은 면과 십자가 남고 3.3초에는 소실한다. 밝은 영문 영역만 줄어들고, 같은 크기의 옅은 영문은 남는다. |
| 2.8~3.4초 | 제목 아래 설명문 3줄이 위로 정착하며 첫째→둘째→셋째 순서로 읽힌다. 프레임 수축과 중첩된다. 메뉴 단순화·듀얼모니터·새로운 작업공간을 굵게 강조한다. |
| 3.6~5.8초 | 가는 점선/실선 원호가 먼저 나타나고, 대형 반투명 G가 짙어진다. 초기 구성선은 줄어들고 이후 민트 윤곽선과 노란 원호·적녹 표식이 생긴다. G 자체의 이동/확대와 선의 변화를 혼동하지 않았다. 원호별 회전 방향·이징은 미확정. |
| 5.8~7.2초 | 왼쪽 CAD 카드가 작게 등장해 커지며 우하향 정착한다. 확대 후반은 감속 성격. 노란 빛이 카드 상단 중간에서 좌상단으로 옮겨 밝아진다. 별도로 적녹 십자는 G 안쪽을 따라 아래 중앙까지 이동한다. |
| 6.8~7.6초 | 좌측 노란 제목 ‘단순한 메뉴구성 / 넓은 작업공간’이 왼쪽→오른쪽으로 드러나고, 아래 설명 두 줄이 뒤따른다. |
| 7.4~8.8초 | 두 번째 카드가 첫 카드 뒤에서 오른쪽으로 이동해 나란히 선다. 현재 우측 카드 우변의 이동량은 감소한다. 가려진 좌변 때문에 전체 폭 확대는 확정하지 않았다. 내부는 검은 영역→도면(7.8~8.0)→흰 상세 패널(8.2~8.4) 순서로 드러난다. ‘듀얼모니터’ 노란 제목은 오른쪽→왼쪽, 설명은 첫 줄→둘째 줄 순서다. |
| 9.2~10.933초 | 두 카드, 한글/옅은 영문, 설명과 G가 유지된다. 배경 우 UI의 4번 선택 행은 1.2/3.2/5.6/8.8/10.933초에서 유지된다. 실제 클릭·명령 실행이나 정착 후 수치 갱신은 확인되지 않는다. |

주 설명문: “사용자 경험을 바탕으로 사용자의 편의성을 최우선적으로 고려하여 / 기존의 복잡한 인터페이스에서 벗어나 메뉴를 단순화하고, / 듀얼모니터기능을 활용한 새로운 작업공간을 제공합니다.” 원본 8.8초 ROI로 확인했다.

좌 카드 설명은 ‘꼭 필요한 기능으로만 단순화한 메뉴구성 / 메뉴의 효율적인 공간배치로 넓은 작업공간 확보’, 우 카드는 ‘듀얼모니터의 화면 분리 및 연동기능으로 / 더욱 넓어진 작업공간 제공’이다. 동일 내용을 요약하는 주제어·본문과 구체 예시의 관계다.

남은 불확실성: 한글 개별 획의 곡선, G 원호/외곽선의 정확한 진행과 회전, 카드 중심과 빛의 정량 궤적, 우 카드 가려진 좌변 및 전체 크기, 표본 사이의 잠깐 나타나는 UI 변화. 속성별 근거·좌표 오차는 JSON에 기록했다. 마지막 근거 164/15초는 분석창 내부이며 영상 밖 동작을 단정하지 않는다. 카탈로그 검사는 해시/시각/참조 연결 검사이고 시각 내용의 정답 판정은 아니다.
