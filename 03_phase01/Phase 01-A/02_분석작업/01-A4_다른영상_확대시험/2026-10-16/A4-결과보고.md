# 01-A4 다른 영상 확대시험 결과

기존 장헌·E 외의 **영상 파일 5개, 자료 묶음 4개, 과제 6개(원본별 구간 7개)**에 스킬을 적용하고 미사용 결과와 비교했습니다. 최초 적용본에서 내용 문제2종, 재시험 검수에서 이징 근거 부족1종을 찾아 **내용 문제 총3종**과 **기록 검사 허점1종**을 보완했습니다. 수정 스킬은 **0.1.0-draft.3**입니다.

영향을 받은 G·싱글·듀얼 3구간을 새 문맥에서 다시 시험했고, 발견한 두 내용 문제는 재시험 결과에서 해소됐습니다. 나머지4구간의 최초 결과와 함께 선택한7개 결과가 이번 명시 기준을 충족합니다. **전체 영상에 더 이상 누락이 없다는 판정은 아닙니다.**

## 검사한 영상과 구간

| V02 | 같은 크레인 영상 | 130–138초 | 반경 면/선, 표의 열·행·셀 강조, 정격하중 숫자 리빌 |

구간은 시작 포함·끝 제외이며 끝 프레임은 다음 문맥으로 표시했습니다. G의 마지막 실제 근거는 10.9333초입니다. 전체 영상의 희소 개요를 확인한 뒤 위 구간을 상세 검사했습니다. 전체 프레임의 연속 재생이나 음성 검수가 아닙니다.

## 발견한 문제와 보완

| 문제 | 발견한 실패 | 수정 |
|---|---|---|
| G 영문 퇴장 동작 누락 | 영문 등장·점선·십자는 찾았지만, 2.6–3.1초 사각형 수축과 옅은 글자 잔존을 ‘사라짐’으로 축약 | 대상의 등장뿐 아니라 정착→약화→마지막 잔존→소실도 역추적. 프레임·면·내용을 별도로 확인 |
| 싱글·듀얼 자막 연결 오류 | 후반 자막의 직전 상태를 앞 장면의 경관 문구로 잘못 기록. 실제는 ‘안전, 품질, 공기, 효율…4대 핵심가치…’→‘한맥가족의 BIM기반…’ | 같은 전환 경계의 직전/직후 문구를 각각 해당 시각 근거에 연결하고 중간 자막 상태 누락 점검 |
| 정착을 감속으로 판정 | 재시험의 듀얼 작업보고 문서에서 잔량15→0→0px, 즉 움직인 한 구간과 정지만 보고 감속이라고 기록 | 진행 중 두 구간 이상의 변화율 차이를 확인하도록 보완. 정지 도착만 확인되면 정착은 기록하고 가감속은 미확정 |
| 근거 검사 허점 | 구판 검사기가 다른 영상의 프레임과 잘못 붙인 시각도 통과시킴. 반례 시험에서 확인한 도구 허점이며 실제 분석자의 원본 혼입 사고는 아님 | 관측 기록과 추출 카탈로그를 연결해 원본 해시·실제 시각·PNG 해시 대조. 직접 근거 크롭도 부모 원본의 실제 픽셀과 비교 |

G 재시험에서는 사각형의 좌변이 오른쪽, 윗변이 아래로 움직이며 우하단으로 수축하는 과정과 같은 크기로 남는 옅은 영문을 분리했습니다. 2.8/2.9/3.0/3.1초 점선 좌변의 이동량 증가도 관측했습니다. 이는 렌더상 가속 성격이며 AE의 원본 보간 함수·핸들값 복원은 아닙니다.

싱글 재시험은 경관 자막→잠시 없음→4대 핵심가치→BIM 프레임워크의 상태를 구분하고, 후반 전환을(244,244.2]초로 좁혔습니다. 듀얼도 같은 문구 순서를 파일 자체의(249.2,249.4]초 근거로 연결했습니다. 사진/내부 그래픽의 별도 등장과 싱글의 사진 소실·아이콘 잔존, 듀얼 창 끝의 사진 유지를 구별했습니다. 재시험 검수에서 작업보고 문서의 감속 과장을 낮추고 경계 다음 제목색 반환도 표시했습니다.

최초 출력은 해시로 고정해 보존했습니다. 초기 두 내용 문제는 수정 스킬과 기본 원본만 제공한 새 분석 문맥에서 다시 수행했습니다. 재시험에서 추가로 발견한 이징 문제는 보정 전 기록을 별도 보존한 뒤 분석자의 재검토·보정과 원본 대조로 처리했습니다. 이 마지막 보정을 또 한 번의 독립 재시험으로 세지 않았습니다. 개정 지침에는 특정 영상의 정답·시각·수치를 넣지 않았습니다.

## 스킬 사용/미사용 비교

스킬 적용본은 크레인 제목 바깥의 얇은 선, EG-BIM 제목의 행별 교체, 반경/표 강조의 감속, 선택창의 확대 감속, 카드 내부 그래픽을 더 구체적으로 기록했습니다. 스킬 미사용본도 주요 순서, 문서와 실제 시간의 차이, UI 선택행 추가, 싱글·듀얼 배치 차이를 찾았습니다.

**스킬 적용본만 틀린 항목도 있습니다.** 싱글·듀얼의 후반 자막 전환은 미사용본이 맞았습니다. G의 영문 수축은 양쪽 최초본 모두 놓쳤습니다. 따라서 이번 결과를 스킬의 무조건적인 정확도 우위로 해석하지 않습니다. 상세한 기록도 내용 대조를 통과해야 합니다.

검수 기준은 최초 출력 열람 전에 7구간×5항목을 동결했습니다. 자막 오류는 이 목록 밖의 추가 발견이므로 양쪽 결과에 같은 추가 기준을 적용했습니다. 동결 기준 V04의 ‘사용자 지정필터’는 기준 작성자의 오기이며 실제 ‘사용자 지정폴더’ 탭을 뜻하도록 판정 설명에 남겼습니다. 단일 총점·일반 정확도·임의 합격선을 만들지 않았습니다.

## 문서 대응과 넓은 화면 처리

DOC063·DOC066·DOC071의 기존 본문 추출을 재사용하고 원본 문서 해시가 같은지 확인했습니다. 문서의 슬라이드/문단 위치를 연결했으며 원본 문서 배치나 음성은 다시 검수하지 않았습니다. 예를 들어 크레인 R9.7m·69ton 장면은 문서의85–100초 계획에 대응하지만 영상에서는130–138초에 관찰됐습니다. EG-BIM UI 선택창도 문서의307–323초 계획과 실제296–302초 구간이 다릅니다. 문서 시간을 실제 동작의 근거로 대체하지 않았습니다.

싱글은3840×2160, 듀얼은7680×2160 래스터입니다. 상단 가로 제목판이 좌측 세로판으로 바뀌고 주야 경관의 순차 표시/동시 표시도 달라 단순 가로 확대나 같은 초의 프레임 비교로 처리하지 않았습니다. 파일 전체 길이 차이도 약4.5초이며 장면별 앵커를 따로 연결했습니다. SAR·정밀 색 범위는 확인되지 않았으므로 저장 픽셀 비율을 물리 표시 비율로 확정하지 않습니다.

새5개 원본만 허용한 로컬 추출기를 사용했습니다. 큰 파일/듀얼 처리를 위해 파일 상한3GiB, 픽셀 상한7680×2160, 작업당 메모리2GiB·60초·읽기256MiB·출력40장으로 제한했고, PTS와 샘플 테이블·편집 목록을 대조했습니다. 서로 다른 프레임율/편집 오프셋을 가진 G·듀얼의8개 표본은 seek와 순차 디코딩 RGB가 일치했습니다. 범용 디코더 검증 완료라는 뜻은 아닙니다.

## 검증 범위와 남은 한계

- 최초 스킬 적용/미사용14개 원본별 실행, 수정본 영향 구간3개 실행입니다. 나머지4구간은 최초 적용 결과를 유지했습니다. 최종 검토 화면은 선택 결과 모음이며 draft3으로7구간을 전부 새로 실행한 결과가 아닙니다.
- draft3은 G의 퇴장 규칙→자막 연결 규칙→정착/감속 구별을 차례로 보완한 후보입니다. 앞 두 규칙은 해당 구간의 새 문맥 재시험, 마지막 규칙은 기존 가감속 근거의 재대조·보정으로 확인했습니다. 합쳐진 최종 지침을 새 문맥에서 전부 재실행하지는 않았습니다. 고정 판본 반복 성능 시험은 아닙니다.
- 보조 검사기의 기존12개 회귀시험, 원본/시각 연결6개, 크롭 검증5개를 확인했습니다. 총23개는 코드 동작 검사이며 영상 인식 점수가 아닙니다. 스킬 형식 검사도 통과했습니다.
- 입력 원본5개와 최초 출력의 해시 보존을 확인했습니다. A4의 성공 추출 PNG는440장, 원본별 고유 시각은397개입니다. 개요·기본·추가·추출기 진단을 모두 합한 수이며 크롭/보드와 별도이고, 전부 연속 열람했다는 뜻이 아닙니다. 모든17개 관측 기록의 구조·원본/시각 연결 검사를 통과했습니다.
- 분석자는 같은 기본 자료·중립 과제를 받았고 필요한 보강 표본은 스스로 선택했습니다. 최종 사용 표본까지 완전히 같은 조건은 아닙니다. 답안 접근 제외는 절차상 분리이며 OS 접근 차단이 아닙니다. 모델 버전·토큰·개별 실행시간 통계는 도구에서 제공하지 않아 추정하지 않았습니다.
- 내용 판정은 작성자의 원본/ROI 대조입니다. 사람 정답·독립 전문 심사·반복 통계가 아니며, 새 AI 발견을 기존 사용자 확인에 포함시키지 않았습니다. G는 앞선 E와 같은 홈페이지 계열이고 싱글·듀얼도 같은 자료 묶음이므로 독립 신작5편의 일반화 검증으로 세지 않습니다.
- 선택 표본 사이의 매우 짧은 UI 변화, 개별 글자/원호의 정확한 곡선, 실제 마우스 입력과 원본 AE 구현, 전체 영상·음성은 미확정 또는 미검수입니다. 원본의 안전성/성능/회사 주장 진위는 판정하지 않았습니다.
- 자료011 K-GEO와 자료014 TOVA는 이번에 열지 않았습니다. Phase00 정본·관리 스킬은 유지했고 전역 스킬 설치·회사 DB 등록은 하지 않았습니다.
