# 전문가 판단·역설계 조사 반영: 분석 스킬 수정

사용자 선택: ① 분석 정확도·근거 기록을 먼저 보완하고 전문가 판단·재제작에 넘길 기록 형식까지 연결한다. 2026-10-19 이 채팅의 실제 답변이다.

## 1. 분해와 근거

현재 draft.3의 경고 문구를 늘리는 대신 대상 식별과 속성별 관찰, 중복 없는 주장과 근거를 연결하는 draft.4 후보를 만든다. 대상 발견 목록부터 빠진 내용은 구조 검사로 알 수 없으므로 시간순 관찰과 정착 화면 역추적을 대조한다. 글자·숫자·문구는 형태 관측과 이름 판정을 분리한다. 원본 시간·크롭·해시 검증은 유지한다.

산출물: 별도 후보 스킬, 새 분석 기록 계약, 근거 연결 검사. 기존 A5b 동결판과 중단·실패·최초 채점은 수정하지 않는다.

## 2. 판단과 재사용

다음 단계가 원본 사실을 새 설계 의도처럼 쓰지 않도록 관측·추론·구현 제안의 경계를 만든다. 원본 사례를 넘길 때 필요한 메시지·정보 관계·보존할 특징·확인된 변화·미해결·적용 조건 후보를 근거 ID로 연결한다. 현재는 전달 계약까지만 만들고 회사 공통 문법 승인과 제작 실행은 별도다.

산출물: 전문가 판단·재제작용 인계 형식과 조건부 재사용 지침, 패턴 번호와 고정 스냅샷을 관리하는 도구. 사용자 ②차 답변에 따라 레이아웃은 전체 디자인을 기록하고 모션은 전체 흐름과 세부 동작을 나눈다. 첫 패턴을 상세히 기록한 뒤 반복 시 카테고리·번호·현행 근거·차이로 연결한다. 수치의 정밀도만 재사용 목적에 맞춰 조절한다.

## 3. 검증과 정착

새 기록 검사기에 잘못된 이름 판정·빠진 속성·다른 근거·거짓 완료를 넣어 거부 여부를 확인한다. 이미 본 A/4·확대 감속·선 순서·사선 개수는 개발 회귀 자료로만 쓴다. 실제 새 자료 비교가 필요하면 판본과 노출 범위를 별도로 고정한다. 개발 확인과 실전 효과 검증을 같은 합격으로 쓰지 않는다.

산출물: 검증 결과·남은 한계·다음 선택, 제출 보고서 PDF. 사용자 답변을 기록하되 내용 확인·회사 승인으로 확대하지 않는다.
