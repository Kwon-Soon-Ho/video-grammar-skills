# T01 관찰 — 3.5–5.5초

- 왼쪽의 여러 녹색 직사각 띠가 오른쪽으로 들어와 큰 E로 맞춰진다(3.5–5.1). 상단 획의 우측 경계는 4.4/4.5/4.6/4.7/4.8/4.9초에 약 2078/2112/2135/2148/2154/2154px로, 후반 감속이 확인된다. 각 조각의 출발/정착은 약간 엇갈린다.
- E는 4.1–4.8초 녹색→황금·주황색으로 바뀌며 도로 선 도면과 격자가 드러난다. 같은 내부 패치의 색 증가량은 중간에 커졌다 끝에서 작아져 명암 전환은 가속 후 감속 성격이다. 실제 opacity 속성이라는 뜻은 아니다.
- 외곽 정착 후에도 내부 격자/밝기 강조가 왼쪽에서 오른쪽으로 진행한다(4.7–5.5). 통과한 왼쪽은 어두워진다. 큰 도로 선형은 5.1/5.5 원본 크롭에서 거의 같은 자리다. 빛의 속도곡선과 도면의 독립 미세 이동은 미확정이다.
- 오른쪽 EG-BIM / Engineering Graphicer for BIM과 한국어 기능 설명이 유지된다. 영문의 E·G·BIM은 노랑이다. 3.5–3.8에는 본문 아래 행이 밝아져 정착한다. 3.5의 Value of 밝은 잔여가 3.6에 지워지지만 어두운 큰 문구는 배경에 남는다.

21개 개요 표본과 선택 원본 크롭을 확인했다. 5.5초는 끝 경계 문맥 프레임이다. 오디오·원고·제작 프로젝트는 미검수이며, 구현 가설은 관측과 분리했다. 정확한 곡선/공식 색/회사 공통 문법은 확정하지 않았다.
