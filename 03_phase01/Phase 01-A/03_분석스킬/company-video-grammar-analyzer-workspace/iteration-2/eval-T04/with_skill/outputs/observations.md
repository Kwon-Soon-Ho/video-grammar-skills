# T04 — 6–18초 관측 초안

- 6.000 표지(장헌 로고, 2026년 경영현황 보고, 사장교·수면·건설 부재)에서 실적 화면으로 혼합 전환한다. 6.033–6.300에는 구/신 화면이 동시에 보이며 신 화면이 짙어진다. 정확한 종료 프레임은 미확정이다.
- 신 화면: 좌측 `01 실적 및 계획 / 2026년 1~8월 누적 실적`, 우측 `01 수주 / 02 매출 / 03 영업이익`. 목표 60억/64억/7억, 회색 막대와 비어 있는 회색 원형 트랙이 먼저 마련된다. 도시·강 배경, 로고·문구·장식선은 이후 표본에서 유지된다.
- 수주: 8.000 비어 있음 → 8.1의 12억/20% → 8.2의 22억/37% → 8.4의 38억/63% → 8.6의 47억/79% → 8.8의 52억/88% → 9.0의 55억/91% → 9.2의 55억/92%, 이후 유지.
- 매출: 15.5 비어 있음 → 15.6의 9억/14% → 15.8의 22억/34% → 16.0의 31억/48% → 16.2의 36억/56% → 16.4의 38억/60% → 16.6의 39억/61%.
- 영업이익: 16.7 비어 있음 → 16.8의 1억/7% → 17.0의 3억/41% → 17.2의 4억/60% → 17.4의 5억/68% → 17.6의 5억/71%, 17.8 및 18.0 경계 표본에서 유지.
- 세 카드 각각 파란 막대가 아래에서 위로 자라고 금액은 막대 윗부분을 따라 올라간다. 원호는 12시에서 시계방향으로 채워진다. 각각의 변화량이 후반에 작아져 정착하는 감속(ease-out) 성격이다. 각 카드의 숫자와 원호를 따로 대조했으며 정확한 AE 보간은 미확정이다.

선택 프레임·원본 1:1 ROI 검사이며 전 프레임/오디오 검사는 아니다. 18초는 끝 경계 문맥이고 표시 값은 이 분석 창의 정착값이다. 입력 해시·actual 시각·ROI 좌표 경로와 연결 근거는 JSON에 기록했다.
