# 스킬 사본의 입력 연결

이 단계 ZIP은 스킬/계약/코드/평가 JSON은 원래 구조로 담고, 반복되는 스킬 evals 바이너리 입력은 스킬 ZIP의 완전한 해당 판본 폴더에서 읽는다. 05_결과보고의 candidate/backup 안에 반복된 같은 입력도 생략했다. 실제 실행 결과·별도 평가 입력·pilot/근거 이미지는 해당 보고 폴더에 보존했다. 개별 제외 경로는 excluded-files.json에 있다.

먼저 01_skills/skill-catalog.json에서 판본의 entry를 고르고 evals 하위 파일을 읽는다. 원본과의 매핑은 각 package-manifest.json의 source/SHA로 대조한다. 과거 receipt의 절대경로 pin을 새 경로로 바꿔 원래 검사를 통과했다고 부르지 않는다.
