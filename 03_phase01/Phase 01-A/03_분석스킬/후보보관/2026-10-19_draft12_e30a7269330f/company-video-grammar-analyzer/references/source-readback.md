# 중요 주장의 원본 재대조

부품의 잘못된 이름은 이후 검색·분류에 반복 전파된다. 모든 작은 글자를 전사하기보다, 정보 관계와 재사용 분류를 바꾸는 주장부터 원본과 다시 맞춘다. 전체 디자인·모션 기록은 이 검토와 함께 유지한다.

## 무엇을 다시 볼지

핵심 명칭/설명, 부정어·제외 조건, 수치·단위·귀속 대상, 요청/지원의 방향, 부품 정체를 정하는 도상이 우선이다. 전사한 문장과 의미 이름을 원본의 해당 위치로 되짚고, 주변 문맥으로 예상한 정답을 보이는 글자나 형태 대신 쓰지 않는다. 이미 분명한 배경의 모든 글자를 검수 표로 늘릴 필요는 없다.

전체 원본에서 위치를 찾은 뒤 필요한 부분을 원본 크기로 크롭한다. 크롭의 원본 파일·시각·대략적 위치와 실제 확인 방법을 기록한다. 확대는 새 증거가 아니며 다른 시점/문서가 없으면 없다고 쓴다. 실행하지 않은 재대조를 완료로 보고하지 않는다.

## 확정과 유보

- **문구:** 보이는 글자 그대로와 내용 해석을 구별한다. 불명확한 구절은 읽힌 부분과 미판독 부분을 보존한다. 스타일화된 로고의 추정 명칭과 함께 있는 풀네임은 근거가 다를 수 있다.
- **도상:** 윤곽·내부 표식·위치와 의미 이름을 나누어 본다. 명확하면 이름을 붙이고, 불명확하면 형태와 후보만 남긴다. 일반적인 UI 관습이나 옆 문구만으로 정체를 확정하지 않는다.
- **수치/관계:** 각 값의 시각·단위·대상부터 맞춘다. 계산이 맞아도 같은 집계임이 확인되지 않으면 총액 관계를 확정하지 않는다. 표본 사이 숫자 변화를 최종 확정액이나 실제 카운트업 관측으로 바꾸지 않는다.

결과에는 중요한 확인 몇 건을 `주장 | 현재 근거/위치 | 대조 결과·확정 수준`으로 짧게 남기거나 본문 해당 행에 통합한다. 애매한 내용을 전부 미상으로 바꾸는 대신 확인된 디자인·형태·관계와 남은 식별 문제를 분리한다.

## 번호의 실제 조회

반복 사용처에서 정식 ID/정의 판본을 찾고, 해당 정의에서 이번 사례의 근거·차이·미검증 부분으로 돌아간다. 소규모 기록은 전체 연결을 확인한다. 큰 색인은 실제 확인한 범위를 남긴다. 명시적 별칭이 없는데 접두사를 생략하거나 다른 번호를 빌린 연결은 정리한다. 정의가 없는 조사 항목을 이미 등록한 모션 패턴처럼 쓰지 않는다.

이 대조는 자기 검수다. 독립 검수·사용자 승인·정본 등록을 뜻하지 않는다. 오류 수정 시 원래 결과와 정정 근거를 보존한다.
