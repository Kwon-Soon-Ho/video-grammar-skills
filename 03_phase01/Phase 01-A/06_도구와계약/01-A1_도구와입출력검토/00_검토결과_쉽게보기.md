# 01-A1 결과 — 실제 영상을 읽기 전의 도구·기록 기준

2026-10-16 · v0.1 · **01-A1 검토 완료 / 01-A2는 진행 선택 대기**

사용자가 선택한 **장헌 → 시나리오 없는 EG-BIM 홈페이지 → 복합 자료 → 별도 확인 시험** 순서를 반영했습니다. 이번에는 실제 영상을 분석하기 전에 ‘어떤 도구로 읽고, 읽은 내용을 어떻게 남길지’만 확인했습니다.

## 이번에 한 일

1. **기존 기준 연결**: Phase 00 사전·시간·좌표·근거·검수 규격과 관리용 세 스킬의 사용 범위를 다시 대조했습니다.
2. **도구 검토**: 현재 실행 경로와 영상 도구 후보의 원문·코드·의존성·라이선스를 확인했습니다. PyAV 19.0.1 공개 원본을 고정하고, 전역 설치 없이 작업 폴더에서만 시험했습니다.
3. **정답 도형 시험**: 일정/불규칙 프레임 간격, 0이 아닌 시작 시간, 화면 좌표 변환, 정보 없음, 손상 파일을 확인했습니다.
4. **반대 관점 검토·수정**: 자동 생성 시간을 원본 시간으로 착각하는 문제, 회전값 0을 ‘회전 정보 있음’으로 착각하는 문제, 문서와 실행값의 차이를 반영했습니다. 작성자 자체 레드팀이며 독립 검토자 평가는 아닙니다.

## 핵심 결과

| 확인한 것 | 쉬운 설명 | 현재 판단 |
|---|---|---|
| 시간은 FPS로 역산하지 않기 | 25fps라고 해도 실제 모든 화면 간격이 0.04초인 것은 아닙니다. 원본이 보고한 시간과 단위를 따로 남깁니다. | 합성 불규칙 간격에서 확인 |
| 원본 시간과 재생 시간 구분 | 파일 시간이 1초부터 시작해도 시청자에게 첫 화면은 0초입니다. 다만 실제 파일의 원점은 확인 없이 첫 프레임으로 정하지 않습니다. | 합성 자료의 알려진 원점으로만 확인 |
| 회전·좌표 변환 기록 | 자른 그림을 돌리고 줄였다면 원본 좌표와 달라집니다. 변환 순서를 남겨야 합니다. | 도형 크롭→90도 회전→확대→패딩 확인 |
| 모르는 정보 남기기 | 회전 정보가 없어 나온 0, 누락된 시간을 채운 값은 확정 사실로 쓰지 않습니다. | 원문 코드·실행값 반영 |

첫 시험 **16/17**, 보완 후 **18/18**입니다. 이는 고정 합성 자료의 기술 확인 횟수입니다. 장헌 영상의 분석 정확도, 한국어 인식률, 실제 MP4 전체 지원이나 새 스킬의 성능을 뜻하지 않습니다.

## 아직 확인하지 않은 것

- 실제 MP4의 편집 목록·B-frame·음성과 영상의 동기, 비정방 픽셀, 회전 메타데이터가 있는 파일.
- 실제 한국어 문구·수치·움직임을 AI가 정확히 읽는지, 표본 간 누락과 비용.
- 음성 인식 경로. 현재 확인한 호출 도구에는 별도의 전사 도구가 없고, 별도 API는 공식 문서만 검토했습니다.
- 패키지에 포함된 모든 네이티브 라이브러리의 사용·재배포 조건. FFmpeg 빌드가 스스로 보고한 라이선스와 전체 배포 적합성은 같은 판정이 아닙니다.

## 다음 단계 추천

**장헌의 작은 구간부터 로컬 도구로 시간·프레임을 추출하고, 그 이미지를 현재 Codex에서 읽는 예비 시험**을 추천합니다. 먼저 메타데이터로 음성 트랙 유무와 화면 방향을 확인합니다. 트랙 존재는 실제 말소리 존재와 구분합니다.

음성 전사가 필요해지면 사용할 API와 전달 범위를 구체적으로 정한 뒤 진행합니다. 그 전까지 음성·전체 의미 분석은 미확인으로 남깁니다. 현재 Codex에서 이미지를 읽는 것도 연결된 AI 처리이며, 완전 오프라인 분석이라는 뜻은 아닙니다. 별도 API 키·결제·업로드는 이번에 사용하지 않았습니다.

아직 실제 회사 영상을 열지 않았고 새 분석 스킬도 만들지 않았습니다. 관리용 세 스킬은 소량 사본 시범 범위를 유지합니다.
