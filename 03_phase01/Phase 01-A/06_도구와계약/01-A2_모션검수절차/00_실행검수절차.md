# 01-A2 모션 검수 실행 절차 v0.2

이 절차는 기존 Phase00 지식을 A2 실행에 연결하는 보완이다. A3 분석 스킬 생성이나 Phase00 규격 변경이 아니다.

1. 원본·시각·구간을 고정한다. 디코딩한 프레임 수, 눈으로 대조한 선택 시점, 확대해서 확인한 영역을 구분한다. 추출 성공은 시각 검수 성공이 아니다.
2. 기존 문장과 독립해서 화면을 구역으로 나누고 대상을 목록화한다. 주 대상뿐 아니라 작은 글자, 숫자, 커서, 선택 영역, 테두리, 선, 배경 격자, 발광 부분, 내부 질감, 그림자, 화면 안 화면을 점검한다. 화면 안 화면은 창 전체와 내부 상태 변화를 반드시 별개 대상으로 나눈다. 안 보이는 세부는 빈칸 대신 보류와 이유를 적는다.
3. 대상마다 이동·크기·형태/회전·가시성/공개·색/광량·내부 변화·중첩·등장/퇴장/순서·가감속의 9칸을 각각 기록한다. 정지·비적용도 시간 근거가 있어야 한다. opacity와 밝기, 회전과 가림, 카메라와 화면상 확대를 구분한다.
4. 전체 구간을 먼저 시간순으로 대조한다. 다음에는 뒤에서 앞으로 고른 시점을 보며, 정착 상태의 모든 요소가 언제 생겼는지 역추적한다. 단순히 동일 화면을 재추출한 것은 두 번째 내용 검수가 아니다.
5. 작은 선은 원본 해상도 crop, 저대비 동작은 원래 화면과 차이 지도/공간-시간 단면을 같이 본다. 차이 증강은 변화 탐색용이며 색·밝기·모양의 원본 근거로 삼지 않는다. 저해상도 픽셀차만으로 정지나 누락 없음 판정을 내리지 않는다.
6. 이미 설명한 대상 밖의 변화도 찾는다. 격자별 차이, 유지 구간, 본문·하단·모서리, 주 대상 내부를 별도 점검한다. 미설명 변화는 조사 목록에 올리고, 해당 구역을 확대해 재검수한다. 특히 정착한 UI 창 내부에 차이가 남으면 목록/선택행/미리보기/포인터 후보로 쪼개어 확인하기 전까지 정지로 닫지 않는다. 완료 문장으로 덮지 않는다.
7. 과거 누락(E 조각, 빛, 십자 커서, 점선 축소)을 회귀 확인 대상으로 둔다. 새 절차가 그 대상을 실제 근거와 연결하는지 검사한다. 사용자가 이미 설명한 표본이므로 독립/블라인드 정확도 평가라고 부르지 않는다.
8. 자동 종료 검사는 목록/9칸/근거 파일/판정/미분류 이유가 빠지면 실패시킨다. 삭제·빈칸·잘못된 사람 승인 상태를 주입해 실패하는지 확인한다. 이 검사는 기록 완전성 검사이며 영상 인식 정확도나 누락 0건을 증명하지 않는다.
9. AI 관측, 기존 사람 확인, 사용자 정정, 구현 가설을 분리한다. 새로 발견한 동작에 기존 승인을 붙이지 않는다. 사람에게는 AI가 근거를 조사한 뒤에도 필요한 판단만 질문한다. 검수 부담을 사용자에게 다시 넘기기 위해 일괄 승인을 요청하지 않는다.

종료 시에는 수행 범위, 새 발견, 기존 기록 정정, 남은 불확실성, 사람에게 남긴 질문 수를 적는다. 필수 관측이 미검수이면 A3 진행 준비 완료를 제안하지 않는다. 보조 동작의 정확한 곡선을 측정할 수 없더라도 존재·방향·순서의 관측을 지우지 않는다.


## 스킬 작성 전 필수 내용 시험

기록 검사 통과를 영상 내용 통과나 A3 작성 준비 완료로 쓰지 않습니다. [스킬 작성 전 통과조건](스킬작성전_재발시험/00_스킬작성전_통과조건.md)에 따라 중립 입력의 실제 분석 출력을 먼저 저장하고, 원본과 기준답안을 내용으로 대조합니다. 확인된 필수 사건의 누락·오탐이 남으면 절차를 보완하고 영향 구간을 재시험합니다. 현재 실행/미실행은 [착수 판정](스킬작성전_재발시험/02_현재판정.json)에서 확인합니다.
