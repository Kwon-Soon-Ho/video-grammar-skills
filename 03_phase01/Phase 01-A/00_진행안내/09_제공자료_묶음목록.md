# 제공 자료 기준 영상·기획서 묶음

2026-10-16 / 사용자 지시 반영 완료

**넣어주신 시나리오·기획자료를 해당 프로젝트 영상에 연결했습니다. 같은 연결 질문을 다시 받지 않습니다.** 시나리오를 넣지 않은 SW 홈페이지 클립 4개 묶음은 ‘별도 시나리오 없음’으로 등록했습니다. 이미 첨부된 SW 홍보 스토리보드는 해당 프로젝트에 연결해 보존했습니다.
