# 자료 연결 확인 — 사용자 지시 반영 완료

영상과 시나리오를 어떻게 묶을지에 관한 질문은 종료했습니다. 제공된 자료대로 프로젝트별로 연결했고, 시나리오 미첨부 SW 홈페이지 영상은 별도 시나리오 없음으로 등록했습니다. [현재 묶음 목록](09_제공자료_묶음목록.md).

가족사 7곳 v4는 완성 영상과 초기 기획서를 대조해 재구성한 원고라는 사용자 설명을 유지했습니다. 이미 제공된 SW 홍보 스토리보드도 그대로 보존했습니다.

## 실제 작업을 시작한 뒤 필요한 경우에만 확인

- 내용 검수 담당·실제 시청 환경: 사용할 자료의 판단에 필요한 범위에서 확인
- 문서 수치·PG 규격·수정 전후 차이: 이후 분석에서 실제 충돌이 확인된 항목만 검수
- 외부 AI/API 처리 범위: 외부 처리를 요청한 시점에 해당 자료와 필요한 범위로 확인

이 항목들은 현재 입력자료 묶음 등록을 막지 않습니다. 실제 영상 분석·스킬 개발·외부 업로드는 아직 시작하지 않았습니다.
