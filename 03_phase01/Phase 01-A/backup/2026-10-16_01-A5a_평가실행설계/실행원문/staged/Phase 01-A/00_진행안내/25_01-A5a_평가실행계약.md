2026-10-16 · 설계 v1.0 · 추천 A안 구체화 완료 · A5b 실행 판단 대기

고정한 `company-video-grammar-analyzer 0.1.0-draft.3`의 구조·문구·시간 관측을 확인한다. 별도 자료 비교는 **2프로젝트 × 2구간 × 2반복 × 2비교군 = 16실행**이다. 먼저 기존 자료3구간의 표적 회귀를1회씩 수행하므로 기본 분석은 총19실행이다. A5a에서는 파일 식별·헤더·판본과 시험 설계만 정리했고 영상 프레임 추출·관측·채점은 수행하지 않았다.

이번 수치는 다음 시험에 적용할 작업 허용 기준이다. A4에서 측정한 정확도나 검수시간의 추정값이 아니다. 과거 기준·점수·사람 확인 범위는 그대로 유지한다.

## 후보와 동일 조건

스킬7파일과 보조 추출기 코드, Python·PyAV·Pillow·NumPy 판본 및 확인 가능한 native 바이너리58개의 해시를 `candidate-pins.json`에 기록했다. 스킬 사본은 `candidate/company-video-grammar-analyzer`다. A5b 시작 때 정본과 사본 해시를 대조한다. 실행 중 스킬·참조·도구 코드·과제·평가 기준을 수정하지 않는다.

두 비교군은 같은 보이는 모델 설정, 중립 과제, 원본·기본 프레임, 추가 관찰 한도와 출력 형식을 받는다. 스킬 적용군만 고정 스킬을 읽는다. 근거 연결 검사는 양쪽 결과에 똑같이 적용한다. 공통 출력 형식은 기존 observations 계약을 재사용하며, 정답이나 새 모션 점검 지침을 미사용군에 넣지 않는다. 모델의 정확한 체크포인트가 호스트에 노출되지 않으면 미상으로 기록한다. 모델 설정이 바뀌면 같은 조건의 연속 실행으로 합치지 않는다.

각 실행은 이전 출력·다른 반복·사용자 정정·기준답안이 없는 새 문맥으로 시작한다. 이는 문맥 분리이며 파일시스템 접근 격리라는 주장은 아니다. 기본 프레임은 공유하고 추가 표본/ROI는 각 실행이 독자적으로 선택한다. 최종 관찰 표본까지 동일했다고 보고하지 않는다. 실행 순서는 구간·반복별로 비교군을 교차 배치하며, 검수 때는 비교군 이름을 가린 실행 번호를 사용한다. 문체로 조건을 추측할 수 있으므로 완전한 이중맹검이라고 부르지 않는다.

## 표적 회귀와 기준답안의 순서

1. A5b 진행 지시 후, 새 자료 화면을 열기 전에 최종 통합 draft.3으로 기존 G퇴장·싱글 자막·듀얼 자막/정착 구별3구간을1회씩 확인한다. A4의 기본 근거와 당시 명시 기준을 재사용한다. 스킬 미사용군 반복이나 과거 전수 재분석은 추가하지 않는다.
2. 회귀가 실패하면 새 자료를 열지 않고 결과를 보고한다. 스킬을 수정했으면 새 판본·해시를 고정해야 한다. 기존 A4 결과를 취소하거나 덮어쓰지 않는다.
3. 회귀를 통과한 뒤 별도4구간의 원본 기반 기준표를 만들고 다른 대조 단계로 확인한다. 분석 실행 출력은 기준표 작성자에게 보여 주지 않는다. 기준표와 근거 해시를 봉인한 후16개 분석을 시작한다.
4. 기준표는 구간당 핵심6~10개와 세부6~10개의 원자 항목을 목표로 한다. 하나의 항목은 대상·속성/관계·상태/방향/순서·시각 범위·직접 근거를 가진다. 맞는 주장과 틀린 주장을 한 문장에 묶어 부분점수로 숨기지 않는다.
5. 실제로 그만큼의 관측 대상이 없으면 항목을 만들지 않는다. 구간당 판독 가능한 핵심6개/세부6개보다 적으면 해당 범위의 성능 판정은 보류하고 실제 분모를 보고한다. 정착이나 무동작 확인 자체는 유효한 관측이다.

기본 기준은 AI가 작성하고 별도 원본 대조를 거친 참고 기준이다. 사람 확인이 이루어진 항목만 해당 범위에서 사람 기준으로 표시한다. DOC064는 내용 대응을 돕는 기획자료이며 원래 제작 의도·최종 승인·영상의 수치 정답으로 대신 쓰지 않는다.

## 항목별 통과 기준

원본·회사·대상·근거 시각 혼동, 의미를 바꾸는 문구/수치/단위/부정어·순서 오류, 근거 없는 이동/가감속/AE 구현 확정, 미검수 음성을 무음 또는 청취완료로 쓰는 것은 중대 오류다. 새 AI 관측을 기존 사용자 승인으로 표시하는 것도 포함한다. 좋은 나머지 항목이나 평균으로 상쇄하지 않는다.

세부 충족률은 맞게 연결한 세부 항목/판독 가능한 세부 항목이다. 확정 주장 정확도는 근거가 있는 사실 주장/전체 확정 사실 주장이다. 같은 뜻의 중복 주장은 한 번만 세며, 맞는 설명 옆에 모순된 설명을 함께 쓴다고 오류를 지우지 않는다. 누락·틀린 항목·판독 가능한데 기권한 항목은 충족한 항목으로 세지 않는다. 근거상 판정 불가능한 이징을 미확정으로 남기는 것은 적절한 기권이며, 확인 가능한 존재·방향·순서는 별도로 평가한다.

개수 기준은 성공 `ceil(기준비율×분모)`, 허용 오류/기권 `floor(기준비율×분모)`로 계산한다. 예를 들어 세부9개면9개 모두가 맞아야90% 이상이고, 확정 주장19개면 잘못된 확정 주장1개는95%에 못 미친다. 분모0은100%로 처리하지 않고 사유와 함께 판단보류다. 비적용·판독 불가는 출력 채점 전에 근거로 정하며 실패한 항목을 사후에 분모에서 빼지 않는다.

시간 기준은 실영상 관측 경계의 작업 허용오차다. 기준표의 마지막 이전 상태와 첫 다음 상태가0.2초 이내로 좁혀져야 수치 판정을 한다. 두 범위가 겹치면 거리0이고 떨어져 있으면 가장 가까운 끝점 간 거리다. 보고 범위가 너무 넓으면 겹치기만 해도 통과시키지 않는다. 기준 경계 자체를 한도 안에서 좁힐 수 없으면 수치 판정은 보류한다. 추출 근거의 실제 PTS·원본 식별은 별개로 정확히 일치해야 한다. 합성 교정의±1프레임을 실영상에 강제하지 않는다.

가감속은 움직이는 중의 같은 특징을 둘 이상의 구간에서 비교하고 관측 오차와 부분 리빌·가림을 고려한다. 도착 후 정지 표본만 늘려 감속으로 판정하지 않는다. 정밀 측정이 필요하지 않으면 방향·순서·정착과 곡선 미확정을 함께 기록한다.

## 관찰과 실행 한도

기본 표본은0.4초 간격, 구간당 최대32장이다. 한 분석은 보강2회, 회당 최대24장으로 추가 원본 프레임48장까지 사용한다. 무배율 RGB 크롭은 실행당40개를 한도로 하고 작은 요소의 확인에 사용한다. 선이나 글자가 안 보였다는 이유로 바로 없음으로 닫지 않는다. 한도 안에서 해결하지 못한 부분은 미확정·미검수로 남긴다.

기준표·분쟁 대조용 보강은 총64장, 추출기 교정은8장까지다. 새 자료 기본 표본은4구간 총94장, 분석 보강의 이론상 최대768장, 기준/분쟁64장, 진단8장으로 총934장이다. 전역 원본 PNG 상한은1,000장, 파생 자료를 포함한 저장 상한은8GiB다. 기존 회귀는 이미 확보한 A4 근거를 우선 재사용한다.

추출 작업 하나는60초·읽기256MiB·메모리2GiB·PNG40장·복호화1,600프레임·패킷4,000개, 등록 파일3GiB·7680×2160픽셀 한도를 유지한다. 새 원본의 헤더/시간 매핑이 기존 어댑터에 맞지 않으면 무단 확장하지 않고 기술적 미지원으로 중단한다. A5a 도구 사본을 그 자리에서 실행하지 않고, A5b 실행 폴더에 같은 코드와 별도 허용목록/요청 설정을 둔다. 회사 자료의 외부 유료 API 호출은0회다.

390분은 역할별 작업시간을 합한 상한이며 달력상 완료시간 약속이 아니다. 병렬 실행이 겹친 경과시간과 사람의 실제 활성 공수는 분리한다. 검수자의 불필요한 대기는 일시중지해 기록하고, 사람이 하지 않은 AI 검수 경과시간을 사람 공수로 바꾸지 않는다. 기술 재시도는 동일 입력으로 총2회까지만 허용하고 기존 시간·저장 상한 안에 포함한다. 이 경우 최대 시도 수는21회이며 최초 기술 실패도 보존한다. 내용에 대한 답을 주고 다시 쓰게 하는 재시도는 최초 확인 시험에 포함하지 않는다.

사용자에게 새로 확인받을 몫은90분 안에서 최대20분·6항목이다. 답변 대기는 활성 공수와 별도다. 기존에 확인한 A2 주장이나 영상·시나리오 연결을 다시 묻지 않는다. 실제 남은 질문만 화면·주장·이유와 함께 묶어 요청한다. 답변이 없어도 이미 가능한 검수는 진행하고, 판단에 필수인 답변은 미확정으로 남긴다.

`A5-run-record-template.json`에 시작/끝, 기본·보강 프레임/ROI, 재시도, 수정·검수 주체와 시간, 대기를 기록한다. 노출되지 않는 모델 버전·토큰·비용이나 과거 A4 공수는 만들어 넣지 않는다. 같은 품질에 도달한 결과의 검수 공수 비율은 스킬/미사용1.2 이하를 선호 기준으로 삼는다. 이를 넘으면 품질 통과와 별개로 비용 보완 대상으로 표시한다. 미사용군이 품질 기준에 못 미치거나 공수가 미기록/0이면 동등 품질의 절감률을 계산하지 않는다.

## 종료와 후속 판단

회귀 실패, 중대 오류1건, 판본 변화, 자원 상한 도달은 중단 사유다. 그 밖의 일반 기준 미달은 잠근 조건 안에서만 확인을 이어 가되 중간에 스킬·과제·답안을 고치지 않는다. 중단되면 계획16회와 실제 완료/실패/미실행 수를 따로 보고한다. 시간을 더 썼다는 이유로 기준을 낮추거나 미검수 항목을 통과로 표시하지 않는다.

중대 오류 중단은 스킬 적용군에 적용하며 해당 배치의 남은 두 비교군 실행을 함께 멈춘다. 미사용군의 오류는 그대로 채점하고, 그 자체만으로 스킬 적용군의 확인을 중단하지 않는다.

8개 스킬 적용 실행 각각의 품질 기준과 구간별 반복 기준을 모두 충족하면 지정 자료·구간의 관측 품질 통과다. 두 반복은 안정성을 살피는 소량 확인이며 일반 성능의 신뢰구간이나 회사 전체 정확도를 추정하지 않는다. 비교군보다 좋아졌다는 판단은 실제 차이가 있을 때만 내리고, 품질 통과·효과 미입증을 구분한다. 기존 결과에 대한 더 낮은 새 기준의 소급 적용은 하지 않는다.

새 자료를 본 뒤 스킬을 수정하면 그 자료는 개발·회귀용으로 전환한다. 같은 자료 재실행을 미노출 시험으로 부르지 않는다. A5b 결과를 보고 A6 인계/추가 보완/범위 축소를 정하며, 회사 문법 승인은01-B, 새 표현 선택·제작 경제성은02에서 다룬다.

## 고정 파일

실행 조건은 `contract-v1.json`, 구간은 `windows.json`, 실행 순서는 `run-matrix.json`, 사전 회귀는 `legacy-regression-plan.json`, 판본은 `candidate-pins.json`, 노출 이력은 `exposure.json`이다. 이 계약과 기준답안은 분석 실행의 입력에서 제외하고 공통 과제·자료·자원 한도만 제공한다.
