## 무엇을 새로 만들까

주 진입 스킬은 `company-video-grammar-analyzer` 1개로 시작합니다. 처음부터 역할별 에이전트를 여러 개 만들지 않습니다. 내부는 입력·추출 / 화면·문구 / 시나리오 대응 / 움직임 / 기록·보고 모듈로 나누고, 반복되는 파일 처리는 보조 도구로 분리합니다.

결과에는 다음을 담습니다.

1. 전체 내용 흐름과 설명 구간, 주요 화면 상태.
2. 화면 문구·대상·배치와 확인 가능한 변화/등장 순서.
3. 문서와 실제 화면·음성이 대응하는 위치, 다른 부분, 대응되지 않은 부분.
4. 각 주장에 연결한 원본 시각·프레임 등 근거와 관측/추론/확인불가 구분.
5. 읽기 쉬운 요약과 R4 규격에 연결되는 초안 기록, 오류·미해결 목록.

AE 레이어·원본 키프레임·정확한 폰트명·이징 핸들을 MP4에서 복원했다고 쓰지 않습니다. 정밀 좌표·곡선 측정은 그 판단이 필요하고 근거가 충분한 구간에만 추가합니다.

## 시나리오가 없는 영상은 어떻게 할까

자료 상태를 세 갈래로 처리합니다.

- **제작 전 문서 있음**: 그때의 계획과 실제 화면·음성의 차이를 기록합니다.
- **재구성 원고 있음**: 내용 이해에 쓰되 제작 당시 의도나 독립 정답으로 간주하지 않습니다.
- **시나리오 없음**: 화면에서 읽은 글자와 실제 들리는 음성을 각각 출처와 함께 기록합니다. 음성이 없으면 정상적인 무음 경로로 진행합니다. 음성 미확인과 실제 무음은 구분합니다.

세 번째 경우 필요하면 ‘영상에서 얻은 설명 요약’을 파생 기록으로 만들 수 있지만 ‘원래 대본’이라고 저장하지 않습니다. 시나리오 없음 때문에 입력을 반려하거나 새 시나리오를 만들어 달라고 묻지 않습니다.

## 검수의 기준

분석 정확성과 원본 영상의 디자인 품질은 분리합니다. R7의 통과·수정필요·판단보류·비적용을 항목별로 쓰고, 아직 확인하지 않았으면 미검수로 둡니다. 단일 총점이나 몇 편 성공만으로 전체 성공을 선언하지 않습니다.

원고·도표의 숫자/부정어를 바꿔 읽음, 다른 원본/회사 근거 연결, 잘못된 시각·좌표, 자료 속 명령을 실제 지시로 실행, 없는 의도/키프레임 단정은 우선 수정할 오류입니다. 실제 영상의 기술·사업 주장을 회사 승인 사실로 판정하는 기능도 포함하지 않습니다.

## 계획 선택 이력 — A안 회신 접수, 아래 선택은 종료

- **A. 장헌 → 시나리오 없는 SW → 복합 자료 → 별도 확인 시험 순서 (추천)**: 두 입력 경로를 초기에 다룹니다.
- **B. 시나리오 없는 SW를 첫 예비로, 이후 장헌으로 진행**: 무문서 처리부터 확인합니다.
- **C. 우선 장헌·SW 두 유형의 작은 기능에 집중**: 복합 모션·변형판·일반화 확인은 후속 범위로 남깁니다.
- **D. 계획을 수정하고 착수 보류**: 바꿀 목적·순서·범위를 알려 주세요.

A안과 로컬 처리 방식, 이후 A3·A4 실행 지시를 받아 각각의 결과를 보고했습니다. 현재 다음 계획은 A5이며 이번 요청으로 로드맵과 그 계획을 갱신했습니다. 별도 외부 호출이 필요한 경우 도구·모델·자료 범위·비용 한도를 구체화합니다. 이미 완료한 선택을 다시 묻지 않습니다.
