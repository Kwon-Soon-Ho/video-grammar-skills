## 기존 맞춤 스킬 3개 — 실제 역할

공통 경로: `Phase 00/06_맞춤스킬/재구성후보/`. 기본 경로와 전역 설치를 바꾸지 않습니다.

| 스킬 / 현재 후보 판본 | 01-A에서 도움받을 일 | 맡기지 않을 일 |

## 외부/전문 스킬은 무엇을 가져올까

| 후보군 | 이번에 참고할 것 | 제외하거나 별도 검토할 것 |
|---|---|---|
| Taste·Impeccable·편집/발표/화면 설계 | Phase 00에 정리된 정보 관계·위계·밀도·가독성 질문 | 자동 리디자인·금지 스타일·고정 웹 px·hover·폰트/사진 묶음 |
| Pixel 계열 | 측정값·눈대중 추정·구현 가설을 구분하는 관찰 절차. 실제 필요한 파일은 현재 설치판과 조사 판본 차이를 확인 | AE 제작 지시·일률 격자·품질 총점·출처/사용 범위가 확인되지 않은 직접/파생 코드 이식 |
| 모션/구도/접근성 계열 | Phase 00 원문 근거와 적용 예·반례를 통한 관찰 항목 | 고정 1/3 이동·항상 한 초점·반드시 특정 이징·UI 규칙의 영상 전역 강제 |
| Anthropic Skill Creator | 의도/입출력, 작은 스킬+참조, 같은 조건 비교, 정적 결과 뷰어, 피드백 후 수정 | Claude CLI/SDK 자동 호출·설명 최적화의 무검토 실행, 미수집 통계를 채우는 기본 집계 |

출처·변형 이력이 미확인인 로컬 스킬과 제한 소스는 그대로 복사·배포하지 않습니다. 기존 R8의 보류 대상인 pptx·비평/Draw.io 관련 범위를 이번 분석 계획으로 해제하지 않습니다. 새 기능에 직접 코드가 필요할 때만 원문→참조→코드→의존성→외부 통신→이용 조건→실행 반례 순서로 검토하고 범위별 결론을 냅니다. 하나가 보류돼도 관련 없는 분석 준비까지 멈추지 않습니다.

## 새 분석 스킬의 계획 구조

예정 이름: `company-video-grammar-analyzer` (아직 생성하지 않음)

1. **입력·추출**: 원본 식별·시각·회전/해상도·음성 유무·적응형 프레임/구간 근거. 도구 후보는 01-A1에서 좁힙니다.
2. **화면과 문구**: 화면 상태·주요 대상·읽을 수 있는 문구·정보 관계를 기록. 추정 폰트나 레이어값은 별도 표시합니다.
3. **문서 대응**: 제작 전/재구성/없음 경로를 분리. 문구·실제 음성·화면의 다대다 대응과 불일치를 보존합니다.
4. **움직임**: 순서·지속·겹침·대상/카메라 변화와 불확실성. 정밀 추적은 조건부로 둡니다.
5. **기록·보고**: R4 연결 초안과 요약, 근거와 한계, 재시험/사람 질문을 생성합니다.

처음부터 5개 독립 스킬·다수 에이전트로 분리하지 않습니다. 모듈별 역할과 반복 보조 도구를 먼저 분리하고 필요성이 실제 시험으로 드러날 때 나눕니다. 관측 획득·기록 검증·내용 판단을 한 번의 ‘AI 통과’로 뭉치지 않습니다.

## 실행 경로 검토 원칙

영상 프레임·음성·시간 정보를 정리하는 일반 로컬 도구와 화면/언어를 해석하는 AI 경로를 구분합니다. 로컬 대형 오픈소스 AI 모델 설치를 기본 해법으로 잡지 않습니다. 현재 연결된 모델/도구로 가능한 입력 형태와 별도 API 필요성은 01-A1에서 실제 지원·자료 범위·비용 기준으로 확인합니다. 개인 구독 이용권을 별도 API 비용/권한과 같은 것으로 가정하지 않습니다.

새 API 키·요금·외부 전송이 필요하면 대상·처리량·비용 한도·보관 범위를 구체화한 뒤 해당 경로를 진행합니다. 정보가 없으면 그 외부 호출만 보류하고 다른 안전한 계약/도구 검토는 계속합니다. AE/Computer Use 연결은 변경하지 않고 로컬 문서·정적 출력 검토 경로를 우선합니다.
