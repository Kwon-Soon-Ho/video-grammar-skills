# 01-A 테스트 영상 선정안

2026-10-16 · 계획 확인 전 · 실제 영상 파일 열람/규격 조사/프레임 추출 없음

이 목록은 ‘어떤 능력을 어떤 자료에서 확인할지’ 정한 초안입니다. 입력자료 묶음 자체는 사용자 지시로 이미 등록됐으므로 다시 승인받지 않습니다. 모든 영상을 곧바로 일괄 분석하거나 이 목록으로 잠금을 확정하지 않습니다.

## 1. 첫 예비 — 자료005 장헌 경영보고

- 영상: `한맥 영상/00_26년 가족사 경영보고 영상/장헌/장헌_최종.mp4`
- 내용 참고: `초기기획서_장헌_2026년_경영보고_v4.docx`
- 비교 참고: 같은 폴더 v03 PPT와 초기 장헌 문서·스크립트.
- 추천 이유: 사용자가 선택한 기준 후보이고 v4의 본문이 다른 경영보고 재구성 원고보다 비교적 짧습니다. 실적·사업계획의 큰 내용 흐름과 문서 대응을 작은 범위로 확인하기 적합하다는 **계획상 판단**입니다.
- 확인할 것: 화면 상태와 동작 구분, 숫자·단위 보존, 실제 표시/발화와 재구성 원고의 차이, 회사 식별, 근거 위치.
- 하지 않을 단정: 실제 장면 수·길이·화질·난도, 정확한 원본 AE 설정, 문서와 영상의 완전 일치.

처음에는 전체 흐름을 거칠게 보고, 그 뒤 **짧은 구간 1~2개**를 자세히 확인하는 안입니다. 예컨대 수십 초 정도는 검수 부담을 줄이는 출발 제안일 뿐 고정 평가 표본 수·시간 오차 기준이 아닙니다. 실제 길이와 구조를 확인한 뒤 범위를 기록합니다. 실패한 구간을 쉬운 장면으로 교체하지 않습니다.

## 2. 초기 시범에 함께 포함 — 자료013 EG-BIM 홈페이지

- 첫 파일 제안: `한맥 영상/SW 홈페이지 영상/EG-BIM/01_(E).mp4`
- 필요하면 같은 묶음의 `02_(G).mp4`로 기능 차이·경계를 추가 확인합니다. 다른 세 클립도 등록 상태를 유지합니다.
- 시나리오: **별도 없음 — 사용자 확인**.
- 첫 파일을 고른 이유: 등록된 순서의 첫 클립으로 작은 입력 경로를 확인하기 위한 제안입니다. 해당 파일의 기능·움직임·무음 여부를 이름만으로 안다고 주장하지 않습니다.
- 확인할 것: 화면 글자·실제 음성·UI/포인터/주요 대상의 변화가 있으면 기록하기, 아무 말이 없는 구간을 실패로 처리하지 않기, 안 보인 의도·원래 대본을 생성하지 않기.
- 비교할 잘못된 응답: ‘시나리오가 없으니 분석 불가’, ‘원래 대본은 다음과 같다’처럼 없는 자료를 채우는 응답.

SW 홍보 EG-BIM 스토리보드를 홈페이지 클립의 숨은 대본으로 사용하지 않습니다. 홈페이지/홍보 결과를 비교하는 별도 과제에서는 양쪽 자료를 명시적으로 허용하고, 평가 중에는 허용 입력을 섞지 않습니다.

## 4. 별도 확인 후보 — 잠금은 나중에

| 후보 | 묶음 전체를 관리할 범위 | 선택 이유 |
|---|---|---|
| 자료014 TOVA 홈페이지 | 4개 클립. 자료018 TOVA 홍보와 같은 제품 자산/파생 여부도 확인 | EG-BIM과 다른 제품의 무문서 입력을 확인할 후보 |
| 자료011 K-GEO | `K-GEO FESTA_250919_3.mp4` + 제공 시나리오 | 다른 프로젝트의 기술·시험 설명 자료를 확인할 후보 |

현재는 후보만 적었습니다. 예비에서 부족한 유형을 보고 01-A5a에서 실제 표본·정답·기준·모델/스킬 판본을 고정합니다. 후보로 적었다는 이유로 이 자료를 지금 미리 추출하거나 분석하지 않습니다.

## 5. 유출과 중복을 막는 규칙

1. 가족사 경영보고 7곳은 같은 시리즈의 노출 묶음으로 우선 관리합니다. 다른 회사 한 편을 골랐다고 완전히 독립된 시험으로 세지 않습니다.
2. 같은 프로젝트의 싱글/듀얼·구본/최종·발췌/전체·원본/저해상도 복사·문서 재구성은 서로 다른 편수로 부풀리지 않습니다. 내용/자산 공유 범위를 확인해 원본 그룹을 연결합니다.
3. 여러 기획 문서와 기획 보드 이미지는 이미 이 대화에서 검토했습니다. 이 이력을 숨기고 ‘완전 미노출 정답’이라고 부르지 않습니다. 실제 영상은 아직 미분석입니다.
4. 최종 확인 실행에는 예비 결과·답안·수정 이유·기획 문서 중 금지한 자료가 들어가지 않도록 별도 입력 목록과 새 실행 문맥을 씁니다. 새 문맥만으로 과거 노출이 사라지는 것은 아닙니다.
5. 영상에서 재구성한 원고를 독립 정답으로 쓰지 않습니다. 사람이 원본을 보고 확정한 화면·소리·시간 근거와 정답 이력을 별도로 만듭니다.
6. 기존 자료로 완전 독립 시험을 확보하기 어렵다면 ‘사전 문서 노출이 있는 별도 원본 확인’이라고 한계를 표시합니다. 독립 일반화 주장이 필요할 때만 새 원본 묶음을 요청합니다.
7. 같은 인트로·로고만 다른 클립에서 반복되면 중복성을 기록하고 핵심 과제의 독립 사례 수와 분리합니다. 현재는 영상 유사도 검사를 실행하지 않았습니다.

## 6. 사람이 받는 검수 자료

파일명을 다시 고르게 하기보다 원본 위치·짧은 확인 구간·추출 근거·모델 기록·확인할 질문을 한 묶음으로 제시합니다. 한 번의 검토에 몇 개의 사례를 보여줄지는 예비에서 조절합니다. 사람이 직접 FPS·타임코드·좌표를 적는 일은 요구하지 않습니다.

사실 확인에는 답을 유도하지 않는 질문을 쓰고, 목적·범위·방법 선택에는 최소 4지선다와 추천안을 씁니다. 이미 확인된 입력자료 연결·CI 최신성·재구성 원고 성격을 다시 승인받지 않습니다.
