# Phase 01-A 자료 준비·진행 계획 - 여기부터 보세요

**입력자료 연결은 완료했고 01-A 진행 계획은 검토 대기입니다. 실제 영상 분석과 스킬 개발은 시작하지 않았습니다.**

[01-A 전체 계획과 시험 순서](00_진행안내/10_01-A_계획_읽는순서.md)를 먼저 보세요. 계획 확인 후 01-A1부터 단계별로 보고합니다.

한맥 영상에서 파일 115개와 영상 후보 41개를 목록으로 확인하고, 영상이 든 23개 폴더를 등록했습니다. 원본은 그대로 두었습니다. 제공된 영상·문서의 프로젝트 연결은 완료했습니다. 최종 납품 상태·첫 시험 대상은 별도이며 분석은 미시작입니다.

1. [기존 자료 등록목록](01_입력자료/00_기존자료_등록목록.md)에서 프로젝트를 고릅니다.
2. [등록된 영상·기획서 묶음](00_진행안내/09_제공자료_묶음목록.md)을 봅니다. 추가 연결 확인이나 시나리오 재작성은 필요 없습니다.
3. 새 파일을 추가할 때는 [자료 넣는 방법](00_진행안내/01_자료넣는방법.md)을 봅니다.

이미 모은 영상·문서를 다시 옮기거나 변환할 필요는 없습니다. 같은 폴더에 넣어주신 영상·기획자료를 묶었습니다. 시나리오 미첨부 SW 홈페이지 영상은 별도 시나리오 없음으로 등록했습니다.

## 최신 보완: 기획서 사전 검토

[검토 색인](00_진행안내/05_기획서검토_색인.md) · [사용자 확인 모음](00_진행안내/04_사용자확인_모음.md) · [작업 결과](05_결과보고/01_기획서검토와_자료설명_보완.md).

19개 자료 묶음에 문서의 목적·주제와 확인 가능한 계획을 기록했고, 홈페이지용 4개 묶음은 사용자 설명에 따라 별도 시나리오 없음으로 등록했습니다. 원래 CSV·JSON과 준비상태.json은 최초 등록 시점의 이력으로 보존하며, 이번 현황은 00_진행안내/기획서검토_현황.json에 따로 기록합니다.

가족사 7곳 v4 Word는 완성 영상과 초기 기획서를 비교해 만든 **재구성 원고**로 사용자 설명을 반영했습니다. 작성 성격 확인과 기준 영상 선택·실제 내용 일치 검수는 구분합니다.

## 가족사 7곳 작업 기준 후보 등록

사용자 A안 선택에 따라 자료002~008의 MP4·v4 재구성 원고·PPT/초기 문서 참고 조합을 등록했습니다. [등록된 7건](00_진행안내/08_가족사7곳_작업기준후보_선택기록.md). 나머지 자료도 제공 폴더 기준으로 묶음 등록을 완료했으며 실제 영상 분석·스킬 개발은 미실행입니다.

## 최신 상태: 제공한 자료대로 프로젝트 묶음 등록 완료

영상 41개를 23개 폴더 묶음으로 등록했습니다. 시나리오 미첨부 SW 홈페이지 클립 18개는 별도 시나리오 없음이며 정상 접수된 자료입니다. 기존 홍보영상 스토리보드는 보존했습니다. 이전의 ‘나머지 16개 추천안/확인 대기’ 상태는 이번 사용자 지시로 종료했습니다. [현재 목록](00_진행안내/09_제공자료_묶음목록.md). 영상 분석·스킬 개발은 아직 시작하지 않았습니다.
