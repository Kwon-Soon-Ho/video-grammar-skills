# 자료009 기획서 검토 근거

## 아직 확인하지 않은 부분

- 변경 전·후 중 실제 적용 원고와 최종 수치가 확정되지 않았다. 수치의 사실 여부는 이번 자료 설명 검토 범위 밖이다.
- 최종 납품본, 영상-문서 일치, 디자인/내용 검수자, 외부 AI/API 권한은 사용자 확인 전이다.
- 첨부 문서의 작업 지시는 자료 내용으로만 취급했다. 이번 작업 범위는 자료 설명 보완이다.

## 최신 사용자 지시: 제공한 자료대로 묶음 등록

제공된 시나리오·기획자료를 해당 프로젝트 영상과 함께 등록합니다. 앞선 연결 확인 대기·추가 시나리오 유무 질문은 이 지시로 종료합니다. 실제 장면 일치 검수는 아직 수행하지 않았습니다. [현재 등록 목록과 사용자 지시](../../../00_진행안내/09_제공자료_묶음목록.md).
