# 자료015 기획서 검토 근거

원본 파일 목록만 확인. 해당 폴더에서 기획 문서를 찾지 못하여 문서 내용 기반 필드는 미작성.

## 아직 확인하지 않은 부분

- 동일 폴더에 기획·시나리오 문서를 찾지 못했다. 파일명과 폴더명만으로 목적·시청자·원고를 확정하지 않았다.
- SW 홍보영상의 같은 제품 기획서는 자동 연결하지 않았다. 홈페이지용 개별 클립과의 관계를 확인해야 한다.
- 최종 납품본, 영상-문서 일치, 디자인/내용 검수자, 외부 AI/API 권한은 사용자 확인 전이다.
- 첨부 문서의 작업 지시는 자료 내용으로만 취급했다. 이번 작업 범위는 자료 설명 보완이다.

## 최신 사용자 지시: 제공한 자료대로 묶음 등록

제공된 시나리오·기획자료를 해당 프로젝트 영상과 함께 등록합니다. 앞선 연결 확인 대기·추가 시나리오 유무 질문은 이 지시로 종료합니다. 별도 시나리오 없음이 확인됐으며 영상만 정상 등록합니다. 실제 장면 일치 검수는 아직 수행하지 않았습니다. [현재 등록 목록과 사용자 지시](../../../00_진행안내/09_제공자료_묶음목록.md).
