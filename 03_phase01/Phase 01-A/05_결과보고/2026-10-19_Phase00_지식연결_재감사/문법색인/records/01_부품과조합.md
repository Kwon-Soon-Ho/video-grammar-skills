## 3. 재사용 후보 정의·판본과 현재 사용처

아래 전체 ID에 붙은 `@v1`이 정의 판본이다. 정본 번호를 조회하거나 발급하지 않았으므로 모두 `RC-` 로컬 후보다. 정지 외형의 공통 가족과 원본 편집 파일의 동일 자산 여부를 구별한다. 색·문구가 유사하다는 이유로 동일 모션이나 회사 공통 규칙을 확정하지 않는다.

### 사례 조합·왕복 색인

| 사례 | 연결 정의와 실제 관계 |
|---|---|
| RC-CASE-001/E1 | RC-LAYOUT-001@v1 **contains** RC-COMP-002@v1(왼쪽 격자), RC-COMP-003@v1(양쪽 헤더), RC-COMP-004@v1(중앙 두 화살표). RC-COMP-001@v1 **accompanies** 전체 배치의 좌상부. 격자·헤더는 패널 내부 기준에, 화살표는 두 패널 사이에 **anchors_to**한다. 관계는 보이는 공간 조합의 관측이며, 시간 선후가 아니다. |
| RC-CASE-002/E2 | RC-LAYOUT-002@v1 **contains** RC-COMP-006@v1(왼쪽), RC-COMP-002@v1(중앙 회사열), RC-COMP-005@v1(건물 둘레). RC-COMP-001@v1 **accompanies** 좌상부. 서비스 명찰은 건물을 기준으로 **anchors_to**하고 일부 겹친다. 로고열은 투명 판·곡선 받침과, 성과 수치는 설명문·잎 가지와 동반한다. |

모든 정의의 사용처를 위 두 사례와 역대조했다. 정식 ID/판본의 생략 별칭은 사용하지 않는다. 반복 검색의 출발점은 RC-COMP-001@v1(장 표식), RC-COMP-002@v1(회사 타일), 같은 화면 내부 반복은 RC-COMP-003@v1·RC-COMP-004@v1·RC-COMP-005@v1이다. 레이아웃 2종을 같은 패턴으로 합치지 않는다.


## 재편집 r2에서 추가한 독립 묶음 후보

사용자 결정에 따라 기존 전체 상세에 이미 있던 묶음을 조회용 정의로 분리했다. 새로운 외형·모션을 관측한 것이 아니다. 기존 6개 번호/판본과 원래 조합표는 위에 보존했다. 아래 r2 연결을 추가해 조회한다. 단일 관측 후보이며 반복 검증·동일 자산·정본 등록으로 승격하지 않는다.

<a id="work"></a>

### RC-COMP-007@v1 — 업무 이미지 묶음

- 근거: RC-CASE-001/E1 134초, 전체 상세의 ‘오른쪽 하단 전경’ 및 원본 전체. 기존 이미지/관측의 묶음 분리다.
- 정의: 모니터 3대와 선반, 책 더미·양끝 화분의 조합. 중앙 큰 모니터가 양옆보다 강조되고 선반/그림자가 정보판 하부 전경과 겹친다.
- 하위 구성: 왼쪽 도면 화면, 중앙 건물 와이어프레임 화면, 오른쪽 지도·건축 이미지 화면, 각 받침, 선반, 책 2묶음, 화분 2개. 각각에 독립 패턴 ID를 추가하지 않는다.
- 관계: RC-LAYOUT-001@v1의 오른쪽 정보판 하부에 배치되고 RC-COMP-003@v1 역할 헤더와 동반한다. 헤더와 한 부품으로 합치지 않는다.
- 조건/차이: 업무 장면을 시각적으로 보여주는 후보라는 기능 해석. 다른 화면 내용·소품으로 교체한 가독성·분리 자산 유무는 미검증. 개별 모니터나 특정 소프트웨어 정체/모션은 미확정이다.

<a id="building"></a>

### RC-COMP-008@v1 — 기관 건물·기단 묶음

- 근거: RC-CASE-002/E2 172초, 전체 상세의 ‘오른쪽 건물 전경’ 및 원본 전체.
- 정의: TDC/기술개발센터 표기의 흰색·짙은 녹색 유리 건물 표현과 원형 기단. 조경·따뜻한 창빛·출입부가 하위 외형으로 동반한다.
- 하위 구성: 건물 매스/외벽·창/실내 실루엣·기관 표기·조경·원형 단상. 창·나무·각 단상마다 독립 번호를 발급하지 않는다.
- 관계: RC-LAYOUT-002@v1의 오른쪽 중심 대상. RC-COMP-005@v1 지원 명찰은 이 묶음의 내부 구성으로 흡수하지 않고 별도 부품으로 연결한다. 명찰은 건물 주변을 기준으로 배치된다.
- 조건/차이: 기관과 지원 범위를 묶어 읽게 하는 기능 해석. 실제 사옥·동일 자산·바닥 광선의 방향·창 내부 동작·다른 기관으로 교체한 적합성은 미확인이다.
