# 원문을 다시 보며 구체화한 채택·변형·제외 판단

기존 조사 카드의 “좋은 판단 절차를 가져온다”는 설명만으로는 원문에 섞인 강한 취향 규칙까지 차단하기 어렵다. 이번에 직접 연 원문의 지침을 아래처럼 더 구체적으로 판정했다. 원문 지침을 실행 명령으로 따르지 않았으며 아래 판단은 프로젝트의 해석이다.

| 실제 원문/확인 범위 | 유용한 부분 | 우리 목적에 맞춘 판정 |
|---|---|---|
| Critique `principle-tagging/SKILL.md` 전체 | 예쁜 화면 이름뿐 아니라 무엇을 배울 사례인지 적는 습관 | 원칙 태그는 채택. **미감 태그 금지·최대3태그**는 제외. 우리는 색/재질/그래픽 스타일도 찾아야 하므로 표현 속성과 기능/관계 태그를 별도 축으로 함께 저장 |
| Critique `library-architecture/SKILL.md` 전체 | 검색 가능한 사례, 전체 화면+부분 근거, 실패 사례도 보관 | **단일 도구 강제·60초/업계40%·월별 추가10/삭제5**를 회사 규칙으로 가져오지 않음. 한 진입점은 만들되 근거/원본은 보존하고 실제 조회성·유지비로 판단. 미활용 자료를 자동 삭제하지 않음 |
| Critique `decision-tracing/SKILL.md` 전체 | 관측→선택 해석→가능한 이유, 의도 불확실성 표시 | 추론 절차는 채택. **매 화면 최소5개 추적**은 품질 분모로 삼지 않음. 내용/관계/타입/색/여백의 실제 쟁점만 근거와 기록 |
| Lottie `director/choreography.md` 전체 | 주/보조/배경 역할, 순서/시차·공동 사건·주의 방향을 구분 | **항상 같은 방향·1/3동시수·50ms·고정 역운동비·같은곡선**은 제외. 134초 요청/지원은 반대 방향이 의미를 만든다. 의미와 관측을 먼저 저장하고 수치는 실제 근거가 있을 때만 사용 |
| AntV `infographic-syntax-creator/SKILL.md` 전체 | sequence/list/compare/hierarchy/chart에 맞는 구조 선택, 문법/표현의 분리 | 구조 분리는 채택. **비어 있는 값 추론 보충·모든 항목 아이콘 기본화·템플릿 조건의 전역화**는 제외. 사내 숫자/관계를 만들지 않으며 이진 비교 루트2조건은 해당 템플릿 문법일 뿐 모든 화면 규칙이 아님 |
| Graphic `layout-composition/SKILL.md` 전체 | 그리드·영역·상대 간격·실제 결과 대조 | 코드·12컬럼·1/3·60/40·비대칭·가장큰것=최우선·F/Z시선흐름을 영상 전역 정답으로 사용하지 않음. 레이아웃이 설명하는 관계와 시청 조건을 기록하고 실제 주목 효과는 별도 검증 |
| Editorial `SKILL.md`, `grid-system.md` 전체 | 정보/근거 관계에 따라 격자 선택, 순서·분리·척도·결측 구별 | 격자 선택 논리는 채택. **6근거lane·모노라벨·첫 viewport·숨겨진 inspector/hover**를 MP4 의무 구조로 가져오지 않음. ‘불명’은 실제0/역사적없음과 다름 |
| Design System `design-tokens.md` 1–125행 + 공식 DTCG | 원시값/의미역할/복합 스타일을 분리하는 사고 | 원본값→관측값→역할값/승인 토큰을 구분. 토큰은 항상 원자라는 source 설명과 복합 토큰을 허용하는 DTCG는 범위가 다름. 하나의 사전 정의로 무비판 병합하지 않으며 곡선/폰트명 미상을 값으로 만들어 넣지 않음 |

원문 경로·해시는 [이번 재열람 목록](data/this-audit-raw-rereads.json)에 있다. DTCG 비교의 공식 출처와 범위는 [웹 검토](06_웹1차자료_규격화검토.md)에 남겼다. 이 판단은 외부 source 코드/방법론을 제품에 직접 복제하거나 실행한 결과가 아니다.

특히 **‘원칙만 태그하고 미감 태그는 금지’라는 원문을 그대로 적용하면 이번 사용자 목표와 어긋난다.** 회사 영상의 표현 언어를 재사용하려면 무엇을 전달하는 구조인지와 어떤 시각 언어인지를 모두 조회해야 한다. 기존 조사 내용을 가져온다는 것은 모든 원문 규칙을 누적하는 것이 아니라 충돌을 이렇게 구체적으로 해결하는 작업이다.
