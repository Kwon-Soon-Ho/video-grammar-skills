| SUBLAYOUT-001 / 2열×4행 로고 격자 | A05, 타일 여백·행열 정렬로 8개 조직 | B04의 한 줄 배치는 이 격자 반복이 아님 | 요소 수가 바뀌는 재배치 규칙 미상 |
| SUBLAYOUT-002 / 원근 가로 로고 열 | B04, 8타일과 곡선 받침·뒤 판을 한 그룹으로 구성 | SUBLAYOUT-001과 같은 로고 집합 후보를 다른 배치로 표현 | 8개 로고가 동일한 시간에 등장/움직였는지 미상 |
| SUBLAYOUT-003 / 중심 대상 주위 역할 표지 | B05를 중심으로 B06–B09가 위·좌·우·앞에 분산 | A10 두 아이콘의 가로 나열과 관계가 다름 | 중심 대상·네 역할이 유지되는 조건의 후보. 정확 연결선·좌표·우선순위 의도 미상 |
| PAT-LAYOUT-001 / 전체 화면 | 상단 공통 표지·우상단 제목 + 좌우 패널 + 중앙 반대방향 화살표 + 밝은 물결 배경 | CASE-001 전체에만 관측 | 쌍방 역할의 시각 표현이라는 해석은 추론. 172초 전체에 반복 적용하지 않음 |
| PAT-LAYOUT-002 / 전체 화면 | 상단 공통 표지 + 좌측 설명/성과숫자 + 가운데 로고열 + 우측 센터건물/서비스 표지 + 금빛 공간 | CASE-002 전체에만 관측 | 성과와 참여 주체/지원 분야를 한 공간에 묶는 구조라는 해석은 추론. 새 성과값·브랜드·화면비 미시험 |

번호 분리 이유: 전체 레이아웃 두 개는 정보의 배치 관계가 달라 별도다. 로고는 정체가 반복되어도 격자와 원근 열의 배치는 분리한다. 색·문구·배치 정도가 바뀐 서비스 표지 네 개나 패널 제목 두 개는 각각 동일 부품의 변형으로 연결한다. 금빛 잎 하나·반사선 하나·각 창문마다 독립 번호를 만들지 않고 전체 사례의 장식/내부 구성에 보존했다. 범용 재사용 가치가 있다고 판단할 근거가 부족한 미세 요소를 새 패턴으로 늘리지 않았다.

|---|---|---|---|
| PAT-FLOW-001 / CASE-001 흐름 조사 슬롯 | A03–A12 | 134초 한 화면에서 두 패널·화살표·내용이 함께 보임 | 등장·강조·퇴장 순서, 패널과 내부의 중첩 시간, 유지 시간 모두 미상. 해당 화면 전후 연속 근거 필요 |

위 FLOW 번호는 흐름을 분석했다는 완료 번호가 아니라 미확인 범위를 연결하는 로컬 조사 슬롯이다. 현재 재사용 가능한 모션 정의는 확정하지 않았다. 한 시각에서 변화가 보이지 않는다는 사실은 정지/유지 동작의 증거도 아니다. 위치·크기·밝기·가시성·내부 상태의 시간 변화 및 각각의 가감속은 전부 미확인이다.

## 5. reuse_map — 사례의 조합 관계

시간 순서와 정적 포함·배치 관계를 혼동하지 않도록 아래 관계는 시간의 선후를 뜻하지 않는다.

|---|---|---|---|

`contains`, `anchors_to`는 보이는 정적 관계다. `precedes`, 시간적 `overlaps`, 시간적 `accompanies` 관계는 현재 근거에서 만들지 않는다. 화면에 동시에 보인다는 사실과 등장 이벤트가 동시라는 판단은 다르다.

## 6. 반복 판정과 재사용 인계

- **지지되는 반복:** CMP-001의 장 표지 구조·주요 문자, 두 화면의 회사 로고 집합 후보, `BIM 설계`·`BIM 지원` 문구. CASE-001 내부의 아이콘+제목+설명 구조, CASE-002 내부의 흰 서비스 표지 네 개도 각각 반복 형태로 관측된다.
- **이번 차이:** 전체 정보 배치가 쌍패널 교류도에서 성과숫자–로고열–센터 공간으로 달라진다. 로고 배치는 2×4 격자→원근 가로열이며 HALLA/피티씨의 읽기 순서가 바뀐다. 우측 표현은 모니터 작업 장면→센터 건물로 달라지고, 서비스 명칭은 기존 두 BIM 항목에 디자인/해외사업 지원이 추가된 상태다. 이 차이는 E01/E02의 상태 비교이며 변화 과정의 증거가 아니다.
- **별도 유지:** CASE-001의 파랑/녹색 화살표와 CASE-002의 금빛 가는 곡선, 평면 둥근 패널과 건물 플랫폼을 같은 동작 단위로 합치지 않는다. 아이보리·금빛 계열 분위기의 유사성만으로 동일 배경 자산이나 회사 공통 스타일 규칙을 확정하지 않는다.
- **재사용 시 보존할 정보:** 전체 사례 링크, 로고 정체와 표시 순서, 요청↔지원의 반대 역할, 서비스 명칭, 성과 숫자의 단위·소수점과 설명 문장의 산정 기준. 다른 문구·요소 수·화면비에서 가독성·배치 적합성은 미시험이다.
- **열린 쟁점:** U01 작은 로고 법인명·책등/화면 내부 문구 원본 ROI 판독, U02 세부 경계/폰트/색/간격 측정, U03 각 화면 전후 등장·퇴장·중간 상태·동시 사건, U04 숫자·선·빛·건물 내부·모니터 내부 변화, U05 추출 로그 및 원본 시간 매핑 독립 대조. 추가 추출·새 제작은 이번 요청에서 수행하지 않는다.

이번 묶음은 제공된 두 전체 화면의 정적 수집과 로컬 분류까지다. 모션 검수·원본 전체 분석·정본 DB 형식 접수·회사 승인·새 화면 제작은 완료 범위에 포함하지 않는다. 사용자 요청에 따라 JSON·PDF·라이브러리 파일을 만들지 않고 이 Markdown으로만 남겼다. 다음 확인은 위 U01–U05의 근거가 제공되거나 별도 작업을 요청받을 때 이어갈 수 있다.
