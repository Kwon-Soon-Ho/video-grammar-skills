# Anthropic skill creator 적용

사용자 지정 anthropic-skill-creator로 전환했다. 설치된 SKILL.md와 schemas/grader를 읽었다. 기본 Codex 지침은 패키지 호환성과 범위 점검에 참고하되 이번 작성·평가 루프는 Anthropic 방식이다.

원래 스킬 이름과 UI 호출 정책을 유지한다. 기존 draft.9 전체 19개 파일을 로컬에 해시 백업했다. 수정 후보는 draft.10이며 기본 수집을 Markdown으로, JSON을 선택적 호환 경로로 바꾼다.

평가 1: 다른 구간의 원본 세 표본에서 새 수집 기록.
평가 2: 원본 두 화면의 반복 부품과 차이 연결.
두 과제를 구버전과 수정판에 같은 입력/프롬프트로 각각 맡긴다. 실행 에이전트는 새 문맥으로 시작하고 기존 분석·정답·수정 이유를 제공하지 않는다. 동시 실행 슬롯은 최대 3개이므로 남은 실행은 슬롯이 비는 즉시 시작한다.

이 비교는 각 과제/판본 1회 개발 시험이다. 회사 품질 승인이나 일반 성능·재현성 입증이 아니며 여러 회차 분산은 측정하지 않는다. 실행 도구가 실제 토큰/모델 ID를 공개하지 않으면 미상으로 남긴다.

기록은 Markdown, 평가 도구의 입력·점수·뷰어용 내부 파일만 JSON이다. PDF·새 화면·AE 제작은 없다.
