# 01-A 진행 계획 정리 보고

2026-10-16 / 계획 검토 대기

Phase 00의 현재 안내·R4 통합 v0.2·R7 평가 계약·R8 후보 세 스킬과 소량 사본 사용 범위, 실제 입력자료 등록 및 사용자 답변을 읽고 진행 계획을 작성했습니다.

장헌 경영보고와 시나리오 없는 EG-BIM 홈페이지를 초기 예비로, 복합 모션·홍보·변형판을 확대 예비로 제안했습니다. TOVA 홈페이지·K-GEO는 별도 확인 후보이며 아직 잠금하지 않았습니다. 문서 사전 노출·같은 시리즈/변형판·재구성 원고의 독립성 한계를 공개했습니다.

기존 관리용 스킬과 새 영상 분석 스킬을 구분하고 단계별 자체검수·레드팀·보완/재시험·사람 검수·보고 계획을 만들었습니다. 수치 기준과 최종 표본 수는 예비 후 검토하도록 미정으로 뒀습니다.

현재 계획 자체를 반대 관점으로 검토해 무문서 입력 누락, 사후 원고를 정답으로 쓰는 문제, 원본 그룹 유출, 형식 통과와 실제 정확성 혼동을 보완했습니다. 독립 검토자/영상 실험을 실행한 것은 아닙니다.

영상 파일은 열지 않았고 프레임 추출·OCR·전사·API 시험·스킬 생성·기본 전환은 하지 않았습니다. 02_분석작업·03_분석스킬·04_검증자료 예약 폴더를 유지했습니다. Phase 00 정본/고정 참조는 변경하지 않았습니다.
