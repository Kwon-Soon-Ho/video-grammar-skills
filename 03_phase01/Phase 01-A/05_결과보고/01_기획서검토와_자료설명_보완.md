# 기획서 사전 검토와 자료 설명 보완

2026-10-16 / Phase 01-A 착수 전 자료 준비

19개 자료 묶음에 문서의 목적·주제와 확인 가능한 구성 계획을 채웠다. 홈페이지용 4개 묶음은 같은 폴더에 기획서가 없어 확인 대기로 표시했다. 총 23개 자료 설명을 갱신했으며, 각 묶음에 출처·원문 위치·파일 해시와 읽기 한계를 따로 남겼다.

## 무엇을 읽었나

- Office/PDF 72개(backup 22개 포함): Word 34, PPT 23, HWP 10, PDF 3, Excel 2. 본문 텍스트가 있는 64개에서 추출했다. 이전 backup은 버전 참고로만 보존했고 현재 주 문서로 채택하지 않았다.
- 이미지형 PPT 7개: 정지 이미지 26개를 추출했다. 표지의 회사명·2026 경영보고 제목을 확인했으며 전 슬라이드 수치를 검증하지 않았다.
- 장헌산업 수정 스캔 PDF 1개: 3쪽의 계약·매출·자금집행 수정 표시를 확인했다. 읽기 어려운 손글씨는 옮기지 않았다.
- 큰 PNG 기획 보드 2개: 700/577메가픽셀 크기라 행 띠 단위로 읽어 축소 전체도를 만들었다. 제목·회사별 묶음·큰 구획만 확인했다. 작은 원고·세부 수정 문구는 미검토다.

본문 추출은 전체 내용의 정확성·모든 표 셀의 문맥·시각적 레이아웃·실제 영상과의 일치를 검증했다는 뜻이 아니다. 이번 자료 설명에 들어간 주장만 출처 위치와 대조했다.

## 사람이 확인할 부분

[사용자 확인 모음](../00_진행안내/04_사용자확인_모음.md)에 영상 후보·문서 후보를 자료ID별로 모았다. 최종 영상, 주 문서와 대응 관계, 실제 시청 환경, 검수 담당, 외부 처리 가능 범위는 미확인 상태다.

가족사 7곳의 v4 Word는 ‘최종 영상을 TTS와 원시 데이터로 정리’했다고 서술한다. 제작 전 시나리오로 단정하지 않았다. 공유 검증표의 과거 검수 주장을 이번 결과로 재사용하지 않았다. 초기 한라 보고서(DOC022)의 ‘“1급” 대외비 문서’, 가치창출 PDF(DOC062)·한번 생각해 봅시다 HWP(DOC072)의 ‘대외비(2등급)’ 표시는 해당 문서 단위로 기록했다. PG 제작 의견의 규격 불일치도 확인 대상으로 남겼다.

## 검토와 보완

별도 독립 평가자를 실행한 것은 아니며, 작성 후 반대 관점의 자체 점검을 했다.

1. 계획 시간을 실제 영상 길이로 오인할 가능성 → 모든 시간값에 계획/예정·실제 영상 미확인을 명시했다.
2. 파일명 최종/v4를 승인으로 오인할 가능성 → 선택·대응·승인 필드를 미확인으로 유지했다.
3. 사후 작성 원고를 독립 정답으로 쓸 가능성 → 문서 성격을 질문으로 분리했다.
4. 같은 제품 홈페이지와 홍보영상을 강제로 연결할 가능성 → 4개 홈페이지 묶음은 문서 부재로 유지했다.
5. 이미지에 텍스트가 없다고 기획서 없음으로 오인할 가능성 → 가족사 소개 PNG를 문서 후보로 포함하고 제한적 시각 확인 범위를 기록했다.
6. HWP 문단의 연결·숨김 Excel 열·스캔 손글씨를 과신할 가능성 → 레이아웃·서식·모호한 문구를 확정하지 않았다.
7. 작성자·제안자 이름을 검수 책임자로 오인할 가능성 → 담당자 미정 유지.
8. 문서의 작업 지시·검증 주장을 이번 사용자 지시/검증 결과로 오인할 가능성 → 자료 내용으로만 기록했다.
9. 초안이 가치창출 PDF의 대외비 표시만 강조한 누락 → 전체 추출 텍스트를 재검색해 DOC022·DOC072도 발견하고 해당 자료 설명·질문 목록에 보완했다. 표시가 없는 자료를 공개 가능으로 판단하지 않았다.

2차 점검은 실제 게시 전후에 출처 인용·로컬 링크·원본 불변·변경전 백업·작업 범위에 맞춰 수행하고 자동 검사 결과를 별도 기록한다. 의미·출처 대응은 위 자체 검토의 범위이며 영상과 내용 일치는 미검증이다.

## 보존과 범위

원본 ‘한맥 영상’의 파일은 이동·수정하지 않았다. 수정 전 자료 설명과 안내는 backup/2026-10-16_기획서검토에 보관한다. 최초 등록 CSV·JSON, 이전 준비 결과, Phase 00 정본·스킬 기본 설정은 변경하지 않는다.

영상 파일은 열기·재생·프레임 추출·ffprobe·OCR·전사하지 않았다. 실제 분석·새 스킬 개발·기본 전환·외부 업로드·평가 표본 배정은 진행하지 않았다.

검토 추출물은 로컬 보존용이며 원본과 동일하게 사내 자료로 취급한다. 일반 공유 문서로 게시하거나 외부 서비스에 올리지 않았다.
