## 3. 시간순 상태와 세부 동작의 한계

로컬 흐름 후보 `LOCAL-FLOW-01/v1`은 **세 표본의 순서 기록**이다: E192 절감 요약 → E204 제품 상세·두 절감 사례·하단 업무 이미지 중첩 → E216 업무 이미지·산정 유보 안내. 192 이전과 216 이후를 이 흐름의 시작·끝으로 닫지 않는다.

| 대상 | E192 → E204 → E216에서 확인된 차이 | 미관측 동작 |
|---|---|---|
| 장 표식/제목 | 세 장에 같은 장 맥락 | 표본 사이 위치·밝기·내부 변화, 등장/퇴장 |
| 카탈로그/허브 | 앞 두 장에 가시 / 세 번째는 업무 이미지와 제품 카드로 구성 변경 | 카탈로그 이동·축소·가림 방식, 허브 퇴장, 선/꺾쇠·타일 운동 |
| 오른쪽 본문 | 11.5억 요약 → EG-BIM 상세·성과 2개 → 보수적 산정 안내 | 교체 경계·중간 문구·전환 방식·겹침 길이 |
| 배경/업무 이미지 | E204 하단에 중첩 / E216 왼쪽에서 명확 | 이미지 출현 방향·마스크·블렌딩, 실제 인물/손 동작 |
| 숫자/그래프/도상 | 각 표본의 숫자·막대 모양·도상 확인 | 카운트업, 숫자와 막대의 선후·동시 완료, 강조 반복·광점 이동 |

시각 사이 내용이 다르므로 상태 변화는 확인되지만 속도·이징·회전·페이드·동시 시작/완료는 판정할 수 없다. 외곽이 비슷한 E192/E204에서도 내부가 연속 정지했다고 볼 근거가 없다. 독립 세부 **모션**은 이번 자료로 관측 패턴을 확정할 수 없어 새 번호를 만들지 않았다.

## 4. 다음 조회를 위한 로컬 재사용 색인

모두 수집 후보이며 공식 PAT 번호·라이브러리 해시를 부여하지 않았다. 정의 판본은 아래 정식 표기 그대로 `v1`이다. 동일 부품의 재사용 구현이나 회사 공통 규칙을 확인한 것이 아니다.

| 정의 ID/판본 | 구성·현재 근거·차이 | 적용 조건과 남은 확인 |
|---|---|---|
| `LOCAL-LAYOUT-01/v1` 카탈로그–허브–설명판 | E192/E204. 왼쪽 2×3 제품 카탈로그, 중앙 연결 허브, 오른쪽 주제 판을 조합. E204는 오른쪽 판의 면적/내용이 달라지고 아래 업무 이미지가 겹침 | 다제품 개요와 우측 상세/성과를 함께 제시할 때 검색 후보. 선을 개별 금액의 일대일 대응으로 쓰지 말 것. 다른 항목 수·화면비·가독성 미시험 |
| `LOCAL-LAYOUT-02/v1` 업무 이미지–다층 안내판 | E216. 왼쪽 업무 이미지와 주변 제품 카드 6개, 오른쪽 제목→제외 이유/추가 조건→현재 결론 띠 | 산정/범위의 유보 조건을 큰 제목과 분리해 설명하는 구조. 인물·제품 이미지와 안내 내용의 관계를 다시 확인해야 함. 도입/퇴장 미관측 |
| `LOCAL-FLOW-01/v1` 표본상 성과→상세→산정 유보 | 위 3절이 정의. E204의 동시 중첩과 장 표식의 반복 가시성을 함께 보존 | 의미 순서 검색에 사용 가능. 실제 컷 순서 전체·타이밍·전환·리듬 재사용의 근거로는 부족 |
| `LOCAL-COMP-01/v1` 금액 성과 카드 외형 가족 | E192 큰 단일 금액 면; E204 같은 높이의 두 사례 카드. 큰 금액/작은 단위·설명·옅은 면을 공유하나 제목·도상·면적·항목 수가 다름 | 단일 총량과 사례별 비용을 구별할 때 조회. 세 금액을 같은 집계로 확정하지 않음. 모든 숫자 변경은 내용 기준 별도 확인 |
| `LOCAL-COMP-02/v1` 제품 식별 카드 외형 가족 | E192 카탈로그 내부 6장과 E216 모니터 둘레 6장. 동일 여섯 명칭; E216은 관련 그림·빛 외곽, E192는 설명문·꺾쇠가 중심 | 여러 제품의 정체성과 배열 비교용. 공통 외형 가족 수준이며 같은 렌더 부품·같은 진입 모션은 미검증 |

조합 연결: `LOCAL-LAYOUT-01/v1`은 `LOCAL-COMP-02/v1`의 E192 카탈로그 사용처와 `LOCAL-COMP-01/v1`의 E192/E204 성과 사용처를 포함한다. `LOCAL-LAYOUT-02/v1`은 `LOCAL-COMP-02/v1`의 E216 분산 사용처를 포함한다. `LOCAL-FLOW-01/v1`은 두 레이아웃의 관측 순서를 연결한다. E204의 업무 이미지와 카탈로그 **중첩**은 관측이며, 연결 허브가 제품과 성과를 개념적으로 매개한다는 관계는 기능 해석이다. 어느 개별 카드가 어느 선에 붙는지는 미확정이다.

원본 언어·외관을 유지할 때는 문구·배치·층을 이 기록과 함께 조회한다. 다른 스타일로 활용할 때도 총량/사례별 지표·미반영 조건·미관측 동작을 분리하는 정보 관계는 보존해야 한다는 **적용상 판단**이다. 실제 다른 주제 적용 시험은 하지 않았다.
