# 사용자 결정 반영: 기록 구조와 묶음 조회

2026-10-19 사용자 선택 두 건을 반영한다.

1. **사례 요약 → 상세 → 근거**. 정보 관계·전체 구도·디자인 언어·핵심 미상을 먼저 읽고 부품·수치·좌표·검수 이력은 연결해 본다. 상세 관측과 원본 근거는 보존한다.
2. **묶음을 독립 조회하고 내부 요소 연결**. 업무 이미지 묶음, 건물/기단 묶음을 독립 후보로 찾는다. 모니터·소품은 하위 구성, 지원 명찰은 별도 부품으로 연결한다.

피드백은 이 두 가지 설계 선택에 대한 것이다. 내용 정확도·미상 정책 전체·스킬 성능·실제 사용판 교체·전편 확장·정본 등록을 승인한 것으로 확대하지 않는다.

Anthropic skill creator의 피드백→후보 수정→실제 과제 비교 절차를 계속 사용한다. 기존 후보 draft.11을 전체 백업한 뒤 별도 draft.12를 만든다. 실제 사용판 draft.10은 유지한다. 원본 내용 오독 대응은 이번 형식/묶음 개선과 구별하며, 새 후보가 오독 문제까지 해결했다고 선결하지 않는다.

작업 범위: 후보 지침 변경, 기존 134/172초 사례의 재편집 및 두 묶음 후보 연결, 같은 두 과제의 draft.11/12 실행과 결과 확인. 새 영상 구간·새 화면 제작·PDF는 포함하지 않는다. 재편집 기록과 독립 실행 결과를 서로 구별한다.

재편집 결과는 records/00_사례요약.md부터 읽는다. 원기록 전체 사본은 해시가 일치하며, 두 사례 상세·기존 6개 정의/조합·모션 미관측 조사 항목은 원문 블록을 그대로 보존했다. 새 로컬 후보 RC-COMP-007@v1(업무 이미지)·RC-COMP-008@v1(건물/기단)을 추가하고 기존 RC-COMP-005@v1 명찰과 분리해 연결했다. 상세 이관 감사는 record-migration-audit.json이다.

검사: 표준 형식·기존 JSON 판본의 역사 읽기와 현행 draft.12 경계·잘못된 해시 거절·로컬 문서/앵커 48개·재편집의 10개 정의 ID(배치 2+부품 8) 연결을 확인했다. 이 검사는 픽셀·문구·도상의 의미 정확성을 증명하지 않는다.

비교 실행은 원래 사용자 과제와 raw PNG/입력 명세만 새 문맥 실행자에게 제공했다. 기존 기록·정답·평가 기준은 제공하지 않았다. 슬롯 제한으로 세 실행을 먼저 시작하고 하나가 끝나자 네 번째를 시작했다. 추가한 평가 3개는 요약/상세/근거의 실질적인 읽기 순서·정보 보존·독립 묶음/하위 구성/명찰 연결이다. 기존 원본 대조 9개와 따로 해석한다. 한 과제/판본 1회이며 일반 성능·creator 간 우열·전체 발견률로 확대하지 않는다.

최종 확인에서는 로컬 링크·앵커 50개가 통과했다. 별도 새 문맥 평가자 2명이 실제 원본과 두 판본의 출력을 각각 비교했다. 두 과제 모두 이전 후보는 원본/연결 9/9·구조 1/3, 새 후보는 원본/연결 9/9·구조 3/3이었다. 이전 판본의 상세 보존은 인정하고 요약 부재를 10/11번에서 중복 감점하지 않았다. S/W 요약의 금액 소유자 가독성은 별도 개선점이다.
