# 사용자 결정 반영 — 기록 구조와 묶음 조회

**사례 요약 → 전체 상세 → 근거**와 **독립 묶음 → 하위 구성 → 배치 연결**을 후보 draft.12에 반영했다. 실제 사용판은 draft.10으로 유지한다. 이전 후보 draft.11과 과거 결과·평가를 보존한다.

## 먼저 볼 실제 기록

[134·172초 사례 요약](records/00_사례요약.md)에서 시작한다. 요약은 전체 구도·정보 관계·디자인 언어·핵심 미상을 먼저 보여준다. [부품/조합](records/01_부품과조합.md), [전체 상세](records/02_전체상세.md), [모션 조사](records/04_모션조사.md), [근거/검수](records/03_근거와검수.md)로 내려갈 수 있다.

이 자료는 **기존 기록의 재편집 r2**다. 원기록은 해시가 같은 사본으로 보존했고, 두 사례 관측·기존 6개 정의/조합·모션 미관측 조사 블록을 그대로 이관했다. 이를 독립 실행이나 새 영상 검수로 보고하지 않는다. [이관 확인](record-migration-audit.json).

| 사용자 결정 | 실제 반영 |
|---|---|
| 요약부터 보기 | 역할 관계·구도·디자인 언어·중요 수치/단위·상태 한계를 앞에 두고 해시·좌표·검수 이력은 공통 근거 문서로 연결 |
| 업무 이미지 묶음 독립 조회 | `RC-COMP-007@v1`: 모니터 3대+선반+책/화분. 내부 구성은 설명으로 보존하고 소품마다 번호를 추가하지 않음 |
| 건물/기단 묶음 독립 조회 | `RC-COMP-008@v1`: 기관 건물·원형 기단. 창·조경·표기는 하위 구성 |
| 명찰 별도 연결 | 기존 `RC-COMP-005@v1`을 유지하고 건물 주변 배치로 연결. 건물 내부 구성에 흡수하지 않음 |

배치 2개+부품 8개를 현재 기록에서 조회할 수 있다. 새 2개는 이미 보인 묶음의 분리 후보이며 반복 검증·동일 소스 자산·정본 등록을 뜻하지 않는다. 다른 영상에서의 분류는 실제 독립 검색/교체 가치와 근거에 따라 판단한다.

## 후보 스킬과 확인 범위

후보 지침은 요약/상세/근거의 읽기 순서와 보존 원칙, 독립 묶음/하위 구성/별도 명찰의 구분을 추가했다. 특정 회사명·수치·정답 도상을 외워 넣지 않았다. JSON 관측 schema 0.4는 유지하며 판본 호환 경계만 draft.12에 맞췄다. UI 호출 정책과 정본 DB는 변경하지 않았다.

표준 스킬 형식, JSON 역사 판본/현행 분리, 잘못된 해시 거절, 로컬 링크·앵커, 재편집 정의/사용처 연결을 확인했다. [검사 결과](validation-summary.json). 이 검사는 문구·도상 정확도나 전체 영상 발견률을 증명하지 않는다. 사용자 선택은 프로젝트 공통 기록 규칙에도 남긴다.

별도 실행 결과는 [실제 출력 비교 페이지](review.html), [과제별 판정](company-video-grammar-analyzer-workspace/iteration-3/benchmark.md)에 있다. 이번 `with_skill`은 draft.12, `old_skill`은 draft.11이다. 이전 결과 표시의 라벨은 당시 판본을 뜻하므로 판본을 함께 확인한다. 사용자 검토용 재편집 자료와 실행자가 스킬을 적용한 출력은 별도 파일이다.

평가에서는 기존 원본/참조 9개와 새 구조/묶음 3개 기준을 따로 읽는다. 이번 12개 총점을 이전 9개 총점과 직접 비교하지 않는다. 판본/과제별 1회, 알려진 다섯 정지 표본이며 독립적인 일반 성능·전편 검수·creator 간 우열 시험이 아니다. AI 평가자는 판본 경로를 알고 있고 실행 과정은 완전한 transcript가 아닌 자기보고다. 정확한 모델/토큰/시간 수치를 추정하지 않았다.

| 과제 | 이전 후보 draft.11 | 수정 후보 draft.12 | 확인된 차이 |
|---|---|---|---|
| S/W 세 표본 | 원본/연결 9/9, 구조 1/3 | 원본/연결 9/9, 구조 3/3 | 요약을 앞에 두고 업무 이미지 묶음을 독립 조회하도록 정의 |
| 지원 두 화면 | 원본/연결 9/9, 구조 1/3 | 원본/연결 9/9, 구조 3/3 | 해시/ROI 장부보다 사례 요약을 먼저 읽고 업무·건물/기단·명찰의 조회 경계를 구별 |

두 실행에서 사용자 선택한 구조가 반영된 것은 확인했다. 이번에 핵심 원본 대조 기준을 통과했다고 이전의 오독 재발 가능성까지 해소된 것은 아니다. 알려진 표본의 1회 시험으로 구조 개선이 일반적 식별 정확도까지 높였다고 말하지 않는다.

S/W 후보 요약은 총액과 두 지표가 별개임을 보존하지만 두 개별 금액의 소유자는 상세에서 찾아야 한다. 핵심 값의 귀속을 요약에서도 쉽게 읽게 하는 편집 개선 여지가 남는다. 이것을 원본 의미 오독과 같은 결함으로 보지는 않으며, 요약에 모든 세부 수치를 반복하도록 강제하지 않는다.

평가 중 두 평가자에게 11번은 상세·근거 보존을 확인하는 항목이며 10번의 요약 부재를 중복 감점하지 않는다고 명료화했다. 모든 세부 수치를 요약에 반복하는 할당량도 요구하지 않았다. 개발 중 정리한 기준이며 사전 고정된 독립 벤치마크로 제시하지 않는다.

## 현재 범위와 남은 작업

이번 묶음은 사용자 선택의 후보 반영, 두 사례 재편집, 내용/연결 보존 확인, 동일 과제 출력 비교다. 실제 사용판 교체·전편 확장·정본 등록은 진행하지 않는다. 남은 큰 범주는 검색·재사용 조회의 실용성, 중요한 식별의 안정성, 연속 모션/미분석 구간 수집, 조사한 전문가 판단·역설계 기법의 적용 추적이다.

## 다음 큰 작업 선택

1. **DB 검색·조회 시험(추천).** ‘양방향 요청/지원’, ‘업무 이미지 묶음’, ‘기관 주변 지원 항목’ 같은 사용 질문으로 적절한 사례·부품·현재 근거·차이를 찾아보는 시험을 한다. 디자인을 새로 만들지 않고 현재 수집물이 찾아 쓰기 좋은지 확인한다.
2. **중요 식별 검수의 안정성 확인.** 문구·도상·수치 귀속을 중심으로 아직 시험하지 않은 짧은 두 구간에서 확인/유보 절차를 검증한다. 기록 구조는 이번 결정대로 유지하며 전편 확장은 보류한다.
3. **짧은 반복 모션 구간 수집.** 가치창출 영상에서 범위를 정한 짧은 구간의 등장·중간·정착·퇴장과 내부/주변 변화를 관찰한다. 전체 흐름/독립 세부 동작·반복 번호를 실제 근거로 채운다. 전편 완료를 목표로 확대하지 않는다.
4. **조사 스킬 적용 대장 재점검.** 전문가 판단·역설계 조사에서 무엇을 어떤 지침으로 가져왔고 무엇이 미반영/보류인지 정리한다. 자료 출처·채택/제외 이유·필요 검증을 연결하고 추가 도입의 우선순위를 정한다.
