# 오독 대응과 실제 조회 검토

사용자 선택: 실제 결과 검토·오독 대응 보강. 전편 확장과 새 화면 제작은 보류한다. Anthropic skill creator의 기존판 보존→수정→같은 과제의 독립 실행→원본 대조→사용자 검토 절차를 계속 적용한다.

기존 draft.9/10의 6개 평가 결과는 보존한다. 새 기준을 소급 적용한 결과는 별도 재평가로 구분한다. 이번 비교 기준판은 현재 실제 사용 중인 draft.10이다. 새 후보는 draft.11이며, 특정 회사명·정답 문구·도상 정답을 스킬 지침에 넣지 않는다.

수정 가설: 형태를 먼저 보라는 지시만으로는 의미 이름을 확정하는 순간의 오독을 막지 못했다. 중요한 주장에 대해 원본 재대조 결과와 확정 수준을 남기고, 도상 정체가 불명확해도 형태/위치로 검색 가능하게 한다. 반복 ID는 존재 여부 외에 정의와 현재 근거로 왕복 가능한지 확인한다. 추가 픽셀 측정이나 재구축은 필요하지 않다.

시험: 기존과 같은 S/W 192·204·216초 세 표본 및 프로젝트 지원 134·172초 두 표본으로 draft.10/11을 각각 새 문맥에서 실행한다. 각 판본/과제 1회이며 표본 오차·일반 성능·creator 간 우열을 추정하지 않는다. 원본/입력은 동일하며 실행자에게 평가 정답·기존 결과를 제공하지 않는다. 평가자만 원본 대조표를 사용한다.

실행 조건: 원래 사용자 과제와 동일한 원본 PNG/입력 메타데이터, 해당 판본의 SKILL.md와 필요한 references만 제공했다. 공통으로 실제 이미지 열람, 필요시 분석용 크롭, 불명확한 정체의 문맥 추정 경계, 짧고 실용적인 기록, 실제 수행 범위 공개를 요청했다. 실행자는 스킬 evals/정답/기존 분석을 읽지 않도록 했다. 이 공통 안내도 결과에 영향을 줄 수 있으므로 스킬 본문만의 인과 효과로 보지 않는다. 실행 종료 메시지의 전체 도구 transcript·정확 모델 ID·토큰 수·비교 가능한 소요시간은 제공되지 않았다.

가용 동시 실행 수에 맞춰 먼저 세 실행을 시작하고 슬롯이 비자 네 번째 실행을 시작했다. 새 문맥 실행자 4개와 원본 대조 평가자 2개를 사용한다. 평가는 판본 경로가 보이는 AI 검토이며 블라인드나 사용자 내용 승인이 아니다. 기존 오독 두 건은 루트 검토에서도 원본 크롭으로 재확인했다. 나머지 검토는 실제 확보한 증거 범위를 결과에 명시한다.

표준 형식 검사, JSON 역사 판본 읽기/현행 판본 분리, 잘못된 해시 거절, 참조 문서 링크 존재, 호출 정책 보존은 통과했다. 이 검사는 Markdown의 의미 정확도나 전체 영상 발견률을 판단하지 않는다. 후보의 변경 파일은 6개이며 실행 지침의 실질 변경은 재대조 참조 1개와 본문/기록 계약의 연결 보강이다. 나머지는 판본·호환 경로·평가 기준 갱신이다.

평가 중 기준 7의 해석을 두 평가자에게 동일하게 명료화했다. 실제 재사용 정의 번호를 접두사/판본 없이 바꿔 조회 연결이 끊긴 경우와, 이미 정의된 대상 여러 개를 문장 안에서 줄여 쓴 가독성 문제는 구별한다. 후자만으로 실패시키지 않는다. 표기 엄격함 자체를 품질로 오인하지 않기 위한 조정이며 사전 고정된 독립 벤치마크로 주장하지 않는다. 기준 9도 사용자 수집 산출물과 제작의 분리를 평가하고 전역 무행위 자기보고는 미검증으로 남긴다.

결정: 후보 draft.11의 S/W 도상 오독이 남아 실제 스킬을 교체하지 않는다. 현재 active는 draft.10이다. 새 후보와 강화한 평가, 기존 출력 정정 근거를 별도로 보관하고 사용자 검토를 받는다. 지원 과제는 양쪽 9/9, S/W는 양쪽 8/9지만 실패 유형은 다르다. 새 지침의 효과를 판정하려면 알려진 문제 외의 근거에서의 안정성이 추가로 필요하다.
