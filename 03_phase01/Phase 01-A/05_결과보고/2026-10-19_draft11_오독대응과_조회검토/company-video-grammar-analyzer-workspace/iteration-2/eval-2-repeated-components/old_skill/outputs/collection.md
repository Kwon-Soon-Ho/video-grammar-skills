**C2-02 / 산정 설명·금액.** 왼쪽 윗부분 두 줄은 `기술개발센터가 실제 투입한 인력과 비용을 기준으로` / `23.7억 원을 가치창출성과로 산정했습니다`이다. 첫 줄은 짙은 갈색 굵은 글씨, 둘째 줄은 상대적으로 가는 글씨다(E2/R3). 아래 큰 입체 금색 `23.7억원`이 같은 금액을 강조하고 소수점이 보인다. 전면 금속광 숫자 뒤에 더 크고 옅은 외곽/반투명 숫자가 겹치고 양옆에 금색 잎 가지가 있다(E2/R8). 이중 외곽은 현재 보이는 외관이며 잔상·이동·확대 모션으로 확정하지 않는다. 좌측 외곽 숫자와 바닥 장식 일부는 화면 경계에 닿는다. 기록의 금액은 원본 화면의 주장이고 회계 검증 값이 아니다. 가족사별 금액, 금액 분할, 네 지원 영역별 금액 배분은 제시되지 않는다.

**C2-03 / 로고열.** 흰 둥근 타일 8개가 한 가로열에 놓이며 왼쪽은 원근상 기울고 아래로 내려온다. 각 로고는 CASE-01처럼 모두 동일한 가로 락업이 아니라 마크 위/글씨 아래 형태도 보인다. 뒤에 큰 투명 둥근 판, 아래 크림색/금색 곡선 받침과 작은 지지부가 있다. 좌측 타일 앞쪽에는 옅은 잎 장식이 겹친다. 로고 정체성 대응은 마크 형태·고유색·읽히는 글씨를 함께 비교했으며 같은 파일·같은 스케일·같은 입체 타일 자산임을 확인한 것은 아니다(E2/R4/R9/R10).

**C2-04 / 센터 건물.** 우측 전경의 낮은 원형 받침 위에 유리창·흰 건물·짙은 초록 정면을 가진 건물 표현이 있다. 정면은 흰 `TDC`와 `기술개발센터`, 내부에는 따뜻한 빛과 사람/사무실처럼 보이는 실루엣, 외부는 작은 나무·식재·출입구·옥상 단차를 담는다. 이는 영상 안 건물 표현이며 실제 장소·실제 센터 건축물의 정확한 복제인지 미확인이다. CASE-01 모니터 속 와이어프레임 건물과 동일 건물이라고 연결하지 않는다(E2/R5).

**C2-05 / 지원 라벨.** 건물 주변 네 흰 유광 둥근 직사각 라벨은 왼쪽 `BIM 설계`, 위 `BIM 지원`, 오른쪽 `디자인 지원`, 아래 전경 `해외사업 지원`이다. 상·좌 라벨 일부는 건물과 겹쳐 깊이가 표현되고, 아래 라벨은 받침 앞에 놓인다. 네 항목은 건물/센터에 동반한 지원 범주로 읽힌다는 기능 해석이 가능하나, 네 개가 완전한 조직 분류나 모든 지원업무임은 미확인이다. CASE-01의 큐브/모니터 도상은 이 라벨에 함께 보이지 않는다(E2/R5).

**C2-06 / 환경·연결선·층.** 크림색 실내 같은 배경에 높은 수직 벽·기둥·광택 바닥과 밝은 빈 벽면이 있고, 금색/백색 곡선 광선이 로고 받침 앞·건물 받침·하단 바닥을 가로지른다. 몇 점은 매우 밝다. 가는 선 다발은 공간을 시각적으로 연결하지만 데이터 전달 방향·이동·펄스는 미관측이다. 뒤쪽 환경→큰 투명 판/받침→로고열→건물/원형 단→주변 라벨·바닥 선의 겹침이 함께 보인다. 왼쪽 금액과 잎은 별도 큰 전경 묶음이다. 전체적으로 금색·백색의 입체/반투명 외관을 공유하지만 CASE-01의 평면형 두 판과 같은 레이아웃은 아니다. 실제 재질·렌더 엔진·레이어 구성·폰트명은 미상이다.

| O1-S | RC-C05 | C1-05 E1/R2 | BIM 설계/지원의 서로 다른 도상. 오른쪽 빈 공간의 시간상 기능 미확인 |
| O1-W | RC-C06 | C1-06 E1 오른쪽 하부 | 모니터 3대·소품 전체 묶음. E2 건물과 동일 자산 연결 없음 |
| O2-K | RC-C07 | C2-02 E2/R3/R8 | 23.7억원 집계. 숫자 진행·최종값 여부 미관측 |
| O2-H | RC-C08 | C2-04/05 E2/R5 | 건물+원형 단+네 지원 라벨. 지원 항목 완전성 미확인 |
| O2-S | RC-C09 | C2-05 E2/R5 | BIM 설계/지원/디자인/해외사업 지원의 네 위치. 일부는 건물 뒤로 겹침 |

위 대응은 관측된 정지 외관과 정보 구조에 대한 비교다. 시간·진입·퇴장·내부 변화까지 같은 패턴이라는 `confirmed` 판정을 하지 않는다.

조합 관계(시간 관계와 구별):

| from → to | 관계 | 근거·뜻 |
|---|---|---|
| O1-L → O1-B,O1-PL,O1-PR,O1-AR,O1-AL | contains / 관측 | 전체 CASE-01의 구성 요소 |
| O1-PL → O1-T | contains / 관측 | 가족사 판 내부 타일 그리드 |
| O1-PR → O1-S | contains / 관측 | 센터 판 내부 지원 도상과 이름 |
| O1-W → O1-PR 하부 | overlaps / 공간 관측 | 책상·모니터가 판의 하부 전경에 겹침. 시간 중첩의 의미 아님 |
| O1-AR → O1-PL/O1-PR | anchors_to / 관측 | 왼쪽에서 오른쪽을 향한 요청 관계 |
| O1-AL → O1-PR/O1-PL | anchors_to / 관측 | 오른쪽에서 왼쪽을 향한 지원 관계 |
| O1-AR ↔ O1-AL | accompanies / 관측 | 같은 E1에 함께 존재. 시작/종료 동시성은 미관측 |
| O2-L → O2-B,O2-T,O2-K,O2-H | contains / 관측 | CASE-02 전체 조합 |
| O2-H → O2-S | contains / 관측 | 건물 주변의 라벨 묶음 |
| O2-S → O2-H 건물 | anchors_to / 기능 해석 | 가까운 배치·동일 지원 문구에서 센터 지원 분야로 읽힘 |
| O2-T ↔ O2-K ↔ O2-H | accompanies / 관측 | 같은 E2의 로고 집합·성과·센터. 금액을 항목별 분배하는 관계는 없음 |

독립 세부의 배치는 위 관계를 통해 조회한다. E1의 CASE-01 시점이 E2보다 앞이라는 사실 외에 `precedes` 모션 관계를 만들지 않았다. 공간 겹침과 시간 겹침을 구분한다.

## 7. 전체 흐름·세부 모션의 수집 상태

**FLOW/모션 패턴은 이번 자료로 확정 등록하지 않았다.** 아래는 후속 근거를 연결하기 위한 미관측 조회 번호이며, 재사용 가능한 동작 정의가 아니다. 시작→진행→끝, 등장 순서·시차·동반·퇴장·정지 유지·곡선 모두 두 정지 화면으로 확인할 수 없다. 한 장에서 멈춰 보인다는 이유로 `정지 확인` 또는 `정착 확인`을 쓰지 않았다.

| 모션 쟁점 번호 | 범위와 현재 보이는 상태 | 확인하지 못한 속성 / 다음 확인 |
|---|---|---|
| RC-MQ01 / 전체 흐름 | E1 요청·지원 두 판 / E2 성과·로고·센터 | 두 화면 사이의 전환, 중간 장면, 전후 경계, 장표식 지속 여부. 원본 전후 및 사이 영상 근거 필요 |
| RC-MQ02 / CARD·TEXT 후보 | O1-PL/PR·O1-T, 제목·설명, O1-S | 판 외곽/내부 항목/글씨 각각의 등장·이동·교체·소실과 동시성. 한 번에 등장한다고 가정하지 않음 |
| RC-MQ03 / DETAIL 후보 | O1-AR/AL 및 주변 옅은 꼬리·빛 | 화살촉 형태 방향만 확인. 화살표 이동·채움·밝기·반복/속도는 미관측. 연속/다른 간격 표본 필요 |
| RC-MQ04 / CARD 후보 | O2-T 및 큰 투명 판·받침 | 로고열의 순차 등장/펼침·원근 이동 여부. E1 타일을 추적한 이동으로 쓰지 않음 |
| RC-MQ05 / TEXT·DETAIL 후보 | O2-K 금색 금액·뒤 외곽 숫자·잎 | 카운트업, 확대, 잔상, 반짝임인지 미관측. 수치와 장식의 각각의 전후 표본 필요 |
| RC-MQ06 / DETAIL·CARD 후보 | O2-H/O2-S, 건물 내부/창빛·바닥 광선 | 건물/라벨/광선 각자의 이동·밝기·순서·완성 시차 미관측. 밝은 점을 이동 입자로 단정하지 않음 |
| RC-MQ07 / 공통 맥락 | O1-B/O2-B 장표식과 두 배경 | 동일 장표식의 사이 지속·별도 재등장, 배경/카메라 이동 여부 미관측 |

이 목록은 놓치기 쉬운 대상 내부·주변 변화도 남긴 질문 목록이다. 다른 대상에서 본 변화량·곡선을 빌려 넣지 않았다. 음성·내레이션·음악·음성 싱크는 자료가 없어 미검수다.

미확인 상태를 구분한다. 미관측=표본 밖 시간·음성·동작, 판독 제한=일부 작은 부속 글씨, 정밀 원값 미상=폰트/효과/색/AE 속성, 해당 없음=이번 요청의 새 화면 제작·적용 시험. `정지 확인`에 해당하는 연속 표본은 없다. 제작 의도·법적 정체성·산정 근거의 외부 확인은 이번 수행 범위 밖이다.

이번 수집 묶음은 **두 화면의 정지 상태·전체 사례·부품/배치 후보 연결까지** 마쳤다. 다음에 모션 DB까지 넓히려면 원본 영상 또는 시간 대응이 검증된 전후·중간 표본이 필요하다. 남은 범위는 두 시점 사이 38초의 실제 전개와 각 화면의 등장/퇴장 경계, 나머지 원본 구간 전체, 오디오다. 표본 수로 영상 전체 분석 완료나 완료율을 만들지 않는다.
