# repeated-components — 원본 대조 재평가

평가 기준: `eval_metadata.json`의 source-grounded-2, 9개 주장. 평가자는 input.md와 원본 PNG 두 장 전체를 직접 읽고, 별도 scratch/repeat에 만든 원본 픽셀 ROI 5개로 로고/문구/금액/건물을 보강 대조했다. 각 실행의 collection.md와 execution.md를 모두 읽었다. 분석 스킬 본문·다른 평가자의 결과·기존 검토 문서는 읽지 않았다. 실행 스킬 판본은 산출물의 자기보고 표기다.

| 보존 실행 | 새 기준 통과 | 실패 | 이번 저장 파일 |
|---|---:|---|---|
| 이전 old_skill (draft.9 표기) | 9/9 | 없음 | `previous-results/eval-2-repeated-components/old_skill/grading-v2.json` |
| 이전 with_skill (draft.10 표기) | 8/9 | 재사용 정의/사용처 ID의 명시적 해소 | `previous-results/eval-2-repeated-components/with_skill/grading-v2.json` |
| iteration-2 old_skill (draft.10 표기) | 9/9 | 없음 | `old_skill/grading.json` |
| iteration-2 with_skill (draft.11 표기) | 9/9 | 없음 | `with_skill/grading.json` |

이전 결과의 원본 collection.md/execution.md는 바꾸지 않았고, 새 기준 회고 판정은 별도 grading-v2.json으로 남겼다. 기존 점수를 읽어 맞추거나 기존 등급을 덮어쓰지 않았다.

실제 원본 대조에서는 네 결과 모두 두 전체 사례, 파랑 좌→우 요청/초록 우→좌 지원, 8개 로고의 2×4와 원근 가로열, HALLA/피티씨 순서 교체, 23.7억원과 건물 주변 네 지원 라벨을 보존했다. 공식 회사 규칙·동일 원본 파일·수치의 회계적 사실성·실제 모션을 확정하지 않았다. 이 중요 주장들에서 명백한 추가 원본 오독은 발견하지 못했다. 통과는 작은 모든 글자나 픽셀 정합을 전수 확인했다는 뜻이 아니다.

이전 with_skill의 구체 문제는 4절 정의 `LOC-COMP-01@1` 등과 5~6절 사용처 `COMP-01`, `LAYOUT-01` 등의 불일치다. 접두어/판본을 생략해도 같은 ID라는 명시적 별칭표가 없다. 사람이 추측할 수 있어도 사례→정의 왕복 조건을 충족하지 못한다. 이전 old_skill의 같은 ID 사용은 이 문제와 다르다. OCC-A-H·P·G·R·S 등의 문장 축약은 읽기 불편으로만 기록했다.

이번 old_skill은 RC-L01/02와 RC-C01~09 정의, v1.0 occurrence 표, 포함/배치/공간 겹침 관계와 7개 모션 조사 묶음을 둔다. 이번 with_skill은 RC-LAYOUT 2종과 RC-COMP 6종의 전체 `@v1` ID를 정의/조합/조사 연결에 일관되게 쓰며, 4개 조사 항목으로 모션 미관측 범위를 묶었다. 전자는 모니터 업무 묶음과 기관·라벨을 더 분리하고, 후자는 전체 사례·레이아웃 안에 일부를 보존한다. 어느 쪽도 수집 누락으로 보지 않았다. 독립 번호 수나 문서 길이를 품질 점수로 사용하지 않았다.

이번 두 결과는 모두 분석용 ROI 좌표와 표시 축소 이력을 남긴다. 이는 이전 old_skill의 축소 전체 보기·ROI 실패 자기보고와 다른 산출물 특징이다. 단, execution.md는 전체 도구 transcript가 아니다. 스킬 읽기, 실제 ROI 관찰 순서, 외부 자료 미열람, 폴더 밖 쓰기/네트워크/PDF 부재 같은 전역 과정은 검증된 사실로 채택하지 않았다. 핵심 내용 판정은 평가자가 실제 원본과 산출물을 직접 대조한 결과다.

기준의 보완점은 (1) 전체 디자인이라는 포괄 항목에 원본의 상단/본문/주변/배경·위계/겹침 체크를 함께 두기, (2) ID를 추측 대신 실제 연결로 검증하기, (3) 실질적인 Markdown 수집과 전역 실행행위 검증을 분리하기다. 두 정지 표본으로 실제 반복 모션 분류·연속 정밀 검수·전체 영상 완전성을 시험할 수는 없다. 폰트/CI/실제 자산과 작은 부속문구는 별도 근거가 필요하다.

이는 원본을 본 AI 재평가이며 블라인드 실험·사람 검수·회사 승인·일반 benchmark가 아니다. 두 실행이 모두 9/9라는 사실이나 이전 판본의 단일 ID 오류로 자동 승자를 정하지 않는다. 토큰/시간/모델 telemetry가 제공되지 않아 비용·속도·모델 효과를 계산하지 않았다.
