2026-10-19. 기준: `source-grounded-2`, assertions 9개. 실제 원본 PNG 3장·input.md를 보고 원본 raster ROI를 따로 잘라 대조했다. 원본 192초 GAIA는 **시추조사의 디지털 혁신**, 중앙 허브 우하단은 **흰 4꼭지 별/반짝임이 있는 구름**이다. 도상 의미를 추측할 필요는 없다.

현재 두 결과는 점수가 같아도 실패 성격이 다르다. old_skill은 허브 도상을 더 정확히 기록했고 with_skill은 전체 ID/판본을 정의와 사용처에 유지했다. 둘 다 전체 구도·지표 귀속·산정 미반영·204초 중첩·정지 표본의 한계를 실질적으로 수집했다. current old의 D01은 실제 보이는 중첩의 조사 후보로 제한되어 있어 미관측 완성 모션 등록으로 처벌하지 않았다. 양식화 첫 로고의 공식명은 이 검수에서 새로 확정하지 않았다.

ID 항목은 실제 재사용 정의의 ID/판본 변경과 일반 문장 축약을 구별했다. prior old의 LAYOUT-LOCAL-01/02/03은 이미 정의한 ID 세 개를 병렬 압축한 표기라 통과다. prior with의 NS-LAYOUT-001@v1→NS-LAYOUT-001, current old의 L01-v1→L01은 조합에서 사용하는 재사용 키에 판본이 빠지고 그 키의 정의/별칭 선언이 없다. 예컨대 `L01 contains C01×6`의 L01/C01은 정의 표의 정확한 키 L01-v1/C01-v1과 일치하지 않는다. 사람이 문맥으로 추정할 수는 있지만 **전체 ID/판본 일치 또는 명시적 별칭** 계약에는 실패한다. 이 참조 계약 실패와 의미를 바꾸는 GAIA·도상 오독을 같은 심각도로 해석하면 안 된다.

이전 보존 결과도 새 기준으로 다시 채점했으므로 기존 `grading.json`은 변경하지 않고 각 결과 폴더에 `grading-v2.json`을 추가했다. 새 iteration-2 결과에는 각각 run 폴더의 `grading.json`을 저장했다. 이 표는 기존 점수와의 자동 향상률 또는 일반 우승자를 뜻하지 않는다.

기준 자체의 한계: 알려진 GAIA·구름 오독을 겨냥한 사례별 사후 회귀 점검이며 보조 도상 전체·다른 영상·연속 모션·실제 재사용의 품질을 대표하지 않는다. ID의 형식 일치는 자동 검사와 연결 추적 시험으로 분리하면 더 명확하다. 각 결과가 자체 재대조를 했다고 적었어도 소스 오독이 남아 있으므로 ROI 수·분량·자기 검수 문구는 내용 정확성의 증거가 될 수 없다.

execution.md는 완전한 transcript가 아닌 자기 보고다. 해시 계산·ROI 열람·폴더 밖 무행위·네트워크 미사용을 독립 검증했다고 쓰지 않았다. 토큰·시간·모델 telemetry를 추정하거나 0으로 채우지 않았다. 이 검수는 판본을 알고 수행한 AI 재검수이며 완전 맹검·사람 승인·회사 승인·일반 벤치마크가 아니다. 미확정 집계 범위, `이들 S/W` 지시 범위, 미세 UI·음성·표본 사이 움직임은 남는다.
