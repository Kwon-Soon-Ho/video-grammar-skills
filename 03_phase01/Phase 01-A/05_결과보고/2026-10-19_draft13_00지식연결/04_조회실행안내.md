# 실제로 문법과 사용처를 조회하기

현재 읽을 기록: [134초](pilot/case-134.md), [172초](pilot/case-172.md), [기존 모션6창](pilot/motion-windows.md). 사례 요약→관점/정의·사용처→실제 검토→보존 원문/근거 순서다. 기본 원본은 가치창출성과 영상_260923_v3.mp4 한 편이다.

PowerShell 예시다. 다음 경로는 D: 보관본을 기준으로 한다. Python은 프로젝트에 이미 있는 번들 런타임을 사용한다.

```powershell
$resultRoot = 'D:/00작업/2026-10-02_AI 기반 영상 기획·제작 스킬 체계 개발 및 검증/Phase 01-A/05_결과보고/2026-10-19_draft13_00지식연결'
$pythonPath = 'C:/Users/User/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
$linkTool = "$resultRoot/candidate/company-video-grammar-analyzer/scripts/knowledge_links.py"
& $pythonPath -B -X utf8 $linkTool query --catalog "$resultRoot/knowledge/catalog.json" --index "$resultRoot/pilot/usage-index.json" --query '업무 이미지 묶음'
& $pythonPath -B -X utf8 $linkTool query --catalog "$resultRoot/knowledge/catalog.json" --index "$resultRoot/pilot/usage-index.json" --query '건물/기단'
& $pythonPath -B -X utf8 $linkTool query --catalog "$resultRoot/knowledge/catalog.json" --index "$resultRoot/pilot/usage-index.json" --query '크림 공간의 입체 정보 무대'
& $pythonPath -B -X utf8 $linkTool query --catalog "$resultRoot/knowledge/catalog.json" --index "$resultRoot/pilot/usage-index.json" --id 'MR-08'
& $pythonPath -B -X utf8 $linkTool query --catalog "$resultRoot/knowledge/catalog.json" --index "$resultRoot/pilot/usage-index.json" --id 'FUNCTION-REVEAL' --motion-only
```

반환에서 `unit`은 정의, `use`는 현재 내용/시각·차이/조건, `evidence`는 실제 근거, `reviews`는 범위별 판정이다. `knowledge_links`의 `classified_as`는 분류 해석이고 `review_relevant`는 검토 관련성이다. 관련 지식이 있다는 이유로 원칙 효과/회사 승인이 생기지 않는다.

명시한 이름·별칭/텍스트 또는 정확ID를 찾는 조회다. 문맥에 언급된 상위/하위 단위가 추가로 일치할 수 있으므로 반환 ID/제목/정의의 실제 역할을 읽는다. 자연어 의미 검색·적합성 순위가 아니다. 파일/카탈로그가 바뀌면 기존 pin을 무시하고 계속하지 않고, 변경 이유를 확인한 뒤 새 판본/색인을 만든다.

입력과 기존 관측은 `pilot/preserved/`에 보존했다. 새 MD/부속 색인은 별도이며 자동 동기화나 정본 등록이 없다. 보관 전 실제6질의의 상세 결과는 [actual-queries.json](pilot/actual-queries.json)에 있다. 기존 원문 안의 C: 절대경로는 과거 이력으로 남겼고 현재 사례/근거의 상대경로는 별도로 연결했다.
