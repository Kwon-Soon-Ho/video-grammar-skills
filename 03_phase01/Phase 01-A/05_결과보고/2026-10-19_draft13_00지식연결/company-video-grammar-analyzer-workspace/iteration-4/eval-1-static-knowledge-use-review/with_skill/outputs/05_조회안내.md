# 실제 조회 명령과 결과

실행: PowerShell에서 `& ./run_queries.ps1`. 정확 실행인수/종료코드는 [commands.json](commands.json), 검사결과는 [check-result](check-result.json), 색인생성은 [index-result](index-result.json). 조회는 정확 개념ID 또는 명시 부분문자열이며 의미검색/추천/회사승인이 아니다.

| 검색 | 실제반환 사용처수 | 저장결과 |
|---|---:|---|
| work | 1 | [work.json](queries/work.json) |
| building | 2 | [building.json](queries/building.json) |
| roleplate | 2 | [roleplate.json](queries/roleplate.json) |
| space | 3 | [space.json](queries/space.json) |
| network | 1 | [network.json](queries/network.json) |
| tiles | 2 | [tiles.json](queries/tiles.json) |
| group | 4 | [group.json](queries/group.json) |
| question | 2 | [question.json](queries/question.json) |
| observed-motion | 0 | [observed-motion.json](queries/observed-motion.json) |
| investigations | 4 | [investigations.json](queries/investigations.json) |

왕복실행: 업무이미지→007@v1→U-C9→134초/E1/e1_work→원문정의·현재차이·미검증. 건물/기단→008@v1→U-C10→172초/E2/e2_building→005명찰과anchors_to/overlaps. 역할판→LAYOUT001@v1→U-L1→134초전체→SPLIT/NETWORK와Q-INFO-02검토. [타일조회](queries/tiles.json)는같은정의002@v1의E1/E2두사용처와2×4/원근열·HALLA/피티씨차이를반환한다.

LAYOUT-SPACE-CALLOUT→002무대/008건물/005명찰→각사용처/근거로역조회, SCREEN-GROUP→역할판/무대/업무묶음/건물의다른사용처로이동, Q-SCREEN-01→실제판정행/범위를조회했다. events/event_links는모션미관측이며 observed-motion은0건, include-unobserved조사는4건이다. 이0은실제모션없음을뜻하지않는다.

해시가바뀌면조회/검사가실패하도록pin한다. MD/sidecar를편집하면연결이유를검토하고 색인을다시생성해야한다. R4통합v0.2자동이관/등록·원본상세자동동기화는없다. prior의과거scratch/original링크는이력으로보존하고 활성경로를02/03문서에서별도제시했다.
