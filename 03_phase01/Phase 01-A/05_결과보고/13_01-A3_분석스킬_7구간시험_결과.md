# 01-A3 분석 스킬 작성·7구간 시험 결과

사용자 지시에 따라 `company-video-grammar-analyzer` 초안을 만들고 기존 6개 항목과 EG-BIM UI 선택 변경을 시험했습니다. 최초 적용본에서 내용/기록 문제 2건을 찾아 절차를 보완하고 해당 두 구간을 다시 분석했습니다. **보완 후 선택한 7개 결과가 이번 기준을 충족합니다.** 모든 영상에서 누락이 없다는 판정은 아닙니다.

현재 스킬은 **0.1.0-draft.2**, 프로젝트 내 초안입니다. 전역 스킬 설치나 A4/A5 확대 검증은 수행하지 않았습니다.

## 실제로 발견하고 고친 문제

1. **장헌 카드별 근거 혼용**: 최초본은 세 카드의 동작을 모두 찾았지만 수주·이익 설명에도 매출 숫자를 반복했습니다. 같은 대상·속성의 표본인지 역대조하도록 보완하고 T04를 새 문맥에서 재시험했습니다.
2. **겹친 창의 이동 오인**: 최초본은 EG-BIM 후반 두 창이 함께 축소·우하 이동한다고 썼습니다. 원본에서 뒤 목록창 상단/모서리는 유지되고 앞 CAD창이 움직이며 뒤를 더 드러냈습니다. 가림 해소와 외곽 이동을 따로 확인하도록 보완하고 T06을 재시험했습니다.
3. **기록 검사 허점**: 동작 구간과 전혀 다른 시각의 근거 연결, 자기 자신을 부모로 참조하는 순환 기록이 통과했습니다. 두 오류를 차단하도록 수정했습니다. 보조 도구 반례 시험은 최초10/12, 수정 후12/12였습니다. 이는 인식 정확도 점수가 아닙니다.

두 내용 문제는 구조 검사에서 통과했으나 원본 내용 대조에서 발견했습니다. 형식 통과와 내용 판정을 분리해야 한다는 제한을 스킬과 보고에 명시했습니다. 최초 결과를 덮어쓰거나 답안을 고쳐 통과시킨 것이 아니라, 최초본을 해시 고정한 뒤 수정 스킬로 새 분석 결과를 만들었습니다.

## UI 선택 변경에서 확인한 것

창 외곽과 UI 배열이 거의 유지되는 동안 표 선택은 첫째→둘째→셋째→넷째 행으로 내려가고, 썸네일 선택 테두리는 같은 순서로 오른쪽으로 바뀝니다. 전환 중 이전·다음 강조가 함께 보입니다. 연속적인 표식 슬라이드나 실제 마우스 클릭으로 단정하지 않았습니다. 상태 혼합의 정확한 이징은 미확정입니다.

## 스킬에 반영한 지식과 절차

Phase 00에는 이미 가속/감속/ease-in/ease-out 용어와 MP-02의 관측 변화율·정착·추적 오차 원칙이 있었습니다. 부족했던 것은 지식 목록이 아니라 실제 관찰·근거 점검으로 이어지는 절차였습니다. 이번 스킬은 전체 화면, 보조 선/빛, 내부 UI를 나누어 살피고 시간순 확인 후 정착 화면을 역추적합니다. 위치·크기·가시성·광량의 변화율을 각각 기록하며, 정확한 AE 핸들값을 요구하거나 추정값을 확정하지 않습니다.

원본 추출 로그를 확인하는 보조 도구와 분석 기록 연결 검사기를 포함했습니다. 제공된 제한 추출기를 이용하는 경로이며 범용 영상 디코더를 새로 구현한 스킬은 아닙니다. 출력 JSON은 A3 분석 초안으로, R4 정본 DB 변환/등록 완료를 뜻하지 않습니다. Phase 00 정본과 기존 관리 스킬은 변경하지 않았습니다.

## 시험 조건과 한계

- 같은 중립 과제와 원본 기본 표본으로 스킬 사용/미사용을 각각 새 문맥에서 분석했습니다. 처음14건, 보완 후2건으로 총16개 사례 실행입니다. 동시 실행 슬롯 한도 때문에 묶음을 대기열로 진행했습니다.
- 분석 문맥에는 이전 답안·사용자 정정·채점표를 주지 않았습니다. 파일 접근 제한은 작업 절차이며 OS 격리를 뜻하지 않습니다. 열람 목록은 분석자 기록입니다.
- 내용 채점은 작성자의 원본 대조입니다. 별도 사람 채점/미노출 원본 시험/반복 통계는 없습니다. 알려진 두 원본의 단회 회귀시험을 일반 정확도로 환산하지 않았습니다.
- 수정본으로 다시 실행한 구간은 T04·T06입니다. 나머지5건은 최초 스킬 결과를 유지하고 수정 검사기로 구조를 다시 확인했습니다. 최종 뷰어는 이 결과를 모은 표시용 자료이며 새7건 전체 재실행이라고 부르지 않습니다.
- 선택 프레임/원본 ROI 검수이며 전체 영상 연속 재생, 음성, 원고 대응은 이번 시험에 포함되지 않았습니다. SAR와 정밀 색 범위, 정확한 보간 함수는 미확정입니다.
- 스킬 없이도 여러 사건과 UI 선택 변경을 찾았습니다. 스킬 미사용본의 T05 혼합 감속·T06 새 창 우향 진입/속성별 가감속 누락은 적용본에서 보완됐으나, 적용본에도 별도의 오류가 생겼습니다. 따라서 스킬이 무조건 더 정확하다고 결론 내리지 않습니다.

이번 A3에서 새로 추출한 PNG는 170장, 실행 안 고유 원본 시점은 122개입니다. 기존 기본 표본174장은 재사용했으며 크롭/개요 시트는 별도입니다. 입력 원본·프레임·지식 참조 해시와 최초 출력 보존을 확인했습니다. 토큰/개별 실행시간은 도구가 제공하지 않아 만들지 않았습니다.
