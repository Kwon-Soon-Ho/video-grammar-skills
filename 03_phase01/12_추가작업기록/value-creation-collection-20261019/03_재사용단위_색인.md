# 원본 수집의 재사용 단위 색인

이 번호는 이번 영상의 로컬 수집 후보이다. 정본 패턴 번호나 승인된 회사 규칙으로 등록하지 않았다. 기존 6개 시범 패턴을 대량으로 교체한 것도 아니다.

## 1. 사례와 관계를 먼저 찾기

| 수집 단위 | 찾을 내용 | 구성/모션 연결 |
|---|---|---|
| VC-CASE-A / A-01 | 수주·매출 개괄, 정보판+도상+목록 | 큰 판 안의 역할 구분과 지표 비교. 원본 78~84초 |
| VC-CASE-A / A-02 | 수주 구성→비용→실제 매출 구역 누적 | 도넛 2개, 비용 판, 주황 매출 강조. A-M1~3 |
| VC-CASE-B / B-02 | 두 조직 집단의 요청↔지원 | 반대 방향 화살표와 각 정보판. B-M1의 퇴장 맥락 |
| VC-CASE-B / B-03 | 단위가 다른 총량 2개 요약 | 건수 보조+금액 주강조, 받침·라벨. B-M1의 진입 결과 |
| VC-CASE-B / B-04~05 | 여러 업무 영상→핵심 구성 차트 | 지도/영상 분할과 주항목 1+보조 3. B-M2~3 |
| VC-CASE-B / B-06 | 센터 유무의 조건 대비 | 주장 2줄+회색조/컬러 사진 2개. 상세 모션 미보강 |
| VC-CASE-B / B-07 | 가족사와 지원 허브 요약 | 가족사 로고 가로열, 센터 도상, 업무 라벨·빛 연결. 상세 모션 미보강 |

전체 흐름은 각 사례에 보존한다. 위 일곱 구성을 ‘성과 설명’ 하나로 합쳐 버리면 요청/응답·조건 비교·구성비 강조의 선택 근거가 사라진다. 반대로 프레임 경계·도상의 작은 부품마다 새 사례 번호를 만들지 않는다.

## 2. 부품 묶음 - 실제 반복과 변형

| 후보 ID | 구조·역할 | 실제 근거/현재 차이 | 가변·제외 조건 |
|---|---|---|---|
| VC-COMP-01 | 장 번호/TDC 육각 배지 + 짧은 장 제목 띠 | 계약 84/96/112초: 녹색·1 / 지원 134/150/172초: 구리색·2. 서로 다른 본문 레이아웃에서도 반복 | 번호·색·문구는 사례 변형. 본문 대제목까지 같은 부품으로 묶지 않음. 공식 회사 표준 배지인지 미확인 |
| VC-COMP-02 | 밝은 둥근 정보면 + 경계/명암 + 제목/내용 | 계약의 막대 정보판/수주·비용·매출 판, 지원의 조직 정보판/통계 정보판 | 공통 가족 후보이지 동일 컴포넌트 확정 아님. 헤더·접힘 모티프·도시 실루엣·재질과 내부 슬롯의 차이를 하위 변형으로 남김 |
| VC-COMP-03 | 큰 지표 + 단위/설명 라벨 + 받침형 표현 | 지원 140초의 건수/금액, 172초의 큰 금액. 계약 112초의 금액은 정보판 내부로 배치가 다름 | 같은 ‘큰 숫자’라도 받침형 독립 주인공과 판 내부 강조는 구별. 값과 단위 의미를 유지 |
| VC-COMP-04 | 핵심 항목 1개 + 보조 항목 3개 + 비중 강조 | 지원 150초 BIM 설계/나머지 세 유형과 약82% 도넛 | 핵심이 실제로 우세하고 그 비중을 말할 때 후보. 단순히 항목이 4개라는 이유로 사용하지 않음 |
| VC-COMP-05 | 가족사 로고 묶음 | 지원 134/136초의 2열×4행 타일 → 172초의 가로열 | 동일 조직 묶음의 배치 변형 후보. 공식 로고 파일·버전·순서는 제작 전에 따로 확인. 새 화면비에서 원본 로고 이미지를 임의로 찌그러뜨리지 않음 |

현재는 화면에서 조합과 변형을 수집한 것이다. 원본 프로젝트의 편집 가능한 실제 컴포넌트 파일을 추출한 것은 아니다. 항목의 원본 프레임은 각 사례 문서에 연결했다.

## 3. 독립 모션 묶음 - 전체 흐름과 연결

| 참조 | 동작 구조 | 관측 관계 | 적용 후보 / 맞지 않는 입력 |
|---|---|---|---|
| A-M1 | 기존 구역 재배치 + 새 정보판과 내부 내용 누적 | 비용 판 외형/도상/캡슐/숫자가 단계적으로 채워짐 | 설명을 누적할 때 / 이미 공간이 꽉 찬 경우 같은 누적을 강제하지 않음 |
| A-M2 | 기존 두 지표 유지 + 새 정보판 진입·라벨 보강 | 오른쪽 매출 판의 위치/제목/설명이 순서대로 드러남 | 비교 맥락을 남길 때 / 기존 지표가 새 기간으로 바뀌면 같은 값 유지 금지 |
| A-M3 | 숫자 증가 + 도상 단계 조립 | 최종 금액 이후에도 상승 도상 완성 과정이 이어짐 | 성과 금액 강조 / 계약번호·날짜는 카운트업에서 제외 |
| B-M1 | 기존 관계도 분산 퇴장 + 새 총량 장면 중첩 | 옛 판이 남은 상태에서 새 수치가 보임 | 맥락에서 요약으로 넘길 때 / 정확한 양자 비교 정보를 끝까지 읽어야 한다면 퇴장 시점 재검토 |
| B-M2 | 대각 경계의 여러 영상층 전개 | 총액 화면을 업무 영상 묶음으로 바꾸며 분할 구획을 구성 | 여러 업무 사례 소개 / 서로 비교하면 안 되는 시간·범위의 자료는 구별 표시 필요 |
| B-M3 | 영상층 재구성 + 통계판·비중·보조 카드 누적 | 큰 비중 82%가 보조 카드 전체와 동시에 완성되는 것은 아님 | 핵심 비중과 나머지 구성을 설명 / 우세 항목이 없으면 같은 주항목 강조 부적합 |

이 묶음은 **관측한 단계와 동반 관계의 후보**이다. 정확한 곡선·이동량·마스크·전체 내부 변화가 확정된 실행 템플릿은 아니다. A-M1과 A-M2는 기존 VC-MOTION-02의 서로 다른 원본 변형으로 검토할 수 있지만, 이번 표본만으로 둘의 동일 패턴 분류를 확정하지 않는다.

기존 시범 `VC-MOTION-01`의 ‘수치와 차트의 의미 상태 일치’는 의미/끝값의 관계로만 사용한다. 모든 관련 요소가 동시에 출발하고 끝나는 동작이라는 뜻으로 확대하지 않는다.

## 4. 기존 시범 ID와 혼합하지 않을 것

| 이전 ID/내용 | 수집에서의 취급 |
|---|---|
| VC-LAY-01 매출 중심+보조 지표 | 원본의 역할을 바탕으로 만든 별도 설계 제안. 원본 112초의 실제 배치와 구별 |
| VC-LAY-02 총액 고정+분류 교체 | 새 세로 시안의 제안. 원본에서 같은 장면으로 관측한 패턴이 아님 |
| VC-FLOW-01 맥락→주장→근거→한계 | 여러 장면을 요약한 해석 후보. 각 사례의 실제 상태·순서·겹침 기록을 대체하지 않음 |
| VC-MOTION-03 가족사별→유형별 교체 | 새 시안의 동작 제안. 관측 수집의 실제 사례 검색 결과로 반환하지 않음 |

## 5. 수동 조회 예시 - 새 화면 없이 기록을 확인

이 표는 사람이 만든 색인에서 해당 사례를 찾는 예시다. 검색 엔진 성능 평가가 아니다.

| 질문 | 반환할 기록/근거 | 함께 알려줄 조건 |
|---|---|---|
| 큰 비중 하나를 강조하고 나머지 업무도 보여준 화면은? | B-05 / VC-COMP-04 / B-M3 / 148~150초 | 약82% 강조와 보조 3개. 동작 원값·공식 브랜드 규칙은 미확인 |
| 양쪽 조직의 요청과 지원을 설명한 사례는? | B-02 / 134~136초 | 화살표 방향과 두 정보판의 역할. 서로 더하는 금액 흐름이 아님 |
| 같은 로고 집합의 배치를 바꾼 원본 사례는? | VC-COMP-05 / 134~136초와 172초 | 그리드→가로열. 자산 원본 파일/버전까지 동일하다고 확정하지 않음 |
| 총액을 고정하고 가족사별→업무별로 바뀐 원본은? | 현재 수집에서 확인한 사례 없음 | 이전 새 시안의 제안은 별도 참고로만 구분. 원본 관측으로 혼입하지 않음 |

수집 기록의 쓸모는 이처럼 **근거·관계·차이·적용 조건을 함께 찾을 수 있는지**로 확인한다. 새 화면을 반드시 만들어야만 확인할 수 있는 것은 아니다.
