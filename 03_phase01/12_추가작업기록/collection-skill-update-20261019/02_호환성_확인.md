# 호환성 확인

- draft.9 실제 기록은 원본 해시를 유지하며 보존했다. 새 검사에서는 현행 기록으로 통과시키지 않고 역사 자료로만 읽는다.
- 기존 기록을 복사하고 판본만 바꾼 개발 fixture로 draft.10/0.4 구조 수용과 MD renderer 동작을 확인했다. 이는 새 분석이나 내용 재검증이 아니다.
- 잘못된 원본 해시는 여전히 거절한다.
- 새 Markdown 계약은 기존 JSON 검사기의 검증 대상이 아니다.
- 스킬 내 Markdown 참조 링크의 대상이 존재한다. UI 호출 정책은 그대로다.
- Anthropic quick_validate 최초 실행은 PyYAML 미설치로 중단됐다. 의존성 해결/형식 검사 결과는 후속 기록에 남긴다.

- PyYAML 설치는 기본 경로에서 DNS 실패, 정상 승인 경로에서는 검토 모델 용량 초과로 실행 전 차단됐다. 표준 quick_validate는 미완료다. 필수 이름·설명 길이·현재 plain-scalar frontmatter 모양과 호출 정책 보존은 제한된 직접 검사로 확인했다. 이 검사는 전체 YAML 파서와 같지 않다.

## 후속 해결

D: 반영 승인 성공 후 정상 승인 경로로 PyYAML 6.0.3을 작업 폴더에만 설치했다. Anthropic quick_validate.py를 로컬 후보와 D: 활성 스킬에 각각 실제 실행하여 둘 다 “Skill is valid!”를 확인했다. 이전 설치/검사 실패 이력은 위에 보존한다. 형식 통과가 내용 정확도·품질 승인을 뜻하지 않는다는 범위는 그대로다.
